# 시민 참여와 공공의 일

사람이 투표, 기부, 신고, 봉사 같은 공공의 일에 참여하거나 참여하지 않는 일이다.

[문서 묶음](../README.md#문서-묶음), [전체 문서 목록](../INDEX.md)

- [공용 우산 돌려주지 않기](../docs/not-returning-shared-umbrellas.md) 역이나 관공서에서 무료로 빌린 공용 우산을 빌린 사람이 제자리에 돌려놓지 않는다.
- [과다복용 현장에서 신고 꺼리기](../docs/not-calling-for-help-at-overdose.md) 약물 과다복용을 목격한 사람이 경찰이 오거나 체포될까 두려워 구급 신고를 하지 않거나 미룬다.
- [기부 단체 불신](../docs/distrust-of-charities.md) 기부하지 않는 사람이 모금 단체를 믿지 못해 기부하지 않는다.
- [기부하지 않기](../docs/not-donating.md) 기부를 요청받거나 기부를 떠올린 사람이 형편이 안 된다거나 단체를 믿을 수 없다는 이유로 돈을 내지 않거나 더 내지 않는다.
- [기후 행동 하지 않기](../docs/climate-inaction.md) 기후변화를 아는 사람이 기후를 위해 생활을 바꾸거나 다른 사람과 함께 행동하지 않는다.
- [길고양이에게 밥 주기](../docs/feeding-stray-cats.md) 동네의 주인 없는 고양이에게 사람이 사료나 물을 꾸준히 챙겨 준다.
- [길에 쓰레기 버리기](../docs/littering.md) 밖에서 쓰레기가 생긴 사람이 쓰레기통이 아닌 길이나 주변에 두고 간다.
  - [담배꽁초 길에 버리기](../docs/tossing-cigarette-butts.md)
- [노력이 소용없다는 생각](../docs/feeling-ones-effort-makes-no-difference.md) 사람이 자기 한 사람의 행동이 결과에 차이를 만들지 못한다고 생각한다.
  - [신고해도 소용없다는 믿음](../docs/believing-reporting-is-futile.md)
- [다원적 무지](../docs/pluralistic-ignorance.md) 집단 안의 사람이 속으로는 이해하지 못하거나 동의하지 않으면서 다른 사람들은 이해하거나 동의한다고 믿고 겉으로 따른다.
  - [또래 음주량 과대 추정](../docs/overestimating-peer-drinking.md)
- [대중교통 무임승차](../docs/fare-evasion.md) 대중교통 승객이 단속에 걸리지 않으리라 여기거나 돈을 아끼려고 요금을 내지 않거나 덜 내고 탄다.
- [모금 요청 방식에 대한 거부감](../docs/disliking-fundraising-solicitation.md) 기부를 요청받는 사람이 거리나 집 앞에서 기부를 권하는 것 같은 모금 방식을 싫어한다.
- [물티슈 변기에 버리기](../docs/flushing-wet-wipes.md) 물티슈를 쓴 사람이 그것을 쓰레기통이 아니라 변기에 버려 물로 내린다.
- [반려견 배설물 치우지 않기](../docs/not-picking-up-dog-waste.md) 개를 산책시키는 사람이 개의 배설물을 치우지 않거나 봉지에 담아 나무나 덤불에 두고 간다.
- [배심원 소환 회피](../docs/avoiding-jury-duty.md) 배심원으로 소환된 사람이 소환에 응하지 않거나 핑계를 대고 빠진다.
- [범죄 피해 신고하지 않기](../docs/not-reporting-crime.md) 범죄 피해를 당한 사람이 경찰에 알리지 않고 넘어간다.
  - [보복이 두려워 신고하지 않기](../docs/not-reporting-for-fear-of-reprisal.md)
  - [사기 피해를 부끄러워 숨기기](../docs/scam-victim-silence.md)
- [분리배출 하지 않기](../docs/not-sorting-recyclables.md) 가정에서 재활용할 수 있는 쓰레기를 사람이 분리하지 않고 일반 쓰레기와 함께 버린다.
- [비둘기에게 먹이 주기](../docs/feeding-pigeons.md) 공원이나 광장에서 사람이 비둘기에게 빵이나 곡식을 준다.
- [쇼핑카트 반납하지 않기](../docs/not-returning-shopping-carts.md) 마트에서 쇼핑카트를 다 쓴 사람이 카트를 반납 장소에 돌려놓지 않고 주차장에 두거나 집까지 끌고 가 둔다.
- [자원봉사 하지 않기](../docs/not-volunteering.md) 자원봉사를 떠올린 사람이 시간이 없다는 이유로 봉사하지 않는다.
- [장바구니와 텀블러 챙기지 않기](../docs/forgetting-reusable-bags.md) 장바구니나 텀블러를 가진 사람이 집을 나설 때 그것을 챙기지 않아 일회용 봉투나 컵을 쓴다.
- [재활용되기를 바라며 재활용함에 넣기](../docs/wishcycling.md) 재활용될지 확실하지 않은 물건을 사람이 재활용되기를 바라며 재활용함에 넣는다.
- [정치 무력감](../docs/political-inefficacy.md) 유권자가 정부와 정치인이 자기 같은 사람의 생각에 관심이 없고 자기 표가 결정을 바꾸지 못한다고 믿는다.
- [주운 지갑 돌려주기](../docs/returning-lost-wallets.md) 돈이 든 남의 지갑이나 분실물을 주운 사람이 그것을 경찰이나 주인에게 돌려준다.
- [통계 조사 응답 거부](../docs/refusing-statistical-surveys.md) 사람이 정부 통계 조사나 인구조사의 조사원이나 설문을 받고 사생활 걱정, 바쁨, 불신 따위를 이유로 응답하지 않는다.
- [투표 불참](../docs/not-voting.md) 투표권이 있는 사람이 선거일에 투표하지 않는다.
- [투표했다고 거짓으로 답하기](../docs/claiming-to-have-voted.md) 투표하지 않은 사람이 설문이나 면접에서 투표했다고 답한다.
