# 시간과 하루 습관

사람이 약속 시간, 잠, 끼니, 결심을 두고 되풀이하는 일이다.

문서 12개. [문서 묶음](../README.md#문서-묶음), [전체 문서 목록](../INDEX.md)

- [늦는 사람을 기다리며 서성이기](../docs/waiting-for-someone-late.md) 올 시간이 지나도 오지 않는 사람을 기다리는 사람이 불안해하며 서성이거나 거듭 연락한다.
- [다이어트 중 폭식](../docs/diet-breaking-binge.md) 먹는 것을 참던 사람이 한 번 다이어트가 깨지면 그동안 참던 음식을 한꺼번에 많이 먹는다.
- [상습 지각](../docs/chronic-lateness.md) 약속이나 정해진 시간에 번번이 늦는 사람이 스스로는 제시간에 올 수 있다고 여긴다.
- [시간 부족으로 운동하지 않기](../docs/no-time-to-exercise.md) 일이나 학업에 쫓기는 사람이 운동할 시간이 없다고 여기고 규칙적인 운동을 하지 않는다.
- [시간에 쫓기는 느낌](../docs/feeling-rushed.md) 일과 집안일을 하는 사람이 할 일에 비해 시간이 모자란다고 느끼며 늘 쫓긴다.
- [아침 식사 거르기](../docs/skipping-breakfast.md) 시간이 없거나 입맛이 없는 사람이 아침을 먹지 않고 하루를 시작한다.
- [알람 끄고 다시 잠들기](../docs/snoozing-the-alarm.md) 아침에 알람을 들은 사람이 알람을 끄거나 미루고 다시 잠든다.
- [작심삼일](../docs/abandoning-resolutions.md) 새해 목표나 결심을 세운 사람이 며칠이나 몇 주 만에 그 일을 그만둔다.
- [저녁형 성향](../docs/evening-chronotype.md) 저녁형 성향의 사람이 밤늦게 정신이 맑아지고 아침 일찍 일어나는 일정을 힘들어하며 이 성향이 여러 해 이어진다.
- [주말 몰아 자기](../docs/weekend-catch-up-sleep.md) 평일에 잠을 덜 잔 사람이 주말이나 연휴에 평소보다 오래 자서 모자란 잠을 메운다.
- [지나치게 일찍 도착하기](../docs/arriving-too-early.md) 늦을까 마음 쓰는 사람이 정해진 시간보다 한참 앞서 나가거나 깨어 기다린다.
- [추운 아침 이불 속에 머물기](../docs/lingering-in-bed-on-cold-mornings.md) 추운 아침에 잠이 깬 사람이 따뜻한 이불 속에 더 있고 싶어 일어나기를 미룬다.
