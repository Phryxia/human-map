# 친구 만남 뒤로 미루기

별칭: 없음

일과 앞날 준비에 바쁜 어른이 언제든 만날 수 있다고 여기는 친구와의 만남을 뒤로 미뤄 친구와 보내는 시간이 줄어든다.

묶음: [가까운 사이의 감정과 말](../groups/close-relationships.md)

# 서술

2018년 기사[^1]가 전한 영국 조사에서 응답자들은 너무 바쁘거나 돈이 없어 친구와 시간을 보내기 어렵다고 답했다.

2022년 GQ 코리아 기사[^2]는 앞날을 준비하느라 시간이 모자라면 언제든 만날 수 있는 친구와의 관계를 잠시 미뤄 두게 된다고 썼다.

2025년 캐나다 통계청 발표[^3]에서 1986년부터 2022년 사이 하루에 친구를 만날 가능성은 25\~64세에서 3분의 2 줄었고 이 나이대의 감소 폭이 가장 컸다.
