# 안경을 쓰지 않고 지내기

별칭: 없음

안경이 필요한 사람이 불편함이나 놀림을 이유로 안경을 쓰지 않고 지낸다.

묶음: [건강과 위험](../groups/health-and-safety.md)

# 서술

2001년 익산 초등학생 조사 논문[^1]에서 안경을 쓰던 응답자의 32.3%는 안경이 불편하다는 이유로 제대로 쓰지 않게 되었다.

2019년 기사[^2]가 전한 인도 학생 시험에서 안경을 쓰지 않은 가장 큰 이유는 놀림과 괴롭힘(48.9%)이었다.

2024년 영국 병원 안내문[^3]은 아이가 안경을 쓰려 하지 않을 때 먼저 안경이 편하게 맞는지 보라고 적었다.
