# 화장실 뒤 손 안 씻기

별칭: 손씻기 생략, 물로만 손 씻기

공중화장실을 쓴 사람이 손을 씻지 않거나 비누 없이 물만 묻히고 나간다.

# 서술

2012년 Infection Control Today 가 전한 미국 설문에서 응답자 70%는 공중화장실을 쓴 뒤 늘 손을 씻는다고 답했다. 29%는 가끔 건너뛴다고 답했다. [F1]

2026년 질병관리청의 공중화장실 관찰조사에서 물로만 손을 씻은 경우는 39.3%, 손을 씻지 않은 경우는 14.0%였다. [F3]

# 조건

2019년 F2 의 관찰에서 손씻기 준수율은 화장실에 혼자 있을 때가 다른 사람이 있을 때보다 낮았다. [F2]

# 파편
