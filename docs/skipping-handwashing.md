# 화장실 뒤 손 안 씻기

별칭: 없음

공중화장실을 쓴 사람이 손을 씻지 않거나 비누 없이 물만 묻히고 나간다.

# 서술

2012년 Infection Control Today 가 전한 미국 설문에서 응답자 70%는 공중화장실을 쓴 뒤 늘 손을 씻는다고 답했다. 29%는 가끔 건너뛴다고 답했다.[^1]

2013년 연구[^2]의 저자들은 대학가 공중화장실에서 손을 씻어야 할 행동을 한 뒤에도 많은 사람이 손을 씻지 않는다고 적었다.

질병관리본부가 2013년 공중화장실 이용자를 관찰한 조사에서 용변 뒤 손을 씻은 사람은 73%였다. 그 가운데 비누로 씻은 사람은 33%였다.[^3]

2019년 연구[^4]의 관찰에서 손씻기 준수율은 화장실에 혼자 있을 때가 다른 사람이 있을 때보다 낮았다.

2023년 기사[^5]가 전한 조사에서 화장실을 쓰고도 손을 씻지 않은 사람이 꼽은 가장 큰 이유는 귀찮아서(38.8%)였다.

2026년 질병관리청의 공중화장실 관찰조사에서 물로만 손을 씻은 경우는 39.3%, 손을 씻지 않은 경우는 14.0%였다.[^6]
