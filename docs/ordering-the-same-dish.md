# 같은 메뉴만 주문하기

별칭: 없음

자주 가는 식당에 간 사람이 다른 메뉴를 맛볼 기회가 있어도 처음 먹었던 메뉴나 늘 먹던 메뉴를 다시 주문한다.

묶음: [시간과 하루 습관](../groups/daily-time.md)

# 서술

2011년 1월 Straight Dope 댓글[^1]의 글쓴이는 좋아하는 식당에 가면 처음 갔을 때 시킨 바로 그 요리를 늘 다시 주문하게 된다고 썼다.

2023년 11월 Franchising.com 기사[^2]가 전한 미국 성인 600명 조사에서 57%는 특정 식당에 갈 때마다 시키는 메뉴가 몇 가지 정해져 있다고 답했고 30%는 매번 같은 것을 시킨다고 답했다.
