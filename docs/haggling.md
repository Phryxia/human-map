# 값 흥정

별칭: 값 깎기, 에누리, Haggling

물건값이나 삯을 두고 사는 사람과 파는 사람이 값을 깎거나 지키려고 말을 주고받는다.

# 서술

1924년 현진건의 소설에서 손님은 일 원 오십 전이 너무 많다며 고개를 기울이고 인력거꾼은 거리가 시오 리가 넘고 날이 궂다며 값을 더 받으려 한다.[^1]

2026년 브런치 에세이의 필자는 시장에서 값을 깎아 달라는 말을 몇 마디 꺼내지만 끝까지 밀지 못하고 머뭇거리다 원래 값을 낸다고 썼다.[^3]

# 조건

2009년 진현정과 정아영의 재래시장 설문에서 흥정을 시장의 장점보다 부담으로 여기는 응답자가 더 많았고 그 가장 큰 이유는 시장 가격을 믿기 어렵다는 것이었다.[^2]
