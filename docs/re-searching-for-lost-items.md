# 잃어버린 물건을 찾은 곳에서 또 찾기

별칭: 없음

둔 곳을 잊은 물건을 찾는 사람이 이미 찾아본 곳을 다시 뒤진다.

# 서술

1900년 소설[^1]에서 신문을 잃은 삼촌은 방금까지 손에 있었다고 외쳤다. 식구들이 결국 찾아낸 신문은 그가 깔고 앉은 경우가 많았다.

2005년 연구[^2]에서 불빛 스위치를 눌러 목표를 찾는 아이들은 잘 쓰지 않는 손으로 찾을 때 이미 확인한 자리를 더 많이 다시 찾았다. 2017년 2월 연구[^3]가 소개한 넓은 공간 탐색 실험에서는 참가자가 이미 열어 본 통을 다시 확인하는 일이 드물었다.

2017년 8월 칼럼[^4]의 필자는 잃어버린 물건이 어머니 집에 꼭 있을 거라 믿었다. 어머니가 찾아봐도 없다고 하자 필자는 믿기지 않아 직접 찾아보러 갔다.

2024년 8월 기사[^5]가 전한 설문에서 응답자는 잃어버린 물건을 찾는 데 한 해 평균 17시간 가까이, 물건 하나에 16분쯤 썼다.
