# 격식 차린 자리에서 예절 실수 걱정하기

별칭: Fork anxiety[^2]

익숙하지 않은 격식 차린 식사 자리에 가게 된 사람이 예절을 틀려 남 앞에서 드러날까 봐 미리 걱정하고 위축된다.

묶음: [선물, 대접과 예의](../groups/gifts-and-hospitality.md)

# 서술

1885년 소설[^1]에서 상류층 집안의 만찬에 초대받은 남편에게 아내는 그 사람들 앞에서 뭔가 잘못할까 봐 겁이 나 제 목숨이 제 것이라고 말할 엄두도 못 낸다고 말했다.

2014년 National Geographic 기사[^2]는 여러 벌의 식기를 익히기 어려웠던 시절에 익숙하지 않은 사람들이 식기를 잘못 써 실례할까 괴롭게 걱정하던 상태를 한 음식 작가가 fork anxiety 라 부른다고 적었다.

2017년 학교 매체의 글[^3]은 격식 차린 식탁에 놓인 여러 벌의 접시와 수저가 사람을 어리둥절하게 하고 주눅 들게 할 수 있다고 적었다.
