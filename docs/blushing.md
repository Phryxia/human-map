# 얼굴 붉어짐

별칭: 홍조, 블러싱, Blushing

사람이 남의 시선이나 칭찬이나 창피한 일 앞에서 얼굴이 붉어진다.

# 서술

1813년 F1 의 인물은 수치와 분함으로 거듭 얼굴을 붉혔다. [F1] 1935년 F2 의 인물은 상대에게 쏘아붙인 뒤 얼굴이 빨개져 산으로 달아난다. [F2]

2005년 F3 의 기사는 면접관 앞에서 긴장해 얼굴이 금세 붉어지고 곤란한 질문에 귀까지 달아오르는 사례를 전한다. [F3] 2017년 F5 의 실험에서 대화가 칭찬으로 끝나면 뺨과 이마의 온도가 선형으로 올랐다. [F5]

# 조건

2015년 F4 에서 얼굴이 자주 붉어지는 사람은 드물게 붉어지는 사람보다 붉어질 때 수치를 더 크게 느꼈다. [F4]
