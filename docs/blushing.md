# 얼굴 붉어짐

별칭: Blushing[^4]

사람이 남의 시선이나 칭찬이나 창피한 일 앞에서 얼굴이 붉어진다.

# 서술

1813년 작품[^1]의 인물은 수치와 분함으로 거듭 얼굴을 붉혔다. 1935년 작품[^2]의 인물은 상대에게 쏘아붙인 뒤 얼굴이 빨개져 산으로 달아난다.

2005년 글[^3]의 기사는 면접관 앞에서 긴장해 얼굴이 금세 붉어지고 곤란한 질문에 귀까지 달아오르는 사례를 전한다. 2017년 연구[^5]의 실험에서 대화가 칭찬으로 끝나면 뺨과 이마의 온도가 선형으로 올랐다. 2019년 글[^6]은 거짓이 탄로 날지 모른다는 긴장과 압박으로 얼굴이 붉어지기도 한다고 쓴다.

2015년 연구[^4]에서 얼굴이 자주 붉어지는 사람은 드물게 붉어지는 사람보다 붉어질 때 수치를 더 크게 느꼈다.

2024년 글[^7]의 기사는 청소년기에 붉어짐이 늘어나는 이유로 청소년이 남의 의견에 민감하고 거절당하거나 나쁜 인상을 남기기를 두려워한다는 점을 든다.
