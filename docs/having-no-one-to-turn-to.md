# 기댈 사람이 없다는 느낌

별칭: 없음

어떤 사람이 힘들거나 아플 때 속을 털어놓거나 도움을 부탁할 사람이 곁에 없다고 여긴다.

묶음: [혼자 있음과 상실](../groups/solitude-and-loss.md)

# 서술

2006년 6월 McPherson 외의 연구[^1]에서 중요한 일을 의논할 사람이 아무도 없다고 답한 사람의 수는 2004년에 1985년의 3배 가까이 되었다. 같은 달 Duke Today 기사[^2]가 전한 미국 조사에서 중요한 일을 의논할 사람이 아무도 없다고 답한 사람은 1985년의 두 배를 넘어 2004년에 25% 가까이 되었다.

2026년 1월 e-나라지표의 사회적 고립도 해설[^3]에서 2025년 응답자의 24.9%는 아플 때 집안일을 부탁할 곳이 없다고 답했고 21.3%는 힘들 때 이야기할 상대가 없다고 답했다.
