# 손님으로 너무 오래 머물까 걱정하기

별칭: 없음

남의 집에 묵는 손님이 머문 날이 길어지면 집주인에게 폐가 되거나 불편을 준다고 여겨 떠날 때를 걱정한다.

묶음: [선물, 대접과 예의](../groups/gifts-and-hospitality.md)

# 서술

1817년 소설[^1]에서 친구 집에 초대받아 묵던 주인공은 머문 지 넷째 주가 되었다고 헤아리고 더 오래 있으면 폐가 될지 모른다고 생각했다.

2009년 게시글[^2]의 글쓴이는 집을 구하는 동안 친구 집 소파에서 자며 자기를 재우는 일이 친구들에게 주는 불편을 너무 작게 어림했는지 모른다고 적었다.

2025년 NPR 기사[^3]는 남의 집을 찾는 손님이 자기가 머무는 일을 짐이 아니라 선물로 느끼게 하려면 어떻게 해야 하는지를 물었다.
