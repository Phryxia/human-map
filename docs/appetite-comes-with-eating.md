# 먹기 시작하면 도는 입맛

별칭: Appetite comes with eating[^1], Appetizer effect[^3]

음식을 몇 입 먹은 사람이 먹기 전보다 허기와 먹고 싶은 마음을 더 크게 느낀다.

묶음: [시간과 하루 습관](../groups/daily-time.md)

# 서술

1534년 라블레의 소설[^1]에서 술꾼들은 먹다 보면 입맛이 돌지만 마시면 갈증은 사라진다는 말을 주고받는다.

2024년 Psychology Today 글[^2]의 저자는 때로 첫 입이 심한 식욕을 일으킨다고 쓴다.

2026년 Schulz 등의 논문[^3]은 맛보기 시험의 여러 단계에 걸친 그렐린과 먹고 싶음, 좋아함 평가의 연관을 그렐린이 애피타이저 효과를 키운다는 근거로 든다.
