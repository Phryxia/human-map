# 진료 예약 부도

별칭: 없음

병원이나 의원에 진료를 예약한 환자가 취소 연락 없이 예약한 때에 나타나지 않는다.

묶음: [건강과 위험](../groups/health-and-safety.md)

# 서술

2004년 미국 가정의학 연구[^1]에서 한 환자는 발이 부어 있을 때는 예약을 생각했지만 부기가 빠지자 잊었다고 말했다.

2005년 영국 일반의 진료소 설문[^2]에서 예약에 오지 않은 응답자의 30%는 예약을 취소하려 했다고 답했다.

2023년 코메디닷컴 기사[^3]에 따르면 국립대병원들은 노쇼의 원인으로 건강이 나아져 방문할 필요가 없어진 것, 예약일을 잊은 것, 다른 병원으로 옮긴 것을 꼽았다.

2026년 영국 켄트 지역 NHS 재단의 글[^4]에서 첫 예약에 오지 않은 한 환자는 기다리는 동안 의뢰받은 문제가 나았다고 말했다.
