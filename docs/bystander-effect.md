# 방관자 효과

별칭: 책임 분산[^9], Bystander effect[^4]

위급한 상황을 여러 사람이 함께 볼 때 그 가운데 한 사람이 도울 가능성이 줄어든다.

# 서술

1985년 Shotland·Heinold 의 동맥 출혈 상황 실험에서 다른 구경꾼이 있을 때 도운 사람이 더 적었고 상황이 모호할수록 도움이 줄었다.[^2]

2008년 Levine·Crowther 의 거리 폭력 시나리오 연구에서 사람 수가 늘면 구경꾼끼리 모르는 사이일 때는 개입이 줄었고 친구일 때는 개입이 늘었다.[^3] 2011년 Fischer 외의 메타분석은 위급한 상황에 다른 사람이 있으면 한 개인이 도울 가능성이 줄어든다는 연구가 많다고 적었다.[^4]

2017년 클리앙 게시글의 글쓴이는 지하철역에서 노인이 쓰러졌을 때 다들 쳐다만 보고 있었고 자신이 달려가 의식을 확인한 뒤 구경하던 시민 한 명을 집어 119 신고를 맡겼다고 적었다.[^5]

CCTV 기록을 본 두 연구는 결과가 갈린다.[^6][^7] 2019년 Liebst 외는 폭력 사건에서 구경꾼이 많을수록 개입이 줄었다고 보고했다.[^6] 2020년 Philpot 외는 여러 나라의 공공장소 다툼에서 구경꾼이 많을수록 누군가 개입할 가능성이 컸다고 보고했다.[^7]

2026년 한국교육신문 칼럼은 '누군가 하겠지' 하는 책임 분산 때문에 움직이지 않거나 '아무도 심각하게 생각하지 않네' 하는 다원적 무지 때문에 상황 자체를 잘못 판단할 수 있다고 적었다.[^9]
