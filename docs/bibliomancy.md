# 책을 아무 데나 펼쳐 답 구하기

별칭: Bibliomancy[^2]

사람이 경전이나 책을 아무 데나 펼쳐 처음 눈에 든 구절을 자기 처지에 내린 답으로 받아들인다.

묶음: [기억과 떠오르는 생각](../groups/memory-and-thoughts.md)

# 서술

1719년 소설[^1]의 화자는 책을 아무렇게나 펼쳤더니 처음 눈에 든 말이 "환난 날에 나를 부르라" 로 시작하는 구절이었다고 적었다.

2015년 기사[^2]의 필자는 비블리오맨시를 평소의 읽기 방식을 내려놓고 글을 앞일을 알려 주는 것으로 대하는 일이라고 정의했다.
