# 혼자 여가 보내기

별칭: 1인 여가[^2]

여가 시간이 생긴 사람이 가족이나 친구와 함께하지 않고 혼자서 여가활동을 한다.

# 서술

2017년 문화체육관광부 발표[^1]에서 여가활동을 혼자서 한다는 사람은 2014년 56.8%에서 2016년 59.8%로 늘었고 가족과 함께한다는 사람은 32.1%에서 29.7%로 줄었다. 2024년 기사[^2]가 전한 조사에서 1인 여가활동을 한다는 사람은 54.9%로 가족이나 친구와 함께한다는 사람보다 많았다.
