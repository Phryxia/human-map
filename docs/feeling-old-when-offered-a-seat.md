# 자리를 양보받고 늙었다고 느끼기

별칭: 없음

대중교통에서 자리를 양보받은 사람이 자기가 늙어 보였다고 느껴 당황하거나 자리를 사양한다.

묶음: [낯선 사람과 공공장소](../groups/strangers-and-public-places.md)

# 서술

1997년 뉴욕 데일리 뉴스 기사[^1]에서 예절 강사는 스스로를 늙었다고 여기지 않는 사람이 자리를 양보받고 기분이 상할 수 있어서 일부 젊은이가 양보를 망설인다고 설명했다.

2005년 게시글[^2]의 글쓴이는 서른 살 무렵 버스에서 처음 자리를 양보받았을 때 늙었다고 느끼고 충격을 받았지만 웃으며 고맙다고 받아야 할 것 같았다고 썼다.

2006년 한국교육신문 글[^3]의 필자 부부는 시드니의 통학버스에서 여학생들이 자리를 내주자 아직은 버스에서 자리를 양보받을 나이가 아니라는 속마음을 품었다.

2021년 Mishpacha 칼럼[^4]의 필자는 55세에 처음 자리를 양보받고 조금 당황했다고 적었다.

2025년 NZ Herald 기고[^5]의 64세 필자는 버스에서 자리를 권받자 힘없이 웃으며 괜찮다고 사양하고 바닥으로 눈을 내렸다.
