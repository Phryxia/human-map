# 눈 굴리기

별칭: Eye-roll[^3]

상대의 말이나 행동이 못마땅하거나 어이없다고 느낀 사람이 눈알을 위나 옆으로 굴린다.

묶음: [가까운 사이의 감정과 말](../groups/close-relationships.md)

# 서술

2009년 3월 해커 뉴스 댓글[^1]의 글쓴이는 사람들이 일 이야기로 불평을 늘어놓기 시작하면 늘 눈을 굴린다고 썼다. 글쓴이는 상대를 공격하려는 것은 아니라고 덧붙였다.[^1]

2016년 2월 바이스 기사[^2]는 눈 굴리기가 항의와 토라짐의 표시로 남아 있고 십대만 하는 몸짓도 아니라고 썼다.

2021년 연구[^3]는 대화에서 누군가 한 말이나 행동에 대한 반응으로 눈을 위나 옆으로 굴리는 몸짓을 반대를 드러내는 행동으로 다뤘다. 2025년 연구[^4]는 직장에서 상대를 가볍게 무시하는 작은 무례의 예로 눈 굴리기, 이메일 무시, 말 끊기를 들었다.
