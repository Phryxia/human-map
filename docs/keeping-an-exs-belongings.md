# 헤어진 연인의 물건 간직하기

별칭: 없음

사랑이 끝난 사람이 상대에게 받은 편지와 선물을 버리지 않고 간직하거나 그대로 쓴다.

# 서술

1853년 브론테의 소설[^1]에서 루시는 그레이엄에게 받은 편지를 봉해 묻으면서 보물을 숨길 뿐 아니라 슬픔도 묻으려 한다고 말했다.

2013년 박사논문[^2]은 자기를 넓혀 준 관계에서 얻은 물건을 사람들이 넓어진 자기를 지탱하려고 간직한다는 생각을 어느 정도 뒷받침했다.

2022년 기사[^3]가 전한 미혼남녀 설문에서 헤어진 연인에게 받은 선물을 그대로 쓴다는 답이 51.3%로 가장 많았다. 종류에 따라 다르다는 답은 30.4%였고 미련 없이 버린다는 답은 12.1%였다.[^3]

2026년 6월 지식iN 게시글[^4]의 글쓴이는 헤어진 연인과 찍은 사진을 화가 나서 찢어 버리고 싶으면서도 나중에 추억이 될 것 같아 버릴지 말지 고민했다.
