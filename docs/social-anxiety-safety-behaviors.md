# 사회불안의 안전 행동

별칭: 안전행동, safety behaviors

사회적 상황에서 불안한 사람이 남의 눈에 띄거나 부정적으로 보이지 않으려고 눈 맞춤을 피하거나 말수를 줄인다.

# 서술

2022년 F1 의 논문은 다른 사람 앞에서 말을 줄이고 눈 맞춤을 피하는 것을 자주 관찰되는 회피 행동의 예로 든다. [F1]

2025년 F2 의 댓글 글쓴이는 상대와 눈을 똑바로 마주치지 못하면서도 예의 있게 보이려고 웃으며 좋은 인상을 주려 애썼다고 썼다. [F2]

# 조건

기록된 조건 없음. [F1][F2]
