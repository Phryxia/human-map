# 가난 수치심

별칭: Poverty shame, 가난이 부끄러움

가난한 사람이 남이 자기 형편을 보는 자리에서 부끄러움을 느낀다.

# 서술

2011년 F1 의 기사는 대구시가 결식아동 급식에 전자카드를 들인 이유 가운데 하나로 아이들이 음식점에서 식권을 내는 일 자체를 수치스럽게 여긴다는 점을 들었다. [F1]

2013년 Damelang 과 Kloß 는 앞선 빈곤 연구들이 경제적 제약과 함께 수치심에서 나온 사회적 물러남이 참여율을 낮춘다는 것을 보였다고 적는다. 2019년 Ali 등은 가난하게 사는 사람들이 사회와 제도의 여러 자리에서 수치를 겪는다는 앞선 주장을 정리한다. [F2][F3]

2025년 F4 의 기사가 전한 설문에서 아동급식카드를 쓰는 응답자 321명 가운데 22%가 다른 사람 앞에서 카드 쓰기가 꺼려진다고 답했다. [F4]

# 조건

2011년 F1 에서 아이들의 수치는 음식점에서 식권을 내는 장면처럼 다른 사람 앞에서 지원을 받는 자리에서 나타난다. 2025년 F4 의 응답도 다른 사람 앞에서 급식카드를 쓰는 때를 가리킨다. [F1][F4]

2013년 F2 는 젊은 사람들의 사회 참여를 다룬다. [F2]
