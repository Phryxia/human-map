# 효과 없는 버튼 누르기

별칭: placebo buttons[^1]

신호나 문이 바뀌기를 기다리는 사람이 누른 효과가 거의 없는 횡단보도 버튼이나 엘리베이터 닫힘 버튼을 누른다.

# 서술

2013년 기사[^1]는 뉴욕에서 많은 곳의 횡단보도 버튼이 효과가 없어 보여 플라세보 버튼으로 불린다고 전한다. 2018년 기사[^3]에서 뉴욕시 교통국 대변인은 횡단보도 버튼 1,000개 가운데 약 100개만 실제로 작동한다고 확인했다.

2018년 지역 방송 기사[^2]에서 한 뉴욕 시민은 버튼에 손가락을 대고 누르면 기분이 훨씬 나아지고 무언가를 통제하고 있다고 느낀다고 말했다. 2021년 논문[^4]은 1975년 연구가 우연으로 정해지는 게임의 결과를 통제할 수 있다는 착각 속에서 사람들이 움직이는 모습을 보였다고 쓴다.

2023년 기사[^5]는 한국의 보행자 작동 신호기에서 버튼을 눌러도 신호기가 제대로 작동하지 않는다는 시민 불만을 다룬다. 2024년 기사[^6]는 서울 지하철역 엘리베이터에서 닫힘 버튼을 눌러도 일정 시간이 지나야 문이 닫혀 답답하다고 쓴다. 2026년 기사[^7]는 한국 사람들에게 엘리베이터 닫힘 버튼 누르기가 자동 반응에 가깝다고 적는다.
