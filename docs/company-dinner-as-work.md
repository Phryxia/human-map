# 회식을 업무의 연장으로 느끼기

별칭: 없음

회식에 나가는 직장인이 회식을 쉬는 자리가 아니라 근무 시간 밖으로 이어진 업무로 느낀다.

묶음: [일터와 일자리](../groups/work.md)

# 서술

2008년 10월 기사[^1]가 전한 설문에서 술자리 회식을 하는 회사의 직장인 가운데 60.8%는 술자리 회식을 업무의 연장으로 생각했다.

2021년 9월 기사[^2]가 전한 조사에서 회식 문화에 부정적인 감정을 가진 직장인들은 그 이유로 회식이 업무의 연장 같다는 생각(48.2%, 중복응답)을 꼽았다.

2026년 7월 취업 커뮤니티 댓글[^3]의 글쓴이는 회식을 업무의 연장선으로 생각하는 추세라 회식이 줄어드는 것 같다고 썼다.
