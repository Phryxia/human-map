# 난방기기 켜 둔 채 잠들기

별칭: 없음

추운 밤에 사람이 전기장판, 전기담요, 전기난로 같은 난방기기를 켜 둔 채 잠든다.

묶음: [건강과 위험](../groups/health-and-safety.md)

# 서술

2008년 영국 조사[^1]에서 전기담요를 가진 사람의 69%는 실수로 담요를 켜 둔 적이 있다고 답했다. 2014년 기사[^2]의 58세 소비자는 전기장판 온도를 저온으로 맞추고 잠들었다가 일어나 보니 발목에 3도 화상을 입었다.

2022년 증례 보고[^3]의 환자는 집 밖에서 휴대용 히터에 기대 잠들었다가 등과 엉덩이에 화상을 입었다. 같은 해 일본 기관 글[^4]은 전기난로를 켠 채 잠들면 이불 같은 것이 뜨거운 부분에 닿아 불이 붙을 수 있다고 적었다. 2023년 영국 소방서의 정보공개 답변[^5]에는 밤새 켜 둔 전기담요가 매트리스를 태운 화재가 있다. 2023년 게시글[^6]의 글쓴이는 겨우내 밤에 잘 때 전기장판을 켜도 요금이 얼마 나오지 않는다고 적고 아침에 따뜻한 장판을 벗어나기 힘들다고 했다.

2025년 1월 일본 기관 글[^7]은 전기 앙카를 두 무릎 사이에 끼고 잠든 사람이 허벅지에 저온화상을 입은 사례를 전한다. 2025년 11월 기사[^8]는 난방비를 아끼려고 전기장판을 오래 켜 두는 가정이 많다고 적었다.
