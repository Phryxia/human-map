# 행운의 물건 지니기

별칭: Lucky charm[^4], 럭키 아이템[^6]

사람이 운을 가져다주거나 자기를 지켜 준다고 여기는 물건을 몸에 지니고 다닌다.

# 서술

1901년 키플링의 소설[^1]에서 소년 킴은 야영지를 기웃거리고도 매를 맞지 않자 부적이 자기에게 유리하게 듣고 있다고 여긴다.

2010년 미국 심리과학회 보도자료[^2]는 어떤 행운의 물건을 지니면 자신감이 올라 실제로 수행이 나아진다는 연구를 소개했다.

2013년 게시판 글[^3]의 글쓴이는 행운의 동전을 지갑에 넣지 않고 주머니에 넣는다며 운이 좋은 물건이니 하루 내내 가까이 두어야 한다고 썼다.

2019년 연구[^4]의 저자는 많은 사람이 행운의 물건이나 숫자, 의례, 옷을 갖고 있다고 적었다. 2025년 7월 연구[^5]는 성공을 바라고 행운의 물건을 지니는 일을 좋은 결과를 북돋우려는 긍정 미신의 예로 들었다. 2025년 10월 기사[^6]는 청년들이 키링과 굿즈를 사고 직접 부적을 적어 휴대전화에 끼워 다닌다고 적었다.
