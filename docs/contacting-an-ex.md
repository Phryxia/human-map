# 헤어진 연인에게 연락하기

별칭: 없음

연인과 헤어진 사람이 헤어진 상대에게 먼저 문자나 전화로 연락한다.

묶음: [가까운 사이의 감정과 말](../groups/close-relationships.md)

# 서술

2004년 게시판 글[^1]의 글쓴이는 헤어진 연인에게 느닷없이 연락하는 것이 나쁜 생각인지 아주 나쁜 생각인지 물었다.

2016년 연구[^2]의 저자들은 이별 뒤 적응하기 어려워하는 것이 전 연인과 연락을 이어 가려는 시도를 예측한다고 적었다.

2017년 기사[^3]의 필자는 전 연인에게 연락하고 싶은 충동을 참아 왔으나 넷째 잔을 비우자 그에게 문자를 보내 속에 있는 말을 털어놓는 것이 그리 나빠 보이지 않았다고 썼다.
