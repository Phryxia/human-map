# 시험 불안

별칭: Test anxiety[^2], 시험불안[^3], exam anxiety[^5]

시험을 앞두거나 시험을 치르는 학생이 불안해하고 머리가 잘 돌아가지 않는다.

묶음: [걱정과 기분](../groups/worry-and-mood.md)

# 서술

1887년 소설[^1]에서 장학 시험을 앞둔 학생은 다가오는 시험에 대한 두려움이 악몽처럼 되살아나 몹시 비참해졌다.

1992년 연구[^2]에서 의대생이 시험 직전에 느낀 불안은 면허시험 성적과 관계가 있었다. 그 관계는 평소에 지닌 불안과 성적의 관계만큼 크지 않았다.

2003년 기사[^3]의 조사에서 시험불안이 높은 학생의 수능 평균은 266.1점으로 시험불안이 낮은 학생의 275.4점보다 9.3점 낮았다.

2010년 게시판 댓글[^4]의 글쓴이는 시험지를 읽고도 읽은 낱말을 머릿속에서 문장으로 엮지 못했다고 썼다.

2024년 연구[^5]에서 고등학교 1학년 학생의 79.8%가 시험 불안 증상을 보였다.
