# 주운 물건 갖기

별칭: Stealing by finding[^1], 점유이탈물횡령[^4]

남이 잃어버리거나 놓아둔 물건을 주운 사람이 그것을 주인이나 경찰에 돌려주지 않고 자기가 갖는다.

묶음: [시민 참여와 공공의 일](../groups/civic-life.md)

# 서술

발행일이 적히지 않은 호주 태즈메이니아 경찰의 안내문[^1]은 주운 물건을 돌려주지 않고 갖는 일을 'stealing by finding' 이라 부르고 범죄로 적는다.

2006년 행정심판 보도자료[^2]에서 오래 놓여 있던 오토바이를 가져간 사람은 누가 버린 것을 고쳐 청년회를 위해 다시 쓰려 했을 뿐 훔칠 생각은 없었다고 진술했다.

2019년 지갑 반환 실험[^3]에서 거의 모든 나라의 시민이 돈이 더 많이 든 지갑일수록 더 자주 돌려주었다.

2023년 11월 경찰청의 집중 단속 결과[^4]에서 점유이탈물횡령 사범으로 검거된 사람은 2752명이었다.
