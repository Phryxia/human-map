# 돌멩이 주워 오기

별칭: 없음

바닷가나 물가를 걷는 사람이 눈에 띄는 돌멩이를 골라 주머니에 넣어 집에 가져온다.

묶음: [시간과 하루 습관](../groups/daily-time.md)

# 서술

2012년 Creative Nonfiction 에세이[^1]의 필자는 호숫가를 거닐며 주머니 가득 돌을 줍는 취미로 충분히 행복했다고 썼다.

2025년 Hacker News 댓글[^2]의 글쓴이는 해변에 갈 때마다 가장 흥미로운 모양과 색의 돌을 찾아 주머니를 채우고 집에 가져오는 것을 자기 책임으로 여겼다고 썼다.
