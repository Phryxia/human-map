# 말대꾸

별칭: 없음

꾸중이나 지시를 받은 아이나 아랫사람이 부모나 윗사람에게 맞서는 말로 대답한다.

묶음: [가까운 사이의 감정과 말](../groups/close-relationships.md)

# 서술

1936년 소설[^1]의 주인공은 치받치는 설움과 분노를 꾹꾹 참는다. 화자는 감독에게 말대꾸하는 일이 공장을 그만두는 사람의 일이었다고 적었다.[^1]

1959년 소설[^2]의 창선은 우겨 대다가 담뱃대로 등줄기를 맞은 뒤로 달아날 구멍부터 보아 놓고서 말대꾸를 한다.

2014년 육아 기사[^3]는 초등 고학년 사춘기 자녀가 말대꾸를 하는 일이 많아진다고 적었다. 기사는 반항하려는 말대꾸와 다른 의견을 주장하려는 말대꾸를 나눈다.[^3]

2018년 초등 교사의 글[^4]은 몇 달 전까지 어린아이 같던 자녀가 갑자기 말대꾸를 시작하고 방문을 잠그고 큰소리로 대들면 부모가 속상해한다고 적었다.

2019년 아동 면담 연구[^5]에서 여러 아이가 동의하지 않는 요청에 부모와 말다툼하는 방법으로 의견을 말하거나 요청에 맞선다고 답했다.
