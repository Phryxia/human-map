# 남의 집 약장 엿보기

별칭: 없음

남의 집에 손님으로 간 사람이 그 집 욕실의 약장을 몰래 열어 본다.

# 서술

1995년 The Spokesman-Review 기사[^1]는 새 조사 결과를 전하며 손님들이 욕실 수납장을 엿본다고 적었다.

2008년 VPM 에 실린 Gosling 의 책 발췌[^2]에서 저자는 약장을 엿보기의 전형적인 자리라 부르고 엿보는 손님을 위해 약장 안에 방명록을 두면 재미있겠다고 생각해 왔다고 썼다.

2011년 Straight Dope 댓글[^3]의 글쓴이는 사람들이 약장을 들여다보는 사람을 나쁘게 짐작한다고 쓰고 자기는 비밀을 캐려고 뒤지는 것이 아니라 그냥 들여다볼 뿐이라고 했다.

2017년 Scientific American 블로그 글[^4]의 저자는 남의 욕실을 엿보는 일이 그 사람에 대해 이미 안다고 믿는 바를 확인하거나 그에 반하는 증거를 얻는 방법이 된다고 썼다.
