# 외로움

별칭: 고독감, Loneliness

사람이 일상생활에서 외롭다고 느낀다.

# 서술

1936년 이효석의 「메밀꽃 필 무렵」에서 화자는 여자와 연분이 멀었던 허 생원의 반생을 쓸쓸하고 뒤틀렸다고 적는다. [F1]

2018년 영국 통계청 ONS 는 16~24세 성인이 더 나이 든 연령대보다 외로움을 더 자주 느낀다고 답했다고 발표했다. [F2]

2019년 아시아경제 기사는 대인관계에 문제가 없어도 일상생활에서 외로움을 느끼는 20~30대가 늘고 있다고 전한다. [F3]

2025년 3월 코메디닷컴 기사는 혼밥이 잦으면 사회적 고립감이 커질 수 있다는 보고서 내용을 전하고 일주일 내내 혼밥을 한 사람의 38%가 외로움을 느꼈다고 적었다. [F4]

2025년 안선경 등은 선행 연구가 외로움 같은 정신건강 문제를 청년기 고립은둔으로 옮겨 가는 과정을 앞당기는 요인으로 보고해 왔다고 적었다. [F5]


# 조건

1936년 F1 의 허 생원은 여자 편에서 정을 보낸 적이 없는 처지로 그려진다. [F1]

2018년 F2 는 나이를 조건으로 들고 16~24세에서 외로움을 더 자주 느낀다고 적는다. 2019년 F3 는 대인관계에 문제가 없는 경우에도 외로움이 나타난다고 적는다. [F2][F3]
