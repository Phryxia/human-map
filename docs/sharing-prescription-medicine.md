# 처방약 나눠 먹기

별칭: 없음

자기에게 처방된 약을 가족이나 친구에게 나눠 주거나 남이 처방받은 약을 얻어 먹는다.

묶음: [건강과 위험](../groups/health-and-safety.md)

# 서술

2009년 HealthDay 기사[^1]가 전한 조사에서 남의 처방약을 빌려 먹은 사람의 77.3%는 의료인을 만나는 대신 약을 얻었다고 답했다.

2011년 도시 의료센터 성인 환자 연구[^2]에서 약을 빌린 응답자의 67%인 78명이 빌린 이유로 편리함을 들었다.

2023년 4월 코메디닷컴 기사[^3]는 가족이나 친지 같은 다른 사람이 처방받은 아스피린 따위를 무턱대고 먹는 사람이 있다고 적는다.

2023년 5월 미국 식품의약국 안내문[^4]은 각성제를 처방받은 사람이 약을 나눠 달라는 부탁을 자주 받는다고 적는다.
