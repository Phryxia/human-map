# 위조품인 줄 알고 사기

별칭: 없음

물건을 사는 사람이 위조품인 줄 알면서 값이 싸다는 이유로 그것을 산다.

묶음: [돈과 소비](../groups/money.md)

# 서술

2012년 유승엽의 연구[^1]에서 위조명품을 사는 동기에는 경제성, 만족도, 품질이 유의한 영향을 주었다.

2021년 영국 지식재산청 조사[^2]에서 응답자의 27%는 위조품인 줄 알면서 산 적이 있다고 답했고 15%는 지금도 자주, 가끔 또는 이따금 산다고 답했다.

2025년 같은 기관의 조사 보고서[^3]에 실린 참가자는 먹고살려고 식료품을 더 싸고 적게 사기 시작했으며 돈이 덜 들어서 위조품을 더 산다고 말했다.
