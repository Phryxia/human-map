# 공중화장실 변기에 앉지 않기

별칭: 없음

공중화장실을 쓰는 사람이 세균이나 오물이 옮을까 봐 변기에 앉지 않고 몸을 띄운 채 볼일을 본다.

# 서술

2019년 4월 코메디닷컴 기사[^1]는 1991년 영국 리버풀 대학교 연구진이 여성 대부분이 공중화장실에서 세균이나 오물을 피하려고 엉거주춤 쪼그린 자세를 고른다는 것을 발견했다고 전했다. 2019년 11월 배뇨 자세 연구[^2]의 저자들은 오염이 두려워 변기에 앉지 않는 환자가 드물지 않다고 적었다.

2025년 9월 코메디닷컴 기사[^3]는 공중화장실을 꺼림칙해하는 한 시민이 그곳에서 소변을 볼 때 변기에 앉지 않고 엉거주춤 선 채 볼일을 마친다고 전했다.
