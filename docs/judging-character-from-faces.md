# 얼굴로 성격 짐작하기

별칭: 관상[^4]

처음 본 사람의 얼굴 생김새를 보고 사람이 그의 성품과 능력을 짐작한다.

묶음: [판단과 어림의 치우침](../groups/judgment-biases.md)

# 서술

1890년 와일드의 소설에서 화가는 비참한 사람에게 악덕이 있으면 그것이 입매의 주름, 처진 눈꺼풀, 손의 생김새에까지 드러난다고 말했다.[^1]

2005년 연구[^2]에서 선거 후보들의 얼굴을 보고 내린 유능함 추론은 얼굴을 1초 동안 보는 사이에 일어났다. 2006년 논문[^3]의 저자들은 사람들이 남의 얼굴 생김새로 특성을 추론하는 일이 잦다고 적었다.

2022년 기사[^4]의 기자는 관상으로 남의 심성을 짐작할 수 있다고 생각하는 사람이 여전히 많다고 적었다. 같은 기사는 한때 국내 일부 기업이 채용 면접에 관상 면접관을 두어 지원자의 인상으로 채용 여부를 판단했다고 전했다.[^4]

2025년 기사[^5]에서 연구진은 부유한 관상에 가까운 얼굴일수록 신뢰감, 정직함, 유능함이 돋보인다고 설명했다.
