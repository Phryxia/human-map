# 명절 친지 모임 피하기

별칭: 혼추족, 명절 귀성 안 하기

명절을 맞은 사람이 친척의 질문과 잔소리를 부담스러워하며 친지 모임에 가지 않고 혼자 또는 따로 지낸다.

# 서술

2014년 F1 의 정책브리핑 글은 오랜만에 만난 친척들이 취업과 결혼을 물어 명절 스트레스를 받는 사람이 많다고 적었다. 2021년 F6 의 강남구청 카드뉴스는 손님상을 차리면 잔소리가 돌아와 자괴감이 든다고 적었다. [F1][F6]

2015년 F2 의 설문에서 20~30대 미혼 응답자의 21%가 추석을 홀로 보낸다고 답했다. 2018년 F3 이 전한 설문에서는 성인 남녀의 46.7%가 추석 친지 모임에 참석하지 않겠다고 답했다. [F2][F3]

2019년 F4 의 기사는 명절이 괴로운 청년들 가운데 불편한 상황을 모면하려고 혼자 여행을 가거나 명절 특근을 자청하는 사람들을 적었다. 2020년 F5 의 정책주간지 기사는 명절마다 부모를 여행 보내 만남을 피하는 방법을 잔소리 대처법의 하나로 소개했다. 2025년 F7 의 기사는 가족 대신 동네 이웃과 추석을 맞는 사람을 혼추족이라 부르고 그 수가 늘고 있다고 적었다. [F4][F5][F7]

# 조건

2015년 F2 의 응답자는 20~30대 미혼이다. 2021년 F6 는 코로나19 집합금지 시기의 설에 집에 머무는 이유를 들었다. 2025년 F7 의 기자는 MZ세대를 중심으로 귀향하지 않는 사람이 늘었다고 적었다. [F2][F6][F7]
