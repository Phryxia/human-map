# 도박사의 오류

별칭: 몬테카를로 오류, Gambler's fallacy

같은 결과가 이어지는 것을 본 사람이 다음에는 다른 결과가 나올 차례라고 믿는다.

# 서술

1866년 소설[^1]의 화자는 방금 0이 나왔으니 한동안 다시 나오지 않을 것이라며 조금 기다리면 더 나은 기회가 온다고 노부인을 말렸다.

2015년 7월 연구[^3]의 저자들은 룰렛의 빨강과 검정을 맞히는 과제에서 빨강이 여러 번 이어지면 다른 쪽인 검정을 고르는 경향이 커진다고 적었다.

2015년 3월 연구[^2]에서 대학생이 이 믿음을 따르는 정도는 도박에 관한 생각, 성별과 관련이 있었고 충동성과는 관련이 없었다.
