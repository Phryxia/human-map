# 빗소리에 마음 놓이기

별칭: 없음

실내에 있는 사람이 지붕이나 창에 떨어지는 빗소리를 들으며 편안함을 느끼고 잠들 때 빗소리를 일부러 틀기도 한다.

묶음: [걱정과 기분](../groups/worry-and-mood.md)

# 서술

1912년 선집에 실린 Kinney 의 시[^1]의 화자는 시골집 침대에서 베개를 베고 머리 위로 부드럽게 떨어지는 빗소리를 듣는 일을 더없는 기쁨이라 불렀다.

2025년 1월 교차 실험[^2]의 참가자들은 자연의 소리로 짠 음향을 들은 뒤 더 편안하고 이완된 상태가 되었고 긍정적 감정도 높아졌다. 2025년 12월 이오플래닛 기사[^3]는 팬데믹으로 시청자들이 집에 머물던 때 유튜브에서 '잠잘 때 듣는 빗소리 10시간' 영상이 폭증했다고 썼다.
