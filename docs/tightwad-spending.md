# 돈 쓰기 아까워하기

별칭: 인색함, 구두쇠 기질, 지불의 고통, tightwad, pain of paying

돈을 낼 때의 괴로움을 미리 느끼는 사람이 스스로 바라는 것보다 적게 쓴다.

# 서술

1861년 소설[^1]에서 금화와 은화가 쌓여 갈수록 직조공은 자기에게 필요한 데 쓰는 돈을 점점 줄였다.

2007년 와튼스쿨 팟캐스트 소개글[^2]은 남성이 여성보다, 학력이 높은 사람일수록 돈 쓰기를 아까워하는 쪽이 많고 젊은 사람은 헤프게 쓰는 쪽이 많다고 전했다. 2008년 논문[^3]의 저자들은 돈을 낼 때 예상되는 고통 때문에 이런 사람이 바라는 것보다 적게 쓴다고 제안한다.
