# 따뜻한 물 나올 때까지 물 틀어 두기

별칭: 없음

샤워하거나 설거지하려는 사람이 따뜻한 물이 나올 때까지 수도나 샤워기를 틀어 두고 기다린다.

묶음: [시간과 하루 습관](../groups/daily-time.md)

# 서술

발행일이 적히지 않은 미국 에너지부 교육 자료[^1]는 어떤 수도꼭지는 온수가 오기까지 오래 찬물이 흐르고 샤워기를 60초 틀 때마다 물이 3갤런쯤 버려진다고 적었다. 발행일이 적히지 않은 안산시 상하수도사업소 안내[^2]는 온냉수 혼합꼭지를 틀어 처음 나오는 찬물을 따로 받아 두었다가 다른 데 쓰라고 권한다.

1999년 게시판 글[^3]의 글쓴이는 양치하다 입에서 치약이 흐르는 채로 온수기에서 욕실까지 따뜻한 물이 오기를 서서 기다린 적이 많다고 썼다.

2013년 클리앙 게시글[^4]의 글쓴이는 쌀쌀한 아침 샤워하려고 물을 틀면 찬물이 나오고 따뜻해질 때까지 그것을 쳐다보며 하품한다고 썼다.

2014년 NRDC 블로그 글[^5]의 필자는 샤워기를 틀어 놓고 기다리는 동안 양치를 하거나 커피를 내리거나 옷장에서 옷을 꺼낸다고 썼다. 같은 해 로렌스 버클리 국립연구소 논문[^6]은 지금의 온수 배관이 원하는 온도를 얻으려면 사용자가 한동안 물을 틀어 두게 되어 있고 그사이 에너지와 물이 버려진다고 썼다.
