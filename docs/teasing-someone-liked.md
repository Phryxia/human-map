# 좋아하는 상대 괴롭히기

별칭: 좋아해서 괴롭히기, Pulling pigtails

마음에 둔 상대에게 호감을 바로 말하지 않고 놀리거나 깎아내리거나 귀찮게 군다.

# 서술

1936년 김유정의 소설에서 점순이는 구운 감자를 남몰래 건네면서 "느 집엔 이거 없지?" 하고 생색을 낸다. [F1]

2016년 Emma Hollis 는 어릴 적 어머니에게서 놀림은 사랑이고 머리카락 잡아당기기는 애정이라는 말을 들었다고 쓴다. [F2]

# 조건

2016년 F2 는 어린 시절 아이들 사이의 놀림을 어른이 설명한 말이다. [F2]
