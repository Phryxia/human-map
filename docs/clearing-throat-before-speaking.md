# 말 꺼내기 전 헛기침

별칭: 없음

여럿 앞에서 말을 꺼내려는 사람이 먼저 헛기침으로 목청을 가다듬는다.

# 서술

표준국어대사전[^1]은 헛기침을 인기척을 내거나 목청을 가다듬으려고 일부러 하는 기침으로 풀이한다.

1922년 싱클레어 루이스의 소설[^2]에서 모임 사람들이 말 잘하는 이로 통하는 인물을 바라보자 그는 안경끈을 당기고 헛기침을 한 뒤 늘 하던 말을 꺼냈다.

2024년 기사[^3]에서 몸짓 언어 전문가는 말을 꺼내기 전의 헛기침을 하고 싶은 말이 긴장이나 망설임 때문에 목에 걸린 상태로 설명한다. 2025년 블로그 글[^4]의 글쓴이는 목을 정말 가다듬어야 할 때도 있으나 대개는 청중에게 도움이 되지 않는 의례에 매여 헛기침을 한다고 쓴다.
