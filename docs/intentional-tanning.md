# 일부러 피부 태우기

별칭: intentional tanning[^6]

피부를 그을린 모습으로 만들고 싶은 사람이 햇볕이나 태닝 기계 아래에서 일부러 피부를 태운다.

# 서술

1993년 대학생 조사[^1]에서 햇볕에 일부러 피부를 태우는 일이 잦은 학생일수록 그을린 모습이 더 보기 좋고 건강해 보인다고 믿는 경향이 컸다.

2002년 기사[^2]가 전한 미국 청소년 조사에서 지난여름 햇볕에 여러 번 덴 응답자의 절반은 뒤따르는 그을린 피부를 얻을 만한 값어치가 있었다고 답했다.

2002년 연구[^3]의 영국 학생 조사에서 피부를 태우고 싶어서 피부를 보호하지 않았다고 답한 학생은 다른 이유를 든 학생보다 햇볕에 덴 일을 더 많이 보고했다.

2018년 6월 지식iN 게시글[^4]의 글쓴이는 흰 피부 때문에 약해 보이고 남자다움이 떨어지는 것 같다며 남자다운 구릿빛 피부를 갖고 싶어서 태닝도 해 보았다고 썼다.

2024년 연구[^5]에서 많은 젊은 여성은 고등학교 졸업 무도회나 결혼식 같은 특별한 행사를 앞두고 실내 태닝을 시도한다.

2026년 자료[^6]의 미국 성인 조사에서 지난 1년 사이 햇볕에 덴 사람의 15.9%는 가장 최근에 덴 때가 일부러 피부를 태우던 중이었고 이 상황은 물놀이(60.6%), 운동(24.7%), 음주(17.6%) 다음이었다.
