# 벼락치기

별칭: Cramming[^2]

시험을 앞둔 학생이 공부를 미루다가 시험 직전에 몰아서 외운다.

묶음: [걱정과 기분](../groups/worry-and-mood.md)

# 서술

1861년 소설에서 옥스퍼드 졸업시험을 치르는 학생은 자기가 저지른 실수를 곱씹으며 다음 날을 바라고 밤을 거의 새워 몰아서 외웠다.[^1]

2008년 연구[^2]는 대학 기말시험 벼락치기가 흔하다고 적었고 마케팅원론 수강생 가운데 여럿이 그 과목 기말시험도 벼락치기로 준비하는 것으로 보았다. 2009년 10월 재경일보 기사[^3]가 전한 설문에서 평소 꾸준히 준비하는 쪽과 시험 때 몰아서 하는 쪽 가운데 벼락치기형을 고른 중학교 3학년은 88%였다.

2016년 아일랜드 의대생 연구[^4]에서 학생의 47.1%는 시험을 통과하려고 막판 벼락치기에 기댔다.
