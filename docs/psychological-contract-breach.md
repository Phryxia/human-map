# 심리적 계약 위반 지각

별칭: Psychological contract breach, 입사 전 약속과 다른 조건

직원이 회사가 고용 때 약속한 의무를 지키지 않았다고 느끼고 회사를 덜 믿게 된다.

# 서술

1994년 Robinson·Rousseau 의 조사에서 위반을 겪은 응답자일수록 이직이 많았고 신뢰, 만족, 남으려는 의도가 낮았다.[^1]

2024년 뉴시스 기사에 실린 제보에서 한 직장인은 급여일이 되어서야 근로계약서를 썼고 연봉이 처음 구두로 약속한 것과 크게 달라 항의했다고 적었다.[^4]

2007년 Zhao 외의 메타분석에서 계약 위반이 태도와 개인의 효과성에 미치는 영향은 정서를 거쳐 나타났다.[^2]

2022년 Balikçi·Uğurlu 는 지각된 계약 위반이 체념에서 나오는 침묵과 방어적 침묵에 양의 효과가 있다고 보고했다.[^3]
