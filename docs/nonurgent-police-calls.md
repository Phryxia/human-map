# 경찰 긴급번호 비긴급 신고

별칭: 없음

긴급하지 않은 일을 겪은 사람이 경찰이 해결해 주리라 여기고 112나 999 같은 경찰 긴급번호에 전화한다.

묶음: [시민 참여와 공공의 일](../groups/civic-life.md)

# 서술

2015년 매일신문 기고[^1]에서 대구지방경찰청 종합상황실 팀장은 경찰관이 모든 일을 해결해 주리라 믿고 신고하는 경우가 아직 많다고 적었다.

2025년 11월 런던 경찰청 보도자료[^2]에 따르면 배달 기사가 오지 않아 답답해하는 사람과 방에 거미가 있다는 사람이 999 상담원에게 전화했다.
