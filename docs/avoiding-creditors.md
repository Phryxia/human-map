# 빚 독촉 피하기

별칭: 추심 연락 회피, 빚쟁이 피하기, debt avoidance

빚을 진 사람이 채권자의 전화, 편지, 방문을 받지 않거나 채권자와 마주치지 않으려고 피하는 행동이다.

# 서술

1866년 도스토옙스키의 소설에서 라스콜니코프는 하숙집 여주인에게 빚이 많아 그와 마주치기를 두려워한다. [F1]

2003년 경향신문 기사에서 추심원은 채권팀 전화번호가 발신자 표시에 뜨면 연체자들이 아예 받지 않는다고 말했다. [F2]

2017년 Custers 는 많은 소비자가 채권자의 연락 시도를 피하고 편지를 열지 않거나 전화를 받지 않는다고 적는다. 2026년 Reynal 은 한 내담자가 채권자 편지를 몇 달 동안 열지 않았다고 적는다. [F3][F5]

# 조건

2022년 Dewies 등의 로테르담 현장 실험에서 상환 안내 편지를 받은 채무자의 다수가 기한 안에 응답하지 않았다. [F4]

2017년 F3 는 연락 회피를 채권자의 압박에 대한 감정 반응의 결과로 적는다. 2026년 F5 의 내담자는 상황이 감당할 수 없을 만큼 나쁠 것이라고 확신해 편지를 미뤘다. [F3][F5]
