# 여행지에서 엽서 보내기

별칭: 없음

여행 중인 사람이 여행지에서 고향의 가족이나 친구에게 그림엽서를 써서 부친다.

묶음: [가까운 사이의 감정과 말](../groups/close-relationships.md)

# 서술

1920년 싱클레어 루이스의 소설에서 캘리포니아를 여행한 부부는 고향 마을로 기념 그림엽서 117장을 부쳤다.[^1]

1922년 같은 작가의 소설에서 출장지 호텔에 묵은 아버지는 딸에게 아빠와 함께 놀러 다니면 좋겠다는 한 줄을 적은 엽서를 보냈다.[^2]

2019년 연구[^3]의 저자는 휴가 중의 일과 관광의 장면을 짧게 담은 엽서가 사람들이 낯선 곳에서 이동하는 자신을 어떻게 기록하는지 보여 주는 자료라고 적는다.

2026년 에세이[^4]의 필자는 여행 중 심심한 밤이나 커피숍에서 쉬는 틈에 그때 생각나는 사람에게 엽서를 썼다.
