# 외국어 말하기 불안

별칭: 영어 울렁증[^1]

외국어를 배운 사람이 그 말로 말해야 하는 자리에서 긴장하고 실수와 남의 평가를 두려워한다.

묶음: [남의 시선과 창피함](../groups/others-gaze.md)

# 서술

2008년 코메디닷컴 기사[^1]는 외국인 앞에만 서면 괜히 긴장하고 목소리가 갈라지는 현상을 다뤘다.

2017년 Hacker News 댓글[^2]의 글쓴이는 20년에 걸쳐 프랑스어와 스페인어를 익혔고 제2 언어를 배우는 사람이 서툰 자신을 부끄러워하고 어색해한다고 썼다.

2024년 연구[^3]에서 학습자들이 꼽은 불안의 첫 원천은 완벽한 영어로 말해야 한다는 믿음과 실수하면 부정적 평가를 받고 또래에게 거부당할 수도 있다는 믿음이었다.
