# 장 볼 때 필요보다 많이 사기

별칭: 없음

장을 보는 사람이 집에서 다 먹지 못할 만큼 식료품을 사고 남은 것을 버린다.

# 서술

2011년 신문 기사[^1]에 실린 음식물쓰레기 줄이기 사례는 많이 사서 냉장고에 넣어 두었다가 유통기한이 지나 버리는 일이 많아 장을 볼 때 되도록 적게 산다고 적었다. 2012년 서울시 기사[^2]는 끼워 주기 상품이 양에 비해 싸게 느껴지지만 다 먹지 못하고 유통기한을 넘겨 버리는 경우가 많다고 전했다.

2015년 싱가포르 환경청 조사[^3]에서 참가자 다수는 장보기 목록이나 식단 대신 행사 상품 같은 충동에 따라 장을 본다고 말했다.

2019년 6월 Hacker News 댓글[^4]의 글쓴이는 식단을 짜고 일주일에 한 번 장을 보면 다 먹지만 느슨하게 하면 너무 많이 사서 버리게 된다고 썼다. 2019년 9월 네덜란드 연구[^5]에서 매장에서 너무 많이 사는 것 같은 장보기 행동에 기댈수록 버리는 음식이 늘었다. 2019년 12월 싱가포르 환경청 조사[^6]에서 응답자의 약 4분의 1은 장을 볼 때 필요보다 많이 산다고 답했고 가장 많이 든 이유는 식구가 넉넉히 먹어야 한다는 걱정이었다.

2021년 영국 소비자단체 조사[^7]에서 회원 1,362명 가운데 45%는 크리스마스 음식을 너무 많이 사서 남았다고 답했고 14%만 음식이나 음료가 모자랐다고 답했다.
