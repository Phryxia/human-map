# 헌혈 꺼림

별칭: 헌혈 망설임, 헌혈 기피, 헌혈 두려움

헌혈할 수 있는 나이의 사람이 헌혈을 무서워하거나 꺼려 헌혈하지 않는다.

# 서술

2018년 F1 의 영국 조사에서 18~24세의 81%가 헌혈한 적이 없었고 이 연령대의 35%는 헌혈이 무섭다고 인정했다. [F1]

2026년 F2 의 가나 동부 지역 학생 2,200명 조사에서 40.3%는 자발적으로 헌혈할 의사가 없었다. [F2]

# 조건

기록된 조건 없음. [F1][F2]
