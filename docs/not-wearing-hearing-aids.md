# 보청기 쓰지 않기

별칭: 없음

청력이 떨어진 사람이 보청기가 도움이 될 만한데도 보청기를 쓰지 않는다.

# 서술

2024년 미국 국립 난청·의사소통장애 연구소 통계[^1]에서 보청기가 도움이 될 만한 청력 손실을 가진 70세 이상 성인 가운데 보청기를 써 본 사람은 30%였다.

2025년 한국 기사[^2]는 국내 난청 환자 상당수가 보청기를 낀 모습을 드러내기 꺼리고 비용을 부담스러워해 보청기 착용을 망설인다고 썼다.
