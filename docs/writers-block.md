# 글 막힘

별칭: Writer's block[^2]

글을 쓰려는 사람이 첫 문장이나 다음 문장을 쓰지 못하고 빈 종이나 화면 앞에서 오래 머문다.

# 서술

1891년 기싱의 소설에서 원고를 써야 하는 소설가는 책상에 앉아 빈 종이를 바라보며 절망했다.[^1]

1998년 논문[^2]은 글이 막힌 상태를 쓰지 못해 몹시 불편한 상태로 정의하고 그 상태가 직업상의 생산성에 지장을 줄 수 있다고 적었다.

2026년 에세이[^3]의 필자는 빈 화면 앞에서 한 시간을 보내는 동안 커서가 같은 자리에서 깜빡였고 첫 문장을 끝내 쓰지 못했다고 적는다.
