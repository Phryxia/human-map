# 문손잡이와 버튼 맨손으로 만지지 않기

별칭: 없음

공공장소에 있는 사람이 세균이 묻을까 봐 문손잡이나 엘리베이터 버튼을 맨손으로 만지지 않고 종이타월, 소매, 발, 엉덩이로 열거나 누른다.

묶음: [건강과 위험](../groups/health-and-safety.md)

# 서술

2007년 12월 msnbc.com 기사[^1]는 소매를 손 위로 끌어내려 문을 열고 버스와 지하철, 비행기에서 몰래 손을 소독하는 사람들을 전했다. 2008년 12월 Straight Dope 게시판 댓글[^2]의 글쓴이는 종이타월로 화장실 문을 열 때가 있고 그것은 앞서 쓴 사람들이 손을 씻었으리라 얼마나 믿는지와 화장실 구조가 얼마나 편한지에 달렸다고 썼다.

2016년 6월 기사[^3]가 전한 미국 설문에서 응답자들은 변기 물을 발로 내리고 화장실 문과 수도꼭지 손잡이를 종이타월로 만지며 문을 엉덩이로 여닫는다고 답했다. 2018년 6월 클리앙 댓글[^4]의 글쓴이는 공중화장실에서 휴지로 손을 닦고 그 휴지로 문을 연 뒤 발로 문을 받치고 나온다고 적었다.

2021년 1월 이란 온라인 조사[^5]에서 응답자 1,414명(67.4%)이 엘리베이터 버튼을 맨손으로 만지지 않는다고 답했다. 2021년 4월 미국 조사[^6]는 공중화장실에서 다른 표면을 만질 때 종이타월로 코로나19 바이러스를 피할 수 있어 종이타월로 손을 말리는 쪽을 고른다는 문항을 응답자에게 물었다.
