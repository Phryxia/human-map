# 출산 앞둔 둥지 짓기

별칭: Nesting instinct[^2]

출산을 앞둔 임신부와 예비 부모가 아기를 맞으려고 집을 치우고 정리하고 공간을 준비하려는 충동을 느낀다.

묶음: [가까운 사이의 감정과 말](../groups/close-relationships.md)

# 서술

2013년 Anderson 과 Rutherford 의 연구[^1]에서 여성들은 공간 준비와 사람을 가려 만나는 행동을 보였고 이 행동은 임신 3분기에 가장 강했다.

2024년 Cleveland Clinic 의 건강 정보 글[^2]은 이 충동을 새 아기를 맞으려고 집을 준비하려는 욕구라고 설명했다.
