# 학습된 무력감

별칭: 학습된 무기력, learned helplessness

피할 수 없는 나쁜 일을 겪은 사람이 나중에 그 일을 피하거나 바꿀 수 있을 때에도 시도하지 않는다.

# 서술

2016년 연구[^1]의 저자들은 사람을 대상으로 한 실험에서 피할 수 없는 조건에 짝지어진 집단의 다수가 이후 셔틀박스에서 소음을 피하지 못했다고 옮긴다.

2023년 글[^2]의 칼럼은 직장을 구하려고 여러 번 애썼는데 구하지 못한 사람이 새 직장 구하기를 포기하고 학습된 무력감에 빠질 수 있다고 적는다.

2024년 연구[^3]의 저자들은 오래 실업 상태에 있는 사람이 더 무감해지고 통제를 되찾으려는 노력과 자기 미래를 능동적으로 그리는 일을 덜 한다고 쓴다.

# 조건

2016년 연구[^1]에서 소음을 피할 수 있었던 집단과 소음을 받지 않은 집단은 셔틀박스에서 소음을 잘 피했다.
