# 초상집 시계 멈추기

별칭: 없음

사람이 집안에 죽은 이가 생기면 집 안의 시계를 멈춰 둔다.

묶음: [혼자 있음과 상실](../groups/solitude-and-loss.md)

# 서술

에든버러 왕립 의사회의 소장품 글[^1]은 죽은 시각에 시계를 멈추는 일이 거울을 덮는 일과 함께 나쁜 영을 막으려는 의례였다고 적었다.

영국 고시계 학회의 블로그 글[^2]은 죽은 사람의 집에서 시계를 멈춰 소리를 죽이는 일을 블라인드나 커튼을 치고 거울을 덮는 일과 비슷한 오래된 전통으로 소개했다.
