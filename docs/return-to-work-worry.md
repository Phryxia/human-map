# 복직 앞의 걱정

별칭: 없음

육아휴직이나 출산휴가를 마치고 직장에 돌아갈 사람이 아이 돌봄과 업무 적응, 동료의 시선을 걱정한다.

묶음: [일터와 일자리](../groups/work.md)

# 서술

2010년 경남신문 기사[^1]에서 회사 복귀를 앞둔 한 어머니가 가장 크게 고민한 것은 아이들의 육아였다.

2021년 블라인드 게시글[^2]의 글쓴이는 일이 하고 싶어 복직하면서도 아이가 잘 견딜지와 집안이 어떻게 돌아갈지를 걱정했다. 2023년 서울시 글[^3]은 육아휴직자의 복직에 대한 두려움을 없애려고 복직자 업무적응 교육을 추진한다고 밝혔다. 2024년 블라인드 게시글[^4]의 글쓴이는 눈치를 보며 휴직하는 중이고 이듬해 복귀를 잘 할 수 있을지 걱정된다고 썼다.

2025년 간호사 복직 연구 검토[^5]에서 일부 참가자는 직장 복귀를 두고 커진 스트레스와 불안, 걱정을 보고했다. 2026년 아일랜드 보건서비스청 안내문[^6]은 복귀하는 부모가 안도, 죄책감, 슬픔, 설렘이 섞인 감정을 느낄 수 있다고 적었다.
