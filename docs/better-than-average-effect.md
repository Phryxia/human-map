# 평균 이상 효과

별칭: 우월 착각, 워비곤 호수 효과, Better-than-average effect, Illusory superiority

사람이 자기 능력과 성격을 같은 처지의 평균적인 사람보다 낫다고 평가한다.

# 서술

2012년 글[^1]이 전한 연구에서 학생들은 정직과 끈기 같은 좋은 특성은 평균 학생보다 자기에게 훨씬 더 있다고 평가했고 나쁜 특성은 덜 있다고 평가했다.

2020년 메타분석[^2]에서 이 효과는 능력보다 성격 특성에서, 나쁜 면보다 좋은 면에서 더 컸다.
