# 집배원 오기를 기다리기

별칭: 없음

편지를 기다리는 사람이 우편이 배달되는 때마다 창밖이나 길을 살피며 집배원이 오기를 기다린다.

묶음: [걱정과 기분](../groups/worry-and-mood.md)

# 서술

1871년 소설[^1]에서 광고에 답이 오리라 굳게 기대한 인물은 아침 식사 때 집배원이 답장 없이 지나가는 모습을 또 보았다.

2001년 기사[^2]는 군대 간 애인의 편지를 기다리는 아가씨들이 우체부의 모습만 봐도 가슴이 두근거렸다고 적었다. 2009년 3월 기사[^3]의 글쓴이는 창문으로 집 밖을 기웃거리며 우편배달부를 기다리던 일을 더없는 행복으로 떠올린다.

2009년 8월 게시글[^4]의 글쓴이는 인터넷이 퍼진 뒤로 편지가 온 적이 없는데도 우편이 오면 여전히 달려간다고 썼다.

2014년 백과 항목[^5]은 1차대전 동안 집에 남은 민간인이 사랑하는 남자가 아직 다치지 않았다는 안심을 정기 우편 배달에 기댔다고 적었다.

2026년 블로그 글[^6]의 글쓴이는 예전에 우체부가 골목으로 들어오면 괜히 창밖을 내다보곤 했다.
