# 동료의 냄새 거슬려 하기

별칭: 없음

직장인이 함께 일하는 사람의 몸 냄새나 담배 냄새를 견디기 힘들어한다.

묶음: [일터와 일자리](../groups/work.md)

# 서술

2010년 정책브리핑 기사[^1]가 전한 직장인 703명 조사에서 응답자 10명 가운데 6명 정도가 담배 냄새가 몸에 밴 직원을 볼 때 참을 수 없다고 답했다.

2012년 SHRM 기사[^2]는 직원들이 몸 냄새가 나는 동료를 남의 아이디어를 가로채는 동료만큼 싫어한다고 적었다.

몸과 입 냄새를 안고 사는 사람들을 조사한 2024년 연구[^3]에서 한 응답자는 사무실 동료들이 자기 자리 주위에 방향제를 뿌리고 일부러 옆에 앉지 않는다고 답했다.

2026년 게시판 댓글[^4]의 글쓴이는 동료가 머리를 잘 감지 않아 냄새가 역한데 몇 달째 말도 못 하고 있다고 썼다.
