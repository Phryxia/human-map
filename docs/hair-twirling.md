# 머리카락 배배 꼬기

별칭: Hair twirling[^2]

긴장하거나 멍하니 있는 사람이 무심코 손가락으로 자기 머리카락을 돌리거나 감는다.

묶음: [걱정과 기분](../groups/worry-and-mood.md)

# 서술

1898년 소설[^1]에서 한 소녀는 손님을 바라보고 서서 손가락에 머리카락 한 가닥을 감았다 풀었다 했다.

2001년 연구[^2]에서 한 어린아이의 머리 꼬기는 주로 잠자리에 혼자 있을 때 일어났다.

2007년 게시판 댓글[^3]의 글쓴이는 이상한 신경성 습관을 묻는 글에 자기도 머리를 꼰다고 답하고 몇 년 동안 머리를 묶고 다니던 때 붙은 버릇이라고 적었다.

2023년 기사[^4]는 긴장하는 순간에 손톱을 물어뜯거나 머리카락을 배배 꼬는 사람들이 있다고 썼다.

2025년 기사[^5]는 회의 시간이나 대화 중, 혼자 멍하니 있을 때 손이 머리로 가서 머리카락을 돌리거나 감는 행동을 적었다.
