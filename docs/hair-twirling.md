# 머리카락 배배 꼬기

별칭: Hair twirling[^1]

긴장하거나 멍하니 있는 사람이 무심코 손가락으로 자기 머리카락을 돌리거나 감는다.

묶음: [걱정과 기분](../groups/worry-and-mood.md)

# 서술

2001년 연구[^1]에서 한 어린아이의 머리 꼬기는 주로 잠자리에 혼자 있을 때 일어났다.

2023년 기사[^2]는 긴장하는 순간에 손톱을 물어뜯거나 머리카락을 배배 꼬는 사람들이 있다고 썼다.

2025년 기사[^3]는 회의 시간이나 대화 중, 혼자 멍하니 있을 때 손이 머리로 가서 머리카락을 돌리거나 감는 행동을 적었다.
