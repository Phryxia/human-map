# 낯선 곳에서 깨어 어디인지 모르기

별칭: 없음

낯선 방에서 자고 깬 사람이 잠깐 자기가 어디에 있는지 몰라 당황하다가 곧 지난 일을 떠올린다.

묶음: [기억과 떠오르는 생각](../groups/memory-and-thoughts.md)

# 서술

1841년 디킨스의 소설에서 아이는 낯선 방에서 깨어 놀라 일어나고 어젯밤 잠든 익숙한 방에서 어떻게 옮겨졌는지, 어디로 실려 왔는지 궁금해한다.[^1] 1868년 앨저의 소설에서 소년은 새로 얻은 방에서 깨어 팔꿈치를 짚고 잠깐 어리둥절하게 주위를 둘러본 뒤 자기가 어디 있는지 잊었다고 혼잣말을 했다.[^2]

1895년 하디의 소설에서 남자는 깨어 처음에는 어디인지 몰랐고 차츰 자기 처지를 알아차렸다.[^3]

2024년 수면 건강 앱 Pillow 의 글은 호텔처럼 새로운 곳에서는 뇌가 위치를 다시 맞추는 데 몇 초가 걸린다고 썼다.[^4]
