별칭: 없음

# 서술

2022년 F1 의 댓글 글쓴이는 옆집 어르신들에게 몇 번 인사해도 본체만체해서 이제 인사하지 않는다고 썼다. 글쓴이는 서로 그쪽이 속 편할 것 같다고 덧붙였다. [F1]

2025년 F2 의 기사에서 50대 직장인은 엘리베이터에서 같은 층 이웃에게 인사했는데 아무 반응이 없었다고 말했다. 그는 너무 머쓱해서 그 뒤로 되도록 아는 체하지 않는다. [F2]

# 조건

2022년 F1 의 이웃은 옆집에 사는 어르신들이고 2025년 F2 의 이웃은 엘리베이터에서 마주친 같은 층 주민이다. [F1][F2]
