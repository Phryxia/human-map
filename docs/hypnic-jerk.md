# 잠들 무렵 움찔하며 깨기

별칭: Hypnic jerk[^2], Sleep starts[^3]

막 잠들려는 사람이 몸이 떨어지거나 중심을 잃는 듯한 느낌과 함께 움찔하며 깬다.

묶음: [시간과 하루 습관](../groups/daily-time.md)

# 서술

1936년 김유정의 수필[^1]에서 앓아누운 글쓴이는 허공에 떠오른 몸이 중심을 잃고 삐끗하는 느낌에 아찔해 눈을 떴고 그사이 잠이 좀 들었던 것을 알았다.

2025년 1News 가 다시 실은 The Conversation 글[^2]은 이 움찔함에 떨어지거나 발이 걸려 넘어지는 느낌이 흔히 따르고 약 70% 가 언젠가 이것을 겪는다고 추정한다. 2026년 Grünberger 등의 조사[^3]에서 응답자 65.62% 가 떨어지거나 균형을 잃는 감각을 보고했다.
