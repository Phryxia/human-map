# 모금 요청 방식에 대한 거부감

별칭: 없음

기부를 요청받는 사람이 거리나 집 앞에서 기부를 권하는 것 같은 모금 방식을 싫어한다.

# 서술

2009년 캐나다 통계청 조사 요약[^1]에서 상당수의 기부자는 기부를 요청하는 방식이 마음에 들지 않았다고 답했다.

2015년 댓글[^2]의 글쓴이는 영국의 거리 모금원이 이름난 자선단체를 위해 일하면서 집 앞과 번화가에서 사람들을 괴롭히고 공격적으로 가입을 권한다고 썼다.
