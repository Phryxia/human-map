# 태풍 앞두고 유리창에 테이프 붙이기

별칭: 없음

태풍이나 허리케인이 오기 전에 사람들이 유리창에 테이프를 X자로 붙이거나 젖은 신문지를 붙인다.

묶음: [건강과 위험](../groups/health-and-safety.md)

# 서술

2002년 게시판 댓글[^1]의 글쓴이는 데이드 카운티에서 자라며 어릴 때 이 대비 절차를 여러 번 겪었고 창에 붙이는 테이프가 그 절차의 일부였다고 회상했다.

2012년 경기일보 칼럼[^2]에 따르면 젖은 신문지가 유리창 파손을 막는 데 도움이 된다는 정보가 빠르게 퍼지자 아파트마다 유리창에 신문지를 붙였다.

2015년 서울시 자료[^3]는 국립재난안전연구원의 강풍 실험에서 젖은 신문지나 X자 테이프보다 유리와 창틀 이음새를 테이프로 붙이는 방법이 더 효과적이었다고 전했다. 2019년 학회 초록[^4]에 따르면 2018년 태풍 망쿳 때 홍콩 응답자 45%가 창문에 테이프를 붙였고 이것이 가장 흔한 대비였다. 2023년 미국 해양대기청 안내문[^5]은 테이프를 붙이면 날아온 물체에 맞아도 유리창이 깨지지 않는다는 생각을 미신이라 부른다.
