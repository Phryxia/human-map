# 소득 상실 우려

별칭: 생계 걱정, Fear of losing pay

아프거나 다친 근로자가 일을 쉬면 소득이나 일자리를 잃을까 걱정한다.

# 서술

2013년 F1 의 식당 종사자 조사에서 아픈 채 일하기로 한 이유로 가장 많이 나온 것은 식당에 유급 병가나 병가 제도가 없다는 것이었고 43%가 이를 들었다. [F1]

2021년 F2 의 기고문은 미국 조사에서 몸이 아파도 출근하는 이유의 60%가 경제적인 이유였다고 전했다. [F2]

2022년 F3 의 국회의원 기고문은 국내 연구를 들어 아픈 노동자가 급격한 소득 감소로 치료를 받거나 쉬지 못한다고 적었다. 2023년 F4 의 기사는 근로자가 질병이나 부상으로 오래 쉬게 될 때 가장 먼저 하는 걱정이 생계라고 적었다. [F3][F4]

# 조건

2013년 F1 은 유급 병가나 병가 제도가 없는 식당에서 일하는 사람들의 응답이다. [F1]

2023년 F4 는 질병이나 부상으로 장기간 일을 쉬게 되는 경우를 말한다. [F4]
