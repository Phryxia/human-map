# 소득 상실 우려

별칭: 없음

아프거나 다친 근로자가 일을 쉬면 소득이나 일자리를 잃을까 걱정한다.

# 서술

2013년 연구[^1]의 식당 종사자 조사에서 아픈 채 일하기로 한 이유로 가장 많이 나온 것은 식당에 유급 병가나 병가 제도가 없다는 것이었고 43%가 이를 들었다. 2017년 연구[^2]의 저자들은 일자리를 잃을까 두려워 아픈 채 출근하는 일이 근로자들 사이에 흔하다고 적었다.

2021년 글[^3]의 기고문은 미국 조사에서 몸이 아파도 출근하는 이유의 60%가 경제적인 이유였다고 전했다.

2022년 글[^4]의 국회의원 기고문은 국내 연구를 들어 아픈 노동자가 급격한 소득 감소로 치료를 받거나 쉬지 못한다고 적었다. 2023년 글[^5]의 기사는 근로자가 질병이나 부상으로 오래 쉬게 될 때 가장 먼저 하는 걱정이 생계라고 적었다.

2013년 연구[^1]는 유급 병가나 병가 제도가 없는 식당에서 일하는 사람들의 응답이다.

2023년 글[^5]은 질병이나 부상으로 장기간 일을 쉬게 되는 경우를 말한다.
