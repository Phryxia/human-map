# 벌초 대행 맡기기

별칭: 없음

조상의 묘를 둔 사람이 벌초를 직접 하지 않고 조합이나 업체에 돈을 주고 맡긴다.

묶음: [혼자 있음과 상실](../groups/solitude-and-loss.md)

# 서술

2017년 Chang 등의 조사[^1]에서 벌초를 맡긴 이유는 대부분 맡긴 사람이 묘에서 멀리 산다는 것이었다.

2026년 9월 KNN 보도[^2]에서 밀양의 한 마을 이장은 핵가족이 되고 후손이 줄면서 벌초 대행이 많이 늘었다고 말했다.
