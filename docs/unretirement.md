# 은퇴 번복

별칭: Unretirement[^1]

은퇴한 사람이 일을 그만둔 뒤 다시 일자리로 돌아간다.

묶음: [일터와 일자리](../groups/work.md)

# 서술

2010년 Maestas 의 연구[^1]에서 은퇴자의 50% 가까이가 부분 은퇴나 은퇴 번복을 거쳤고 적어도 26%는 은퇴한 뒤 다시 일했다.

2022년 6월 Fortune 기사[^2]가 옮긴 CNBC 조사에서 팬데믹 동안 은퇴한 노동자의 68%가 다시 일하러 돌아오는 것을 생각해 보겠다고 답했다.

2024년 11월 Hacker News 댓글[^3]의 글쓴이는 지쳐서 회사를 팔고 은퇴했다가 지루해져 다시 일로 돌아갔다고 썼다.

2025년 5월 한국은행 보고서를 소개한 KDI 경제교육·정보센터 자료[^4]에서 은퇴한 뒤 자영업자가 된 고령 근로자 상당수는 임금근로보다 더 오래 일할 수 있으리라 기대하고 자영업을 골랐다.

2026년 2월 AARP 보도자료[^5]가 전한 50세 이상 조사에서 은퇴자의 7%가 지난 6개월 사이 다시 노동시장에 들어왔다.
