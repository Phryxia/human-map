# 휴일에 나타나는 몸의 증상

별칭: Sunday neuroses[^1], leisure sickness[^2]

평일에 일하는 사람이 주말이나 휴가 같은 쉬는 날에 두통, 피로, 메스꺼움 같은 몸의 증상을 겪는다.

# 서술

1926년 영어로 옮겨 나온 Ferenczi 의 글[^1]에서 저자가 치료한 신경증 환자 다수는 주기적으로 되돌아오는 증상을 일요일에 겪었다.

2002년 네덜란드 조사[^2]에서 남성 응답자의 3.6%와 3.2%가 각각 주말 증후군과 휴가 증후군의 설명에서 자기 모습을 알아보았고 여성은 2.7%와 3.2%였다.

2018년 4월 patient.info 기사[^3]는 휴일이나 주말에 아픈 일을 일부 보건 전문가가 leisure sickness 라 부른다고 썼다.
