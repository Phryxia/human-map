# 외국인에게 크고 느리게 말하기

별칭: Foreigner talk[^3]

모국어 화자가 말이 서툰 외국인에게 말할 때 목소리를 키우고 낱말을 길게 끌어 말한다.

묶음: [낯선 사람과 공공장소](../groups/strangers-and-public-places.md)

# 서술

1857년 디킨스의 소설[^1]에서 블리딩 하트 야드의 주민들은 영어가 서툰 이탈리아인 세입자에게 귀가 아주 먹은 사람에게 하듯 큰 소리로 말했다.

2014년 대학 신문 기사[^2]의 필자는 다른 나라에서 그 나라 말을 전혀 못 하면서 침대 시트 일로 접수 직원에게 소리치면 된다고 여긴 영국인 일행을 적었다.

2018년 연구[^3]에서 원어민은 비원어민 청자에게 말할 때 원어민 청자에게 말할 때보다 낱말의 길이와 세기를 늘렸다. 같은 대상을 다시 가리키며 낱말을 줄여 말하는 정도는 청자가 원어민이든 비원어민이든 같았다.
