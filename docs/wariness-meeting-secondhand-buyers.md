# 중고 직거래 상대를 만나는 부담

별칭: 없음

온라인으로 중고 물건을 사고파는 사람이 처음 보는 거래 상대를 직접 만나는 일을 부담스러워하고 사람이 많은 곳에서 만나려 한다.

# 서술

2015년 기사[^1]에서 기자가 여러 사람에게 들은 말은 익명의 온라인 거래를 조심하고 상대에 대해 되도록 많이 알아 두며 늘 공공장소에서 만나라는 것이었다.

2023년 서울시 기사[^2]는 온라인에서 알게 된 낯선 사람과 만나 물건을 사고파는 일이 부담일 수밖에 없다고 썼다.
