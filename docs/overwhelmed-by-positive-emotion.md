# 벅찬 감정에 압도되기

별칭: 없음

아주 귀엽거나 기쁜 것을 마주한 사람이 감당하기 어려울 만큼 강한 긍정 감정에 휩싸인다.

# 서술

1929년 김동인의 소설[^1]에서 칭찬을 들은 송 서방은 너무 기뻐서 가슴이 답답해졌고 칼 맞은 자리의 아픔도 잊었다.

2014년 미국 심리과학회 보도자료[^2]는 Aragón 외의 연구에서 귀여운 것에 대한 공격적인 반응을 이끈 것이 긍정 감정에 압도되는 느낌이었다고 전했다.

2018년 Stavropoulos 와 Alba 의 연구[^3]에서 동물과 아기 모두 귀엽다는 평가와 귀여운 공격성 사이의 관계를 압도되는 느낌이 매개했다.
