# 걸으며 휴대전화 보기

별칭: 스몸비, 보행 중 스마트폰 사용, Distracted walking

걷는 사람이 길을 가거나 길을 건너면서 휴대전화 화면을 보거나 메시지를 쓴다.

# 서술

2017년 서울시 교통 누리집 글[^2]은 교통안전공단 조사에서 성인의 95.7%가 보행 중 스마트폰을 쓴다고 답했다고 적는다. 2018년 서울시 글[^3]은 국민안전처 자료를 들어 보행 중인 사람의 33%가 스마트폰을 썼다고 전한다.

2026년 일본 세타가야구 누리집[^4]은 도쿄소방청 관할에서 2021년부터 2025년까지 걸으며 또는 자전거를 타며 스마트폰 화면을 보다 난 사고로 171명이 구급 이송됐다고 적는다.

# 조건

2018년 서울시 글[^3]에서 스마트폰을 쓰는 비율은 걷는 중 33%, 횡단보도를 건널 때 26%였다.

2012년 가상 횡단 실험[^1]에서 문자를 보내거나 음악을 들으며 길을 건넌 참가자는 아무것도 하지 않은 참가자보다 가상 차량에 더 자주 치였다.
