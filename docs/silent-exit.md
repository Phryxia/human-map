# 조용한 이탈

별칭: 말없이 떠나기, Silent defection, Exit without voice

상품이나 서비스에 불만을 느낀 소비자가 판매자에게 말하지 않고 다시 사지 않거나 다른 곳으로 옮긴다.

# 서술

2015년 F3 의 Beard 등은 불만을 품은 소비자 일부가 그 상품이나 서비스를 더 사지 않는 쪽을 택하고 다른 소비자는 불평으로 실망을 드러낸다고 적었다. [F3]

2006년 F2 의 애리조나 주립대 경영대학 소식은 불만을 받는 절차가 수동적이면 고객이 말없이 경쟁사로 넘어간다고 썼다. [F2]

2016년 F4 의 리뷰 관리 업체 블로그는 자체 설문에서 나쁜 경험을 한 사람의 40% 넘게가 다시 오지 않고 무엇이 잘못됐는지 직접 말하지도 않는다고 전했다. [F4]

2006년 F1 의 기사에서 우리홈쇼핑은 불만을 제기한 고객의 재구매율이 불만을 제기하지 않은 고객보다 높다는 자체 분석을 밝혔다. [F1]

# 조건

2006년 F2 는 판매자가 불만을 받는 절차가 수동적일 때를 조건으로 든다. [F2]

2006년 F1 과 2016년 F4 의 수치는 판매자와 업체가 스스로 낸 분석과 설문에서 나왔다. [F1][F4]
