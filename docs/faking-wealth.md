# 부유한 척하기

별칭: 부자 행세, 가짜 부자, 재력 꾸미기

남에게 가난해 보이기 싫은 사람이 빌린 물건이나 연출한 사진으로 실제보다 부유해 보이게 꾸민다.

# 서술

1884년 모파상의 단편[^1]에서 무도회에 가게 된 여자는 부유한 여자들 사이에서 가난해 보이는 것만큼 굴욕적인 일은 없다고 말했다.

2022년 네이트 판 게시글[^2]의 글쓴이는 평범하게 사는데도 고등학교 1, 2학년 때 잘살아 보이고 싶어서 부자인 척 거짓말을 했다고 썼다.

2024년 Dupas 외의 실험 연구[^3]는 사람들이 더 높은 계층으로 보이려고 외모에 투자하고 소비 선택을 바꾼다고 보고했다.

2026년 기사[^4]가 전한 중국의 한 유료 서비스는 일상 사진과 연출된 여행·비즈니스 사진을 조합해 고객을 부유하거나 성공한 인물처럼 보이게 꾸몄다.

1884년 단편[^1]의 여자가 느낀 굴욕은 부유한 여자들이 모이는 자리를 앞두고 나왔다.
