# 생일을 잊혀 서운해도 내색하지 않기

별칭: 잊힌 생일의 서운함

가족이나 친구가 자기 생일을 잊었을 때 서운함을 느끼면서 그 마음을 스스로 누르거나 낮춰 말한다.

# 서술

1902년 존스턴의 소설에서 열두 살 로이드는 가족이 생일을 잊었다고 여긴다. 로이드는 가족이 생일을 잊었어도 자기를 똑같이 사랑한다는 것을 안다고 속으로 생각하며 우울한 생각이 몰려오지 못하게 하겠다고 다짐한다. [F1]

2018년 캡틴 어쿼드 상담란에 실린 편지에서 글쓴이는 친구들에게서 생일 메시지를 하나도 받지 못해 생각보다 훨씬 마음이 아팠다고 적었다. 글쓴이는 올해 모두에게 메시지를 기대한 것도 아니었다고 먼저 적었다. [F2]
