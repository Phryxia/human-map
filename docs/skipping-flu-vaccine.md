# 독감 예방접종 거르기

별칭: 독감 백신 기피

권고 대상인 사람이 필요 없다고 여기거나 부작용을 걱정해 독감 예방접종을 받지 않는다.

# 서술

1999년 F1 에서 최근 독감 예방접종을 받지 않은 메디케어 수급자의 40%쯤은 백신이 독감을 일으키거나 부작용이 있을 수 있다는 걱정을 이유로 들었다. [F1] 2023년 F3 의 기사는 일반인이 독감 예방접종을 피하는 공통된 이유로 부작용을 든다. [F3]

2011년 F2 의 폴란드 조사에서 접종하지 않은 사람이 가장 많이 든 이유는 몸 상태가 좋다는 것(27.6%)이었고 백신 효과에 대한 불신(16.8%)과 비용(9.7%)이 뒤를 이었다. [F2]

2024년 F4 이 전하는 노르웨이 연구에서 가장 많이 나온 이유는 백신이 필요 없다는 답과 특별한 이유가 없다는 답이었다. [F4]

# 조건

1999년 F1 의 응답자는 미국 메디케어 수급자이고 2024년 F4 의 응답자는 노르웨이 사람이다. [F1][F4]
