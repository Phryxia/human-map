# 말을 섞지 않으려고 시늉하기

별칭: 없음

남과 말을 나누고 싶지 않은 사람이 못 본 척, 바쁜 척, 자는 척 같은 시늉으로 대화나 응대를 피한다.

묶음: [낯선 사람과 공공장소](../groups/strangers-and-public-places.md)

# 서술

2009년 칼럼[^1]의 필자는 길에서 마주친 아는 사람이 고개를 숙이고 못 본 척하거나 갑자기 통화에 빠진 척한다고 적었다.

2012년 그레이하운드 버스 승객 연구를 전한 보도자료[^2]는 사람들이 남을 피하려고 바쁜 척하고 휴대폰을 확인하고 가방을 뒤지고 사람을 지나쳐 보거나 잠이 든다고 적었다.

2018년 연구[^3]에서 청소년 참가자들은 문자를 보내는 척한 이유로 회피, 좋은 모습 지키기, 불안한 상황에서 얻는 안도감을 들었다.
