# 서술

1859년 윌키 콜린스의 소설[^1]에서 포스코 백작은 서랍을 곧바로 닫고 팔짱을 낀 채 비꼬는 웃음을 띠고 화자의 말을 들었다.

2008년 4월 영국심리학회 리서치 다이제스트 기사[^2]가 전한 실험에서 풀 수 없는 철자 바꾸기 문제를 받은 학생 가운데 손을 허벅지에 둔 학생은 평균 30초쯤 버텼다. 팔짱을 낀 학생은 55초 가까이 매달렸다.[^2]

2015년 연구[^3]에서 평소 팔짱을 자주 낀다고 답한 사람은 대인 관계에서 더 순종적이었고 사회적 결정을 내릴 때 더 머뭇거렸다.

2022년 12월 블라인드 게시글[^4]의 글쓴이가 보고하러 가면 부장은 회의 테이블에 같이 앉지 않고 팔짱을 낀 채 서 있었다.
