# 부모가 창피함

별칭: 부모 앞에서 민망함, 가족이 부끄러움, Embarrassed by parents

자녀가 남이 보는 자리에서 부모의 말이나 행동이나 집안 모습을 창피하게 여긴다.

# 서술

1814년 소설[^1]의 화자는 패니가 부끄러워했고 다른 무엇보다 아버지를 더 부끄러워했으리라고 적었다.

2011년 영국 설문[^2]에서 참여한 10대 1,500명의 88%가 부모 때문에 자주 창피하다고 답했다.

2011년 설문[^2]의 응답자는 영국의 10대였다.

2017년 영국 설문[^3]에서 어린이 8명 가운데 1명(12%)은 부모가 전혀 창피하지 않다고 답했다.
