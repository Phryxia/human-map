# 어린 시절 장소가 작아 보이기

별칭: 없음

어른이 되어 어린 시절의 집, 학교, 동네에 다시 간 사람이 그곳이 기억보다 작다고 느낀다.

묶음: [기억과 떠오르는 생각](../groups/memory-and-thoughts.md)

# 서술

1860년 Dickens 의 수필[^1]에서 어린 시절을 보낸 마을에 돌아온 화자는 마을이 몹시 줄어들었다고 썼다.

1905년 Eugene Wood 의 글[^2]은 어린 시절의 장소가 그대로 있어도 줄어들고 초라해져 예전만큼 넓고 화려하지 않다고 적었다.

2020년 Suszek 외의 논문[^3]에 따르면 어린 시절 기억하는 방이나 학교 건물이 나중에 다시 가 보니 훨씬 작아 보였다고 말하는 사람이 드물지 않다.

2023년 에세이[^4]의 글쓴이에게 어른이 되어 본 옛집은 기억보다 훨씬 작았고 그 안에 일곱 식구가 살았던 모습이 그려지지 않았다. 2026년 5월 게시판 댓글[^5]의 글쓴이는 수십 년 만에 찾아간 국민학교를 보고 처음에 학교가 이렇게 작았나 하고 생각했다.
