# 귀벌레

별칭: 머릿속에 맴도는 노래, 비자발적 음악 심상, earworm

노래를 들은 사람의 머릿속에서 그 노래의 한 대목이 저절로 되풀이해 울린다.

# 서술

2010년 F1 의 글쓴이는 아무리 애써도 떨쳐 낼 수 없는 노래가 성가시다고 적었다. [F1]

2022년 F3 의 댓글 글쓴이는 노래를 들어야만 머릿속에 박힌 음악에서 놓여나서 하루 종일 한 곡을 반복 재생했다고 썼다. [F3]

# 조건

2014년 F2 에서 머릿속에 맴도는 노래는 대부분 성가시지 않았고 일부는 주의 분산에서 불안과 괴로움에 이르는 지장을 주었다. [F2]
