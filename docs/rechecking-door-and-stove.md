# 문과 전기 기구 다시 확인하기

별칭: checking[^3]

집을 나서는 사람이 문을 잠갔는지나 기구를 껐는지 이미 확인하고도 그것을 다시 확인한다.

묶음: [걱정과 기분](../groups/worry-and-mood.md)

# 서술

1892년 소설[^1]에서 귀중품을 맡은 인물은 상대가 방을 나가자 잠가 둔 서랍을 열어 그것이 무사한지 보고 다시 잠갔다. 그는 평소 하녀에게 맡기던 집 문단속도 그날 밤에는 직접 돌아보았다.

2000년 기사[^2]는 문을 잠갔는데도 안 잠근 것 같아 또 확인하는 사람들을 적었다.

2011년 연구[^3]가 인용한 말에서 화자는 전기레인지를 확인한 것은 기억하면서도 제대로 확인했는지, 스위치가 완전히 꺼졌는지는 기억하지 못한다.

2020년 게시글[^4]의 글쓴이는 집을 나설 때 문을 잠그고 계단을 한 층 내려간 뒤 정말 잠갔는지 다시 올라가 확인하는 버릇이 있다고 적었다.

2022년 기사[^5]는 잠들기 전 문이 잠겼는지 확인하고도 불안해서 다시 일어나는 사람이 가스 불도 끈 것을 확인하고 곧 다시 스위치와 밸브를 살핀다고 썼다.
