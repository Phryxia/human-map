# 문과 전기 기구 다시 확인하기

별칭: 문단속 재확인, 잠금 다시 확인하기, checking

집을 나서는 사람이 문을 잠갔는지나 기구를 껐는지 이미 확인하고도 그것을 다시 확인한다.

# 서술

2020년 F2 의 글쓴이는 집을 나설 때 문을 잠그고 계단을 한 층 내려간 뒤 정말 잠갔는지 다시 올라가 확인하는 버릇이 있다고 적었다. [F2]

# 조건

2011년 F1 이 인용한 말에서 화자는 전기레인지를 확인한 것은 기억하면서도 제대로 확인했는지, 스위치가 완전히 꺼졌는지는 기억하지 못한다. [F1]

# 파편

- F1 [학술] "“Yes, I remember that I did check the stove but I cannot remember if I checked it satisfactorily. Was the switch fully turned off? I cannot remember if it is safe”" (“그래, 전기레인지를 확인한 건 기억나. 그런데 제대로 확인했는지는 기억이 안 나. 스위치가 완전히 꺼졌나? 안전한지 기억이 안 나.”) — Harkin B, Rutherford H, Kessler K, "Impaired Executive Functioning in Subclinical Compulsive Checking with Ecologically Valid Stimuli in a Working Memory Task", Frontiers in Psychology 2:78, 2011-05-03, https://www.frontiersin.org/journals/psychology/articles/10.3389/fpsyg.2011.00078/full, 2026-10-20 접속
- F2 [SNS] "I have a tendency to lock the door when I leave the apartment, go down a flight of stairs, and then go back up to check if I really locked the door."
