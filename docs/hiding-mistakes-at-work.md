# 업무 실수 숨기기

별칭: 없음

일하다 실수한 사람이 비난이나 처벌을 받을까 봐 상사나 동료에게 알리지 않고 숨긴다.

# 서술

2005년 기사[^1]가 전한 조사에서 영국 노동자들은 자기가 일하며 저지른 실수의 72%가 끝내 드러나지 않는다고 답했다.

2013년 Martinez 와 Lehmann 의 연구[^2]에서 외과 전공의는 비외과 전공의보다 의료 실수를 인정하면 다른 사람들에게 가혹한 대우를 받으리라 믿는 경우가 많았다.

2015년 AHRQ PSNet 이 요약한 재향군인병원 연구[^3]에서 직원 가운데 상당한 소수는 오류를 보고하지 않겠다고 했고 가장 흔한 이유는 보복이 두렵다는 것이었다.

2026년 8월 직무 질문 게시판의 답변 댓글[^4]은 신입이 문제가 생겼을 때 혼날까 봐 상사에게 알리지 않고 혼자 해결하려 하는 일이 잦다고 적었다.
