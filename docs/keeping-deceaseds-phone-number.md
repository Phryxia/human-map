# 고인의 전화번호 지우지 못하기

별칭: 없음

가까운 사람이 죽은 뒤 남은 사람이 휴대전화에서 고인의 번호와 음성메시지를 지우지 못하고 남겨 둔다.

# 서술

2014년 게시판 댓글[^1]의 글쓴이는 2012년에 죽은 애인이 아직 연락처에 있고 2011년에 그가 남긴 음성메시지도 그대로 있다고 적는다.

2018년 기사[^2]는 사람들이 떠난 사람의 목소리를 다시 들으려고 음성메시지를 남겨 두고 일상의 말이 오간 문자 기록도 남겨 둔다고 적는다.

2023년 기사[^3]가 전한 누리꾼은 죽은 가족의 전화번호를 지우지도 못하고 '알 수 없음'으로 뜨는 프로필을 보는 일도 안타까웠다고 적었다. 2024년 논문[^4]은 사람들이 고인의 음성메시지를 저마다 다른 횟수로 듣고 어떤 사람은 그 경험을 너무 고통스럽게, 다른 사람은 위안으로 여긴다고 적는다.
