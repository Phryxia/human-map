# 암 재발 두려움

별칭: 없음

암 치료를 마친 사람이 암이 다시 생길까 봐 두려워한다.

# 서술

발행일이 적히지 않은 기사[^1]가 전한 암 생존자 설문에서 응답자의 66%가 재발에 대한 두려움과 불안을 가장 큰 정서적 어려움으로 꼽았다.

2023년 연구[^2]에서 치료를 마친 성인 암 생존자의 재발 두려움에 영향을 준 주요 요인은 두 가지 이상의 중복 암 진단과 우울 증상이었다.
