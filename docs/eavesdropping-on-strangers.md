# 낯선 사람의 대화 엿듣기

별칭: Eavesdropping[^3]

공공장소에서 사람이 가까이 있는 낯선 사람들이 나누는 대화를 몰래 귀 기울여 듣는다.

# 서술

1889년 톨스토이의 소설에서 기차 객차의 화자는 노인의 말에 관심이 생기자 더 가까이 다가갔다. 맞은편의 신경질적인 신사도 자리를 옮기지 않은 채 귀를 기울였다.[^1]

1922년 맨스필드의 단편에서 일요일마다 공원 벤치에 앉는 미스 브릴은 듣지 않는 듯 들으며 남들이 주위에서 이야기하는 동안 잠깐 그들의 삶 속에 앉아 있는 일에 자기가 꽤 능숙해졌다고 여겼다.[^2]

2024년 기사[^3]의 필자는 사람이 많은 곳에 사는 즐거움 가운데 하나로 그 사람들 모두의 말을 듣는 일을 꼽는다.
