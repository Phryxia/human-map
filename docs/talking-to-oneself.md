# 혼잣말

별칭: self-talk[^1]

혼자 있거나 생각에 잠긴 사람이 자기 자신에게 소리 내어 말한다.

# 서술

2019년 연구[^1]의 저자는 혼자 보내는 시간이 많거나 사회적으로 고립된 경험이 있으면 혼잣말이 늘어난다는 사회적 고립 가설을 검토한다.

2020년 게시글[^2]의 글쓴이는 다른 사람과 함께 있지 않은 시간이 길어지면 소리 내어 혼잣말을 하기 시작한다고 적었다.

2021년 게시글[^3]의 글쓴이는 생각할 때 소리 내어 혼잣말을 한다. 아내가 혼잣말을 이상하게 여겨서 혼자 있을 때만 한다.[^3]
