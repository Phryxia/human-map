# 또래 음주량 과대 추정

별칭: 없음

대학생이 다른 학생들이 실제보다 술을 더 많이 마시고 과음을 더 편하게 여긴다고 믿는다.

# 서술

NIAAA 의 대학 음주 안내 자료[^1]는 학생들이 대학에 오기 전부터 캠퍼스에서 과음이 널리 퍼져 있고 받아들여진다고 기대한다고 쓴다.

1993년 Prentice 와 Miller 의 연구들은 학생들이 캠퍼스의 음주 관행을 평균적인 학생보다 자신이 더 불편하게 여긴다고 믿었다고 보고했다. 저자들은 이를 다원적 무지라 부른다.[^2]

2005년 글[^3]이 전한 조사에서 학생의 70% 넘게 또래의 음주량을 실제보다 높게 어림했고 이 과대 추정은 학교의 실제 음주 수준과 상관없이 나타났다.

2009년 신행우의 한국 대학생 조사에서 응답자 다수는 친한 친구와 보통 학생이 자신보다 더 자주, 더 많이 마신다고 평가했다.[^4]

2010년 류미 등의 조사에서 폭음집단의 남녀 학생은 친한 친구의 음주 정도를 과대추정했다. 그 조사에서 지각된 음주규준은 폭음집단에서 음주 정도와 관련이 있었고 비폭음집단에서는 관련이 없었다.[^5]

2019년 연구[^6]의 1학년 대학생 조사에서 또래의 과음을 높게 어림한 학생일수록 과음을 더 자주 했고 마실 의향도 높았다.
