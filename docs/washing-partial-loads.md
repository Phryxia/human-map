# 세탁기 덜 채워 돌리기

별칭: 없음

빨래를 하는 사람이 세탁기가 다 차지 않은 채로 세탁기를 돌린다.

묶음: [시간과 하루 습관](../groups/daily-time.md)

# 서술

발행일이 적히지 않은 호주 연방과학산업연구기구 자료[^1]에서 찬물에 빨고 가득 채워 돌린다고 말한 참가자는 평균 가구보다 전기를 40%쯤 덜 썼다.

2016년 클리앙 게시글[^2]의 글쓴이는 젖은 수건과 속옷을 빨래 바구니에 모아 두면 여름에 냄새가 나서 세탁기를 반만 채워 일주일에 두 번쯤 돌리고 싶다고 썼다. 글쓴이는 같이 사는 사람이 그것을 탐탁지 않아 한다고 적었다.

2024년 6월 4일 가전 업체 보도자료[^3]가 전한 조사에서 영국 성인의 71%는 빨래가 다 차지 않았을 때도 세탁기를 쓴다고 인정했다. 같은 달 FOX Weather 기사[^4]가 전한 연구에서 소비자 대부분은 매번 세탁기 용량을 다 채운다고 말했다.
