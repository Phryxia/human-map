# 시계를 빠르게 맞춰 두기

별칭: 없음

어떤 사람들은 손목시계, 알람 시계, 자동차 시계를 실제보다 몇 분 빠르게 맞춰 둔다.

묶음: [시간과 하루 습관](../groups/daily-time.md)

# 서술

1998년 하버드 크림슨 칼럼[^1]의 필자는 손목시계를 몇 분 앞당겨 맞춰 두었다고 적었다.

2011년 게시판 댓글[^2]의 글쓴이는 자신과 남편이 손목시계, 알람 시계, 자동차 시계를 모두 조금 빠르게 맞춰 두되 몇 분만 앞당긴다고 썼다.

2018년 MEL Magazine 기사[^3]가 인용한 심리학자는 시계를 빠르게 맞춰 둔 사람이 얼마 뒤에는 그것을 알아채고 앞당긴 15분쯤을 빼고 시간을 읽기 시작한다고 말했다.

2026년 데일리닷 기사는 아버지가 시계를 10분 빠르게 맞춰 둔다는 레딧 글에 달린 댓글을 전했다. 한 댓글은 가족의 시계를 늘 10\~15분 앞당겨 두었다고 했고 다른 댓글은 어머니가 자동차 시계를 늘 10분 빠르게 두었다고 했다.[^4]
