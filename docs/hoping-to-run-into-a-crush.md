# 좋아하는 사람을 마주치려고 기다리기

별칭: 없음

좋아하는 사람을 한 번이라도 보려는 사람이 그 사람이 나타날 만한 곳에 일부러 가서 기다린다.

# 서술

1869년 Flaubert 의 소설에서 프레데릭은 아르누 부인이 있는 가게로 다가갔지만 들어가지는 않았다. 그는 그녀가 나타나기를 기다렸다.[^1]

2024년 7월 기사[^2]는 짝사랑하는 사람이 상대의 얼굴을 한 번이라도 더 보려고 그 사람이 좋아하는 카페나 자주 가는 곳을 찾아가 기다린다고 적었다. 기사는 상대를 우연히 마주친 날에는 온종일 마음이 들뜨고 끝내 나타나지 않은 날에는 아쉬움이 크게 남는다고 덧붙였다.[^2]
