# 혼자 살며 아플 때의 서러움

별칭: 없음

혼자 사는 사람이 아프거나 위급할 때 돌봐 줄 사람이 없어 서러워하거나 그때를 걱정한다.

묶음: [혼자 있음과 상실](../groups/solitude-and-loss.md)

# 서술

2008년 서울신문 기사[^1]에서 30대 독신 여성은 아플 때 혼자 있는 것만큼 서러운 일이 없고 기댈 남편이 있는 친구들이 부럽다고 말했다.

2015년 위키트리 기사[^2]는 자취생이 한밤중에 혼자 앓다가 깨면 이마를 짚어 주거나 괜찮냐고 묻는 사람이 없어 서럽다고 적었다. 같은 해 Straight Dope 게시판 댓글[^3]의 글쓴이는 어머니가 1,000마일 떨어져 살아 모든 일을 혼자 겪기가 매우 힘들다고 썼다.

2021년 서울시 복지실태조사 보도[^4]에서 1인가구가 혼자 살며 가장 곤란하다고 꼽은 것은 위급할 때 대처의 어려움 32.5%, 외로움 23.3%, 경제적 불안감 20.3% 순이었다.

2022년 주간경향 서평[^5]은 혼자 살면 아플 때 서럽다는 말이 돌볼 사람이 없다는 뜻이고 결혼하지 않겠다고 말한 여성이 숱하게 듣는 말이라고 적었다.
