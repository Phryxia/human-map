# 얹혀사는 대가로 집안일 거들기

별칭: 없음

남의 집에 얹혀 지내는 사람이 집세나 신세를 갚는 몫으로 그 집의 집안일을 맡아 한다.

# 서술

1937년 김유정의 따라지[^1]에서 누님은 불평할 거리를 찾기 시작하지만 누님 집에 얹혀 지내는 아우는 이미 마당을 쓸고 부뚜막의 그릇을 치우고 물독 뚜껑을 덮어 놓았다.

2010년 Straight Dope 댓글[^2]의 글쓴이는 임시직으로 일하던 때 함께 살던 집에서 정규직을 얻기 전까지는 돈 대신 집안일로 갚으라는 말을 들었다고 적었다. 2012년 기사[^3]가 전한 Pew 조사에서 부모 집에 사는 18\~34세 거의 모두가 집안일을 거든다고 답했고 집세를 내는 사람은 3분의 1 남짓이었다.
