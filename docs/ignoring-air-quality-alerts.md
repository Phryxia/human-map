# 대기오염 경보에도 바깥 활동 줄이지 않기

별칭: 없음

대기오염 경보나 미세먼지 나쁨 예보가 나온 날 사람들이 마스크를 쓰지 않거나 바깥 활동을 줄이지 않는다.

# 서술

2013년 기사[^1]에 따르면 대기질 경보가 나올 때 활동을 크게 바꾸거나 줄인다고 답한 켄터키 성인은 20%였다.

2019년 1월 기사[^2]는 온라인 커뮤니티와 SNS 에 마스크를 썼다가 답답하기만 하고 효과를 못 봤다는 글이 올라온다고 전했다. 2019년 3월 기사[^3]에 실린 설문에서 미세먼지 나쁨 이상인 날 외출할 때 보건용 마스크를 쓴 사람은 48.7%였다.

2020년 미국 연구[^4]에서 사는 곳의 공기가 나쁘다고 생각하거나 그런 말을 듣고 행동을 바꾼 응답자는 14.7%였다.
