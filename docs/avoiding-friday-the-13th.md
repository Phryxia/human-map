# 13일의 금요일 꺼리기

별칭: 없음

13일의 금요일을 불길하게 여기는 사람이 그날 길을 나서는 일을 꺼리거나 불안해한다.

묶음: [걱정과 기분](../groups/worry-and-mood.md)

# 서술

1993년 연구[^1]에서 영국 M25 고속도로 남쪽 구간을 지난 차량은 6일의 금요일보다 13일의 금요일에 꾸준하고 유의하게 적었다.

2009년 TripAdvisor 조사[^2]에서 영국 여행자의 4분의 1은 13일의 금요일에 길을 떠나는 것이 한 해의 다른 날보다 더 불안하다고 답했다.
