# 기시감

별칭: 데자뷔, Déjà vu

처음 겪는 상황에서 사람이 그 일을 전에 겪은 적이 있다고 느낀다.

# 서술

2003년 연구[^1]의 문헌 검토에 따르면 인구의 약 60%가 기시감을 겪은 적이 있었다. 2016년 연구[^2]에서는 응답자 324명(88.8%)이 기시감을 겪었다고 답했다.

2022년 The Conversation 글[^3]의 필자는 이미 일어난 일을 다시 겪는 것처럼 느껴지기도 한다고 적었다.

2003년 연구[^1]에서 기시감을 겪는 빈도는 나이가 들수록 줄었다. 2016년 연구[^2]에서도 기시감을 겪은 사람은 겪지 않은 사람보다 나이가 적었다.
