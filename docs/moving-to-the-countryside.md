# 도시를 떠나 시골로 옮겨 살기

별칭: 귀농[^5], 귀촌[^5]

도시에 살던 사람이 농사를 짓거나 자연 가까이 살려고 시골로 옮겨 간다.

묶음: [사는 곳과 옮겨 살기](../groups/where-to-live.md)

# 서술

1907년 에세이[^1]의 화자는 흙과 자라는 것들을 갈망해 8년 전 이곳으로 왔다고 썼다.

2007년 미국 농무부 경제연구소 글[^2]은 자녀를 떠나보내거나 은퇴한 성인일수록 시골로 옮겨 가는 경향이 커진다고 적었다.

2015년 러시아 연구[^3]는 시골로 옮긴 사람들 가운데 도시가 밀어낸 사람과 시골이 끌어당긴 사람이 섞여 있다고 적는다. 2022년 댓글[^4]의 글쓴이는 집값과 땅값이 훨씬 싼 곳을 찾아 샌프란시스코 베이 지역을 떠나 시에라 산기슭으로 옮겼다고 썼다.

2025년 농림축산식품부 실태조사[^5]에서 귀농 이유는 자연환경 31.9%, 가업승계 20.0% 순이었고 귀촌 이유는 자연환경 19.3%, 정서적 여유 19.0% 순이었다.
