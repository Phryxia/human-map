# 보안 피로

별칭: Security fatigue[^1], Cybersecurity fatigue[^2]

컴퓨터 보안 요구를 거듭 받은 사람이 보안을 챙기는 일에 지쳐 그 일을 꺼린다.

묶음: [메시지와 휴대전화](../groups/messages-and-phones.md)

# 서술

2016년 미국 국립표준기술연구소 보도자료[^1]가 전한 연구는 보안 피로를 컴퓨터 보안을 다루는 일에 대한 싫증이나 꺼림으로 정의했다.

2025년 2월 연구[^2]는 사이버보안 피로를 보안 요구를 거듭 받으면서 생기는 정신적, 정서적 소진 상태로 적는다. 2025년 11월 기고[^3]의 필자는 잦은 비밀번호 변경 요구와 복잡한 규칙이 사용자의 피로감을 높이고 그 결과 비밀번호 재사용으로 이어진다고 썼다.
