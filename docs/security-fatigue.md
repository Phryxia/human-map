# 보안 피로

별칭: Security fatigue[^2], Cybersecurity fatigue[^3]

컴퓨터 보안 요구를 거듭 받은 사람이 보안을 챙기는 일에 지쳐 그 일을 꺼린다.

묶음: [메시지와 휴대전화](../groups/messages-and-phones.md)

# 서술

2013년 Hacker News 댓글[^1]의 글쓴이는 보안 피로 때문에 사용자가 안전하지 않은 콘텐츠를 그냥 불러온다고 썼다.

2016년 미국 국립표준기술연구소 보도자료[^2]가 전한 연구는 보안 피로를 컴퓨터 보안을 다루는 일에 대한 싫증이나 꺼림으로 정의했다.

2025년 2월 연구[^3]는 사이버보안 피로를 보안 요구를 거듭 받으면서 생기는 정신적, 정서적 소진 상태로 적는다. 2025년 11월 기고[^4]의 필자는 잦은 비밀번호 변경 요구와 복잡한 규칙이 사용자의 피로감을 높이고 그 결과 비밀번호 재사용으로 이어진다고 썼다.

2026년 9월 보안 교육 업체의 글[^5]은 NIST 연구가 꼽은 보안 피로의 원인으로 보안 선택이 너무 많아 생기는 결정 피로와 거짓 경보로 드러나곤 하는 경고를 거듭 받아 무뎌지는 일을 든다.
