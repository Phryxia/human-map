# 겉봉 글씨로 보낸 사람 알아보기

별칭: 없음

우편물 겉봉의 손글씨를 본 사람이 봉투를 뜯기 전에 누가 보냈는지 알아보고 반가움이나 동요를 느낀다.

묶음: [기억과 떠오르는 생각](../groups/memory-and-thoughts.md)

# 서술

1860년 소설[^1]에서 여자는 겉봉의 주소를 보자마자 글씨를 알아보고 보낸 사람을 아느냐는 물음에 너무 잘 안다고 답한 뒤에야 편지를 연다.

2002년 칼럼[^2]의 필자는 세로획 끝이 조금 들리는 필체를 오랜만에 대하며 그리움을 느꼈다고 썼다.

2014년 댓글[^3]의 글쓴이는 두툼한 봉투를 우편으로 받는 일을 좋아했고 누군가의 손글씨를 보는 일을 중요하고 개인적인 일로 느꼈다. 2021년 칼럼[^4]의 필자는 몇 달 떨어져 지낸 뒤 문간에 온 봉투의 어머니 글씨를 보고 어머니가 봉투의 모습으로 거기 와 있는 듯했다고 썼다.
