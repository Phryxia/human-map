# 서머타임 전환 뒤의 피로

별칭: 없음

서머타임이 시작되어 시계를 한 시간 앞당긴 뒤 며칠 동안 사람들이 잠이 모자라고 피곤하다고 느낀다.

묶음: [시간과 하루 습관](../groups/daily-time.md)

# 서술

2008년 연구[^1]의 저자들은 서머타임에 들어가고 나올 때 밤의 뒤척임이 늘어 잠의 질이 떨어졌다고 보고했다.

2022년 연구[^2]의 저자들은 서머타임 전환 직후 수면 시간이 줄고 잘 못 잤다거나 개운하지 않다고 답한 사람의 비율이 늘었다고 보고했다.

2024년 3월 영국 국립보건연구원 옥스퍼드 연구센터의 글[^3]은 봄의 시계 전환 뒤 잠이 흐트러지고 모자라 일부 사람이 낮에 멍하고 짜증이 나며 집중을 덜 한다고 적었다. 2025년 3월 NPR 기사[^4]는 표준시에서 서머타임으로 바뀌면 시차를 겪을 때처럼 몸의 시계가 어긋나 짜증이 나고 피곤해진다고 썼다.
