# 서술

1986년 논문[^1]은 이길 확률이 판마다 같은 운의 게임에서도 아깝게 빗나간 결과가 다음 판을 부추긴다고 널리 믿어진다고 적는다.

2009년 연구[^2]에서 참가자들은 아깝게 빗나간 결과를 완전히 빗나간 결과보다 덜 즐겁게 느꼈지만 그 뒤 더 하고 싶어 했다. 같은 연구를 다룬 기사[^3]는 참가자가 릴에 나올 그림을 직접 고른다고 여길 때 이 효과가 더 강했다고 전한다.

2019년 캐나다 온타리오주 도박 연구 기관의 자료[^4]는 즉석복권에서 잭팟에 조금 못 미친 결과가 돈을 잃은 결과인데도 하는 사람에게 크게 작용한다고 적는다.

2026년 기사[^5]는 도박하는 사람들이 아깝게 진 결과에 거의 이긴 것처럼 반응한다고 적는다.
