# 강한 감정에 기절하기

별칭: 없음

충격적인 소식을 듣거나 피를 보는 것처럼 감정이 크게 흔들리는 순간에 사람이 정신을 잃고 쓰러진다.

묶음: [건강과 위험](../groups/health-and-safety.md)

# 서술

1790년에 쓰여 1922년 간행된 오스틴의 서간체 소설[^1]에서 화자와 친구는 기다리던 남편이 돌아오지 않자 너무 잔인하고 뜻밖의 타격을 견디지 못해 기절할 수밖에 없었다고 말했다.

2013년 연구[^2]에서 심장내과 외래 환자의 7.7%인 254명이 감정 스트레스로 일어난 혈관미주신경성 실신을 겪었다고 답했고 9.0%인 294명은 기립 스트레스로 일어난 실신을 겪었다.

2024년 MSD 매뉴얼 일반인용의 기절 항목[^3]은 강한 감정, 특히 피를 보고 생긴 감정이나 통증이 미주신경을 활성화할 수 있다고 적는다.
