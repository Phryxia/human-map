# 살던 집에서 늙기

별칭: Aging in place[^2]

나이 든 사람이 몸이 불편해져도 시설이나 다른 집으로 옮기지 않고 오래 살던 자기 집에서 계속 살기를 바란다.

묶음: [사는 곳과 옮겨 살기](../groups/where-to-live.md)

# 서술

2009년 게시판 글[^1]의 글쓴이는 나이 든 부모가 다른 거처로 옮기는 데 한 번도 동의하지 않았고 집에서 살기를 원한다고 적었다.

2017년 미국 국립노화연구소 글[^2]은 나이 들어 가는 사람 다수가 자기 집에 머물고 되도록 오래 독립을 지키며 필요할 때 가족과 친구에게 도움을 청하기를 바란다고 적었다.

2019년 연구[^3]의 참가자들에게 집에 남는 일은 독립과 자유, 자기 가치와 정체성, 편안함, 지역사회 안에서 이어지는 역할을 주었다.
