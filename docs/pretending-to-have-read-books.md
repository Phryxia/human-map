# 읽지 않은 책을 읽은 척하기

별칭: fake-reading[^3]

사람이 읽지 않은 책을 남 앞에서 읽었다고 말한다.

# 서술

1836년 희곡[^1]에서 흘레스타코프가 유명한 소설과 같은 제목의 소설을 자기도 썼다고 하자 안나는 그의 것을 읽었는데 멋지다고 맞장구쳤다.

2009년 영국 조사를 전한 기사[^2]에서 응답자의 65%가 책을 읽은 척한 적이 있었고 그 가운데 42%가 「1984」를 꼽았다.

2012년 박사논문[^3]의 저자는 읽을 줄 아는 학생이 읽지 않기로 하고 좋은 성적을 받으려고 과제로 받은 책을 읽은 것처럼 꾸미는 일을 가짜 읽기라 부른다.

2017년 조사 보도자료[^4]에서 남성의 19%는 면접에서 좋은 인상을 주려고 독서 습관을 거짓으로 말하겠다고 답했다. 2019년 기사[^5]가 전한 조사에서 응답자 절반 넘게 책을 읽었다고 남에게 거짓말한 적이 있었고 40% 가까이는 대화에 끼려고 그랬다고 답했다.

2026년 댓글[^6]의 글쓴이는 사람들이 싫어하는 감시를 두고 "오웰적" 이라는 말을 쓰려고 「1984」를 읽은 척한다고 썼다.
