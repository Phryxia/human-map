# 첫눈 반기기

별칭: 없음

그해 처음 내리는 눈을 본 사람이 들떠 걸음을 멈추거나 밖으로 나가 눈을 본다.

# 서술

1932년 강경애의 수필에서 바느질하던 화자는 눈이 온다는 말을 듣자 어린애처럼 뛰어 일어났다. 바늘에 찔린 손끝을 천 오라기로 동이고 밖으로 뛰어나갔다.[^1]

2018년 전북일보 수필의 필자는 첫눈이 소담스럽게 내리니 자기도 모르게 가슴이 설렌다고 적었다.[^2] 2019년 Bustle 기사는 눈이 자주 오는 곳에 살아도 첫눈이면 새로움이 커진다는 말을 옮겼다.[^3]

2024년 인사이트 기사는 첫눈 날 설레는 마음으로 휴대전화를 들어 눈 덮인 세상을 찍는 사람들을 전했다.[^4] 2025년 뉴시스 기사에서 서울의 퇴근길 시민들은 첫눈 속에서 사진을 찍거나 잠시 걸음을 멈췄다.[^5]
