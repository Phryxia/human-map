# 생각하려고 걷기

별칭: 없음

사람이 생각을 정리하거나 마음을 가라앉히려고 밖으로 나가 걷는다.

# 서술

1774년 괴테 소설[^1]의 편지 화자는 들판을 헤매고 가파른 절벽을 오르고 길 없는 덤불을 헤치며 걸을 때 마음이 놓인다고 쓴다.

1910년 포스터 소설[^2]에서 언짢아진 인물은 일을 곰곰이 생각하려고 성 둔덕으로 걸어 나간다.

2014년 Oppezzo 와 Schwartz 의 네 실험[^3]에서 걷기는 걷는 동안과 걸은 직후의 창의적 발상을 늘렸다. 같은 해 기사[^4]는 걷는 데 의식을 많이 쓰지 않아도 되므로 주의가 자유롭게 떠돈다고 썼다.

2026년 방송사 기사[^5]는 고민이 많을 때 가볍게 산책하거나 답답할 때 잠시 밖을 걸으며 기분을 바꾸는 일을 흔한 일로 소개했다.
