# 리바운드 연애

별칭: 없음

연애가 끝난 사람이 옛 연인에 대한 감정이 정리되기 전에 곧바로 새 상대를 만나 연애를 시작한다.

묶음: [가까운 사이의 감정과 말](../groups/close-relationships.md)

# 서술

2004년 11월 Straight Dope 댓글[^1]의 글쓴이는 10월에 연인과 헤어지고 그해 추수감사절 주말에 새 남자를 만났다고 적었다.

2014년 2월 연구[^2]에서 이별의 괴로움을 달래거나 옛 연인을 잊거나 되갚으려고 성관계를 갖는 일은 이별 직후에 많았고 시간이 지나며 줄었다.

2018년 6월 얼루어 코리아 기사[^3]는 이별 뒤 바로 새 연애를 시작하는 사람들이 다른 사람의 존재로 상처를 넘긴다고 적었다.
