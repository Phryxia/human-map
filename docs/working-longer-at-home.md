# 재택근무 중 더 오래 일하기

별칭: 없음

재택근무하는 사람이 집에서 일하면서 사업장에서 일할 때보다 더 오래 일한다.

# 서술

2013년 해커뉴스 댓글[^1]의 글쓴이는 원격근무를 하면 일을 멈추기 어렵다고 쓰고 저녁 식사 중과 주말과 밤늦게까지 일한다고 적었다.

2016년 Glass 와 Noonan 의 연구에서 집에서 일한 시간은 사업장에서 일한 시간보다 초과근무로 잡힐 가능성이 세 배 높았다.[^2]

2017년 국제노동기구 보도자료는 텔레워크의 불리한 점으로 더 오래 일하는 경향과 유급 노동과 사생활이 겹치는 일을 들고 이것이 높은 스트레스로 이어질 수 있다고 적는다.[^3]

2021년 영국 통계청 자료에서 2020년에 조금이라도 집에서 일한 사람은 주당 평균 6.0시간의 무급 초과근무를 했다. 집에서 전혀 일하지 않은 사람은 3.6시간이었다.[^4]
