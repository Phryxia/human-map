# 꾀병 부리기

별칭: Malingering[^3]

사람이 공부나 일처럼 해야 할 일을 피하려고 아프지 않은데 아프다고 말하거나 아픈 척한다.

# 서술

1925년 소설[^1]에서 한 인물은 다음 날 아침 글을 다 외우지 못하면 머리나 배가 아프다고 꾀병을 하면 된다고 말한다. 그는 아프다고만 하면 아버지도 어쩌지 못한다고 덧붙인다.

2004년 연구[^2]는 스웨덴 자료에서 텔레비전으로 스포츠 경기를 보려고 아프다고 신고한 남성의 수가 늘었다고 보고한다.

2021년 논문[^3]은 꾀병이 예로부터 맡은 일과 임무를 피하는 일과 이어져 왔다고 쓴다.
