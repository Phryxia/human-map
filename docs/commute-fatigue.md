# 통근 피로

별칭: 없음

긴 시간 출퇴근하는 직장인이 통근 때문에 지치고 스트레스를 느낀다.

묶음: [일터와 일자리](../groups/work.md)

# 서술

2000년 서울신문 칼럼[^1]은 영국 국제스트레스관리협회의 발표에서 직장인에게 스트레스를 주는 항목 가운데 출퇴근 문제가 으뜸이었다고 전했다.

2010년 영국 재테크 포럼 댓글[^2]의 글쓴이는 런던을 떠나 편도 2시간을 통근했다. 첫해는 그 변화를 즐겼으나 2년이 지나자 통근이 자신을 미치게 한다고 썼다.

2019년 Gimenez-Nadal 과 Molina 의 미국 시간 사용 조사 분석[^3]에서 하루 통근 시간이 길수록 통근하는 동안의 피로와 스트레스가 높았다.

2026년 10월 클리앙 게시글[^4]의 글쓴이는 경기도민의 설움을 말하며 퇴근하는 길에 집에 갈 생각만으로 벌써 한숨이 나온다고 썼다.
