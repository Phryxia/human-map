# 아는 척하기

별칭: 아는 체[^1], Overclaiming[^3]

잘 모르는 것을 앞에 둔 사람이 모른다고 말하지 않고 아는 것처럼 말하거나 행동한다.

묶음: [남의 시선과 창피함](../groups/others-gaze.md)

# 서술

1925년 동화[^1]의 이 선생 영감은 모르는 것을 모른다고 하지 않고 아는 체를 하며 집안사람들에게 물을 끓이게 한 뒤 초를 썰어 넣어 끓인다.

1937년 소설[^2]의 리긔봉은 주인마누라가 대담히 아는 체 하는 말을 무엇보다 더 듣고 싶어 한다.

2021년 연구[^3]에서 참여자 168명 가운데 64%가 존재하지 않는 수학 개념을 한 번 이상 안다고 답했다.
