# 흥정 회피

별칭: 없음

값을 깎을 수 있는 자리에서 어떤 사람은 흥정을 부담스러워해 하지 않거나 돈을 더 내더라도 피한다.

묶음: [돈과 소비](../groups/money.md)

# 서술

2009년 재래시장 설문[^1]에서 흥정을 시장의 장점보다 부담으로 여긴 응답자가 더 많았고 가장 큰 이유는 시장 가격을 믿기 어렵다는 것이었다. 2009년 게시글[^2]의 글쓴이는 무엇을 사든 흥정이 싫고 자동차처럼 비싼 물건은 더 그렇다고 썼다.

2018년 칼럼[^3]의 필자는 예물 매장에서 주는 사람도 받는 사람도 값을 깎아 달라는 말을 꺼내기 어려워 터무니없이 비싼 값에도 거래가 쉽게 이루어진다고 썼다.

2024년 게시글[^4]의 글쓴이는 값을 불러 놓고 버틸 용기가 아직 없다면서도 몇 천을 깎으면 그게 어디냐고 썼다.

2026년 기사[^5]가 전한 2025년 연구에서 소비자는 2만 달러짜리 차를 살 때 협상을 피하려고 1,100달러 넘게 더 낼 뜻이 있었다.
