# 도서관 책 훼손

별칭: 없음

도서관 책을 빌린 이용자가 책에 밑줄을 긋고 메모하거나 필요한 쪽을 찢어 간다.

# 서술

1998년 서울신문 기사[^1]는 도서관 책에서 필요한 내용을 찢거나 오려 간 흔적이 쉽게 눈에 띈다고 적었다.

2022년 클리앙 게시글[^2]의 글쓴이는 빌리려던 책에 앞선 이용자가 볼펜으로 밑줄을 치고 메모까지 남겨 두었다고 적었다. 2025년 전북일보 기사[^3]에 실린 말에 따르면 공공도서관에는 개인 책처럼 밑줄을 긋는 이용자가 많다.
