# 남의 집 살림 엿보기

별칭: 없음

남의 집에 손님으로 간 사람이 주인이 보지 않는 사이 그 집의 찬장이나 수납장을 열어 살림을 살펴본다.

묶음: [선물, 대접과 예의](../groups/gifts-and-hospitality.md)

# 서술

1838년 소설[^1]에서 집주인이 잠시 자리를 비우자 혼자 남은 손님은 찬장을 열고 찻숟가락을 세고 설탕 집게의 무게를 가늠했으며 은 우유 단지가 진짜 은인지 살폈다.

2016년 Ideal Home 기사[^2]가 전한 영국 조사에서 남의 집에서 엿보는 자리로 가장 많이 꼽힌 곳은 부엌이었고 응답자 44%가 곧장 부엌 찬장으로 갔다. 그다음이 욕실 수납장이었다.
