# 독초를 산나물로 알고 먹기

별칭: 없음

산이나 들에서 나물을 캐는 사람이 생김새가 비슷한 독초를 먹는 나물로 알고 캐서 먹는다.

묶음: [건강과 위험](../groups/health-and-safety.md)

# 서술

1994년 미국 질병통제예방센터 보고[^1]는 미국에서 적어도 58명이 먹는 열매나 채소로 잘못 안 독초를 먹고 숨졌다고 적는다.

2005년 연구[^2]는 잘 훈련된 전문가만 먹는 나물과 그것을 닮은 독초를 가려낼 수 있다고 쓴다.

2013년 식품의약품안전처 자료[^3]는 나물과 비슷하게 생긴 독초 때문에 식중독 사고가 종종 생긴다고 적는다.

2020년 기사[^4]에서 사람들은 캔 독초를 주변 사람과 자주 나눴고 한 사고에 평균 7명(20건 128명)이 피해를 입었다. 2021년 기사[^5]는 나물을 직접 캐는 사람들이 가족이나 지인에게 안심하고 먹일 나물 음식을 해 주고 싶은 마음을 앞세운다고 쓴다. 2023년 기사[^6]에서 식약처는 독초 사고의 85%가 봄철인 3∼6월에 접수됐고 꽃이 피기 전에는 잎이나 뿌리만으로 산나물과 독초를 가리기 어렵다고 설명했다.
