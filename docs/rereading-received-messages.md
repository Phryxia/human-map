# 받은 편지와 메시지 되풀이해 읽기

별칭: 편지 다시 읽기, 옛 문자 다시 보기, 카톡 다시 읽기

사람이 가까운 사람에게서 받은 편지나 메시지를 몇 번이고 다시 읽는다.

# 서술

1850년 소설[^1]의 화자는 그녀의 편지를 여러 번 읽었다고 적는다. 1920년 소설[^2]의 주인공은 올렌스카 부인의 쪽지를 자정이 지나 집에 돌아와 다시 꺼냈고 천천히 여러 번 읽었다.

2026년 2월 댓글[^4]의 글쓴이는 그의 문자를 되풀이해 읽고 사진을 보며 마음이 무너졌다고 썼다. 2026년 5월 에세이[^5]의 필자는 이별 뒤 매일 밤 같은 대화를 처음부터 읽었고 아침이면 전날 밤 찾은 단서가 아무 의미 없다는 것을 깨닫고 다시 처음부터 시작했다.

# 조건

1850년과 1920년 소설[^1][^2]에서 읽는 것은 종이 편지와 쪽지이고 2026년 댓글[^4]에서는 문자다. 2017년 게시글[^3]의 글쓴이는 남편의 사진을 보거나 문자를 읽는 일이 가슴에 칼이 박히는 것 같아서 하지 못한다고 썼다.
