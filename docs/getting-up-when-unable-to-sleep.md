# 잠이 오지 않을 때 자리에서 일어나기

별칭: 없음

잠자리에 누워도 잠이 오지 않는 사람이 계속 누워 있지 않고 일어나 다른 일을 하다가 다시 눕는다.

묶음: [걱정과 기분](../groups/worry-and-mood.md)

# 서술

1860년 디킨스의 에세이[^1]에서 화자는 잠 못 드는 증세를 눕자마자 바로 일어나 밖으로 나가고 해 뜰 무렵 지쳐 돌아오는 방법으로 곧 이겨 냈다고 썼다.

2016년 에세이[^2]의 필자는 잠이 오지 않는 밤을 괴롭게 여기지 않고 다음 날 꼭 나갈 일이 없으면 책을 읽거나 영화를 보거나 옷장을 정리한다고 썼다.

2024년 앨버타 보건 당국의 수면 안내[^3]는 잠들지 못하면 침실을 떠나 집 안의 다른 곳에서 불을 어둡게 하고 낱말 퍼즐이나 조각 그림 맞추기 같은 차분한 일을 하라고 권한다.

2026년 질적 연구[^4]에서 경도인지장애와 불면을 함께 겪는 지역사회 노인 한 사람은 침대에서 뒤척이면 온갖 생각이 떠오르니 차라리 일어나 마사지 운동을 한다고 말했다.
