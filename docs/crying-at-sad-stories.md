# 슬픈 이야기를 보며 울기

별칭: 없음

슬픈 영화나 소설을 보는 사람이 지어낸 이야기에 눈물을 흘린다.

# 서술

1994년 연구[^1]에서 슬픔을 일으킨다고 알려진 짧은 영화를 여성 150명에게 보여 주자 33명이 저절로 울었고 117명은 울지 않았다.

2007년 매일신문 기사[^2]는 슬픈 영화를 보며 울다 보면 가슴속 응어리가 되살아나고 영화가 끝날 무렵 카타르시스의 쾌감을 느낄 수 있다고 적었다.

2026년 브런치 글[^3]의 글쓴이는 감독이나 작가가 울 차례라고 만들어 둔 장치 앞에서 이번에도 의도대로 눈물을 쏟는 관객이 된다고 썼다.
