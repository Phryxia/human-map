# 가난했던 시절 그리워하기

별칭: 없음

형편이 나아진 사람이 돈이 넉넉하지 않던 시절을 떠올리며 그때가 더 즐거웠다고 여기고 그리워한다.

묶음: [기억과 떠오르는 생각](../groups/memory-and-thoughts.md)

# 서술

1823년 수필[^1]에서 브리짓은 돈이 넉넉한 지금은 물건을 사도 그저 사는 일일 뿐이지만 예전에는 물건 하나를 사는 일이 승리였다고 말한다.

2014년 게시글[^2]의 글쓴이는 자신과 친구들이 모두 가난했던 1970, 80년대를 누군가의 낡은 셋집에서 이어진 긴 파티로 떠올리며 가난했던 때가 그립다고 썼다.

2016년 블로그 글[^3]의 글쓴이는 형편이 나아진 40대에 가난했던 시절을 떠올리며 그때는 친구들도 모두 형편이 어려워 서로 꾸밈없이 지냈고 누구에게 잘 보일 부담이 없었다고 썼다. 2017년 기사[^4]의 글쓴이는 물건 하나하나를 신중히 따져 사고 특별한 것을 사려고 돈을 모으던 가난한 시절이 그립다고 썼다.
