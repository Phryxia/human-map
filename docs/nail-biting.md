# 손톱 물어뜯기

별칭: Nail biting, Onychophagia

사람이 초조하거나 지루하거나 어려운 일을 붙잡고 있을 때 손톱을 물어뜯는다.

# 서술

1844년 뒤마의 소설[^1]에서 달타냥은 한 시간 넘게 초조하게 손톱을 물어뜯다가 손톱 밑 살까지 물기 시작했다.

2010년 기사[^2]는 손톱 물어뜯기가 어릴 때 혼난 뒤나 엄마가 곁에 없어 불안할 때, 심심할 때 시작되고 버릇이 되면 커서도 무의식적으로 이어진다고 쓴다. 2023년 게시글[^6]의 글쓴이는 스트레스를 조금만 받아도 자동으로 손톱을 물어뜯어 슬프다고 썼다.

2011년 Ghanizadeh 의 글[^3]은 손톱 물어뜯기가 대개 불안보다 지루함이나 어려운 문제를 풀 때 일어난다고 적는다. 2022년 Lee 와 Lipner 의 글[^5]은 스트레스, 지루함, 할 일 없음이 그 원인일 수 있다고 쓴다.

2018년 튀르키예 차나칼레 보건국의 글[^4]은 어린이의 33%가 손톱을 물어뜯고 사춘기에는 그 비율이 40~45%로 늘어난다고 적는다.
