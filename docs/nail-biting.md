# 손톱 물어뜯기

별칭: Nail biting, Onychophagia

사람이 초조하거나 지루하거나 어려운 일을 붙잡고 있을 때 손톱을 물어뜯는다.

# 서술

1844년 뒤마의 소설[^1]에서 달타냥은 한 시간 넘게 초조하게 손톱을 물어뜯다가 손톱 밑 살까지 물기 시작했다.

# 조건

2011년 Ghanizadeh 의 글[^2]은 손톱 물어뜯기가 대개 불안보다 지루함이나 어려운 문제를 풀 때 일어난다고 적는다. 2022년 Lee 와 Lipner 의 글[^3]은 스트레스, 지루함, 할 일 없음이 그 원인일 수 있다고 쓴다.
