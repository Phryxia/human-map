# 뒷좌석 안전띠 미착용

별칭: 뒷좌석 안전벨트 안 매기, Rear seat belt nonuse

자동차 뒷좌석에 탄 사람이 불편하거나 잊거나 뒷좌석이 안전하다고 믿어서 안전띠를 매지 않는다.

# 서술

1998년 Markey 외의 조사에서 응답자가 뒷좌석 안전띠를 매지 않은 주된 이유는 띠가 불편하고 잊기 쉽다는 것이었다. 2017년 IIHS 조사에서 응답자의 12%는 불편하거나 몸에 맞지 않는 띠를 이유로 들었고 10%는 띠를 쓰기 어렵거나 띠와 버클을 찾지 못한다고 답했다. [F1][F3]

2023년 뉴욕주 교통안전위원회 보도자료는 뒷좌석이 앞좌석보다 안전해서 띠 없이 타도 위험하지 않다는 믿음을 흔한 오해라고 부른다. [F4]

# 조건

2016년 장정아 외는 한국의 실제 안전띠 착용률이 낮고 특히 뒷좌석에서 낮다고 적었다. [F2]
