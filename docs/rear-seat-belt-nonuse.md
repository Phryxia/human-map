# 뒷좌석 안전띠 미착용

별칭: 없음

자동차 뒷좌석에 탄 사람이 불편하거나 잊거나 뒷좌석이 안전하다고 믿어서 안전띠를 매지 않는다.

# 서술

1998년 Markey 외의 조사에서 응답자가 뒷좌석 안전띠를 매지 않은 주된 이유는 띠가 불편하고 잊기 쉽다는 것이었다.[^1]

2008년 영국 교통부 보도자료에서 뒷좌석 탑승자의 안전띠 착용 비율은 14세 미만 어린이 96%, 성인 69%였다.[^2]

2015년 YTN 보도에서 한국도로공사 조사의 고속도로 뒷좌석 착용률은 17%였다.[^3] 2016년 장정아 외는 한국의 실제 안전띠 착용률이 낮고 특히 뒷좌석에서 낮다고 적었다.[^4]

2017년 IIHS 조사에서 응답자의 12%는 불편하거나 몸에 맞지 않는 띠를 이유로 들었고 10%는 띠를 쓰기 어렵거나 띠와 버클을 찾지 못한다고 답했다.[^5] 2018년 Jermakian 외의 조사에서 응답자 5명 가운데 4명은 짧은 거리나 고용한 차량처럼 이동의 종류 때문에 뒷좌석 안전띠를 매지 않는다는 데 동의했다.[^6]

2019년 경향신문 기사에서 한국교통안전공단 조사의 뒷좌석 착용률은 32.6%였고 앞좌석 착용률은 88.1%였다.[^7] 2021년 데일리안 기사는 앞좌석은 단속반의 눈에 띄기 쉽고 띠를 매지 않으면 소리가 나서 착용이 비교적 지켜지지만 뒷좌석은 사각지대라고 적었다.[^8]

2023년 뉴욕주 교통안전위원회 보도자료는 뒷좌석이 앞좌석보다 안전해서 띠 없이 타도 위험하지 않다는 믿음을 흔한 오해라고 부른다.[^9] 2025년 1월 콜로라도주 교통부 기사에서 2022년 미국의 안전띠 착용률은 앞좌석 약 91.6%, 뒷좌석 약 81.7%였다.[^10] 2025년 10월 미주헤럴드경제 기사에서 오전 11시부터 오후 1시까지의 점심시간대 뒷좌석 착용률은 12%까지 떨어졌다.[^11]
