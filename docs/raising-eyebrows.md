# 눈썹 치켜올리기

별칭: 없음

뜻밖이거나 미심쩍은 말을 들은 사람이 말없이 눈썹을 치켜올린다.

묶음: [가까운 사이의 감정과 말](../groups/close-relationships.md)

# 서술

1855년 트롤럽의 소설[^1]에서 톰 타워스는 친구의 말에 눈썹만 치켜올리고 두 손을 주머니에 찌른 채 친구가 말을 잇기를 기다렸다.

1881년 헨리 제임스의 소설[^2]에서 이저벨은 핑계라는 상대의 말에 놀라 눈썹을 치켜올리고 자기가 변명해야 하느냐고 되물었다.

2021년 연구[^3]에서 참가자들이 지은 놀람의 표정은 진짜 놀란 것이든 일부러 지은 것이든 주로 눈썹과 눈꺼풀을 들어 올리는 움직임으로 이루어졌다.
