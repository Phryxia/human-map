# 서술

1595년 소네트[^1]의 화자는 모래 위에 연인의 이름을 썼고 파도가 지우자 한 번 더 썼다.

2012년 에세이[^2]의 필자는 십대 시절 수업이 끝나기를 기다렸다가 좋아하던 아이의 반에 몰래 가서 그 이름을 크고 굵은 글씨로 쓰고 별과 꽃으로 둘레를 꾸몄다. 2016년 기사[^3]는 짝사랑할 때 하는 일로 상대의 이름을 되풀이해 쓰는 것과 자기 이름에 상대의 성을 붙여 써 보는 것을 꼽는다.
