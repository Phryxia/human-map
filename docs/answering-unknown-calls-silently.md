# 모르는 번호의 전화를 받고 먼저 말하지 않기

별칭: 없음

모르는 번호의 전화를 받은 사람이 인사하지 않고 상대가 먼저 말할 때까지 기다린다.

# 서술

2017년 1월 노스캐롤라이나 법무부의 안내문[^1]은 전화를 받았는데 "Can you hear me?" 처럼 "yes" 라는 대답을 끌어내려는 목소리가 들리면 대답하지 말고 전화를 내려놓으라고 했다.

2022년 11월 Hacker News 댓글[^2]의 글쓴이는 로보콜이 수화기 너머에서 아무 소리도 듣지 못하면 끊긴다는 것을 알고 나서 모르는 번호의 전화를 받아도 바로 말하지 않고 스피커폰으로 1분쯤 둔다고 썼다.

2026년 3월 YouGov 조사[^3]에서 Z세대의 42%는 모르는 번호로 전화한 사람이 먼저 말할 때까지 기다렸다가 응답한다고 답했고 다른 세대에서도 36\~50%가 같은 답을 했다. 2026년 9월 위키트리 기사[^4]는 모르는 번호의 전화가 오면 통화 버튼을 누른 뒤 아무 말 없이 기다리는 젊은 세대의 행동을 다뤘다.
