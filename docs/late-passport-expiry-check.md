# 출국 직전 여권 만료 알아채기

별칭: 없음

해외여행을 앞둔 사람이 여권 유효기간을 미리 확인하지 않다가 출발이 가까워서야 또는 출국 공항에서 여권이 만료됐거나 기간이 모자란 것을 알아챈다.

묶음: [시간과 하루 습관](../groups/daily-time.md)

# 서술

2003년 게시글[^1]의 글쓴이는 여권이 2월에 만료된 것을 뒤늦게 알고 새 여권을 구하느라 서둘렀다.

2013년 영국 여권청 보도자료[^2]는 여권 신청을 늦게 하면 최대 55.50파운드를 더 내고 여권이 제때 오지 않을 수도 있다고 적었다.

2019년 기사[^3]에 따르면 2018년 인천공항 여권민원센터에 들어온 긴급여권 신청 사유의 58%가 유효기간 부족이었다. 2026년 기사[^4]는 여행객이 여권 유효기간 문제를 알게 되는 곳이 목적국 입국심사장보다 출국 공항 체크인 카운터인 경우가 많다고 썼다.
