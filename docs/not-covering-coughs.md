# 기침할 때 가리지 않기

별칭: 기침 예절 지키지 않기, 맨손으로 기침 가리기, Uncovered coughing

공공장소에서 기침이나 재채기를 하는 사람이 습관이 되지 않았거나 귀찮아서 입과 코를 가리지 않거나 맨손으로만 가린다.

# 서술

2011년 Barry 외가 2009년 뉴질랜드 공공장소에서 관찰한 기침과 재채기에서 가장 흔한 행동은 손으로 가리기(64.4%)였고 휴지나 손수건으로 가린 경우는 3.4%, 팔꿈치나 팔로 가린 경우는 1.3%였다. [F1]

2015년 YTN 보도에서 기침 예절을 실천하지 않는 이유로 가장 많이 나온 답은 습관이 되지 않았다거나 귀찮다는 것이었고 방법을 몰라서라는 답은 2% 남짓이었다. [F3]

# 조건

2015년 의약일보 기사가 전한 질병관리본부의 2014년 기침예절 실태조사에서 올바른 기침 예절을 모두 실천한다고 답한 비율은 성인 37.6%, 청소년 39.8%였다. [F2]

2021년 코메디닷컴 기사가 전한 관찰 조사에서 기침 예절 실천율은 2019년 33.1%에서 50.1%포인트 늘어 83.2%가 되었다. [F4]
