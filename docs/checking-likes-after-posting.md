# 올린 글의 반응 자꾸 확인하기

별칭: checking for likes[^3], likes checking[^2]

소셜 미디어에 글이나 사진을 올린 사람이 좋아요나 점수가 얼마나 늘었는지 보려고 자꾸 다시 확인한다.

# 서술

2009년 1월 댓글[^1]의 글쓴이는 댓글을 단 뒤 자기 점수가 얼마나 바뀌었는지 확인하기 번거롭게 하려고 일부러 로그아웃한다고 썼다.

2017년 셀카 연구[^2]에서 셀카를 올리는 동기 가운데 자기 승인 동기만 좋아요를 확인하는 빈도와 관련이 있었다.

2021년 5월 댓글[^3]의 글쓴이는 좋아요를 끊임없이 확인했고 중요한 목소리로 느끼고 싶어 대화에 끼어들고 싶었다고 적었다.

2026년 8월 기사[^4]는 인정받고 싶은 마음이 강한 사람이 SNS 에 사진을 올린 뒤 조회 수와 좋아요를 계속 들여다본다고 쓴다.
