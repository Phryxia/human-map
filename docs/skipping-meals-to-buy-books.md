# 밥값 아껴 책 사기

별칭: 없음

돈이 넉넉하지 않은 사람이 끼니에 쓸 돈으로 책을 사고 끼니를 거르거나 값싼 음식으로 때운다.

묶음: [돈과 소비](../groups/money.md)

# 서술

1903년 소설[^1]의 화자는 책 앞에서 두 가지 허기가 안에서 싸웠다고 쓴 뒤 책을 샀다. 그날 저녁은 빵과 버터로 먹으며 책장을 넘겼다.

2008년 Goodreads 댓글[^2]의 글쓴이는 대학원 시절 음식보다 책에 돈을 썼고 몇 해 동안 25센트짜리 마카로니 치즈로 지냈다고 썼다. 2009년 학생 블로그 글[^3]의 글쓴이는 점심과 책 가운데 무엇을 살지 스스로 묻고 음식 대신 책을 샀다.

2013년 블로그 글[^4]이 옮긴 글에서 글쓴이는 밥값으로 책을 샀고 이틀 동안 밥을 먹지 않겠다고 적었다. 책 읽기가 두렵지만 그래도 읽고 싶다고 덧붙였다.

2020년 칼럼[^5]의 필자는 1970년대 말 대학에 들어간 뒤 점심을 굶고 라면값을 아껴 책을 사 모았다고 회고했다.
