# 지루함

별칭: boredom[^2]

사람이 하는 일이나 지내는 날에 흥미를 느끼지 못하고 따분해한다.

# 서술

소설[^1]의 주인공은 날들이 늘 같은 모습으로 이어지며 아무 일도 가져오지 않는다고 여기고 다른 삶에는 적어도 무슨 일이 일어날 기회가 있다고 생각한다.

2017년 블로그 글[^2]이 전한 연구에서 참가자는 낯선 사람이나 직장 동료와 있을 때, 혼자 있을 때 지루하다고 더 자주 답했고 아이, 연인이나 배우자, 친구와 있을 때 가장 드물게 답했다.
