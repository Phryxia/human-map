# 남몰래 울기

별칭: 없음

남 앞에서 울음을 참은 사람이 남이 보지 않는 곳을 찾아가 혼자 운다.

# 서술

1954년 김내성의 소설[^1]에서 지운은 무더운 여름에도 문을 꼭 닫고 자기 방에 들어앉아 어머니 몰래 운다.

2008년 기사[^2]가 전한 직장인 설문에서 회사에서 남몰래 운 장소는 화장실이 59.7%로 가장 많았다.

2012년 칼럼[^3]의 필자는 차 안이 닫혀 있고 소리가 거의 새지 않아 아는 사람이 보더라도 우는지 알아차리기 어렵다고 적는다.

2013년 연구[^4]에서 응답자들은 아는 사람이 곁에 있을 때 울음을 눌렀고 혼자 있을 때는 거의 누르지 않았다.

2020년 블로그 글[^5]이 모은 직장 내 울음 응답 가운데 한 응답자는 문이 잠기는 1인용 화장실에 들어가 혼자 운다고 적었다.

2025년 기사[^6]의 필자는 회사에서 울 때 화장실이나 계단을 찾은 일을 두고 비공개로 하려고 그랬다고 적는다.
