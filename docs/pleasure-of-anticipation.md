# 즐거운 일을 기다리는 즐거움

별칭: 없음

즐거운 일을 앞둔 사람이 그 일이 오기 전 기다리는 동안 이미 들뜨고 즐거워한다.

# 서술

1909년 몽고메리의 소설[^1]에서 앤은 좋은 일이 일어나리라 생각하면 기대의 날개를 타고 날아오르다가 어느새 땅으로 쿵 떨어진다고 말했다.

2010년 연구[^2]에서 휴가를 떠날 사람들은 떠나기 전 행복도를 휴가를 가지 않는 사람들보다 높게 보고했다. 저자들은 그것이 휴가를 기다리는 마음 때문일 수 있다고 추측했다.[^2]
