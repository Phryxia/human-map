# 애착 회피

별칭: Attachment avoidance[^1], 회피형 애착[^2]

사람이 연인이나 가까운 사람과 친밀해지는 것을 불편해하며 감정적으로 거리를 둔다.

묶음: [가까운 사이의 감정과 말](../groups/close-relationships.md)

# 서술

2014년 4월 연구[^1]의 저자들은 애착 회피 점수가 높은 사람이 관계에 덜 마음을 쏟고 연인에게서 감정적으로 독립된 채로 남으려 한다고 적었다.

2025년 8월 잡지 기사[^2]는 회피형 애착을 가진 사람이 감정 소모에 민감해 친밀함을 피하려 한다고 적었다.
