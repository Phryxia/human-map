# 잠든 아기의 숨 확인하기

별칭: 없음

어린 아기를 돌보는 부모가 잠든 아기가 숨을 쉬는지 되풀이해 들여다보고 만져 본다.

# 서술

1892년 Poet Lore 에 실린 Arbes 의 소설[^1]에서 어머니는 잠든 아이에게 이따금 몸을 숙여 숨소리를 듣거나 이마가 뜨겁지 않은지 짚어 본다.

2012년 Straight Dope 게시글[^2]의 글쓴이는 거실 그네에서 낮잠 자는 아기가 살아 있는지 알려고 10분마다 가서 뺨이나 발가락을 간질여야 한다고 썼다. 2013년 ScienceDaily 기사[^3]에 따르면 갓 어머니가 된 사람은 아기가 아직 숨 쉬는지 늘 걱정하고 확인하기도 한다.

2021년 Cincinnati Review 에 실린 에세이[^4]의 필자는 아기의 가슴이 오르내리는 것을 느끼거나 작은 소리를 듣고서야 심장이 다시 뛰었다고 적었다.

2024년 연구[^5]에서 출산 뒤 어머니들이 가장 흔히 떠올린 사고 위해 생각은 아기가 숨을 멈추거나 영아돌연사로 죽는 생각이었다.
