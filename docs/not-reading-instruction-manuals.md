# 사용설명서 읽지 않기

별칭: 없음

새 제품이나 약을 산 사람이 함께 든 사용설명서를 읽지 않고 바로 쓴다.

묶음: [건강과 위험](../groups/health-and-safety.md)

# 서술

2006년 기사[^1]의 기자는 사람들이 포장지를 뜯어 제품을 쓰고 안에 든 사용설명서는 읽지도 않고 버린다고 적었다.

2013년 연구[^2]에서 응답한 입원 환자 1,218명 가운데 18.8%는 약의 환자용 설명서를 읽은 적이 없었고 6.5%는 예상하지 못한 일이 생겼을 때만 읽었다.

2018년 기사[^3]가 전하는 영국 설문에서 응답자의 19%는 크리스마스에 새 기기를 받은 뒤 설명서를 거의 읽지 않았다. 2024년 일본 기관 발표[^4]는 손을 덜 들이고 싶은 마음에 주의사항을 확인하지 않고 조리가전을 잘못 쓰는 경우를 들었다.
