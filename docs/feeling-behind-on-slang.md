# 신조어 몰라 뒤처졌다고 느끼기

별칭: 없음

남들이 쓰는 신조어나 밈을 모르는 사람이 유행에 뒤처졌다고 느낀다.

묶음: [남의 시선과 창피함](../groups/others-gaze.md)

# 서술

2015년 서울신문 칼럼[^1]은 솔까말이 흔한 신조어 가운데 하나이고 이 말을 모르면 뒷방 노인네 취급을 받는다고 썼다.

2024년 정책주간지 기사[^2]가 전한 설문에서 응답자의 40.4%가 밈이나 신조어를 모를 때 유행을 따라가지 못한다고 느낀다고 답했다.
