# 도덕적 위선

별칭: moral hypocrisy[^2]

사람이 남에게는 엄하게 탓하거나 금하는 일을 자기가 할 때는 너그럽게 보거나 몰래 한다.

묶음: [판단과 어림의 치우침](../groups/judgment-biases.md)

# 서술

1925년 소설[^1]의 기숙사 사감은 연애편지를 받은 학생을 두 시간 넘게 꾸짖으며 연애가 자유니 신성이니 하는 말은 악마가 지어낸 소리라고 설교한다. 소설에서 그 사감은 밤마다 혼자 학생들의 연애편지를 펼쳐 놓고 연인의 대화를 흉내 낸다.

2007년 대학 소식[^2]이 전한 실험에서 무작위 배정 절차를 쓰지 않고 쉬운 과제를 자기에게 준 참가자들은 자기의 그 행동을 남이 한 같은 행동보다 훨씬 너그럽게 판정했다.
