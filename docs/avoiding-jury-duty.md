# 배심원 소환 회피

별칭: 없음

배심원으로 소환된 사람이 소환에 응하지 않거나 핑계를 대고 빠진다.

# 서술

2001년 미주리주 법원행정처 보고서[^1]에서 잭슨 카운티 순회법원의 소환장을 받은 배심원 가운데 14%가 매주 응답하지 않았다.

2013년 1월 The Jury Expert 의 글[^2]은 스스로를 윤리적이고 책임 있는 시민으로 여기는 사람도 배심 의무 앞에서는 거의 어떤 거짓 핑계라도 받아들이는 거짓말쟁이로 바뀔 수 있다고 적었다. 같은 해 8월 전북일보 기사[^3]에 따르면 법원은 출석 통지를 받고도 정당한 이유 없이 나오지 않은 국민참여재판 배심원 후보자 20명에게 과태료를 매겼다.

2018년 PhillyVoice 기사[^4]가 전한 보고서에서 우편으로 소환장을 받은 필라델피아 주민의 35%에서 42%가 응답하지 않았다.
