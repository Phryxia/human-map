# 다원적 무지

별칭: Pluralistic ignorance

집단 안의 사람이 속으로는 이해하지 못하거나 동의하지 않으면서 다른 사람들은 이해하거나 동의한다고 믿고 겉으로 따른다.

# 서술

시사경제용어사전 자료[^3]는 다원적 무지를 소수의 의견을 다수의 의견으로, 또는 다수의 의견을 소수의 의견으로 잘못 인지하는 일로 정의한다.

2022년 글[^4]의 칼럼은 강의실에서 학생 대부분이 이해하지 못했으면서도 다른 사람이 손을 들지 않으니 자신만 이해하지 못했다고 생각해 손을 들지 않는다고 쓴다.

1837년 안데르센의 「벌거벗은 임금님」에서 구경꾼은 누구도 옷이 보이지 않는다고 인정하지 않는다. 인정하면 자신이 바보이거나 직위에 맞지 않는 사람이 되기 때문이다.[^1]

# 조건

2022년 글[^4]은 같은 학생이 선생님과 일대일로 만났을 때는 질문에 눈치 보지 않고 답할 수 있다고 쓴다.

2014년 Rendsvig 는 확신이 없을 때 남을 보고 결정하는 사람들의 집단이 다원적 무지에 빠져 아무도 행동하지 않게 될 수 있다고 보였다.[^2]
