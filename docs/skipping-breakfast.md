# 아침 식사 거르기

별칭: 아침 결식, 아침밥 굶기, breakfast skipping

시간이 없거나 입맛이 없는 사람이 아침을 먹지 않고 하루를 시작한다.

# 서술

2006년 정책브리핑의 한 기고는 아침을 굶고 등교하는 학생이 늘고 있다고 쓴다. 글쓴이는 그 이유로 입맛이 없음, 늦잠으로 먹을 시간이 없음, 부모가 챙겨 주지 못함을 든다.[^1]

2023년 자료[^2]의 청소년 조사에서 아침을 거르는 이유는 시간이 없어서가 35.1%로 가장 많았다. 식욕이 없어서가 21.4%, 배가 아프거나 소화가 안 돼서가 14.0%로 뒤를 이었다.

2024년 연구[^3]의 노르웨이 청소년 조사에서 스스로 답한 이유는 시간 부족 59%, 아침을 먹고 싶지 않음 48%였다. 2006년 글[^1]과 2023년 자료[^2]의 한국 학생 자료도 시간과 입맛을 이유로 든다.
