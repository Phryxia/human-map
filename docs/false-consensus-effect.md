# 서술

1815년 오스틴의 소설에서 우드하우스 씨는 자기 위가 기름진 음식을 받지 못했고 남들이 자기와 다르다는 것을 믿지 못했다. 그는 손님들이 결혼식 케이크를 먹지 못하게 하려고 애썼다.[^1]

2019년 논문의 저자들은 자기 의견을 지지하는 사람의 비율을 실제보다 높게 어림하는 치우침을 허위 합의 효과라 부른다. 18\~35세 참가자 380명의 연구에서 온라인 인맥이 비슷한 사람들로 이루어졌을수록, 하루 SNS 사용 시간이 길수록, 모호함을 덜 견딜수록 이 치우침이 컸다.[^2]

2022년 논문[^3]에서 자기 경험을 혼자만 겪는다고 느끼는 실존적 고립이 클수록 참가자들은 또래가 자기와 같은 선택을 하리라고 덜 기대했다.
