# 은퇴 뒤 따뜻한 곳으로 옮겨 살기

별칭: Retirement Migration[^5]

일을 그만둔 사람이 은퇴한 뒤 날씨가 따뜻하거나 생활비가 싸거나 편의시설이 많은 지역으로 옮겨 산다.

묶음: [사는 곳과 옮겨 살기](../groups/where-to-live.md)

# 서술

2009년 서울신문 기사[^1]에서 은퇴이민을 생각하던 한 사람은 먼저 떠난 사람들이 친구나 다른 가족과 떨어져 지내며 외로움을 많이 느끼는 것 같았다고 말했다.

2013년 1월 미국 농무부 경제연구소 자료[^2]는 애리조나, 뉴멕시코, 플로리다가 은퇴자가 흔히 옮겨 가는 곳이고 편의시설을 갖춘 다른 지역도 인기가 있다고 적었다. 2013년 7월 게시판 글[^3]의 글쓴이는 은퇴하면 따뜻한 곳으로 옮길지 정하지 못했다며 찬반 의견을 물었다.

2014년 이코노믹리뷰 기사[^4]는 은퇴 후 이민을 떠났던 많은 사람이 비슷한 이유로 다시 한국으로 돌아왔다고 적었다.

2021년 연구[^5]에서 다른 나라로 옮긴 은퇴자 다수는 옮겨 간 나라의 좋은 날씨, 싼 생활비, 여러 편의시설을 누렸다.

2022년 미국 인구조사국 글[^6]은 노인 일부가 따뜻하고 편의시설이 많은 지역으로 먼 거리의 은퇴 이주를 한다고 적었다.
