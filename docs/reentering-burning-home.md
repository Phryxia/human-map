# 불난 집에 다시 들어가기

별칭: 없음

불난 집에서 빠져나온 사람이 불을 끄거나 물건을 챙기거나 사람을 구하려고 다시 안으로 들어간다.

묶음: [건강과 위험](../groups/health-and-safety.md)

# 서술

2010년 기사[^1]에 따르면 뉴질랜드에서 집 화재로 다친 사람의 57%가 다시 안으로 들어갔다. 불을 끄려고 들어간 사람이 47%, 물건을 챙기려던 사람이 7%, 누군가를 구하려던 사람이 3%였다.

2018년 기사[^2]는 해마다 무언가를 가지러 불붙은 집으로 다시 뛰어들었다가 숨지는 사람이 몇 명씩 있다고 적었다. 2021년 화상 사례 연구[^3]의 저자들은 성인 환자가 소지품을 구하거나 불을 끄려고 건물이나 집에 다시 들어갔다는 이야기가 자주 나온다고 썼다.

2025년 영국 소방 당국의 안내[^4]는 불을 직접 끄려 하거나 귀중품을 가지러 돌아가지 말라고 적었다.
