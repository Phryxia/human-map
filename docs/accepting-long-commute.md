# 긴 통근 감수

별칭: Commuting paradox[^1]

직장인이 집값이 싼 먼 곳에 살며 긴 출퇴근 시간을 받아들인다.

# 서술

2008년 Stutzer 와 Frey 의 패널 자료 분석[^1]에서 통근 시간이 긴 사람은 주관적 안녕감을 체계적으로 더 낮게 답했다.

2013년 서울시 자료[^2]에서 대중교통 출근 시간은 서울 안에서 51분, 인천과 경기에서 서울로 1시간 18분이었다.

2025년 기사[^3]는 일자리가 많고 집값이 서울보다 싸서 경기도에 사는 사람이 늘고 있다고 썼다. 2026년 10월 기사[^4]에서 집값이 오른 뒤 입사한 직장인은 서울 외곽에서 왕복 3시간을 이동하며 출근한다고 말했다.
