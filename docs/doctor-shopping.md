# 여러 병원 전전하기

별칭: Doctor shopping[^1]

이상이 없다는 진단을 받은 사람이 병이 있다는 걱정을 놓지 못해 이 병원 저 병원을 옮겨 다니며 검사를 받는다.

# 서술

1976년 Kasteler 등의 연구[^1]에서 상위 소득 집단의 건강염려 경향은 의사를 바꿔 다니는 행동과 관련이 있었다.

1995년 Sato 등의 연구[^2]는 일본 1차 진료 환자 가운데 의사를 바꿔 다닌 환자들에게서 정신질환의 평생 유병률이 높게 나왔다고 보고했다.

2023년 전요섭의 논문[^3]은 건강에 대한 지나친 염려 때문에 잦은 건강검진을 받으며 병원을 전전하는 일을 적는다.

2024년 3월 서울신문 기사[^4]는 이상이 없다는 진단을 받아도 걱정과 불안으로 병원을 전전하는 사람을 다뤘다.
