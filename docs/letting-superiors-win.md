# 윗사람에게 일부러 져 주기

별칭: 없음

아랫사람이 상사처럼 잘 보여야 할 사람과 시합이나 놀이를 하며 일부러 진다.

묶음: [일터와 일자리](../groups/work.md), [가까운 사이의 감정과 말](../groups/close-relationships.md)

# 서술

2002년 10월 기사[^1]가 전한 설문에서 임원의 20%는 거래를 더 따낼 수 있다고 생각되면 고객이 자기를 이기게 두겠다고 답했다.

2009년 7월 기사[^2]는 상사와 골프를 칠 때 상사가 이기도록 경기를 일부러 내주지 말라고 적었다.

2013년 2월 골프 칼럼[^3]은 접대 골프에서 일부러 져 주는 인상을 주면 안 되고 그린에서 퍼팅으로 점수를 조절하는 것을 하수 중의 하수라 불렀다.

2020년 1월 골프장 블로그 글[^4]은 상사의 자존심을 다치게 하고 회사 안의 입지를 잃을까 두려워 상사를 이기기를 꺼릴 수 있다고 적는다.

2022년 2월 게시판 댓글[^5]의 글쓴이는 매니저보다 탁구를 훨씬 잘 친다는 글에 자기라면 몇 판은 티 나지 않게 일부러 지겠다고 답했다.
