# 잠든 얼굴 바라보기

별칭: 없음

사람이 곁에서 잠든 가족이나 연인의 얼굴을 한참 들여다본다.

묶음: [가까운 사이의 감정과 말](../groups/close-relationships.md)

# 서술

1947년 다자이 오사무의 소설[^1]에서 화자는 방이 희붐하게 밝아 오자 곁에서 잠든 사람의 얼굴을 찬찬히 바라보았다.

2014년 육아 에세이[^2]의 필자는 숨소리를 내며 깊이 잠든 아이의 얼굴을 하염없이 바라볼 때의 사랑스러움을 적었다. 2021년 육아 일기[^3]의 필자는 새벽까지 일할 때 잠든 남편과 아이를 지켜보다가 둘의 자는 자세와 잠꼬대 버릇이 닮은 것을 보았다.
