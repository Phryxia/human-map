# 말을 피하려고 다른 일에 몰두한 척하기

별칭: 없음

주변 사람과 말을 섞고 싶지 않은 사람이 신문이나 책, 휴대폰, 헤드폰에 몰두한 척해 말을 막는다.

# 서술

1908년 소설[^1]에서 잔뜩 겁을 먹은 인물은 다른 인물이 탁자에 앉자 책을 집어 들고 읽는 척했다.

2011년 조사 보고서[^2]에서 휴대폰 사용자의 13%가 주변 사람과 마주하지 않으려고 휴대폰을 쓰는 척했다.

2019년 기사[^3]가 전한 설문에서 헤드폰을 쓰는 응답자의 절반 가까이는 남이 귀찮게 하지 않기를 바라서 헤드폰을 쓴다고 답했다.
