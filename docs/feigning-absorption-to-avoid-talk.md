# 말을 피하려고 다른 일에 몰두한 척하기

별칭: 없음

주변 사람과 말을 섞고 싶지 않은 사람이 신문이나 책, 휴대폰, 헤드폰에 몰두한 척해 말을 막는다.

묶음: [낯선 사람과 공공장소](../groups/strangers-and-public-places.md)

# 서술

1908년 소설[^1]에서 잔뜩 겁을 먹은 인물은 다른 인물이 탁자에 앉자 책을 집어 들고 읽는 척했다.

2011년 조사 보고서[^2]에서 휴대폰 사용자의 13%가 주변 사람과 마주하지 않으려고 휴대폰을 쓰는 척했다.

2014년 댓글[^3]의 글쓴이는 말 걸기를 피하는 흔한 방법이 헤드폰이고 음악을 계속 듣는 사람이 아니면 헤드폰을 어디에도 꽂지 않아도 된다고 썼다.

2019년 기사[^4]가 전한 설문에서 헤드폰을 쓰는 응답자의 절반 가까이는 남이 귀찮게 하지 않기를 바라서 헤드폰을 쓴다고 답했다.

2021년 댓글[^5]의 글쓴이는 주변 사람이 말을 거는 것이 싫을 때 이어폰이나 헤드폰만 낀다고 적었다.

2023년 기사[^6]는 예전 부부들도 골프 클럽이나 헛간으로 물러나거나 신문 뒤에 숨거나 개에게 정성을 쏟지 않았느냐고 묻는다.

2024년 논문[^7]은 예전에는 기차에서 신문과 잡지를 읽으면 방해하지 말라는 뜻이 저절로 전해졌고 지금은 스마트폰과 헤드폰이 그 일을 한다고 썼다.
