# 자원봉사 하지 않기

별칭: 자원봉사 불참, 봉사 미루기

자원봉사를 떠올린 사람이 시간이 없다는 이유로 봉사하지 않는다.

# 서술

2015년 F1 의 캐나다 통계에서 자원봉사를 하지 않은 사람의 66%가 시간 부족을 이유로 들었고 여성과 남성 모두에게 시간 부족이 가장 큰 장벽이었다. [F1]

2024년 F2 의 사우디아라비아 치과대학생과 치과의사 655명 조사에서 가장 두드러진 장벽은 시간 제약(74.50%)이었고 가장 덜 중요한 장벽은 부모나 가족의 반대(28.85%)였다. [F2]

# 조건

기록된 조건 없음. [F1][F2]
