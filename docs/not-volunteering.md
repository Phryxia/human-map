# 자원봉사 하지 않기

별칭: 자원봉사 불참, 봉사 미루기

자원봉사를 떠올린 사람이 시간이 없다는 이유로 봉사하지 않는다.

# 서술

2015년 F2 의 캐나다 통계에서 자원봉사를 하지 않은 사람의 66%가 시간 부족을 이유로 들었고 여성과 남성 모두에게 시간 부족이 가장 큰 장벽이었다. [F2]

2024년 F4 의 사우디아라비아 치과대학생과 치과의사 655명 조사에서 가장 두드러진 장벽은 시간 제약(74.50%)이었고 가장 덜 중요한 장벽은 부모나 가족의 반대(28.85%)였다. [F4]

# 조건

1990년 F1 이 전하는 미국 조사에서 지난해 봉사를 부탁받은 41% 가운데 87%가 실제로 봉사했고 부탁받지 않은 57% 가운데서는 30%만 봉사했다. [F1]

2022년 F3 의 논문은 학력이 높고 건강한 노인이 봉사를 부탁받을 가능성이 높아서 봉사할 가능성도 높다고 적는다. [F3]
