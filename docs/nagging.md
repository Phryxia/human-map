# 잔소리

별칭: nagging[^1]

가까운 사람이 상대에게 같은 요구나 지적을 되풀이해 말한다.

묶음: [가까운 사이의 감정과 말](../groups/close-relationships.md)

# 서술

학술 백과사전 항목[^1]은 잔소리를 되풀이되거나 끈질긴 불평이라고 정의한다.

2000년 인터넷 조사[^2]에서 아내 곁을 떠나고 싶은 때를 묻는 문항에 응답자 45.0%가 잔소리할 때라고 답했다. 2002년 대학 보도자료[^3]가 전한 연구는 요구가 되풀이되면 상기가 되고 상기가 다시 되풀이되면 잔소리가 된다고 보았다.

2021년 칼럼[^4]에 실린 잔소리하는 쪽의 말은 상대가 하나도 고치지 않으니 계속 말한다는 것이었다. 2022년 기사[^5]의 필자는 부모의 잔소리를 듣다 못한 아이가 자신을 방어하려고 한 말이 말대꾸로 불린다고 썼다.
