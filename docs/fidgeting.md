# 꼼지락거리기

별칭: Fidgeting[^5], 다리 떨기[^7]

초조하거나 주의가 흐트러진 사람이 무심코 다리를 떨거나 손가락으로 무언가를 두드리며 몸을 가만히 두지 못한다.

묶음: [걱정과 기분](../groups/worry-and-mood.md)

# 서술

1868년 콜린스의 소설에서 당혹한 인물은 혼잣말을 하며 걷다가 창가에 멈춰 서서 손가락으로 유리창을 두드렸다.[^1]

1908년 회고록[^2]에서 골턴은 사람들이 지루한 정도를 꼼지락거림의 횟수로 잴 수 있다고 적었다.

1999년 연구[^3]는 꼼지락거림을 자세 유지와 함께 운동이 아닌 일상 활동의 열 생산(NEAT)에 넣었다.

2011년 기사[^4]는 꼼지락거림을 불안이나 지루함에 대한 반응이라고 적는다.

2013년 연구[^5]의 저자들은 주의가 흐트러지거나 생각이 딴 데로 갈 때 사람들이 더 꼼지락거린다는 일화 보고를 소개했다.

2024년 7월 연구[^6]에서 저자들이 ADHD 진단을 받았다고 적은 성인 70명은 주의 과제를 하며 정답을 낸 시행에서 더 많이 꼼지락거렸다.

2024년 12월 기사[^7]는 다리 떨기가 스트레스나 긴장을 풀려는 무의식적인 반응일 수 있다고 적는다.
