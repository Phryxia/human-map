# 기부 단체 불신

별칭: 없음

기부하지 않는 사람이 모금 단체를 믿지 못해 기부하지 않는다.

# 서술

2019년 서울시 발표[^1]가 전한 기부 인식 실태 조사에서 기부하지 않는 이유로 믿을 수 없어서를 든 사람은 24.4%로 경제적 여유가 없어서(48.7%) 다음이었다.

2020년 기사[^2]는 시민단체에 대한 불신이 커지면서 모금 단체를 못 믿어 기부하지 않았다는 사람의 비중이 계속 늘고 있다고 전했다.
