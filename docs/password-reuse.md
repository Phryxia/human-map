# 비밀번호 재사용

별칭: password reuse[^1]

여러 온라인 계정을 쓰는 사람이 사이트마다 다른 비밀번호를 만들지 않고 같은 비밀번호를 여러 곳에 쓴다.

# 서술

2006년 연구[^1]는 3개월 동안 50만 명의 비밀번호 사용과 재사용 습관을 쟀다. 2016년 연구[^4]에서 사람들은 비밀번호 하나를 웹사이트 1.7\~3.4곳에 다시 썼고 자주 입력해야 하는 비밀번호를 주로 재사용했다. 2017년 연구[^6]가 분석한 유출 자료에서 사용자의 38%는 여러 사이트에 똑같은 비밀번호를 썼고 20%는 쓰던 비밀번호를 고쳐 새 비밀번호를 만들었다. 2020년 기사[^7]가 전하는 한국인터넷진흥원 조사에서 응답자의 26.46%인 557명이 개인 계정과 업무 계정에 같은 ID 를 썼고 그 가운데 170명은 비밀번호까지 같았다.

2014년 연구[^2]의 면접에서 사용자 대부분은 비밀번호를 재사용하거나 적어 두는 방식으로 버텼다. 2015년 댓글[^3]의 글쓴이는 모든 곳에 같은 비밀번호를 쓰다가 비밀번호 관리자를 들인 뒤로 비밀번호를 생성해 쓴다. 보안 피로를 다룬 2016년 기관 글[^5]은 비밀번호를 여러 번 바꾼 사람이 예전에 써서 기억나는 비밀번호로 돌아가는 장면을 든다.
