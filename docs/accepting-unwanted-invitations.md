# 내키지 않는 초대에 응하기

별칭: 없음

가고 싶지 않은 모임이나 행사에 초대받은 사람이 거절하지 못하고 초대에 응해 간다.

# 서술

2019년 기사[^1]가 전한 벼룩시장 구인구직 설문에서 직장인 78.2%는 참석하기 부담스러운 경조사에도 참석하거나 경조사비라도 낸다고 답했다.

2022년 Straight Dope 댓글[^2]의 글쓴이는 가고 싶지 않은 모임에 가는 까닭으로 대개 가겠다고 약속했기 때문이라고 답하며 가겠다고 했으면 그날 가서 손님 노릇을 한다고 적었다.

2023년 Givi 와 Kirk 의 논문[^3]은 거절하기 어려운 탓에 초대받은 사람이 원하지 않을 때에도 초대를 받아들인다고 쓴다.
