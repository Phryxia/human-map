# 노후 준비 미루기

별칭: 없음

일하는 나이의 사람이 노후 준비를 아직 하지 않고 나중에 하겠다고 미룬다.

# 서술

2013년 글[^1]이 전한 통계청 사회조사에서 노후 준비를 하지 않는 이유로 24.0% 가 준비할 계획은 있다고 답했다.

2023년 글[^3]이 전한 같은 조사에서는 노후 준비를 하지 않는 30.3% 가운데 34.3% 가 준비할 계획은 있다고 답했고 19.0% 는 아직 생각하지 않았다고 답했다.

2014년 Brown 과 Previtero 는 일을 미루는 사람이 미루지 않는 사람과 은퇴 관련 금융 행동 다섯 가지에서 다르게 행동한다고 보고했다.[^2]

2013년 글[^1]과 2023년 글[^3]에서 노후 준비를 하지 않는 이유로 가장 많이 나온 답은 준비할 능력이 없다는 것이었다. 준비할 계획은 있다는 답은 2013년 24.0% 에서 2023년 34.3% 였다.
