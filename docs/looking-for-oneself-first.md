# 단체 사진과 신문에서 자기부터 찾기

별칭: 없음

자기가 함께 찍힌 단체 사진이나 자기 일이 실렸을 신문을 받아 든 사람이 다른 사람이나 기사보다 자기 얼굴이나 이름부터 찾아본다.

묶음: [남의 시선과 창피함](../groups/others-gaze.md)

# 서술

1886년 체호프의 단편[^1]에서 다리를 지은 기술자는 준공식 다음 날 지역 신문을 집어 들고 네 면을 오래 훑으며 자기 이름을 찾는다.

2006년 게시글[^2]의 글쓴이는 단체 사진을 볼 때 왜 대개 자기부터 찾느냐고 묻는다.

2011년 논문[^3]에서 중국인 참가자들은 상사의 얼굴이 함께 있으면 자기 얼굴에 더 빨리 반응하던 우위를 잃고 자기 얼굴보다 상사의 얼굴에 더 빨리 반응했다.

2025년 칼럼[^4]의 필자는 인화한 단체 사진을 받으면 사람들이 제일 먼저 자기 모습을 찾아본다고 쓴다.
