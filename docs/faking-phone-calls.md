# 통화하는 척하기

별칭: Fake calls[^3], Fake phone call[^5]

밖에서 낯선 사람과 말을 섞고 싶지 않거나 불안한 사람이 휴대전화를 귀에 대고 통화하는 척한다.

묶음: [낯선 사람과 공공장소](../groups/strangers-and-public-places.md)

# 서술

2005년 CBS 뉴스 칼럼[^1]의 필자는 여성이 남성의 수작을 피하려고 통화하는 척하고 남성은 여성에게 다가가면서 통화하는 척한다고 썼다.

2010년 스트레이트 도프 게시판 게시글[^2]의 글쓴이는 구걸하는 사람이 다가오거나 누군가와 잡담을 피하고 싶을 때 가짜 통화를 한다고 적었다.

2011년 NBC 뉴스 기사[^3]에 따르면 휴대전화 사용자 13% 가량이 실제 대화를 피하려고 가짜 통화를 했다.

2020년 굿모닝 아메리카 기사[^4]는 집에 걸어가거나 차량 공유 서비스를 탈 때 불안을 느끼는 사람이 켤 수 있는 가짜 영상 통화가 틱톡에 퍼진다고 전했다.

2024년 체계적 문헌 고찰[^5]은 여성이 밤에 공공장소를 걸을 때 혼자가 아니라는 인상을 주려고 가짜 통화를 하는 전술을 든다.
