# 자기 지식 과대평가

별칭: 없음

사람이 어떤 분야나 사물에 대해 자기가 아는 정도를 실제보다 높게 여긴다.

# 서술

2002년 논문[^1]에서 사람들은 복잡한 현상을 실제보다 훨씬 정밀하고 깊이 이해한다고 느꼈고 저자들은 이를 설명 깊이의 착각이라 불렀다.

2015년 7월 논문[^2]에서 지리를 잘 안다는 느낌을 북돋운 참가자는 없는 지명도 안다고 답했다. 같은 달 연구 소개 기사[^3]에서 제1저자는 처음부터 자기가 많이 안다고 믿는 사람에게 특히 자기 지식을 가늠하는 일이 단순하지 않다고 말했다.
