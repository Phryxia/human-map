# 브라우저 탭 쌓아 두기

별칭: Tab overload[^1]

컴퓨터 사용자가 열어 둔 웹 브라우저 탭을 닫지 못하고 여러 개 쌓아 둔다.

# 서술

2021년 카네기멜런대 보도자료[^1]가 전한 연구에서 사람들은 열어 둔 탭에 들인 것이 있다고 느껴 탭 수에 압도되거나 부끄러움을 느끼기 시작해도 탭을 닫기 어려워했다.

2023년 ITWorld 기사[^2]가 전한 조사에서 응답자들은 평균 5\~10개의 탭을 열었고 400개까지 여는 사람도 있었다.

2025년 Hacker News 댓글[^3]의 글쓴이는 방문 기록과 북마크에서 페이지를 못 찾을까 두려운 것이 아니라 다시 찾는 일이 괴로워 하고 싶지 않다고 썼다.

2026년 디지털 저장 연구[^4]는 사람들이 평균 1,000통쯤의 읽지 않은 메일과 정리하지 않은 디지털 파일 수천 개와 함께 브라우저 탭을 많이 열어 둔다는 보고를 인용한다.
