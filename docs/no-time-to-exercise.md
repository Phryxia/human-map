# 시간 부족으로 운동하지 않기

별칭: 운동할 시간이 없음, 시간 부족 때문에 운동 안 함, lack of time as a barrier to physical activity

일이나 학업에 쫓기는 사람이 운동할 시간이 없다고 여기고 규칙적인 운동을 하지 않는다.

# 서술

1919년 글[^1]의 저자는 너무 바빠 걷지 못하고 탈것을 탔다거나 운동할 시간이 없었다는 말을 예로 들었다.

2007년 자료[^2]의 호주 통계에서 운동을 하지 않거나 드물게 하는 이유로 가장 많이 꼽힌 것은 일이나 학업으로 시간이 부족함(22%)이었다. 2017년 자료[^5]의 한국 조사에서는 규칙적으로 체육활동을 한 경험이 없는 응답자의 64.6%가 시간 부족을 원인으로 꼽았다. 2017년 연구[^6]의 호주 성인 조사에서는 비활동으로 분류된 사람의 50.0%가 시간 부족을 장벽으로 골랐고 가장 많이 고른 응답이었다.

2019년 네이버 지식iN 게시글의 글쓴이는 대학생이고 과제가 많아 운동할 시간이 따로 생기지 않으며 일주일에 사나흘은 밤을 샌다고 적었다.[^7]

# 조건

2011년 연구[^3]의 고용 인구 자료에서 4세 미만 자녀를 둔 일하는 어머니는 6%가 매일 신체 활동을 한다고 답했고 같은 조건의 일하는 아버지는 14%였다.

나이에 따라 드는 이유가 다르다. 2012년 자료[^4]의 한국 조사에서는 20대 이하에서 시간 부족 응답 비율이 높았고 50대 이상에서는 건강상의 문제가 주된 이유였다. 2026년 글[^8]이 전한 2025년 조사에서는 50대 이하에서 시간 부족, 60대에서 관심 부족, 70세 이상에서 건강 문제 응답 비율이 가장 높았다.
