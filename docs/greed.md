# 탐욕

별칭: Greed[^2]

이미 가진 것이 있는 사람이 그것에 만족하지 못하고 더 많은 돈이나 것을 바란다.

묶음: [돈과 소비](../groups/money.md)

# 서술

1886년 단편[^1]에서 새 땅에 자리 잡은 농부는 처음에는 모든 것에 기뻐했으나 익숙해지자 여기에도 땅이 모자라다고 생각하기 시작했다.

2023년 Hoyer 외의 논문[^2]은 탐욕을 지금 가진 것에 대한 불만족과 더 얻으려는 욕구가 합쳐진 것으로 정의하고 사람들이 그것을 서로 반대로 평가한다고 적었다.

2025년 WorkingUS 게시글[^3]의 글쓴이는 초봉 5만 달러에서 시작해 10만, 15만, 18만 달러에 닿을 때마다 다음 금액을 바랐고 18만 달러를 찍은 뒤에는 앞자리가 2로 바뀌었으면 했다고 썼다.
