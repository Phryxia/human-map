# 늦잠에 대한 불안

별칭: 없음

아침에 제때 일어나야 하는 사람이 늦잠을 잘까 봐 불안해한다.

# 서술

2016년 클리앙 댓글[^1]의 글쓴이는 한 번에 일어난다는 보장이 없어 불안해서 알람을 여러 개 맞춘다고 적었다.

2022년 연구[^2]에서 응답자의 70.5%가 휴대전화의 스누즈 기능을 자주 쓴다고 답했고 주된 이유는 늦잠에 대한 불안을 줄이려는 것이었다.
