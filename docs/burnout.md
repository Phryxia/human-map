# 번아웃

별칭: Burn-out[^2], 번아웃증후군[^3]

일하는 사람이 오래 쌓인 일의 스트레스로 지치고 일에서 마음이 멀어지며 일을 해내지 못한다고 느낀다.

묶음: [일터와 일자리](../groups/work.md)

# 서술

2016년 Maslach 와 Leiter 의 리뷰[^1]는 이 반응의 세 차원을 압도적인 소진, 일에 대한 냉소와 분리감, 비효능감과 성취감 결여로 적었다. 2019년 세계보건기구 발표[^2]는 번아웃을 성공적으로 관리되지 못한 만성 직장 스트레스에서 비롯되는 증후군으로 개념화했다.

2021년 기사[^3]는 어떤 직무를 맡는 도중 극심한 육체적, 정신적 피로를 느끼고 직무에서 오는 열정과 성취감을 잃는 증상을 번아웃증후군이라 부른다고 썼다. 2022년 Hacker News 댓글[^4]의 글쓴이는 너무 많은 일을 하고 매일 끝에 지치고 의욕이 꺾일 때를 번아웃의 때로 들었다.

2023년 중국 농촌 가정의 연구[^5]의 저자들은 표면 행위가 정서적 소진으로 이어지고 그것이 다시 이직 의도를 낳는다고 썼다.
