# 다른 나라로 옮겨 살고 싶어 하기

별칭: Migration aspirations[^3]

자기 나라에 사는 사람이 기회가 있으면 다른 나라로 옮겨 살고 싶다고 바란다.

묶음: [사는 곳과 옮겨 살기](../groups/where-to-live.md)

# 서술

2004년 게시판 글[^1]의 글쓴이는 자라 온 곳과 달리 그 나라가 영혼에 더 고향처럼 느껴져서 그곳으로 옮겨 가고 싶다고 적었다.

2008년 갤럽 기사[^2]에서 2006년부터 2008년까지 세계 각지에서 조사한 응답자 넷 중 하나 넘게 외국으로 옮겨 가고 싶다고 답했다.

2024년 9월 연구[^3]는 개인 수준과 지역사회 수준의 요인이 모두 다른 나라로 옮겨 가려는 바람을 만든다고 보고했다. 2024년 10월 갤럽 기사[^4]에서 2023년 세계 성인의 16%가 할 수만 있다면 자기 나라를 영구히 떠나고 싶다고 답했다.
