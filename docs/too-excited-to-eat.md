# 들떠서 입맛 잃기

별칭: 없음

기다리던 날을 맞거나 즐거운 일을 앞둔 사람이 들뜬 마음에 입맛을 잃고 음식을 잘 먹지 못한다.

묶음: [걱정과 기분](../groups/worry-and-mood.md)

# 서술

1841년 디킨스의 소설에서 두 젊은이는 그날 아주 일찍 일어났고 아침에도 점심에도 입맛이 별로 없었다. 두 사람은 몹시 들떠 있었다.[^1]

2006년 Straight Dope Message Board 댓글[^2]의 글쓴이는 스트레스를 받거나 들뜰 때 입맛을 완전히 잃는다고 썼다. 2016년 요리 뉴스레터[^3]의 필자는 크리스마스 아침 아이들 대부분이 너무 들떠서 아침을 먹지 못한다고 썼다.

2017년 감정 식욕 설문 연구[^4]는 음식 섭취가 부정 정서와 긍정 정서 양쪽에 반응해 늘 수도 있고 줄 수도 있다고 적었다.
