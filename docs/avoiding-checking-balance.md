# 잔액 확인 피하기

별칭: Financial avoidance[^4]

돈이 모자라거나 많이 썼다고 느끼는 사람이 무서워서 통장 잔액이나 카드 명세를 확인하지 않는다.

# 서술

2021년 Monzo 블로그 글의 필자는 계좌를 확인하거나 잔액을 알고 싶지 않았고 저절로 해결되기를 바랐다고 적었다.[^2] 같은 해 금융 게시판 글의 글쓴이는 그달에 너무 많이 써서 카드 명세를 보기가 무섭다고 적었고 마주하지 않는 것이 불안을 더 키우는 줄 안다고 썼다.[^1]

2022년 영국 금융행위감독청 보도자료에서 어려움을 겪으면서 대출기관의 연락을 외면한 차입자의 42%는 부끄러워서 그랬다고 답했다.[^3]

2023년 Xin 외의 연구에서 재무 불안이 높은 사람은 재무 회피를 고를 가능성이 2.75배였다.[^4] 2024년 Hilbert 외의 논문은 청구서가 들었을 법한 편지를 받고도 낼 돈이 없다고 느껴 뜯지 않는 경우를 예로 들었다.[^5] 2025년 OneFamily 조사에서 청구서나 명세서를 열지 않은 적이 있다고 답한 영국의 18세에서 40세 성인은 열에 일곱이었다.[^6] 같은 조사를 전한 2025년 12월 The Intermediary 기사에서 확인을 피한 적이 있는 사람 가운데 36%는 확인할 생각만 해도 불안해서라고 답했다.[^7]
