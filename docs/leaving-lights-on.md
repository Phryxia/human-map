# 불과 전자제품 켜 두기

별칭: 없음

방을 나가거나 기기를 다 쓴 사람이 불이나 전자제품을 끄지 않고 켜 둔다.

# 서술

2014년 영국 지역 매체 기사[^1]가 전한 조사에서 소비자의 41%는 다시 쓸 기기를 끄는 것이 소용없다고 여겼다. 같은 조사에서 11%는 끄기가 귀찮다고 했고 13%는 그냥 잊는다고 답했다.

2018년 영국 스마트미터 보급 기관의 조사[^2]에서 약 8명 가운데 1명(12%)은 잘 때 수면등 삼아 빈 방에 불을 켜 둔다고 답했다.

2019년 Hacker News 댓글[^3]의 글쓴이는 나갈 때 불 끄는 것을 자주 잊어서 원격으로 불을 끌 수 있는 것이 좋다고 썼다.
