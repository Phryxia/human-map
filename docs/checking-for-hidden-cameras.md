# 숨은 카메라 살피기

별칭: 없음

공중화장실이나 탈의실을 쓰는 사람이 불법촬영 카메라가 숨어 있을까 불안해 벽과 문의 구멍을 살피거나 막는다.

묶음: [낯선 사람과 공공장소](../groups/strangers-and-public-places.md)

# 서술

2018년 기사[^1]에서 한 대학생은 휴대용 실리콘을 들고 다니며 화장실 구멍을 막는 방법을 친구에게서 들었다.

2019년 서울시 조사에서 불법촬영이 의심되는 장소를 쓸 때 하는 행동으로 화장실 등에 구멍이 뚫려 있는지 확인한다는 답이 61% 로 가장 많았다.[^2] 같은 해 서울시 매체의 시민기자[^3]는 화장실이나 탈의실을 쓸 때면 불법촬영 카메라가 숨겨져 있지 않을까 하는 불안이 먼저 든다고 썼다.
