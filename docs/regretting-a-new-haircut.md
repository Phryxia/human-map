# 새 머리 모양 후회

별칭: 없음

머리를 자르거나 모양을 바꾼 사람이 그 결과를 마음에 들어 하지 않고 후회한다.

묶음: [남의 시선과 창피함](../groups/others-gaze.md)

# 서술

1905년 오 헨리의 단편에서 머리를 잘라 판 아내는 짧게 지진 머리를 거울에 비춰 보며 남편이 자기를 보고 코니아일랜드의 코러스 걸 같다고 할까 걱정했다.[^1] 1920년 피츠제럴드의 단편에서 이발소 거울 앞에 앉은 인물은 새로 자른 머리가 흉하다고 느꼈고 그럴 줄 알았다고 여겼다.[^2]

2000년 1월 AP 기사[^3]가 전한 연구에서 남성 참가자는 머리가 뻗치거나 잘못 잘렸을 때 자신이 덜 똑똑하고 덜 유능하다고 느끼는 경향을 보였다. 2000년 10월 게시판 게시글[^4]의 글쓴이는 35세에 머리를 짧게 자르고 곧바로 후회했다고 적었다.

2014년 연구[^5]에서 헤어 커트 뒤 불만족을 느낀 적이 있는 여대생은 98.4%, 불평 행동을 한 적이 있는 여대생은 78.6%였다.

2024년 영국 Stylist 기사[^6]는 마음에 들지 않는 머리를 하고도 미용사에게 고개를 끄덕이며 고맙다고 하고 값을 치른 뒤 집에 가서 혼자 우는 모습을 적었다. 2025년 디시인사이드 게시글[^7]의 글쓴이는 얼굴 길이까지만 잘라 달라고 했는데 결과가 달랐고 미용사가 길이를 묻자 괜찮다고 답해 버렸다고 적었다.
