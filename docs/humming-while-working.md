# 일하거나 씻으며 흥얼거리기

별칭: 없음

사람이 집안일이나 손일을 하거나 샤워하는 동안 혼자 노래를 흥얼거린다.

묶음: [시간과 하루 습관](../groups/daily-time.md)

# 서술

1859년 엘리엇의 소설에서 긴 빗자루로 비질을 하던 인물은 귀를 기울여야 들릴 만큼 낮은 소리로 혼자 찬송가를 불렀다.[^1]

1874년 하디의 소설에서 풀을 베던 일꾼은 낫질 박자에 맞춰 곡조를 흥얼거렸다.[^2]

2000년 Straight Dope 댓글[^3]의 글쓴이는 두 주째 머릿속에 박힌 게임 주제곡을 머리가 자동으로 돌아갈 때마다 흥얼거린다고 썼다.

2007년 기사[^4]가 전한 조사에서 미국 소비자 29%와 캐나다 소비자 26%는 샤워하며 로큰롤 노래를 부른다고 답했다.

2015년 연구[^5]에서 하루 동안 일상을 녹음한 참가자 78명 가운데 23명(29%)이 노래하는 장면이 82개 녹음됐고 노래한 참가자의 비율은 남성 33%, 여성 25%였다.
