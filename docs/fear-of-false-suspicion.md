# 결백한데 의심받을까 겁내기

별칭: 없음

잘못이 없는 사람이 의심을 가려내는 자리에서 자기가 누명을 쓸까 봐 겁내고 긴장한다.

묶음: [걱정과 기분](../groups/worry-and-mood.md)

# 서술

1926년 5월 동화[^1]에서 두꺼비가 물건을 훔친 사람의 손가락을 문다는 말을 듣고 어두운 방에서 차례로 동이에 손가락을 넣은 사람들은 가슴이 두근거렸다. 그들은 두꺼비가 까닭 없이 자기 손가락을 물면 도둑 누명을 쓸까 봐 공연히 겁을 냈다.

2020년 4월 연구[^2]의 저자들은 기능적 자기공명영상 실험 끝에 신문을 받는 사람에게서 결백 여부와 상관없이 불안이 공통된 신경 반응으로 나타난다고 결론지었다.

2022년 12월 기사[^3]는 경찰 단속으로 차를 세운 사람이 아무 잘못도 하지 않았다고 확신하면서도 범죄자처럼 식은땀이 난다고 적었다.

2026년 5월 에세이[^4]의 필자는 술을 한 방울도 마시지 않았는데도 마음은 큰 죄라도 저지른 기분이었다고 썼다.
