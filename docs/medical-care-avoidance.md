# 진료 회피

별칭: 검진 미루기, 병원 미루기, Medical care avoidance

진료나 검진을 받아야 할 것 같다고 여기는 사람이 불편함이나 나쁜 결과에 대한 두려움, 시간 부족을 이유로 그것을 미루거나 받지 않는다.

# 서술

2014년 Taber 외가 분석한 2008년 미국 조사에서 응답자의 약 4분의 1은 불편해서(26.8%) 또는 심각한 병이 두려워서(26.4%) 진료를 피했다고 답했다. [F1]

2018년 F2 의 기사가 전한 국립암센터 조사에서 암검진을 받지 않은 이유로 시간적 여유가 없어서(19.7%), 검사과정이 힘들어서(15.5%), 암 발견의 두려움(6.2%)이 나왔다. [F2]

2025년 F3 의 보도자료는 진료 예약을 미루거나 가지 않기, 검사 거부, 검사 결과를 들으러 다시 오지 않기를 건강 정보 회피의 모습으로 든다. [F3]

2026년 F4 의 기사가 전한 국립암센터 암검진 수검행태조사에서 검진을 받지 않은 이유 1위는 자기 건강 상태에 문제가 없다고 생각해서(43.4%)였다. [F4]

# 조건

F1 의 수치는 2008년 미국 전국 조사의 응답이고 F2 의 수치는 2018년 한국 암검진 대상자 조사의 응답이다. [F1][F2]

2026년 F4 는 자기 건강 상태에 문제가 없다고 여기는 경우를 미수검 이유의 첫째로 적는다. [F4]
