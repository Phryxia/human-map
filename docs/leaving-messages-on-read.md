# 읽고 답하지 않기

별칭: 읽씹[^4]

메신저로 메시지를 받은 사람이 메시지를 읽고도 답을 보내지 않는다.

# 서술

2011년 4월 파이낸셜뉴스 기사[^1]에서 카카오톡에 수신 확인 기능이 있는 줄 몰랐던 사람은 소개팅 상대의 메시지를 읽고 답하지 않았다가 상대가 그것을 어떻게 아는지 주위에 물었다.

2020년 1월 연구[^2]에서 일본 여대생 213명은 상대가 메시지를 읽은 상태에서 답을 기다릴 때 읽지 않은 상태보다 부정 감정이 더 빨리 생겼다고 답했다.

2026년 7월 개념 분석 논문[^3]의 저자는 메시지를 받은 쪽이 읽고 답하지 않는 침묵을 경계를 지키고 관계를 다루는 데 전략적으로 쓸 수 있다고 썼다. 같은 달 주간경향 칼럼[^4]은 읽씹을 메시지를 읽고 무시하는 행위라 부르고 그것이 일상과 관계에 영향을 미친다고 썼다.
