# 실망할까 봐 기대 접기

별칭: 없음

바라는 일의 결과를 앞둔 사람이 실망할까 봐 일부러 기대하지 않거나 결과를 나쁘게 예상해 둔다.

묶음: [걱정과 기분](../groups/worry-and-mood.md)

# 서술

1915년 몽고메리의 소설에서 인물은 셋집으로 나온 집을 빌릴 수 있겠느냐는 물음에 그런 일은 너무 좋아서 일어날 리 없다고 답했다. 그는 실망이 견디기 힘들 것이라며 바라지 않겠다고 했다.[^1]

1998년 플로리다 대학교 기사에서 연구자는 결과를 알게 되는 순간의 사람들에게서 비관 쪽 치우침을 발견했다고 말했다. 그는 그러지 않으면 충격으로 닥칠 나쁜 소식의 아픔을 줄이려는 것일 수 있다고 추측했다.[^2]

2024년 연구[^3]의 저자들은 사람들이 실망을 막으려고 소식이 오기 전에 기대를 비관 쪽으로 낮춘다고 썼다.

2026년 Psychology Today 글[^4]의 필자는 실망을 미리 예상해 두면 덜 아프리라고 믿게 된다고 썼다.
