# 옆 빈자리에 가방 두기

별칭: 없음

버스나 기차에 탄 승객이 옆 빈자리에 가방이나 짐을 올려 두어 다른 사람이 옆에 앉지 못하게 한다.

# 서술

2012년 Live Science 기사[^1]는 대중교통에서 옆에 누가 앉지 않기를 바라는 사람이 옆자리에 가방을 두거나 눈을 마주치지 않는다고 적었다.

2014년 클리앙 댓글[^2]의 글쓴이는 버스에 사람이 없을 때는 짐을 옆자리에 두기도 하지만 정류장에서 사람들이 타기 시작하면 주변에 자리가 있든 없든 짐을 무릎에 올린다고 썼다. 2019년 블라인드 댓글[^3]의 글쓴이는 옆에 가방을 놓아 아무도 못 앉게 한다고 했다.

2026년 위키트리 기사[^4]가 전한 시내버스 장면에서 노인은 2인용 좌석 한 자리에 앉고 나머지 한 자리에 가방을 올려 두었다.
