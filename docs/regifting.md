# 받은 선물 다시 선물하기

별칭: Regifting[^2]

받은 선물을 쓰지 않은 사람이 그것을 다른 사람에게 다시 선물로 준다.

# 서술

1904년 단편[^1]의 화자는 선물로 받은 오마르 하이얌 시집 가운데 마지막 네 권을 승강기 소년에게 주었다고 말한다.

2007년 기사[^2]는 해리스 인터랙티브 조사에서 절반이 넘는 사람이 원치 않는 선물을 처음 주는 것처럼 건넨 적이 있다고 인정했다고 쓴다. 2008년 댓글[^3]의 글쓴이는 다시 주는 선물이 티 나지 않게 되기를 바랐다.

2012년 연구[^4]에서 받은 선물을 다시 준다고 상상한 참가자는 자기 선물이 남에게 넘어갔다고 상상한 참가자가 보고한 것보다 원래 준 사람이 더 불쾌해할 거라고 여겼다. 2012년 기사[^5]가 전한 조사에서 응답자들은 받은 선물을 다시 주는 상대로 가족을 가장 먼저, 직장 동료를 그다음으로 꼽았다.

2017년 조사 기사[^6]에서 연말에 원치 않는 선물을 받은 사람의 42%는 그 선물을 다른 사람에게 다시 주었다.
