# 길에서 마주 오는 사람에게 비켜 주기

별칭: 없음

길에서 마주 오는 사람과 부딪힐 듯할 때 걷던 사람이 자기 쪽에서 옆으로 비켜 길을 내준다.

# 서술

1864년 소설[^1]의 화자는 넵스키 거리를 걸으며 장군과 근위대 장교, 귀부인이 지나갈 때마다 옆으로 비켜 길을 내주었다.

2006년 게시판 댓글[^2]에서 글쓴이 앞을 걷던 남편은 마주 오는 여자아이와 부딪히지 않으려고 인도에서 내려섰다.

2016년 실험을 소개한 기사[^3]에서 참가자들이 어떤 방식으로 충돌을 피하는지는 성격, 성별, 나이, 키, 몸무게와 관계가 없었다.

2019년 블로그 글[^4]의 필자는 여성들이 길에서 걷는 사람들을 위해 자기가 비켜야 한다고 자주 불평한다고 적었다.
