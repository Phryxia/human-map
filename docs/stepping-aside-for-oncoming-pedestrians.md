# 길에서 마주 오는 사람에게 비켜 주기

별칭: 없음

길에서 마주 오는 사람과 부딪힐 듯할 때 걷던 사람이 자기 쪽에서 옆으로 비켜 길을 내준다.

묶음: [낯선 사람과 공공장소](../groups/strangers-and-public-places.md)

# 서술

1864년 소설[^1]의 화자는 넵스키 거리를 걸으며 장군과 근위대 장교, 귀부인이 지나갈 때마다 옆으로 비켜 길을 내주었다.

2006년 게시판 댓글[^2]에서 글쓴이 앞을 걷던 남편은 마주 오는 여자아이와 부딪히지 않으려고 인도에서 내려섰다.

2006년 9월 짐 크로 박물관의 글[^3]에 따르면 짐 크로 시대 미국에서 흑인은 백인과 마주치면 보도에서 내려서거나 차도 쪽으로 걸어 백인에게 벽 쪽을 내주리라는 기대를 받았다.

2013년 Olivier 등의 실험에서 두 사람이 엇갈려 걸어 부딪힐 듯할 때 길을 내주는 쪽이 먼저 지나가는 쪽보다 충돌을 피하는 움직임을 더 많이 맡았다. 두 사람 모두 경로를 틀었고 길을 내주는 쪽은 속도도 바꾸었다.[^4]

2016년 실험을 소개한 기사[^5]에서 참가자들이 어떤 방식으로 충돌을 피하는지는 성격, 성별, 나이, 키, 몸무게와 관계가 없었다.

2019년 블로그 글[^6]의 필자는 여성들이 길에서 걷는 사람들을 위해 자기가 비켜야 한다고 자주 불평한다고 적었다.

2021년 Rapos 등의 실험[^7]에서 노인과 젊은 성인이 마주 걸어 부딪힐 듯하면 누가 먼저 지나가든 젊은 성인이 피하는 움직임을 더 많이 맡았다.

2024년 Bourgaize 등의 가상현실 실험[^8]에서 젊은 성인 참가자는 마주 오는 가상 보행자가 노인처럼 보이거나 노인처럼 걸을 때 젊은 사람처럼 보이거나 걸을 때보다 더 넓은 간격을 두고 비켜 지나갔다.
