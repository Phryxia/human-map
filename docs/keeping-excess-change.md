# 더 받은 거스름돈 돌려주지 않기

별칭: 없음

가게에서 거스름돈을 더 받은 손님이 그것을 알고도 돌려주지 않는다.

묶음: [돈과 소비](../groups/money.md)

# 서술

1899년에 영어로 옮겨진 소설[^1]의 화자는 가게에서 받은 돈을 들고 나온 뒤 나중에 더 적당한 때 가게 주인과 셈을 치르면 되고 일이 더 커질 것도 없다고 여겼다.

2013년 식당 현장 실험[^2]에서 거스름돈을 더 받은 손님 192명 가운데 128명이 돌려주지 않았다. 같은 실험에서 단골손님은 한 번 온 손님보다 훨씬 자주 돌려주었다.[^2]

2017년 오마이뉴스 글[^3]의 필자가 더 받은 거스름돈을 가게 아주머니에게 돌려주자 옆 가게 아주머니는 더 받은 거스름돈을 찾아와 돌려주는 경우가 거의 없다고 거들었다. 2019년 시사저널 칼럼[^4]의 필자에 따르면 5만원권 신권이 나왔을 무렵 거스름돈을 더 받은 사례가 인터넷 게시판에 종종 공유됐다.

2021년 재현 연구[^5]에서도 단골과 여성이 한 번 온 손님과 남성보다 더 받은 거스름돈을 자주 돌려주었다. 저자들은 부정직의 심리적 비용이 금전적 이득보다 클 수 있다고 본다.[^5]
