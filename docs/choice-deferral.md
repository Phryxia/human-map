# 선택 연기

별칭: choice deferral[^1], 결정 장애[^3]

고를 대안 앞에 선 사람이 무엇을 고를지 정하지 않고 결정을 뒤로 미룬다.

# 서술

2003년 문헌 고찰[^1]은 결정을 미루거나 행동하지 않거나 현상을 받아들여 결정을 피하는 네 가지 효과 가운데 하나로 선택 연기를 든다.

2019년 연구[^2]에서 대안 하나만 제시했을 때 선택을 미루는 효과는 구매에 대해 예상되는 후회가 매개했다. 2019년 칼럼[^3]의 필자는 갈림길에서 고민을 거듭하고도 결정을 내리지 못하고 뒤로 미루는 모습을 결정 장애라 부른다.
