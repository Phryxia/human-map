# 날닭고기 씻기

별칭: 없음

집에서 닭고기를 요리하는 사람이 조리 전에 날닭고기를 물에 씻거나 헹군다.

# 서술

2015년 미국 전국 조사 논문[^1]에서 소비자의 70% 가까이가 조리 전에 날가금육을 씻거나 헹군다고 답했다.

2021년 기사[^2]가 전한 호주 조사에서 응답자의 49%가 통째로 된 날닭고기를 씻는다고 답했다.

2026년 스코틀랜드 식품기준청 조사[^3]에서 응답자의 62%는 날닭고기를 씻지 않는다고 답했고 33%는 적어도 가끔 씻는다고 답했다.
