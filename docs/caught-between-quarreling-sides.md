# 다투는 두 사람 사이에서 편들지 못하기

별칭: 없음

서로 다투는 두 사람이나 두 집안을 함께 아는 사람이 어느 편도 들지 못하고 난처해한다.

묶음: [가까운 사이의 감정과 말](../groups/close-relationships.md)

# 서술

1925년 9월 작품[^1]의 화자는 날마다 다투는 이웃 두 집안을 지켜보고 어느 편이 그른지 알지 못해 잠자코 있었다.

2014년 3월 연구[^2]의 저자들은 부모가 자녀에게 편을 들라고 압박하는 일을 흔한 삼각관계의 한 형태로 보고 그 때문에 자녀가 두 부모 사이에서 찢기는 느낌을 받을 수 있다고 썼다.

2014년 7월 게시글[^3]의 글쓴이는 서로 갈등하는 아내와 어머니 사이에서 양쪽 성향을 다 이해해 공감이 되면서도 해결할 방도가 없어 자기도 힘들다고 적었다.

2016년 4월 대학생 필자의 글[^4]은 친구들 다툼 한가운데 끼면 한쪽 편을 들라는 압박을 느끼고 그러고 나면 다른 친구에게 미안해진다고 적었다.

2025년 2월 글[^5]의 필자는 아끼는 두 사람이 서로 싫어하면 편을 고르거나 적어도 불만에 맞장구쳐 주기를 말없이 기대받는다고 적었다.
