# 온화한 시기

별칭: benign envy[^1], 온화한 시기심[^2]

앞선 사람을 시기한 사람이 그 사람처럼 되려고 자기 처지를 끌어올리고 싶어 한다.

# 서술

2009년 6월 논문[^1]에서 온화한 시기를 겪은 사람은 자기 처지를 끌어올리려는 동기를 보였다.

2021년 7월 코메디닷컴 기사[^2]는 온화한 시기심을 가진 사람이 상대의 성공에 눈을 두고 자기도 그런 결과를 얻을 방법을 고민한다고 썼다.
