# 키오스크 주문 포기

별칭: 키오스크 눈치, 무인단말기 이용 주저

무인 주문기 앞에 선 사람이 메뉴를 찾지 못하거나 뒤에 선 사람의 눈치를 보다가 주문을 그만두거나 아예 쓰지 않는다.

# 서술

2022년 서울시 자료에서 키오스크를 써 본 서울의 55세 이상 고령층은 45.8%였다. 쓰지 않는 이유로 사용법을 모르거나 어려워서, 필요가 없어서, 뒷사람 눈치가 보여서가 나왔다.[^1]

2023년 스마트투데이 기사가 옮긴 조사에서 10대 응답자가 키오스크 주문을 포기한 이유 1위는 뒷사람 눈치였고 그 비율은 60.6%였다. 같은 응답의 전체 연령대 평균은 44.9%였다.[^2]

2022년 자료[^1]는 서울의 55세 이상에 대한 조사다. 2023년 글[^2]에서는 20대부터 60대 이상까지 뒷사람 눈치를 포기 이유로 꼽은 응답률이 모두 40%대였다.
