# 미칠까 두려워하기

별칭: Dementophobia[^2]

어떤 사람은 자기가 정신을 잃고 미쳐 갈까 두려워한다.

묶음: [걱정과 기분](../groups/worry-and-mood.md)

# 서술

1608년 Shakespeare 의 희곡[^1]에서 왕은 미치지 않게 해 달라고 하늘에 외쳤다.

2022년 Choosing Therapy 글[^2]의 필자는 자기가 미쳐 가거나 기억을 잃거나 언젠가 심한 정신 질환이 생기리라는 생각에 사로잡힌 사람들을 Dementophobia 라는 이름으로 설명했다.
