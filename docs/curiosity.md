# 서술

1865년 소설[^1]에서 앨리스는 조끼 주머니가 있고 거기서 시계를 꺼내는 토끼를 본 적이 없다는 생각이 스치자 호기심에 타올라 토끼를 쫓아 들판을 가로질러 달렸다.

2015년 Kidd 와 Hayden 의 논문[^2]은 Loewenstein 의 정보 공백 이론이 호기심을 배고픔처럼 행동을 이끄는 다른 욕구 상태와 같이 작동한다고 본다고 적었다.
