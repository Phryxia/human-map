# 청첩장 받는 부담

별칭: 없음

청첩장을 받은 사람이 축하하는 마음보다 참석할 시간, 낼 돈, 보낸 사람과의 거리를 먼저 따지며 부담을 느낀다.

묶음: [선물, 대접과 예의](../groups/gifts-and-hospitality.md)

# 서술

2004년 정책브리핑 기고[^1]의 글쓴이는 옆집에 누가 사는지 모르는 아파트에서 이웃이 불쑥 청첩장을 내밀면 반가울 리 없다고 적는다. 2006년 기사[^2]의 기자는 곳곳에서 날아드는 청첩장이 반갑지만은 않다며 참석할지, 부조금을 얼마 낼지 따져야 하기 때문이라고 적었다.

2017년 기사[^3]가 전한 결혼정보회사 설문에서 미혼 남녀 438명 가운데 63%가 청첩장을 받으면 부담된다고 답했다.

2026년 서플 커뮤니티 댓글[^4]의 글쓴이는 봄가을마다 매주 청첩장이 날아온다며 축하는 하고 싶지만 통장 사정이 냉혹하다고 적는다.
