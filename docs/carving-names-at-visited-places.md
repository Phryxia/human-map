# 다녀간 자리에 이름 새기기

별칭: I was here syndrome[^4]

명소나 숲, 유적을 찾은 사람이 그 자리의 나무나 벽, 바위에 자기 이름이나 아는 사람의 이름을 새기거나 써서 남긴다.

# 서술

1623년 희곡[^1]에서 한 남자가 숲을 돌아다니며 어린 나무의 껍질마다 로잘린드라는 이름을 새겼다.

1869년 여행기[^2]의 필자는 자기 일행이 오른 곳에 눈에 띄는 곳에 이름 쓰기를 좋아하는 사람들이 이미 백만이나 이백만쯤 다녀갔다고 적었다.

2019년 사진 기사[^3]는 서울 남산공원의 벽이 빈 곳을 찾을 수 없을 만큼 낙서로 덮였고 관광객들이 그곳에 이름을 남기고 갔다고 썼다.

2023년 6월 논문[^4]은 명소를 찾은 관광객이 다녀간 장소와 기념물에 자기를 드러내는 표식을 남기는 경향을 다뤘다. 같은 해 12월 기사[^5]에 따르면 천전리 각석 낙서 사건에서 10대 고등학생이 친구 이름을 장난삼아 돌로 새겼다가 검거됐다.
