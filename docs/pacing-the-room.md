# 방 안 서성이기

별칭: 없음

고민하거나 마음이 어지러운 사람이 방이나 좁은 자리 안을 이리저리 왔다 갔다 하며 걷는다.

묶음: [걱정과 기분](../groups/worry-and-mood.md)

# 서술

1874년 소설[^1]의 인물은 마음이 흐트러져 더 나아가지 못하고 손가락으로 허공을 치고 이마를 누르며 흐느끼면서 제자리를 오갔다. 1905년 소설[^2]의 인물은 빠져나갈 마지막 문이 닫혔다고 느끼며 고르지 않은 걸음으로 방 안을 오갔다.

2009년 게시글[^3]의 글쓴이는 잘 풀리지 않는 문제를 생각할 때 자주 일어나 탁구공을 차거나 공을 던졌다 받으며 방을 천천히 가로질러 걷는다고 썼다. 2015년 기사[^4]는 문제에 막혔을 때 사람들이 자주 바닥을 서성인다고 적는다.
