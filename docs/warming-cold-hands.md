# 언 손 녹이기

별칭: 없음

손이 찬 사람이 불 앞에 손을 내밀거나 따뜻한 잔을 감싸 쥐어 손을 녹인다.

묶음: [시간과 하루 습관](../groups/daily-time.md)

# 서술

1900년 소설[^1]에서 난로 곁에 앉아 손을 녹이던 사람 옆으로 다른 인물이 다가가 자기 손도 불 쪽으로 내밀었다. 1919년 소설[^2]의 인물은 결혼 이야기가 나오자 몸을 조금 떨고 불 가까이 다가가 석탄 더미 위로 손을 펴서 녹였다.

2021년 게시글[^3]의 글쓴이는 손이 늘 차서 집 안에서도 장갑을 끼고 앉아 있을 때는 따뜻한 차나 커피 잔을 꼭 감싸 쥔다고 썼다.
