# 영정 사진 미리 찍기

별칭: 장수사진[^2]

나이 든 사람이 자기 장례에 쓸 영정 사진을 살아 있을 때 미리 찍어 둔다.

묶음: [혼자 있음과 상실](../groups/solitude-and-loss.md)

# 서술

2015년 3월 서울신문 기사[^1]에서 동대문구 경로당의 노인들은 장수사진을 찍는 날 아침 정성스레 머리를 손질하고 화장을 받았다.

2018년 강동구 보도자료[^2]는 좋은 모습일 때 미리 찍어 두면 오래 산다는 말에서 영정 사진을 장수사진이라고도 부른다고 적었다.
