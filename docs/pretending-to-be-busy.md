# 일터에서 바쁜 척하기

별칭: 고스트워킹, 일하는 척, ghostworking

직장인이 실제로 하는 일과 관계없이 일터에서 바빠 보이도록 행동한다.

# 서술

2025년 F2 가 전하는 조사에서 미국 노동자의 절반 이상이 직장에서 자주 바쁜 척한다고 인정했다. [F2]

# 조건

2023년 F1 의 글쓴이는 사무실에서는 하루에 몇 시간씩 바쁜 척해야 하고 집에서는 할 일을 끝낼 수 있다고 적었다. [F1]
