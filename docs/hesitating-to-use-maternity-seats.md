# 임산부 배려석 앉기 눈치

별칭: 없음

임신한 사람이 대중교통의 임산부 배려석에 앉거나 앉은 사람에게 비켜 달라고 하기를 남의 눈치가 보여 망설인다.

묶음: [낯선 사람과 공공장소](../groups/strangers-and-public-places.md)

# 서술

2006년 런던 지하철 보도자료[^1]는 다른 승객에게 자리를 비켜 달라고 하기를 어색해하는 임신부를 돕겠다며 'Baby on Board' 배지를 내놓았다.

2013년 12월 정책브리핑 기사[^2]에서 한 임신부는 나이가 어리고 겉으로 표시도 나지 않아 임산부석에 앉아 있으면 어르신들이 쳐다봐 민망하다고 말했다.

2017년 아주경제 기사[^3]는 임신 초기에는 배가 눈에 띄게 나오지 않아 임산부가 배려석에 앉기까지 눈치를 보고 일반 승객이나 어르신에게 밀려 자리를 내주는 일이 잦다고 썼다.

2023년 블라인드 댓글[^4]의 글쓴이는 전철에서 보면 임산부 대부분이 눈치가 보여 비켜 달라는 말을 못 한다고 적었다.

2024년 브런치 글[^5]의 임신한 글쓴이는 배려석에서 자는 사람을 깨워서까지 양보를 부탁하기는 어려워 그냥 서서 간다고 썼다.
