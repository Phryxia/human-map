# 휴대전화 없이 연락이 끊길 두려움

별칭: Nomophobia[^3]

사람이 휴대전화를 쓸 수 없어 남과 연락이 끊길까 봐 두려워한다.

묶음: [메시지와 휴대전화](../groups/messages-and-phones.md)

# 서술

2015년 5월 연구 소개 글[^1]에 따르면 면담한 학생들은 온라인 정체성, 특히 소셜 미디어에서 끊기는 것을 두려워하고 휴대전화 알림을 계속 따라잡고 싶어 한다고 말했다.

2017년 7월 기사[^2]가 옮긴 말에서 많은 사람이 연락이 닿지 않게 되는 것을 두려워하고 당장 급한 일이 없어도 휴대전화가 없을 때 하필 그것이 절실해질까 봐 가벼운 공황을 느낀다.

2019년 4월 논문[^3]의 저자들은 휴대전화 연결에서 떨어지는 것을 두려워하는 심리 상태를 NOMOPHOBIA 라 부른다고 적었다.
