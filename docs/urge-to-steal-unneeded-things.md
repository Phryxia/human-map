# 쓸모없는 물건 훔치고 싶은 충동

별칭: kleptomania[^2]

필요하지도 않은 물건을 훔치고 싶은 충동을 사람이 거듭 느끼고 참지 못해 훔친다.

묶음: [걱정과 기분](../groups/worry-and-mood.md)

# 서술

1883년 소설[^1]은 비뚤어진 욕망 때문에 훔치는 사람들을 그렸고 한 의사가 이를 큰 상점의 유혹이 낳은 새 신경 질환으로 분류했다고 적었다.

2004년 논문[^2]에서 저자들이 kleptomania 라 부르는 상태의 사람은 불안에 떠밀려 그 순간에는 즐겁지만 큰 괴로움을 낳는 행위를 하려는 충동을 느낀다.

2008년 미국 전국 조사[^3]의 저자들은 가게 절도가 kleptomania 때문일 수도 있고 단순한 범죄 행동이나 다른 상태의 표현일 수도 있다고 적었다.
