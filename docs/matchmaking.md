# 소개팅 주선

별칭: 중매 서기, 짝 맺어 주기, Matchmaking

사람이 자기가 아는 두 사람을 연인으로 이어 주려고 서로 소개한다.

# 서술

1815년 오스틴의 소설[^1]에서 에마는 아버지에게 자기 짝은 맺지 않겠지만 남의 짝은 꼭 맺어 주어야 한다며 그것이 세상에서 가장 큰 재미라고 말했다.

2016년 설문 기사[^2]에서 20\~30대 미혼남녀 623명 가운데 남성은 상대 얼굴이 예쁘다거나 연예인을 닮았다는 주선자의 소개말을 그대로 믿으면 실망하기 쉽다고 꼽았다. 2017년 설문 기사[^3]에서 응답자 418명의 71%가 소개팅을 주선해 본 적이 있었고 그중 68%가 주선 앞뒤로 피로감을 느꼈다.
