# 친구 끊기를 상대가 알아챌까 봐 망설이기

별칭: 없음

온라인에서 누군가와 친구 관계를 끊고 싶은 사람이 상대가 그것을 알아챌까 봐 망설인다.

묶음: [메시지와 휴대전화](../groups/messages-and-phones.md)

# 서술

2008년 블로그 글[^1]은 페이스북이 친구 끊기를 알리지 않아도 끊긴 사람이 결국 그것을 알아챌 가능성이 꽤 높다고 적었다.

2010년 게시글[^2]의 글쓴이는 페이스북에 별로 가깝지 않은 친구가 너무 많다며 그들을 끊으면 알림이 가는지 묻고 기분을 상하게 하고 싶지는 않다고 썼다.

2019년 연구[^3]에서 응답자 312명의 다수는 지나친 공유 같은 온라인의 언짢은 행동 앞에서 친구 끊기나 언팔로우보다 아무것도 하지 않는 쪽을 택했다. 관계의 친밀도, SNS 이용 빈도, 네트워크 크기, 사이트가 친구 끊기나 숨기기 결정에 영향을 주었다.[^3]

2025년 게시글[^4]의 글쓴이는 다른 매장에 마음이 가서 메이드 카페 직원을 언팔로우하고 싶다면서 그 직원이 눈치챌지 물었다.

2026년 게시글[^5]의 글쓴이는 부담스럽게 구는 상대와 친구를 끊고 싶지만 예전에 답장을 하지 않았을 때 상대가 뭐라 한 일이 있어 해코지당할까 겁난다고 썼다.
