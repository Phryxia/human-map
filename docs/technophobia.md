# 기술 공포

별칭: Technophobia[^1]

사람이 컴퓨터, 휴대전화, 인공지능 같은 기술을 두려워한다.

묶음: [걱정과 기분](../groups/worry-and-mood.md)

# 서술

2019년 연구[^1]의 저자들은 공식 정신질환으로 인정되지 않은 기술에 대한 극단적이고 비합리적인 두려움을 테크노포비아라고 불렀다.

2020년 디스커버 기사[^2]는 새 기술이 익숙한 규범을 흔들면 자기 상황을 더는 통제하지 못하리라는 두려움이 생길 수 있다고 적었다. 2022년 클리블랜드 클리닉 글[^3]은 이 두려움을 가진 사람이 컴퓨터, 휴대전화, 인공지능의 힘을 두려워할 수 있다고 적었다.
