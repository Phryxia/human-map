# 청력 도움 요청 미루기

별칭: 없음

청력이 떨어졌다고 느끼는 사람이 검사나 보청기 같은 도움을 받으러 가는 일을 몇 해씩 미룬다.

묶음: [걱정과 기분](../groups/worry-and-mood.md)

# 서술

2003년 Personnel Today 기사[^1]가 전한 영국 자선단체 조사에서 청력을 잃은 사람의 약 3분의 1은 일반의를 찾아가기까지 2년 넘게 걸렸다.

2013년 기사[^2]가 전한 영국 연구에서 응답자 92%는 청력 문제로 도움을 구하는 일을 미뤘다. 미룬 이유로 가장 많이 나온 것은 대부분의 상황에서 그런대로 잘 들린다고 느꼈다는 것이었다.[^2]

2016년 영국 연구[^3]는 청력이 떨어진 사람 가운데 보청기를 가진 사람이 3분의 1뿐이고 보청기를 받기까지 평균 10년이 걸린다는 앞선 조사를 인용한다.

2025년 기사[^4]가 전한 연구에서 청력이 떨어진 사람의 60%는 비웃음을 산 적이 있다고 답했고 낙인 때문에 도움을 구하지 않았다.
