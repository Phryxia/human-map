# 선물 포장지 모아 두기

별칭: 없음

선물을 받은 사람이 포장지를 찢지 않고 벗겨 접어 두었다가 다음 선물에 다시 쓰려 한다.

묶음: [선물, 대접과 예의](../groups/gifts-and-hospitality.md)

# 서술

2008년 Straight Dope 게시글[^1]의 글쓴이는 찢지 않은 포장지를 버리지 않고 반듯하게 접어 두었다가 다음 선물을 쌀 때 쓴다고 썼다.

2023년 Cape Cod Chronicle 칼럼[^2]의 필자는 할머니가 포장지를 모두 모아 펴고 접어 두었다고 썼다. 어머니도 그렇게 했고 필자도 한동안 그렇게 했다.

2025년 라디오 방송국 기사[^3]에 따르면 미국인 3만 명 설문에서 18%가 포장지를 모아 두었다가 다시 쓴다고 답했다. 16%는 모아 두지만 다시 쓰는 일이 드물다고 답했다.
