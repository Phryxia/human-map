# 서술

2005년 논문[^1]의 저자는 계보학 하면 샤를마뉴 후손이라는 불확실한 혈통으로 스스로를 높이는 소도시 은행가 부부가 떠오른다고 적었다.

2012년 칼럼[^2]은 한국 족보 대부분이 조상을 양반으로 적는다고 썼다. 필자는 OO공파 몇 대 손이라고 자부하는 사람을 요즘도 어렵지 않게 본다고 적었다.
