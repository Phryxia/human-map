# 자녀 사진을 소셜 미디어에 올리기

별칭: sharenting[^1]

부모가 자녀의 사진과 일상을 소셜 미디어에 올린다.

# 서술

2015년 미시간대 C.S. Mott 아동병원 전국 여론조사에서 부모의 52%는 자녀가 자라서 자신이 소셜 미디어에 올린 것을 부끄러워할까 걱정했다.[^1]

2016년 WHYY 기사가 전한 연구에서 자녀는 부모보다 두 배 많이 부모가 온라인에 자기 이야기를 지나치게 올리지 않기를 바란다고 답했다.[^2]

2024년 Conti 외의 조사에서 응답자의 98%가 소셜 미디어를 썼고 그중 75%가 자녀에 관한 내용을 온라인에 올렸다.[^3]

2025년 프랑스 개인정보보호위원회 안내문은 프랑스 부모의 53%가 소셜 미디어에 자녀에 관한 내용을 올린 적이 있다고 적는다.[^4]
