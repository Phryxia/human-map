# 자녀 사진을 소셜 미디어에 올리기

별칭: sharenting[^1]

부모가 자녀의 사진과 일상을 소셜 미디어에 올린다.

# 서술

2015년 미시간대 C.S. Mott 아동병원 전국 여론조사에서 부모의 52%는 자녀가 자라서 자신이 소셜 미디어에 올린 것을 부끄러워할까 걱정했다.[^1]

2016년 WHYY 기사가 전한 연구에서 자녀는 부모보다 두 배 많이 부모가 온라인에 자기 이야기를 지나치게 올리지 않기를 바란다고 답했다.[^2] 같은 날 Slashdot 댓글[^3]의 글쓴이는 어머니가 페이스북에 올린 자기 어린 시절 일화가 자기 사생활을 침해한다는 것을 어머니에게 이해시키기까지 여러 번 진지하게 이야기해야 했다고 썼다.

2019년 게시판 댓글[^4]의 글쓴이는 어머니가 자기가 원하지 않는 사진을 미리 묻지 않고 페이스북에 올릴 때가 있다고 썼다.

2022년 기사[^5]가 전한 세이브더칠드런 조사에서 응답자의 55.4%는 소셜 미디어에 자녀의 사진이나 영상, 일상을 올릴 때 자녀에게 의견을 묻지 않았다.

2024년 Conti 외의 조사에서 응답자의 98%가 소셜 미디어를 썼고 그중 75%가 자녀에 관한 내용을 온라인에 올렸다.[^6]

2025년 프랑스 개인정보보호위원회 안내문은 프랑스 부모의 53%가 소셜 미디어에 자녀에 관한 내용을 올린 적이 있다고 적는다.[^7]
