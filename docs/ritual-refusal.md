# 의례적 사양

별칭: 빈말 사양, 예의로 사양하기, ritual refusal

음식이나 선물, 초대를 권받은 사람이 받을 생각이 있으면서도 처음에는 예의로 사양한다.

# 서술

연구[^1]의 언어교육 자료는 중국어 화자가 초대나 권유를 바로 받지 않고 여러 번 사양한 뒤에 받는다고 적었다. 작품[^3]의 소설에서 술과 윗자리를 권받은 유모는 끝까지 사양한다.

1935년 작품[^2]의 소설에서 술을 권받은 애라는 괜찮다며 사양하고 권하는 쪽은 혼자 가만있으면 안 된다며 다시 권한다.

2020년 연구[^4]의 저자는 중국어 화자가 선물을 받으며 하는 거절의 말이 받기 싫다는 뜻이 아니라고 적었다.

연구[^1]의 자료는 사양하는 쪽이 이 거절로 권유가 진심인지 체면치레인지 가늠한다고 적었다.

2025년 글[^5]의 필자는 한국에서는 예의상 몇 번 사양하고 권하는 쪽도 그 말을 거절로 받아들이지 않았지만 독일에서는 두 번째 권유가 거의 오가지 않았다고 적었다.
