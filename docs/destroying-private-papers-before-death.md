# 죽기 전에 간직한 편지와 기록 없애기

별칭: 없음

죽음을 앞둔 사람이 자기가 죽은 뒤 남의 손에 넘어가지 않도록 간직해 온 편지나 일기, 사진을 태운다.

묶음: [혼자 있음과 상실](../groups/solitude-and-loss.md)

# 서술

1888년 제임스의 소설[^1]에서 죽음을 앞둔 노부인은 평생 간직한 편지를 태우려 했고 곁에 있던 조카가 막았다. 노부인은 그 편지를 침대 속에 숨겨 두었다.

2017년 칼럼[^2]의 필자는 저승길 갈 때가 됐다며 보관하던 앨범 사진을 불에 태우고 눈물을 흘린 어머니 이야기를 다른 이의 글에서 읽었다고 적었다.

2023년 에세이[^3]의 필자는 자기가 죽은 뒤 자녀가 일기를 읽고도 필자에게 물어볼 수 없게 되는 일을 떠올리며 일기를 태우거나 파쇄할지 망설인다.

같은 에세이 아래 2024년 댓글[^4]의 글쓴이는 아직 자녀가 곁에 있을 때 자녀와 함께 모닥불을 피우고 자기 일기를 불에 넣겠다고 적었다.
