# 이민 갔다 고국으로 돌아오기

별칭: Return migration[^3], 역이민[^4]

다른 나라로 이민 가서 살던 사람이 몇 해 뒤 태어난 나라로 돌아와 다시 산다.

묶음: [사는 곳과 옮겨 살기](../groups/where-to-live.md)

# 서술

2009년 서울신문 기사[^1]는 은퇴 이민을 떠난 사람 가운데 과장된 광고에 속아 사기를 당하거나 현지 생활에 적응하지 못해 돌아오는 사람도 여럿 있다고 적었다.

2014년 이코노믹리뷰 기사[^2]는 은퇴 후 이민을 떠났던 많은 한국 사람이 비슷한 이유로 다시 한국으로 돌아왔다고 적었다.

2023년 이란 귀국자 연구[^3]는 돌아오는 과정에서 가족 유대가 하는 역할을 밝히고 귀국을 성공과 실패 둘로 나눠 보는 서술에 반론을 폈다.

2024년 기사[^4]가 전한 보도에서 한국에서 태어난 1세대는 향수와 안락함을 찾아, 2세대는 소수계로서 느낀 소외감에서 벗어나려고 한국으로 돌아오는 길을 택했다.

2025년 게시판 댓글[^5]의 글쓴이는 20대 중반에 미국에 갔다가 40세 직전에 한국으로 돌아왔고 돌아오자마자 향수병과 외로움이 사라져 마음이 편하다고 적었다.
