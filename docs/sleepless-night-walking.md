# 잠이 오지 않아 밤에 걷기

별칭: Night-walking[^3]

잠들지 못하는 사람이 누워 있는 대신 일어나 밤이나 새벽에 집 밖으로 나가 걷는다.

묶음: [걱정과 기분](../groups/worry-and-mood.md)

# 서술

1860년 디킨스의 에세이[^1]에서 화자는 괴로운 인상 때문에 잠을 이루지 못하던 몇 해 전 여러 밤에 걸쳐 밤새 거리를 걸었다.

2014년 에세이[^2]의 필자는 졸업을 한 학기 앞두고 잠 못 드는 밤에 더는 천장을 바라볼 수 없어 코트를 걸치고 운동화 끈을 묶은 뒤 브로드웨이로 걸어 나갔다고 썼다.

2020년 기사[^3]의 필자는 몇 시간이 지나도 잠이 오지 않으면 포기하고 일어나며 오크니로 이사한 뒤로는 밖으로 나간다고 썼다.

2021년 연구[^4]의 저자들은 디킨스가 불면을 다스리려고 잠자리에서 일어나 런던 거리를 걸었고 돌아와서 편히 잠들 수 있었다고 적었다.

2024년 잡지 글[^5]의 필자는 여러 해 동안 잠을 잘 이루지 못하다가 여행지인 뉴욕에서 나아졌다고 썼다. 필자는 어차피 잠들지 못할 거라면 서둘러 거리로 나서자고 다짐했다.
