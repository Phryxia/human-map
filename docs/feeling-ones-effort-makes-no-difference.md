# 노력이 소용없다는 생각

별칭: 나 하나쯤, 무용감, 낮은 지각된 소비자 효과성, perceived consumer effectiveness

사람이 자기 한 사람의 행동이 결과에 차이를 만들지 못한다고 생각한다.

# 서술

1991년 1월 서울신문 기사에서 분리한 쓰레기를 수거차가 다시 섞어 싣고 가는 것을 본 시민들은 불편을 무릅쓰고 분리해 줬더니 무슨 도움이 되느냐고 불평했다. [F2]

2012년 12월 워싱턴 먼슬리의 칼럼이 전한 미국 설문에서 기후변화를 받아들이는 응답자 가운데 자기가 했거나 하려는 탄소 절감 행동이 자기 몫을 줄인다고 본 사람은 32% 였다. [F3]

2024년 F4 의 저자들은 많은 사람이 자기나 자기 집단이 차이를 만들 수 없다고 느껴 기후변화와 사회적 불평등에 맞서 함께 행동하지 않는다고 적었다. [F4]

# 조건

1991년 F1 의 저자들은 환경에 대한 관심이 실제 행동으로 이어지는 정도가 개인의 행동이 차이를 만든다는 지각에 어느 정도 달려 있다고 보고했다. [F1]

1991년 F2 에서 이 생각은 시민들이 애써 분리한 쓰레기가 다시 섞이는 것을 본 뒤에 나왔다. [F2]
