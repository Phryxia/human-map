# 작심삼일

별칭: 새해 결심 포기, 결심 중도 포기, New Year's resolution failure

새해 목표나 결심을 세운 사람이 며칠이나 몇 주 만에 그 일을 그만둔다.

# 서술

2020년 F1 의 저자들은 선행 연구를 인용해 새해 결심을 지킨 참가자가 77% 에서 한 달 뒤 55%, 3개월 뒤 43%, 6개월 뒤 40%, 2년 뒤 19% 로 줄었다고 적었다. [F1]

2026년 1월 네이버 지식iN 게시글의 글쓴이는 해마다 새해 목표를 세우지만 작심삼일로 끝나는 경우가 많다고 적었다. [F2]

2026년 2월 네이버 지식iN 게시글의 글쓴이는 다이어트를 시작할 때마다 사흘 만에 그만두고 굳게 결심해도 같은 일이 되풀이되는 자신이 답답하다고 적었다. [F3]

# 조건

기록된 조건 없음. [F1]
