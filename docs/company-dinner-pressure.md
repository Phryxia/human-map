# 회식 참석 부담

별칭: 없음

직장인이 회식을 부담스러워하면서도 빠졌을 때 상사나 동료가 어떻게 볼지 신경 쓰며 참석하거나 빠질 핑계를 찾는다.

# 서술

2008년 10월 기사가 전한 설문에서 술자리 회식을 부담스러워하는 직장인은 술자리 회식이 있을 때 매번 참석(69.2%)하거나 특별한 일이 없으면 참석(21.7)한다고 답했다.[^1]

2018년 7월 클리앙 게시글의 글쓴이는 회식에 안 온다고 매번 말을 듣는다며 괜찮은 핑계가 없는지 물었다.[^2]

2023년 6월 미코 게시글의 글쓴이는 일정을 바꾸면 회식에 빠지고 싶어서 일부러 그런다는 말을 들을 것 같다고 적었다.[^4]

2021년 9월 기사가 전한 조사에서 직장인 51.7% 는 상사가 참여하지 않는 회식이라면 부담감 없이 참석할 것 같다고 답했다.[^3]
