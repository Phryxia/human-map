# 거울 속 늙은 얼굴의 낯섦

별칭: 주관적 나이, 마음은 아직 젊다는 느낌, Subjective age

나이 든 사람이 거울에 비친 자기 얼굴을 보고 스스로 느끼는 나이보다 늙었다고 여기며 낯설어한다.

# 서술

1898년 F1 의 화자는 거울에서 여윈 피부를 보고 마음도 그만큼 줄어들었으면 하고 바란다. [F1] 1899년 F2 의 인물은 머리가 세기 시작한 자기를 보고 몇 해 사이 그렇게 늙고 볼품없어진 것을 이상하게 여겼다. [F2]

2022년 F3 에서 독일 노인 4,665명 가운데 다수는 실제 나이보다 젊다고 느낀다고 답했다. [F3] 2025년 F4 의 칼럼 저자는 거울 속 주름진 얼굴이 낯선 까닭을 마음속 시간이 예전 어느 시점에 머물러 있는 데서 찾는다. [F4]

# 조건

2022년 F3 의 응답자는 독일의 지역사회에 사는 노인이다. [F3]
