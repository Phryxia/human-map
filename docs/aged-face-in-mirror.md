# 거울 속 늙은 얼굴의 낯섦

별칭: 주관적 나이, 마음은 아직 젊다는 느낌, Subjective age

사람이 거울에 비친 자기 얼굴을 보고 스스로 느끼는 나이보다 늙었다고 여기며 낯설어한다.

# 서술

1898년 작품[^1]의 화자는 거울에서 여윈 피부를 보고 마음도 그만큼 줄어들었으면 하고 바란다. 1899년 작품[^2]의 인물은 머리가 세기 시작한 자기를 보고 몇 해 사이 그렇게 늙고 볼품없어진 것을 이상하게 여겼다.

2022년 연구[^5]에서 독일 노인 4,665명 가운데 다수는 실제 나이보다 젊다고 느낀다고 답했다. 2025년 글[^6]의 칼럼 저자는 거울 속 주름진 얼굴이 낯선 까닭을 마음속 시간이 예전 어느 시점에 머물러 있는 데서 찾는다.

1905년 작품[^3]의 인물은 젊은 여성인데도 거울 속 자기가 늙어 보인다고 느끼고 남에게는 어떻게 보일지 걱정한다. 2022년 연구[^5]의 응답자는 독일의 지역사회에 사는 노인이다.

2006년 연구[^4]의 덴마크 조사에서 25세 미만 성인은 평균적으로 주관적 나이가 실제 나이보다 많았고 25세 이상은 실제 나이보다 적었다.
