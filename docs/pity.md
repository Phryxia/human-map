# 연민

별칭: Pity[^1]

사람이 어려운 처지에 놓인 다른 사람이나 동물을 보고 불쌍하다고 느낀다.

묶음: [남의 처지를 향한 감정](../groups/feelings-toward-others.md)

# 서술

아리스토텔레스의 수사학 번역본[^1]은 연민을 그럴 만하지 않은 사람에게 해롭거나 고통스러운 불행이 닥친 것을 보고 느끼는 괴로움으로 정의했다.

1877년 소설[^2]에서 남편을 잃고 넋이 나간 여인을 둘러싼 사람들은 모두 그 여인을 불쌍히 여겼다.

2018년 기사[^3]가 전한 조사에서 원숭이에게 먹이를 준 방문객의 62%는 원숭이가 불쌍하거나 공격적인 원숭이가 무서워서 먹이를 줬다고 답했다.
