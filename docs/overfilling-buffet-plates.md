# 뷔페 접시 넘치게 담기

별칭: 뷔페 음식 남기기, Plate waste at buffets

뷔페에서 손님이 먹을 수 있는 양보다 많이 접시에 담고 남긴다.

# 서술

2011년 칼럼[^1]은 한 손님이 죽을 수북이 담아 세 그릇을 먹고 또 한 그릇을 가득 담아 한두 숟갈 먹고 그대로 버린다는 이야기를 전한다.

2017년 기사[^2]에서 손님들은 다시 가지러 가지 않으려고 접시에 음식을 높이 쌓았고 원하는 음식을 충분히 얻으려고도 그렇게 했다.

# 조건

2023년 연구[^3]는 뷔페에서 음식이 눈길을 끄는 방식으로 양 제한 없이 차려지는 점을 남긴 음식의 주요 출처로 든다.
