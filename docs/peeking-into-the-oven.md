# 굽는 중에 오븐 문 열어 보기

별칭: 없음

오븐으로 음식을 굽는 사람이 다 익기 전에 오븐 문을 열고 안을 들여다본다.

묶음: [시간과 하루 습관](../groups/daily-time.md)

# 서술

2005년 2월 게시판 글[^1]의 글쓴이는 들여다보려고 오븐 문을 몇 초 열면 안의 공기 온도가 1, 2도 떨어질 뿐 음식 온도에는 영향이 없다고 여겼다. 같은 해 7월 다른 게시판 댓글[^2]의 글쓴이는 케이크를 구울 때 진행을 보려고 오븐 안을 들여다보고 싶은 충동을 참아야 했던 일을 기억한다고 썼다.

2018년 미국 메릴랜드주 에너지청 글[^3]은 오븐 문을 열 때마다 안의 온도가 25도까지 떨어질 수 있다며 음식을 오븐 창으로 확인하라고 썼다.

2023년 Mashed 기사[^4]는 참을성이 넉넉하지 않은 사람이 굽고 있는 것을 보려고 오븐 문을 살짝 열고 싶어진다고 적었다. 2025년 Chowhound 기사[^5]는 갓 구운 냄새가 집 안에 퍼질 때 오븐 문을 열어 들여다보고 싶어진다고 썼다.
