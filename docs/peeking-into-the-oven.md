# 굽는 중에 오븐 문 열어 보기

별칭: 없음

오븐으로 음식을 굽는 사람이 다 익기 전에 오븐 문을 열고 안을 들여다본다.

묶음: [시간과 하루 습관](../groups/daily-time.md)

# 서술

2018년 미국 메릴랜드주 에너지청 글[^1]은 오븐 문을 열 때마다 안의 온도가 25도까지 떨어질 수 있다며 음식을 오븐 창으로 확인하라고 썼다.

2023년 Mashed 기사[^2]는 참을성이 넉넉하지 않은 사람이 굽고 있는 것을 보려고 오븐 문을 살짝 열고 싶어진다고 적었다. 2025년 Chowhound 기사[^3]는 갓 구운 냄새가 집 안에 퍼질 때 오븐 문을 열어 들여다보고 싶어진다고 썼다.
