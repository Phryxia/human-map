# 거절하지 못하기

별칭: 거절 못함, 부탁 거절의 어려움, difficulty saying no

부탁을 받은 사람이 들어주고 싶지 않은데도 거절하지 못하고 들어준다.

# 서술

1861년 트롤럽의 소설에서 마크 로바츠는 친구를 도울 마음이 없었는데도 어음에 이름을 적었다. 소설은 그가 거절할 수 없었기 때문이라고 적는다. 1869년 톨스토이의 소설에서 나타샤는 가기 싫었지만 자기를 위해 마련한 호의라서 거절하지 못했다. [F1][F2]

2014년 해커 뉴스의 한 댓글은 거절을 잘 못한다고 말한다. 글쓴이에게 일은 승진 제안으로 오지 않고 작은 부탁으로 온다. [F4]

2024년 F6 의 저자들은 사람들이 거절하고 싶은 요청에도 응하는 까닭을 거절하기가 어렵다는 데서 찾는다. 2016년 F5 의 저자는 요청하는 사람이 승낙을 과소평가하는 까닭을 거절의 어색함을 헤아리지 못하는 데서 찾는다. [F5][F6]

# 조건

2008년 F3 의 직장인 설문에서 상사의 불편한 부탁을 쉽게 거절하지 못하는 이유로 43.1%가 상사와의 관계가 불편해질까 봐를 골랐다. 1869년 F2 에서 나타샤가 거절하지 못한 부탁은 자기를 위해 마련된 호의였다. [F2][F3]
