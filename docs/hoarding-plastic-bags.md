# 비닐봉지 모아 두기

별칭: 없음

사람이 장보고 받은 비닐봉지를 언젠가 쓰리라 여겨 버리지 않고 봉지 안에 봉지를 넣어 집 안에 모아 둔다.

묶음: [돈과 소비](../groups/money.md)

# 서술

2006년 댓글[^1]의 글쓴이가 본 집에서는 싱크대 아래 수납장 문에서 벽까지 약 4피트 공간이 장보기 비닐봉지로 꽉 차 있었다.

2017년 댓글[^2]의 글쓴이 집에는 여행 가방 속에도, 고양이 화장실을 치우는 다용도실에도 비닐봉지를 가득 넣은 비닐봉지가 있다.

2019년 논문[^3]은 캘리포니아에서 규제가 시행되기 전 장보기 비닐봉지의 12\~22%가 쓰레기봉투로 다시 쓰였다고 적었다.

2026년 에세이[^4]의 글쓴이는 할머니가 모으는 비닐봉지가 어릴 때부터 책장 사이사이에 있어서 놀랍지도 불편하지도 않았다고 적었다.

2026년 기사[^5]는 비닐봉지 같은 물건을 언젠가 쓸 수 있다는 생각에 버리지 않고 모아 두다 보면 서랍과 수납장이 가득 차지만 실제로는 쓰지 않는 경우가 많다고 썼다.
