# 유족의 장기기증 거부

별칭: 없음

가족이 뇌사에 빠지거나 세상을 떠난 사람이 고인의 장기 기증에 동의하지 않는다.

묶음: [건강과 위험](../groups/health-and-safety.md)

# 서술

2017년 News-Medical 기사[^1]는 영국의 사망한 잠재 기증자 1,413명 가운데 91명의 기증 기회를 가족이 막았다고 전했다.

2025년 뉴시스 기사[^2]는 한국에서 고인이 생전에 기증 의사를 밝혔어도 가족이 문화적 관습을 이유로 동의를 거부하는 경우가 적지 않다고 썼다.

2026년 영국 NHS 혈액이식국 자료[^3]에서 고인이 기증 의사를 남기지 않아 동의가 간주되는 사례 가운데 55%인 602건에서 가족이 기증을 지지하지 않았다.
