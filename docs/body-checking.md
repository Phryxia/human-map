# 몸 확인 행동

별칭: body checking[^1]

자기 몸의 생김새나 크기를 신경 쓰는 사람이 거울을 보거나 몸을 만지고 재며 몸을 되풀이해 확인한다.

묶음: [남의 시선과 창피함](../groups/others-gaze.md)

# 서술

2007년 실험[^1]은 여성 60명 가운데 한쪽 무리에게 거울 앞에서 자기 몸을 되풀이해 비판적으로 살피게 했고 이 조건을 high body checking 이라 불렀다.

2020년 기사[^2]가 옮긴 임상심리학자의 말에서 몸 확인은 갈비뼈가 만져지는지 갈비뼈를 만져 보거나 허벅지를 만지거나 거울을 보며 엉덩이와 허리가 너무 큰지 살피는 모양으로 나타난다.

2021년 상담 기관 글[^3]은 몸 확인에 거울이 자주 쓰이지만 반사면, 창문, 휴대전화 카메라, 옷이 맞는지 보기도 같은 구실을 한다고 적는다.

2025년 문헌고찰[^4]은 몸 확인의 예로 거울이나 다른 반사면으로 몸이나 몸의 부위를 살피기, 몸 둘레 재기, 옷과 장신구가 맞는지 보기를 든다.
