# 고스팅

별칭: Ghosting[^1]

연애하던 사람이 아무 설명 없이 상대의 연락에 답하지 않고 사라져 관계를 끝낸다.

묶음: [가까운 사이의 감정과 말](../groups/close-relationships.md)

# 서술

2018년 심리학 잡지 글[^1]은 고스팅이라는 말이 전화, 문자, 소셜 미디어 메시지를 무시하며 연인의 삶에서 그냥 사라지는 행동을 가리키는 데 쓰였다고 적는다.

2024년 게시판 댓글[^2]의 글쓴이는 고스팅을 데이트 한 번을 넘는 관계에 있던 사람이 떠난다는 표시 없이 상대의 삶에서 사라지는 일이라고 적었다.

2026년 Langlais 등의 논문[^3]은 고스팅이 관계를 끝내는 흔한 방법이고 갈등이나 어려운 대화를 피하려고 자주 쓰인다는 앞선 연구 결과를 옮겼다.
