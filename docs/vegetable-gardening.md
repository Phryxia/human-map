# 텃밭 가꾸기

별칭: 도시농업[^1], gardening[^2]

도시에 사는 사람이 작은 텃밭에 작물을 심어 가꾸며 자라는 것을 보고 뿌듯해한다.

# 서술

2016년 강동구 보도자료[^1]는 텃밭을 자식 키우듯 가꾸는 사람이 싹이 트는 생명력에 신비를 느끼고 자라기를 기다리는 인내심을 기른다고 썼다. 2022년 서울시 소식[^3]에서 가족 텃밭을 분양받은 필자는 손바닥만 한 텃밭이 생겼다는 생각에 바라만 보아도 뿌듯했다고 적었다.

2016년 메타분석[^2]이 모은 연구들은 텃밭 가꾸기 뒤에 우울, 불안, 체질량지수가 줄고 삶의 만족, 삶의 질, 공동체 의식이 늘었다고 보고했다.
