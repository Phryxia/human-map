# 텃밭 가꾸기

별칭: 도시농업[^3], gardening[^4]

도시에 사는 사람이 작은 텃밭에 작물을 심어 가꾸며 자라는 것을 보고 뿌듯해한다.

# 서술

2003년 4월 서울신문 기사[^1]는 주말마다 주말농장에 나와 상추와 쑥갓을 키우는 가족들을 다뤘다. 고3 자녀를 둔 부부는 주말농장에 오면 평일의 스트레스가 어느 정도 풀린다고 했고 한 이용자는 키운 것을 거두어 이웃에게 나눌 때의 뿌듯함을 말로 설명하기 어렵다고 했다.[^1] 2010년 Hacker News 댓글[^2]의 글쓴이는 식물을 돌보고 일한 뒤에 열매를 즐기는 데서 보람을 느낀다고 썼다.

2016년 강동구 보도자료[^3]는 텃밭을 자식 키우듯 가꾸는 사람이 싹이 트는 생명력에 신비를 느끼고 자라기를 기다리는 인내심을 기른다고 썼다. 2022년 서울시 소식[^5]에서 가족 텃밭을 분양받은 필자는 손바닥만 한 텃밭이 생겼다는 생각에 바라만 보아도 뿌듯했다고 적었다.

2016년 메타분석[^4]이 모은 연구들은 텃밭 가꾸기 뒤에 우울, 불안, 체질량지수가 줄고 삶의 만족, 삶의 질, 공동체 의식이 늘었다고 보고했다.
