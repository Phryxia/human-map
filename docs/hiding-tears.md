# 남 앞에서 눈물 감추기

별칭: Hiding tears[^2]

남 앞에서 눈물이 나려는 사람이 바쁜 척하거나 다른 핑계를 대어 우는 것을 남에게 감춘다.

묶음: [가까운 사이의 감정과 말](../groups/close-relationships.md)

# 서술

1910년 소설[^1]에서 기숙학교 학생들이 로라를 웃음거리로 삼자 로라는 선반 앞에 무릎을 꿇고 바쁜 척했지만 눈에 고인 눈물 때문에 하는 일이 보이지 않았다.

2008년 대학 소식 기사[^2]에서 경영학 교수는 직장 여성들이 회의 중에 뛰쳐나가거나 문을 닫은 사무실에 틀어박히거나 화장실 칸에 숨으며 일터에서 눈물을 감추는 데 적지 않은 시간과 노력을 쓴다고 말했다.

2012년 웹진 글[^3]의 필자는 직장에서 울 때 콘택트렌즈가 빠진 척하는 쪽을 즐겨 쓴다고 적었다. 2013년 연구[^4]의 응답자 여럿은 남이 자기를 나쁘게 볼까 봐 수업이나 직장에서 울지 않으려 했다.

2017년 게시글[^5]의 글쓴이는 학교 방과후 보충 시간에 소리 없이 울면서 티가 날까 봐 하품하는 척하며 눈물을 닦았다.
