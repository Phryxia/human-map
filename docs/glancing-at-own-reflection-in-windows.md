# 유리창에 비친 제 모습 흘끗 보기

별칭: 없음

길을 걷는 사람이 상점 진열창 같은 유리에 비친 자기 모습을 걸음을 멈추지 않고 흘끗 확인한다.

묶음: [남의 시선과 창피함](../groups/others-gaze.md)

# 서술

1934년 단편소설[^1]의 인물은 연인과 나란히 거리를 걸으며 때때로 진열창에 비친 자기 모습을 본다. 그때마다 연인과 다니기에 모자람이 없는 호남자라는 자신을 새로 다진다.

2014년 Cultural Daily 칼럼[^2]은 바깥보다 안이 어두울 때 주차된 차의 창이나 진열창에 비친 자기 모습을 보고 싶어지는 끌림을 적었다.

2019년 블로그 글[^3]의 필자는 사람들이 낯선 이에게 보도를 무대로 착각한다는 인상을 주지 않으려고 비친 모습을 아주 빨리 본다고 썼다. 그래도 셔츠가 잘 걸쳐졌는지, 머리가 괜찮은지 볼 만큼은 본다.

2020년 논문[^4]은 창이나 반짝이는 물건 같은 반사면이 늘 또렷한 상은 아니어도 거울 구실을 한다고 썼다.
