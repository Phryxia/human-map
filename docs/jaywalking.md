# 무단횡단

별칭: 없음

보행자가 신호가 빨간불일 때나 횡단보도가 없는 곳에서 차도를 건넌다.

# 서술

2013년 3월 정책브리핑 기사에서 한 50대 시민은 바쁜데 신호 간격이 길어 정류장에 온 버스를 놓치지 않으려고 무단횡단을 한 적이 있다고 말했다.[^2]

2018년 연구[^3]의 저자들은 프랑스 교차로에서 보행자 8000명을 관찰했고 대기 시간이 짧아도 64% 가 빨간불을 지키지 않았다고 보고했다.

2026년 6월 연합뉴스 기사에 실린 조사에서 무단횡단한 보행자는 도로 폭이 좁아 충분히 건널 수 있다(38.6%), 주변에 횡단보도가 없다(24.2%), 위험하지 않을 것 같다(19.8%), 급한 일이 있다(14.6%) 순으로 이유를 답했다.[^5]

2009년 연구[^1]에서 보행자는 연석에서 기다리는 사람이 적을수록 빨간불에 더 많이 건넜고 성별에 따라서도 차이가 났다.

2018년 연구[^3]에서 대기 시간이 90초에서 300초 사이로 길 때 빨간불을 지키지 않은 보행자는 80% 였다.

2023년 12월 서울시 소식은 빨간불 남은 시간을 보여 주는 장치를 둔 곳에서 신호주기마다 빨간불에 건너는 사람이 46% 줄었다고 적었다.[^4]
