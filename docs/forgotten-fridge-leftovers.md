# 냉장고 속 남은 음식 잊고 버리기

별칭: 없음

먹다 남은 음식을 나중에 먹으려고 냉장고에 넣어 둔 사람이 그것을 먹지 않고 있다가 버린다.

# 서술

2011년 게시판 댓글[^1]의 글쓴이는 한 달에 한 번쯤 냉장고를 뒤져 안쪽에 숨어 있던 오래된 남은 음식 따위를 버린다고 적었다.

2016년 Whillans 의 글은 가정의 남은 음식 가운데 일부는 바로 버려지고 다른 일부는 나중에 먹을지도 모른다며 냉장고나 냉동실에 들어간다고 썼다.[^2]

2023년 야후 라이프 영국판 기사가 전한 미국 조사에서 사람들은 평균 일주일에 세 번 냉장고에 넣을 남은 음식이 생겼고 그것을 늘 다 먹지는 못했다.[^3]
