# 메신저 알림 꺼 두기

별칭: 없음

메신저를 쓰는 사람이 대화방에서 나가지 않고 그 방이나 상대의 알림만 꺼 둔다.

# 서술

2025년 9월 지식iN 게시글[^1]의 글쓴이는 카톡이 오면 바로 답해야 한다는 부담감, 중요하지 않은 일상 대화, 잦은 알림 때문에 친한 친구들의 알림은 보통 꺼 둔다고 적었다.

2026년 9월 브런치 글[^2]의 필자는 단체 대화방에서 나가기 버튼 대신 알림 끄기 버튼을 눌렀다.
