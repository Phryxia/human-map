# 메신저 알림 꺼 두기

별칭: 없음

메신저를 쓰는 사람이 대화방에서 나가지 않고 그 방이나 상대의 알림만 꺼 둔다.

# 서술

2019년 1월 기사[^1]가 전한 e2save 조사에서 응답자 40퍼센트는 단체 대화방을 떠나고 싶지만 무례하다고 여겨 대신 음소거 버튼을 쓴다고 답했다.

2023년 11월 글에서 연구자는 단체 대화방의 메시지와 알림을 사람들이 흔히 대화방 음소거로 다룬다고 적었다. 같은 글은 음소거 때문에 중요한 정보나 약속을 놓치거나 관련 대화를 확인하려고 대화방을 들락거리게 된다고 적었다.[^2]

2025년 9월 지식iN 게시글[^3]의 글쓴이는 카톡이 오면 바로 답해야 한다는 부담감, 중요하지 않은 일상 대화, 잦은 알림 때문에 친한 친구들의 알림은 보통 꺼 둔다고 적었다.
