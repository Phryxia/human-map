# 흰머리 염색하기

별칭: 없음

사람이 흰머리가 나면 늙어 보이지 않게 하려고 머리를 검게 물들인다.

묶음: [남의 시선과 창피함](../groups/others-gaze.md)

# 서술

1924년 소설[^1]에서 이발사는 맑은 물과 검은 물 두 가지로 손님의 머리를 감겼고 손님의 머리는 젊을 때처럼 검어졌다.

1994년 칼럼[^2]은 노년층이 센 머리칼을 검게 물들여 10년 넘게 젊어 보이게 한다고 적었다.

2010년 연구[^3]에서 면담에 응한 나이 든 여성들은 더 젊어 보이려고 염색약을 쓴다고 말했다. 이들은 나이 든 여성에게 붙는 고정관념에 맞서려고 염색약을 쓴다고도 말했다.

2019년 기사[^4]의 필자는 받아들이기 어려운 실제 나이와 머물고 싶은 나이 사이의 차이를 사람들이 염색으로 메운다고 썼다.
