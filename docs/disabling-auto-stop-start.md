# 스톱앤고 기능 끄기

별칭: 없음

정차하면 시동이 꺼지는 기능이 달린 차의 운전자가 그 작동이 거슬려 기능을 끈다.

묶음: [길과 운전](../groups/roads-and-driving.md)

# 서술

2013년 8월 포르쉐 차주 포럼 게시글[^1]의 글쓴이는 시동 자동 정지 기능이 거슬린다며 그 기능을 아예 끄는 방법을 물었다. 그렇지 않으면 차에 시동을 걸 때마다 버튼을 눌러야 한다고 썼다.

2018년 4월 학회 논문[^2]의 저자들은 앞선 현장 연구에서 시동 자동 정지 기능이 작동이 복잡하고 운전자의 운전 습관과 잘 맞지 않아 고객 사이에서 인기가 없다는 결론을 얻었다고 적었다.

2023년 10월 자동차 매체 기사[^3]가 전한 한 차종 차주 모임의 설문에서 응답자의 13%는 막히는 길 같은 몇몇 상황에서 그 기능이 거슬려 가끔 끈다고 답했다.

2024년 8월 클리앙 게시글[^4]의 글쓴이는 ISG 가 기본으로 켜져 있어 끄게 되어 있는 것에 불만을 적었다. 시동을 걸면서 그 기능을 끄는 일이 습관이 됐다고 썼다.
