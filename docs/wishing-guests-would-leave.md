# 손님이 가 주기를 바라기

별칭: 가 달라는 말 못 하기

머무는 손님이 그만 가 주기를 바라는 주인이 가 달라고 말하지 않고 참거나 돌려서 알린다.

# 서술

1888년 체호프의 소설에서 잔치를 연 주인은 하품을 하고 일어나 시계를 보았다. 그는 손님들이 자비를 베풀어 열한 시에 떠나도 여섯 시간이 남았다고 아내에게만 말했다. 1897년 체호프의 다른 소설에서 손님 시중을 들던 여자는 손님들이 마침내 간다는 것이 기뻐서 조금만 더 계시다 가라고 말했다.[^1][^3]

1892년 Grossmith 형제의 소설에서 일기를 쓰는 주인은 젊은 손님이 갈 기색이 없고 열한 시가 가까워지자 아들에게 내일 일찍 일어나야 한다고 일깨웠다. 일기에는 그것이 암시였다고 적혀 있다. 2020년 지식iN 글쓴이는 남자친구에게 여러 번 돌려 말했는데도 남자친구가 일요일에 와서 화요일에 간다고 썼다.[^2][^4]

2026년 GQ 코리아 기사는 대놓고 먼저 일어나 달라고 말하기는 생각보다 어렵다고 썼다. 2021년 Mastroianni 등의 연구에서 대화의 46.83% 는 두 사람 모두 실제보다 일찍 끝나기를 원했다.[^5][^6]

# 조건

2026년 글[^6]의 기자는 친한 사이일수록 분위기를 깨는 것 같아 가 달라는 말을 더 하기 어렵다고 썼다. 2020년 게시글[^4]에서 머무는 사람은 손님이 아니라 글쓴이의 자취방에 오는 연인이다.
