# 의무 해제 뒤에도 마스크 쓰기

별칭: 마스크 못 벗기, 얼굴 팬티

마스크 착용 의무가 풀린 뒤에도 사람이 습관이나 불편한 느낌 때문에 마스크를 계속 쓴다.

# 서술

2023년 F1 의 기사가 전하는 일본 조사에서 착용이 개인 판단으로 바뀐 뒤에도 마스크를 쓰는 이유로 습관이 되었다는 답이 42.6%로 가장 많았고 아직 쓰는 사람이 많다는 답도 상위에 들었다. [F1] 2025년 F3 에서 일본 대학생의 착용 빈도와 습관을 가장 강하게 예측한 것은 코로나19에 대한 불안이 아니라 마스크를 쓰지 않을 때의 불편한 느낌이었다. [F3]

# 조건

2024년 F2 에서 미국 20개 주의 전체 인구는 의무 해제 뒤에도 착용 행동이 유의하게 달라지지 않았다. [F2]

# 파편

- F1 [매체] "マスクを着用する理由を聞くと、個人判断後は「習慣化しているから」が42.6%で最も多く、以下「コロナ感染対策」「コロナ以外の感染対策」「まだ着用している人が多いから」が上位の回答となった。" (마스크를 쓰는 이유를 물으니 개인 판단으로 바뀐 뒤에는 "습관이 되어서" 가 42.6%로 가장 많았고 "코로나 감염 대책", "코로나 이외의 감염 대책", "아직 쓰는 사람이 많아서" 가 그 뒤를 이었다.) — Web担当者Forum, 2023-04-24, https://webtan.impress.co.jp/n/2023/04/24/44715, 2026-10-19 접속
