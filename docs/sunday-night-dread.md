# 일요일 밤의 출근 걱정

별칭: 월요병, 일요병, Sunday scaries, Sunday night blues

주중에 일하는 사람이 일요일 저녁이나 밤에 다음 날 출근을 떠올리며 긴장하거나 우울해진다.

# 서술

2011년 F1 이 보도한 직장인 설문에서 일요일 저녁이면 괜히 우울해지느냐는 질문에 매우 그렇다는 18.3%, 다소 그렇다는 38.6%였다. [F1]

2021년 F2 가 전한 링크드인 설문은 이 현상을 월요일에 일터로 돌아가기 전 일요일 밤에 느끼는 스트레스와 불안으로 정의한다. [F2]

2023년 F3 의 기사는 심한 사람은 일요일 오후부터 다음 날 출근이 두려워 가슴이 쿵쾅거리고 잠을 못 이루기도 한다고 적는다. [F3]

2026년 F4 의 일요일 밤 댓글은 주말 근무를 마친 뒤 눈 감았다 뜨면 곧 출근이라고 적는다. [F4]

# 조건

2023년 F3 은 그 증상이 일요일 오후부터 시작되는 경우를 적는다. 2011년 F1 과 2021년 F2 는 주중에 출근하는 직장인을 대상으로 한 설문이다. [F1][F2][F3]
