# 초상집 거울 가리기

별칭: 없음

사람이 집안에 죽은 이가 생기면 애도하는 동안 집 안의 거울을 덮어 둔다.

묶음: [혼자 있음과 상실](../groups/solitude-and-loss.md)

# 서술

에든버러 왕립 의사회의 소장품 글[^1]은 죽은 시각에 시계를 멈추고 거울을 덮는 일이 나쁜 영을 막으려는 의례였다고 적었다.

유대교 상가 관습을 다룬 해설[^2]은 애도하는 사람이 그동안 자기 외모에 마음 쓰지 않아야 하므로 거울을 덮는다는 설명을 든다.

2026년 기사[^3]는 여러 나라와 문화에서 장례나 밤샘, 애도 기간에 집 안의 거울을 모두 덮는 전통이 생겼다고 전했다.
