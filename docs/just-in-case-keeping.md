# 혹시 몰라 챙겨 두기

별칭: 없음

사람이 언젠가 필요할지 모른다는 생각에 당장 쓰지 않을 물건이나 돈을 챙기거나 쌓아 둔다.

# 서술

2018년 5월 영국 켄트대학교 학부 소식[^1]은 Michael Mills 의 연구에서 음식이나 물 같은 물건을 쌓아 두는 사람 대부분이 혹시 몰라서 그렇게 했다고 전했다.

2019년 개발자 커뮤니티의 남는 장비 보관 질문에 달린 댓글[^2]의 글쓴이는 혹시 몰라 남겨 두는 물건은 결코 쓰이지 않는다는 것이 자기 경험이라고 썼다.
