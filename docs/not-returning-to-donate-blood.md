# 헌혈 뒤 다시 오지 않기

별칭: 없음

헌혈한 사람이 채혈 때 겪은 불편한 반응이나 두려움 때문에 다시 헌혈하지 않는다.

# 서술

2000년 게시글[^1]의 글쓴이는 헌혈 뒤 겪은 일이 불쾌해서 다시 헌혈하지 않았지만 같은 혈액형인 여동생이 수술할 때는 헌혈할 마음이 있었다고 썼다.

첫 헌혈자를 추적한 2021년 France 등의 연구[^2]에서 채혈을 두려워하거나 헌혈을 불안해한 사람은 그 뒤 헌혈을 덜 시도했다.
