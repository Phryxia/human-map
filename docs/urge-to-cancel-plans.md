# 약속 취소 충동

별칭: 없음

약속 직전에 나가기 싫어진 사람이 약속을 취소할 방법을 찾고 취소하면 안도를 느낀다.

# 서술

2025년 11월 한 공개 Q&A 사이트의 질문 글은 약속 전날 갑자기 나가기 싫어졌다고 적고 솔직하게 말하고 취소할지, 적당한 이유로 미룰지, 잠수를 탈지를 묻는다. [F3]

2020년 Vice 기사는 더는 내키지 않는 약속을 취소할 때 뚜렷한 안도가 따른다고 적는다. 기사는 템플 대학교 심리학 교수 조해나 자코의 말을 옮겨 취소가 많은 사람에게 상당한 안도를 준다고 적는다. [F1]

2026년 BJPsych Open 학술대회 초록은 온라인 설문 응답자 92명 가운데 45%가 사회적 약속이 무산되면 안도를 느낀다고 보고했다고 적는다. 같은 초록은 40%가 사회적 의무에서 제외되면 안도를 느낀다고 적는다. [F4]

# 조건

2020년 F1 은 안도의 일부가 약속에 필요한 일을 하지 않아도 된다는 앎에서 온다고 적는다. [F1]

2022년 F2 는 사회불안이 있는 사람이 안전행동을 순간적으로 안정감을 높이는 것으로 믿는다고 적는다. 약속 취소는 F2 에 나오지 않는다. [F2]

2025년 F3 의 질문 글은 취소하려는 이유를 따로 밝히지 않고 나가기 싫어졌다는 것만 적는다. [F3]

2026년 F4 는 응답자 92명의 온라인 설문이다. 같은 설문에서 45%가 의무를 거절할 수 있으면 만족을 느낀다고 보고했다. [F4]
