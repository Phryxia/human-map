# 셀프 계산대 피하기

별칭: 없음

가게에서 계산하는 사람이 셀프 계산대를 두고 직원이 있는 계산대에 줄을 선다.

묶음: [낯선 사람과 공공장소](../groups/strangers-and-public-places.md)

# 서술

2009년 게시글[^1]의 글쓴이는 셀프 계산대를 피하게 됐다며 차라리 계산대 줄에서 멍하니 서 있다가 사람이 물건을 찍어 주는 편을 고른다고 썼다.

2018년 8월 여론조사 회사의 글[^2]은 계산 시스템을 익히는 일과 스캔 오류가 나면 직원을 기다려야 하는 일, 사람과 마주하지 않는 데서 오는 거부감을 셀프 계산대를 꺼리는 이유로 들었다. 2018년 12월 기사[^3]에서 일부 손님은 계산원의 일자리를 빼앗을까 걱정해 셀프 계산대를 자주 쓰지 않는다고 말했다.
