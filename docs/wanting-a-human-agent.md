# 고객센터에서 상담원 바로 찾기

별칭: 없음

고객센터에 연락한 사람이 자동응답이나 챗봇을 거치기 싫어 0번을 누르는 식으로 사람 상담원에게 바로 닿으려 한다.

묶음: [메시지와 휴대전화](../groups/messages-and-phones.md)

# 서술

2006년 11월 시애틀 타임스 기사[^1]는 대부분의 회사가 여전히 상담원에게 닿으려면 번호판을 이리저리 눌러 찾아가게 만든다고 썼다.

2009년 12월 정책브리핑 기사[^2]에 따르면 그때까지는 여러 단계의 안내를 다 듣고 나서야 상담원과 연결할 수 있었고 이 기사가 다룬 지침은 ARS 첫 단계를 포함한 각 단계마다 상담원 바로 연결 메뉴를 두게 했다.

2016년 4월 The Conversation 기사[^3]가 전한 조사에서 고객 서비스를 시작할 때 응답자의 90%가 사람 상담원과 이야기하고 싶어 했다. 2021년 10월 뉴시스 기사[^4]가 전한 한국소비자원 자료에서 1372소비자상담센터에 들어온 고객센터 상담의 사유는 고객센터 연결 불만이 40%로 가장 많았다.

2025년 4월 Kagan 등의 연구[^5]에서 사람들은 챗봇 성능이 나아지면 긍정적으로 반응했지만 챗봇 창구를 기대 시간을 줄이는 계산이 예측하는 것보다 덜 썼다. 2025년 4월 미코 게시글[^6]의 글쓴이는 ARS 가 메뉴를 하나하나 다 읊는 동안 자기가 기다리는 것은 상담사 연결을 원하면 0번을 누르라는 안내라고 썼다.
