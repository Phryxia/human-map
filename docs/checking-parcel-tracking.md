# 배송 조회 되풀이하기

별칭: 택배 조회 새로고침, 배송 추적 집착

온라인으로 주문한 물건을 기다리는 사람이 배송 조회 페이지를 되풀이해 확인한다.

# 서술

2012년 F1 의 글쓴이는 반지가 도착하기로 한 날 대부분을 배송 조회 페이지를 새로 고치며 보냈다. [F1] 2023년 F4 의 글쓴이는 비싼 기기를 잃어버렸다고 확신하며 한 주 가까이 초조하게 배송 조회 페이지를 확인했다. [F4]

2021년 F2 의 칼럼이 전하는 연구에서 온라인 구매자의 60%가 배송 상태를 매일 또는 하루에 여러 번 확인했다. [F2] 2022년 F3 의 조사에서 미국인의 19%는 하루에 여러 번 소포를 추적한다. [F3]
