# 배송 조회 되풀이하기

별칭: 택배 조회 새로고침, 배송 추적 집착

온라인으로 주문한 물건을 기다리는 사람이 배송 조회 페이지를 되풀이해 확인한다.

# 서술

2012년 F1 의 글쓴이는 반지가 도착하기로 한 날 대부분을 배송 조회 페이지를 새로 고치며 보냈다. [F1] 2022년 F5 의 글쓴이는 꼭 오늘 와야 하는 택배가 아니어도 저녁까지 도착하지 않으면 불안해져 물건이 어디까지 왔는지 찾아본다고 적었다. [F5] 2023년 F6 의 글쓴이는 비싼 기기를 잃어버렸다고 확신하며 한 주 가까이 초조하게 배송 조회 페이지를 확인했다. [F6]

2021년 F3 의 칼럼이 전하는 연구에서 온라인 구매자의 60%가 배송 상태를 매일 또는 하루에 여러 번 확인했다. [F3] 2022년 F4 의 조사에서 미국인의 19%는 하루에 여러 번 소포를 추적한다. [F4]

# 조건

2020년 F2 의 설문에서 쇼핑객의 43%가 팬데믹 이전보다 배송을 더 자주 추적한다고 답했다. [F2]
