# 퇴근 시간 기다리며 시계 보기

별칭: Clock-watching[^2]

일하는 사람이 일이 끝날 시간을 기다리며 시계를 자꾸 보고 시간이 더디 간다고 느낀다.

# 서술

1900년 소설[^1]의 공장에서 일하는 인물은 세 시에 벌써 여섯 시가 된 것 같았고 네 시에는 시간을 잊은 채 모두에게 잔업을 시키는 것 같다고 느꼈다. 2023년 글[^4]은 한 시간쯤 지난 것 같아 시계를 보면 10분밖에 지나지 않은 괴로움을 적는다.

2014년 연구[^3]는 지루한 상태에서 시간이 흐르는 느낌의 속도가 느려진다고 쓴다. 2007년 댓글[^2]의 글쓴이는 시계를 볼 때만 시간이 늘어지고 할 일을 찾으면 시간이 빨리 지나간다고 썼다.
