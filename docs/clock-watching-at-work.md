# 퇴근 시간 기다리며 시계 보기

별칭: Clock-watching[^4]

일하는 사람이 일이 끝날 시간을 기다리며 시계를 자꾸 보고 시간이 더디 간다고 느낀다.

# 서술

1898년 Bennett 의 소설[^1]에서 인물은 저녁 여섯 시가 다가와도 더는 시계가 치자마자 사무실을 나서려고 일을 서두르지 않았다.

1900년 소설[^2]의 공장에서 일하는 인물은 세 시에 벌써 여섯 시가 된 것 같았고 네 시에는 시간을 잊은 채 모두에게 잔업을 시키는 것 같다고 느꼈다. 2023년 글[^6]은 한 시간쯤 지난 것 같아 시계를 보면 10분밖에 지나지 않은 괴로움을 적는다.

1917년 Lewis 의 소설[^3]에서 인물은 오후 세 시가 되면 다섯 시까지 일터를 도저히 견딜 수 없다고 느꼈다.

2014년 연구[^5]는 지루한 상태에서 시간이 흐르는 느낌의 속도가 느려진다고 쓴다. 2007년 댓글[^4]의 글쓴이는 시계를 볼 때만 시간이 늘어지고 할 일을 찾으면 시간이 빨리 지나간다고 썼다.
