# 주머니 두드려 소지품 확인하기

별칭: pocket-patting[^5]

외출하거나 길을 가는 사람이 주머니를 손으로 두드리거나 더듬어 지갑, 휴대폰, 집 열쇠 같은 소지품이 있는지 확인한다.

# 서술

1920년 소설[^1]에서 결혼식의 신랑은 많은 신랑이 하는 것을 본 몸짓대로 조끼 주머니를 더듬어 반지가 제자리에 있는지 확인했다. 1922년 소설[^2]의 인물은 길에서 편지를 어디 뒀는지 떠올리고 조끼 주머니를 두드려 본 뒤 거기 있다고 확인했다.

2004년 칼럼[^3]은 남자가 하루 동안 자주 주머니를 두드려 모든 것이 있는지 확인한다고 썼다.

2012년 블로그 글[^4]의 글쓴이는 집을 나설 때 휴대폰, 지갑, 열쇠를 챙겼는지 확인한다. 세 물건은 주머니마다 자리가 정해져 있어 글쓴이는 주머니를 더듬어 확인한다. 2022년 댓글[^5]의 글쓴이는 주머니를 두드리는 습관 덕분에 차 열쇠와 휴대폰을 챙긴다고 적었다.
