# 목이 메어 말을 잇지 못하기

별칭: 없음

감정이 북받친 사람이 말을 하다가 목이 메어 목소리가 갈라지거나 말을 잇지 못한다.

묶음: [가까운 사이의 감정과 말](../groups/close-relationships.md)

# 서술

1811년 소설[^1]에서 브랜던은 지난날 겪은 괴로움을 털어놓다가 더 말하지 못하고 급히 일어나 몇 분 동안 방 안을 걸었다.

1890년 심리학 책[^2]은 비애, 너그러움, 용기 같은 도덕적 지각에 마음이 흔들릴 때 목소리가 갈라지고 흐느낌이 가슴에서 올라온다고 적는다.

1932년 소설[^3]에서 정선은 목이 메어 말이 나오지 않아 말없이 고개만 끄덕였다.

2008년 댓글[^4]의 글쓴이는 추도사를 혼자 여러 번 소리 내어 읽어 둔 덕에 실제로 읽을 때 목이 크게 메지 않았다고 썼다. 2023년 댓글[^5]의 글쓴이는 고인을 위해 글을 써 두었지만 직접 읽으면 무너지지 않을 수 없다고 여겨 집전자에게 대신 읽게 했다.

2026년 연구[^6]에서 감동한 기억을 떠올린 참가자는 목이 메는 느낌을 28.3%, 목에 덩어리가 걸린 느낌을 34.8%, 말하기 어려움을 28.3% 보고했다. 이 비율은 비교 조건의 6.6%, 12.6%, 4.4% 보다 높았다.
