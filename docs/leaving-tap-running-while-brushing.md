# 양치하며 물 틀어 두기

별칭: 없음

이를 닦거나 설거지를 하는 사람이 그동안 수도꼭지를 잠그지 않고 물을 계속 틀어 둔다.

묶음: [시민 참여와 공공의 일](../groups/civic-life.md)

# 서술

2006년 게시판 댓글[^1]의 글쓴이는 이를 닦거나 면도하거나 설거지하는 동안 물을 틀어 둔다고 적었다.

2018년 조사 기사[^2]에서 미국 응답자의 35%는 이를 닦는 동안 물을 틀어 둔다고 답했다. 2019년 기사[^3]가 전하는 영국 조사에서는 22%가 물을 튼 채 이를 닦았다.

2025년 수도 회사 발표[^4]에서 응답자의 42%는 여전히 이를 닦는 동안 물을 틀어 둔다고 말했다.
