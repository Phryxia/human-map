# 보는 눈이 있을 때 행동 바꾸기

별칭: 지켜보는 눈 효과, 관객 효과, Watching eyes effect, Audience effect

누군가 지켜본다고 느끼는 사람이 혼자일 때와 달리 남이 좋게 볼 만한 쪽으로 행동한다.

# 서술

2006년 실험[^1]에서 사람들은 대조 그림 대신 눈 그림을 붙였을 때 음료값을 거의 세 배 냈다.

2015년 대학 보도자료[^2]에서 연구자 Nettle 은 사람들이 남이 자기를 어떻게 생각하는지 신경 쓰기 때문에 관찰당한다고 느낄 때 더 바르고 정직하게 행동한다고 말했다.

2019년 학위논문[^3]에서 공중화장실 이용자의 손 위생 준수율은 혼자 있을 때가 다른 사람이 있을 때보다 낮았다.
