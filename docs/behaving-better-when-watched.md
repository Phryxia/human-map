# 보는 눈이 있을 때 행동 바꾸기

별칭: 없음

누군가 지켜본다고 느끼는 사람이 혼자일 때와 달리 남이 좋게 볼 만한 쪽으로 행동한다.

# 서술

1976년 실험[^1]에서 폭력 절도를 목격한 구경꾼의 도움은 책임 분산으로 줄었고 평가 염려가 있을 때 늘었다.

2006년 실험[^2]에서 사람들은 대조 그림 대신 눈 그림을 붙였을 때 음료값을 거의 세 배 냈다.

2012년 11월 기사[^3]가 전한 예일대 연구에서 다섯 살 아이들은 누군가 자기 행동을 지켜본다는 것을 알면 더 너그럽게 굴었다.

2013년 Hacker News 댓글[^4]의 글쓴이는 남들 앞에서 생산적으로 보이고 싶어서 다른 사람이 화면을 볼 수 있는 카페나 열린 작업 공간에서는 딴짓을 덜 한다고 썼다.

2015년 대학 보도자료[^5]에서 연구자 Nettle 은 사람들이 남이 자기를 어떻게 생각하는지 신경 쓰기 때문에 관찰당한다고 느낄 때 더 바르고 정직하게 행동한다고 말했다.

2015년 Bateson 외의 현장 실험[^6]에서 사람들은 바로 근처에 다른 사람이 있을 때 없을 때보다 쓰레기를 덜 버렸다.

2019년 학위논문[^7]에서 공중화장실 이용자의 손 위생 준수율은 혼자 있을 때가 다른 사람이 있을 때보다 낮았다.

2020년 10월 클리앙 댓글[^8]의 글쓴이는 누가 모니터를 쳐다보는 것 같은 카페 같은 곳에서 집중이 더 잘 되고 딴짓을 덜 한다며 도서관에서도 일부러 다 보이는 자리에 앉는다고 썼다.
