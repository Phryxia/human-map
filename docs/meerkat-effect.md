# 미어캣 효과

별칭: Meerkat effect, 계좌 자주 확인하기

주식 투자자가 시장이 오르거나 내린 뒤 자기 계좌를 더 자주 확인한다.

# 서술

2014년 Gherzi 외의 연구에서 투자자는 시장 수익률이 양일 때와 일간 음일 때 모두 포트폴리오 확인을 늘렸다.[^1]

2026년 뉴시스 기사는 주가가 오르거나 내릴 때마다 하루에도 수십 차례 계좌를 확인하는 투자자를 적었다.[^3]

2016년 Sicherman 외의 연구에서는 시장이 내린 뒤 계좌 로그인이 9.5% 줄었고 변동성 지수 VIX 가 높을 때도 투자자의 주의가 줄었다. 2014년 연구[^1]는 하락 뒤에도 확인이 늘었다고 보고해 두 연구의 결과가 갈린다.[^2]
