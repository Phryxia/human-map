# 조부모의 손주 돌봄

별칭: 황혼 육아[^5]

자녀 부부가 일하는 동안 조부모가 손주를 맡아 돌본다.

묶음: [가까운 사이의 감정과 말](../groups/close-relationships.md)

# 서술

2007년 연구[^1]는 손주를 맡아 돌보는 할머니들이 노화가 빨라지며 건강이 나빠진다고 적었다.

2013년 기고[^2]에서 필자는 조부모의 양육 지원이 정시 퇴근과 야간 보육시설 이용이 어려운 부부, 또는 일터 사정으로 육아휴직을 쓰기 어려운 엄마가 고르는 선택인 경우가 많다고 썼다.

2021년을 집계한 영국 교육부 조사[^3]에서 취학 전 아이의 24%, 학령기 아이의 14%가 조부모의 돌봄을 받았다. 2024년 댓글[^4]의 글쓴이는 자기 부모가 일주일에 여러 번 아이들을 봐 주고 배우자의 부모도 아이들을 봐 준다고 썼다.

2025년 정책주간지 기사[^5]는 나이가 들며 아픈 곳이 느는 조부모가 기운이 넘치는 손주까지 맡으면 힘에 부쳐 스트레스를 받는다고 적었다.
