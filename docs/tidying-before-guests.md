# 손님 오기 전에 집 치우기

별칭: 손님맞이 청소, 부랴부랴 청소

손님이 집에 온다는 것을 안 사람이 손님이 오기 직전에 집을 서둘러 치운다.

# 서술

1855년 개스켈의 소설에서 메리 히긴스는 예정된 방문에 맞춰 할 수 있는 만큼 집을 정돈하려고 애썼다.[^1]

2024년 12월 토커 리서치가 미국인 2천 명에게 물은 설문에서 응답자들은 손님을 맞을 때 손님이 오기 직전에 평균 한 시간을 정리한다고 답했다.[^2]

2026년 1월 레이디경향 기사는 누군가 집을 방문한다고 하면 부랴부랴 청소에 나서게 된다고 적었다.[^3]

# 조건

2024년 글[^2]과 2026년 글[^3]은 손님이 오기로 정해진 경우를 다룬다. 1855년 작품[^1]에서도 방문은 미리 예정되어 있었다.
