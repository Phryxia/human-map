# 셀프 계산대 고르기

별칭: 없음

가게에서 계산하는 사람이 직원이 있는 계산대 대신 손님이 직접 찍는 셀프 계산대를 고른다.

묶음: [남의 시선과 창피함](../groups/others-gaze.md)

# 서술

2009년 게시글[^1]의 글쓴이는 셀프 계산대에서 일을 다 해도 상관없다고 썼다. 더 빨리 나갈 수 있고 줄도 짧으며 어색한 말을 주고받지 않아도 되기 때문이라고 적었다.

2025년 연구[^2]에서 남이 보기에 부끄러운 물건은 직원 계산대보다 셀프 계산대에서 훨씬 많이 팔렸고 콘돔과 임신 테스트기가 특히 그랬다. 같은 해 대학 보도자료[^3]에서 연구자는 셀프 계산대에서는 남이 무엇을 보는지 손님이 통제할 수 있어 창피한 물건을 살 가능성이 커진다고 말했다.
