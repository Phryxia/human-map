# 물건 못 버리기

별칭: 버리지 못하는 습관, 쓸모 있을까 봐 쌓아 두기, Difficulty discarding

쓰지 않는 물건을 가진 사람이 그것을 버리지 못하고 집 안에 쌓아 둔다.

# 서술

1853년 디킨스의 소설[^1]에서 고물상 크룩은 한번 손에 넣은 것은 무엇이든 내놓지 못한다고 말했다.

2018년 논문[^2]의 저자들은 그들이 저장장애라 부르는 상태에서 낭비를 피하려는 마음이 물건을 모아 두는 두드러진 동기일 수 있다고 썼다.

2026년 에세이[^3]의 글쓴이는 부모님 집을 정리하며 한 번도 쓰지 않은 공구와 휴대용 버너를 버리자고 아버지를 설득하기가 특히 어렵다고 적었다. 같은 글에서 어머니는 몇 달 동안 실랑이한 끝에 웬만하면 버리는 데 동의했다.
