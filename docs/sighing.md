# 한숨 쉬기

별칭: 한숨, Sighing

사람이 답답하거나 안도할 때 숨을 길게 내쉰다.

# 서술

1861년 디킨스의 소설[^1]에서 화자는 한동안 말없이 서 있다가 한숨을 쉬며 더 할 말이 없다고 말했다.

2016년 기사[^3]의 기자는 조용한 사무실에서 한숨을 연달아 쉬는 후배에게 이유를 물었다. 후배는 자기가 한숨을 쉬고 있는 줄 몰랐다. 2025년 게시글[^6]의 글쓴이는 한숨을 쉬지 않으면 가슴이 답답하고 주변에서 무슨 일이 있냐고 물을 만큼 한숨이 잦다고 썼다.

2024년 기사[^5]의 기자는 한숨을 쉬면 어른에게 무슨 걱정이 그렇게 많으냐는 꾸지람을 듣거나 복이 달아난다는 말을 들었던 기억이 있다고 썼다.

# 조건

2009년 Vlemincx 등의 연구[^2]에서 세 실험 모두 스트레스 조건보다 안도 조건에서 한숨이 더 많이 나왔다. 2016년 기사[^4]가 전한 연구에서 참가자가 보고한 안도는 한숨 뒤 5초 동안 커졌고 숨 참기 뒤나 지시가 없을 때는 커지지 않았다.
