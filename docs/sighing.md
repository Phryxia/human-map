# 한숨 쉬기

별칭: 한숨, Sighing

사람이 답답하거나 안도할 때 숨을 길게 내쉰다.

# 서술

1861년 디킨스의 소설[^1]에서 화자는 한동안 말없이 서 있다가 한숨을 쉬며 더 할 말이 없다고 말했다.

# 조건

2009년 Vlemincx 등의 연구[^2]에서 세 실험 모두 스트레스 조건보다 안도 조건에서 한숨이 더 많이 나왔다. 2016년 기사[^3]가 전한 연구에서 참가자가 보고한 안도는 한숨 뒤 5초 동안 커졌고 숨 참기 뒤나 지시가 없을 때는 커지지 않았다.
