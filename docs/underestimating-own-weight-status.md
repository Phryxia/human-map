# 자기 체중을 실제보다 가볍게 여기기

별칭: 없음

과체중이거나 비만인 사람이 자기 체중을 알맞다거나 비만이 아니라고 여긴다.

묶음: [건강과 위험](../groups/health-and-safety.md)

# 서술

2006년 4월 ABC News 기사[^1]가 전한 퓨 리서치 센터 조사에서 응답자 10명 가운데 9명은 다른 미국인 대부분이 뚱뚱하다고 여겼고 자기가 과체중이라고 여긴 사람은 10명 가운데 4명이었다.

2008년 연구[^2]에서 1999년부터 2004년까지의 NHANES 조사에 든 과체중자 가운데 스스로를 과체중으로 여긴 사람은 1988년부터 1994년까지의 조사에 든 과체중자보다 적었다.

2014년 7월 미국 국립보건통계센터 자료[^3]에서 8세부터 15세까지의 과체중 남아 약 81%와 여아 71%는 자기 체중이 알맞다고 믿었다.

2026년 11월 질병관리청 보도자료[^4]에서 비만이면서 자신을 비만으로 여기지 않는 집단의 36.0%는 체중 조절을 하지 않았다. 이 집단의 77.4%는 남성이었고 60대 이상에서 비율이 높았다.
