# 퇴직 뒤 허전함

별칭: 은퇴 후 상실감, 은퇴 우울, retirement blues

오래 다니던 일터를 떠난 사람이 할 일과 목적을 잃고 허전함과 무력감을 느낀다.

# 서술

2007년 신문 고민 상담[^1]에서 산업현장에서 퇴직한 50대 후반 남성은 경제적으로는 어렵지 않지만 새로 무언가를 시작하기에는 나이 때문에 망설여지고 무력감이 들어 힘든 날들을 보낸다고 썼다. 2021년 학술대회 초록[^2]은 퇴직 뒤 삶의 목적의식이 줄어드는 사람이 있지만 모두 그렇지는 않고 은퇴 기간에 목적을 지니는 일을 꼭 필요하다고 보지 않는 사람도 있다고 정리했다.
