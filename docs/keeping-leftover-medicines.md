# 남은 약 버리지 않고 두기

별칭: hoarding medicines[^1]

다 먹지 않고 남은 약을 가진 사람이 그 약을 버리지 않고 집에 둔다.

# 서술

2017년 호주 기사[^1]가 전한 조사에서 사람들이 약을 버리지 않는 이유로는 돈을 낭비하기 싫은 마음과 버리는 방법을 모르는 것이 꼽혔다.

2023년 미국 환경보호청 페이지[^2]가 인용한 조사에서 37%는 남은 처방약을 나중에 쓰려고 보관했다.
