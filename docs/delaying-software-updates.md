# 소프트웨어 업데이트 미루기

별칭: 없음

기기를 쓰는 사람이 소프트웨어 업데이트 알림을 받고도 설치를 미룬다.

# 서술

2012년 기사[^1]가 전한 설문에서 응답자 절반 넘게는 보통 업데이트 알림을 두 번에서 다섯 번 본 뒤에야 새 소프트웨어를 내려받아 설치했다. 2021년 보도자료[^4]의 조사에서 업데이트를 미루는 이유로 가장 많이 나온 답은 일하느라 바쁘다는 것(30%)이었고 그 순간 기기 사용을 멈추고 싶지 않다는 답(26%)이 뒤를 이었다.

2012년 기사[^2]에 따르면 사람들은 업데이트가 안전한지 확신하지 못하거나 새 기능이 쓸모 있으리라고 믿지 않아서 업데이트를 하지 않는다. 2018년 연구[^3]는 업데이트에 대한 사용자의 믿음 밑에 있는 요인으로 업데이트의 비용, 필요성, 위험 셋을 들었다.
