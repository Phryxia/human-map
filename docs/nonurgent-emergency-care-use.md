# 경증 응급 의료 이용

별칭: 없음

급하지 않은 증상을 가진 사람이 구급차나 응급실처럼 응급 상황을 위한 의료 서비스를 쓴다.

# 서술

2022년 영국 설문 연구[^1]에서 가볍거나 급하지 않은 문제로 응급 구급차와 응급실을 고르는 경향은 남성, 소수 민족 공동체 사람, 나이 든 사람에게서 다른 사람보다 높았다.

2023년 기사[^2]에서 응급실 의사들은 응급실 진료가 필요하지 않은 환자가 119 구급차를 타고 오는 일을 응급실 과밀화의 원인으로 보았다.
