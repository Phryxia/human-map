# 죽음 이야기 피하기

별칭: 죽음 회피, death avoidance

사람이 자기 죽음이나 생애 말기에 관해 생각하거나 가족과 이야기하기를 피한다.

# 서술

2018년 Today's Wills and Probate 기사[^2]가 전한 Co-op 조사는 1800만 명이 자기 죽음을 생각하고 이야기하기를 점점 더 어려워한다고 어림했다.

2025년 기사[^5]가 전한 한국보건사회연구원 조사에서 죽음이나 생애 말기 상황, 치료 계획을 가족에게 이야기해 본 응답자는 45.7%였다. 2024년 뉴질랜드 공공신탁 자료[^4]가 전한 조사에서 뉴질랜드인 57%는 죽음을 이야기하기가 불편하거나 두렵거나 꺼려진다고 답하거나 아예 피한다고 답했고 24.9%는 죽음을 직접 이야기하기가 편하다고 답했다.

2023년 연구[^3]의 저자들은 생애 말기 대화를 피하는 경향이 젊은 성인에게서 특히 두드러지고 친척이나 가까운 사람과 나눌 대화에 대한 부정적 예상이 주된 이유의 하나라고 적는다.
