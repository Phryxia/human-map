# 물건에 이름 붙이고 사람처럼 대하기

별칭: 없음

사람이 오래 쓰거나 곁에 두는 물건에 이름을 붙이고 사람이나 동물을 대하듯 대한다.

# 서술

1851년 멜빌의 소설에서 선장은 항해 도구인 사분의를 너라고 부르며 어리석은 장난감이라고 꾸짖었다.[^1]

1861년 조지 엘리엇의 소설에서 혼자 사는 직조공에게 12년 동안 쓴 물동이는 동반자였다. 직조공은 늘 같은 자리에서 아침마다 손잡이를 내미는 그 물동이의 모양에서 기꺼이 돕는 표정을 읽었다.[^2]

2007년 AP 통신 기사[^3]에서 로봇청소기 룸바의 주인들은 청소기에 별명을 붙이고 청소기가 도움을 청하는 신호를 내면 걱정했다. 일부는 청소기를 믿음직한 반려동물처럼 대했다.[^3] 2008년 연구[^4]의 저자들은 다른 사람과의 사회적 연결이 모자란 사람이 사람 아닌 대상과 사람 같은 연결을 만들어 그것을 메우려 할 수 있다고 썼다.

2012년 Straight Dope 게시판의 한 댓글[^5]의 글쓴이는 바퀴 하나가 빠진 진공청소기를 집에서 기르던 개의 이름을 따 Tripod 라고 불렀다고 썼다.
