# 물건에 이름 붙이고 사람처럼 대하기

별칭: 없음

사람이 오래 쓰거나 곁에 두는 물건에 이름을 붙이고 사람이나 동물을 대하듯 대한다.

# 서술

1861년 조지 엘리엇의 소설에서 혼자 사는 직조공에게 12년 동안 쓴 물동이는 동반자였다. 직조공은 늘 같은 자리에서 아침마다 손잡이를 내미는 그 물동이의 모양에서 기꺼이 돕는 표정을 읽었다.[^1]

2007년 AP 통신 기사[^2]에서 로봇청소기 룸바의 주인들은 청소기에 별명을 붙이고 청소기가 도움을 청하는 신호를 내면 걱정했다. 일부는 청소기를 믿음직한 반려동물처럼 대했다.[^2] 2008년 연구[^3]에서 오래 외로웠던 사람과 실험에서 외로움을 느끼게 된 사람은 동물과 기기를 더 사람처럼 여겼다.

2012년 Straight Dope 게시판의 한 댓글[^4]의 글쓴이는 바퀴 하나가 빠진 진공청소기를 집에서 기르던 개의 이름을 따 Tripod 라고 불렀다고 썼다.
