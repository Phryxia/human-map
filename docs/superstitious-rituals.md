# 징크스 지키기

별칭: 미신 행동, 액막이 의례, Superstitious behavior

결과를 알 수 없는 일을 앞둔 사람이 불운을 막거나 일이 잘되도록 정해 둔 작은 의례를 하거나 어떤 행동을 피한다.

# 서술

1884년 Twain 의 허클베리 핀에서 허크는 거미를 죽인 뒤 제자리에서 세 번 돌며 매번 가슴에 성호를 긋고 마녀를 쫓으려고 머리카락 한 타래를 실로 묶었다.[^1]

2019년 브런치 에세이의 글쓴이는 수능 이틀 전 식탁에서 미역에 젓가락을 대자 아버지가 다급하게 먹지 말라고 했다고 적었다.[^4]

2025년 헤럴드경제 기사는 AFP 통신이 한국 수험생이 수능날 미역국을 먹지 않는 이유를 미끄러운 미역을 먹으면 시험에서 미끄러질 수 있다는 미신으로 풀이했다고 전했다.[^6]

# 조건

2013년 Perkos 등은 운동선수가 미신 믿음과 의례를 쓰는 정도가 통제 소재와 불안에 크게 좌우된다고 적었다.[^2]

2016년 Daily Bruin 칼럼[^3]의 필자는 시험 보러 가는 길에 행운의 운동복 바지를 입고 교내 곰 동상의 발을 문지르는 자기 의례를 하면 조금 우스운 기분이 들면서도 묘하게 안심이 된다고 썼다.

2025년 Cherwell 칼럼의 필자는 시험 날 손목에 행운의 옥팔찌가 없으면 과호흡 직전까지 가고 시험 결과가 나쁘리라 확신하게 된다고 썼다.[^5]

2025년 Ofori 등은 영국과 가나의 학생 선수를 조사해 선수들이 스트레스 상황에서 통제하고 있다는 느낌을 얻는 대처로 미신 행동을 할 수 있다고 적었다.[^7]
