# 가까운 사람 이름 바꿔 부르기

별칭: misnaming[^5], name substitutions[^3]

가족이나 친구를 부르는 사람이 그 사람을 다른 가족이나 친구, 반려견의 이름으로 잘못 부른다.

묶음: [기억과 떠오르는 생각](../groups/memory-and-thoughts.md)

# 서술

1927년 소설[^1]의 할머니는 손자를 맏아들의 이름으로 부르다가 곧이어 귀염둥이라고 불렀다. 2002년 게시글[^2]의 글쓴이는 할머니가 자식 다섯 가운데 하나를 부를 때 맞는 이름이 나올 때까지 자식들 이름을 차례로 불렀다고 어머니에게 들었다.

2013년 연구[^3]에서 부모가 자녀를 잘못 부른 이름은 거의 모두 다른 가족의 이름이었고 응답자의 5% 넘게는 부모가 반려동물 이름으로 부른 적이 있다고 답했다.

2016년 보도자료[^4]에 따르면 연구 참가자들은 형제끼리, 딸과 아들 사이에서 이름을 바꿔 불렀고 가족을 반려동물 이름으로도 불렀다. 반려동물 이름은 그 동물이 개일 때만 섞였다. 같은 해 연구[^5]에서 가족은 다른 가족의 이름으로, 친구는 다른 친구의 이름으로 잘못 불렸다.
