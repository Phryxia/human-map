# 무더위 쉼터 가지 않기

별칭: 없음

폭염 때 노인이 지자체가 연 무더위 쉼터에 가지 않고 집이나 다른 곳에서 더위를 보낸다.

묶음: [건강과 위험](../groups/health-and-safety.md)

# 서술

2011년 호주 애들레이드의 관계자 면담 연구[^1]에서는 키우는 동물을 두고 떠나기 싫은 마음이 냉방 쉼터 이용이 적은 이유의 하나로 나왔다.

2015년 서울 관악구의 저소득 노인과 정책 집행자를 면담한 연구[^2]는 무더위 쉼터의 심리적 접근성을 문제점의 하나로 들었다.

2022년 미국 질병통제예방센터 보고[^3]는 노인이 쉼터에 가지 못하는 이유로 쉼터 위치를 모르는 것과 교통을 들었다.

2023년 매일신문 기사[^4]의 90대 노인은 경로당은 동네 아는 사람만 모이는 것 같아 불편하고 지하철역은 편히 앉아 있을 수 있어 좋다고 말했다.

2024년 뉴스토마토 기사[^5]가 전한 2023년 서울시 실태조사에서 쪽방 주민이 무더위 쉼터를 이용하지 않은 이유로 가장 많이 꼽은 것은 쉼터에 가는 일이 귀찮거나 힘들어서(37.5%)였다.

2026년 7월 뉴시스 기사[^6]에서 노인들은 무더위쉼터를 이용하지 않는 이유로 접근성과 이용 편의성을 꼽았다. 2026년 8월 뉴시스 기사[^7]가 전한 행정안전부 의뢰 보고서에서 취약 고령층 500명 가운데 59.1%는 무더위 쉼터를 이용한 적이 없었다. 이용하지 않은 이유로는 쉼터를 잘 알지 못해서(33%), 이용할 필요가 없어서(29%), 주변 사람의 시선이 불편해서(10.3%)가 꼽혔다.[^7]
