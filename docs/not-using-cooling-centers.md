# 무더위 쉼터 가지 않기

별칭: 없음

폭염 때 노인이 지자체가 연 무더위 쉼터에 가지 않고 집이나 다른 곳에서 더위를 보낸다.

# 서술

2011년 호주 애들레이드의 관계자 면담 연구[^1]에서는 키우는 동물을 두고 떠나기 싫은 마음이 냉방 쉼터 이용이 적은 이유의 하나로 나왔다.

2022년 미국 질병통제예방센터 보고[^2]는 노인이 쉼터에 가지 못하는 이유로 쉼터 위치를 모르는 것과 교통을 들었다.

2023년 매일신문 기사[^3]의 90대 노인은 경로당은 동네 아는 사람만 모이는 것 같아 불편하고 지하철역은 편히 앉아 있을 수 있어 좋다고 말했다. 2026년 뉴시스 기사[^4]에서 노인들은 무더위쉼터를 이용하지 않는 이유로 접근성과 이용 편의성을 꼽았다.
