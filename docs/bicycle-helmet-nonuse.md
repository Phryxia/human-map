# 자전거 헬멧 미착용

별칭: 자전거 안전모 안 쓰기, Bicycle helmet nonuse

자전거를 타는 사람이 짧은 거리, 불편함, 머리 모양 따위를 이유로 헬멧을 쓰지 않는다.

# 서술

1999년 CPSC 조사에서 자전거 이용자들은 헬멧을 쓰지 않는 이유로 짧은 거리만 탄다는 것, 쓰기를 잊는다는 것, 헬멧이 불편하다는 것을 들었다. [F1]

2018년 서울신문 기사는 출퇴근길에 헬멧을 쓰면 머리가 눌리고 땀이 차서 착용을 꺼린다고 적었다. 같은 해 정책브리핑 기사에서 자전거를 매일 타는 한 이용자는 안전모가 귀찮고 보관할 곳이 없어 들고 다녀야 하며 여름에는 땀과 섞인다고 말했다. 2026년 Halfords 조사에서 응답자의 13%는 머리 모양이 흐트러지는 것을 피하려고 헬멧을 쓰지 않는다고 답했고 여성 응답자에서는 그 비율이 18%였다. [F2][F4][F5]

# 조건

2018년 서울시는 공공자전거 따릉이의 안전모 의무화를 두고 짧게 이용하고 저속으로 운행하므로 안전모가 필요 없다는 반대 근거를 정리했다. [F3]

1999년 F1 의 응답자는 짧은 거리와 잊음과 불편함을 이유로 들었고 2026년 F5 의 응답자 가운데 일부는 머리 모양을 이유로 든다. [F1][F5]
