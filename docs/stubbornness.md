# 고집

별칭: Stubbornness[^2]

사람이 남의 조언이나 만류에도 자기 방식과 생각을 굽히지 않고 우기거나 버틴다.

묶음: [성향과 기질](../groups/traits.md)

# 서술

1759년 소설[^1]의 화자는 같은 기질을 좋은 일에서는 끈기, 나쁜 일에서는 고집이라 부른다고 적었다. 화자의 어머니는 남편의 그 기질을 잘 알아서 항의해도 소용없다는 것을 알았다.

2015년 Heid 외의 연구[^2]에서 자녀의 77% 이상과 나이 든 부모의 66% 가 부모가 적어도 가끔은 고집으로 여겨지는 방식으로 행동한다고 보고했다.

2017년 클리앙 게시글의 글쓴이는 고집 센 동생을 타이르고 혼내고 기다려 보아도 벽과 말하는 것 같다고 썼다. 동생은 친구 말은 잘 들으면서 가족 말은 듣지 않았다.[^3]

2020년 매일신문 기사[^4]는 나이 든 사람에게 안정감을 주는 정신적 노화가 흔히 노인의 고집으로 치부되며 세대 간 갈등의 앞에 선다고 적었다.
