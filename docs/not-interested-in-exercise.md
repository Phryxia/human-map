# 운동에 관심이 없어 운동하지 않기

별칭: 없음

운동하지 않는 사람이 그 까닭으로 운동에 관심이 없다는 것을 든다.

# 서술

2007년 호주 통계청 발표[^1]에서 남성은 일 때문에 운동할 시간이 없다는 답(27%)이 많았고 여성은 운동에 관심이 없다는 답(19%)이 많았다.

2026년 기사[^2]가 전한 문화체육관광부 조사에서 규칙적으로 체육활동을 하지 않는 까닭은 시간 부족이 61.3%, 체육활동에 대한 관심 부족이 50.8%였다.
