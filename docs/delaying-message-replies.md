# 답장 미루기

별칭: 없음

메신저나 문자로 받은 메시지에 답장을 미루는 사람이 시간이 지나도 답을 보내지 못하거나 메시지를 열지 않는다.

# 서술

1888년 봄 스티븐슨은 편지에서 어떤 곳을 떠나게 될 때까지 받은 편지를 쌓아 두었다가 그제야 더미를 뒤지며 참회한다고 적었다.[^1]

2024년 2월 네이버 지식iN 질문 글에서 글쓴이는 연락을 늦게 보고 미루다 잊거나 하루 뒤에 보기도 한다고 적었다. 글쓴이는 귀찮고 보지 않아도 될 연락에만 그렇고 전화나 용건, 물음표로 끝나는 말에는 답장을 잘 한다고 적었다.[^3]

2024년 10월 Substack 댓글에서 글쓴이는 오래 둘수록 죄책감이 커지고 한 달 걸린 답장을 어떻게 설명할지 몰라 더 보내지 못한다고 적었다.[^4]

2026년 6월 네이버 지식iN 질문 글에서 글쓴이는 상대가 안 좋은 말을 보냈을 것 같아 답장을 바로 보기 힘들고 미루다가 마음을 먹어야 볼 수 있다고 적었다.[^5]

2014년 연구[^2]의 저자들은 모바일 메신저 사용자들 사이에서 늦은 응답이나 무응답이 양해되는 것으로 보고 상대에게 빠른 응답을 강요하지 않으려 한다고 적었다.

게시글[^3]의 글쓴이는 용건이 없는 연락에서 미루고 용건이나 질문이 있는 연락에는 답한다. 게시글[^5]의 글쓴이는 나쁜 내용일 것이라는 두려움 때문에 미룬다.
