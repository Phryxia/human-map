# 술김에 속마음 털어놓기

별칭: 취중진담[^5]

술에 취한 사람이 평소에 말하지 않던 원망이나 걱정, 감정을 털어놓는다.

묶음: [가까운 사이의 감정과 말](../groups/close-relationships.md)

# 서술

1886년 소설[^1]에서 럼을 탄 죽을 여러 그릇 마신 남자는 아내와 아이 앞에서 열여덟에 결혼한 것을 원망하는 말을 낯선 사람들에게 꺼낸다.

1924년 소설[^2]에서 선술집에서 취한 인력거꾼은 아내가 죽었다며 마누라를 두고 술을 먹은 자신을 탓하며 운다.

2005년 게시글[^3]의 글쓴이는 친구가 몹시 취한 밤에 자신을 사랑한다고 고백했다고 썼다.

2019년 연구[^4]가 인용한 실험에서 술을 마신 집단은 이어진 토론에서 마시지 않은 집단보다 말을 더 많이 하고 자기 이야기를 더 털어놓았다. 2024년 기사[^5]는 통제력을 잃어 마음속에 담아 두었던 고백을 하는 사람을 예로 들었다.
