# 모르는 번호의 전화 받지 않기

별칭: 모르는 번호 안 받기, 낯선 번호 거르기, Call screening

휴대전화를 쓰는 사람이 저장되지 않은 번호로 걸려 온 전화를 받지 않는다.

# 서술

2020년 12월 퓨 리서치 센터의 글은 미국인의 67% 가 모르는 번호로 걸려 온 전화는 받지 않고 음성 메시지가 남으면 확인하는 것을 평소 습관이라고 답했다고 적었다.[^1]

2023년 10월 기사가 전한 알바천국 조사에서 콜 포비아 대처 방법으로 가장 많이 꼽힌 것은 모르는 번호의 전화를 받지 않는 것(39.2%)이었다.[^2]

2026년 1월 다음 카페 댓글의 글쓴이는 010 으로 시작하는 번호의 전화를 받았다가 검찰을 사칭한 보이스피싱 전화를 겪은 뒤로는 두 번 걸려 와야 받는다고 적었다.[^3]
