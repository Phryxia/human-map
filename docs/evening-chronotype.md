# 저녁형 성향

별칭: 올빼미형, 저녁형 인간, Evening chronotype, Night owl

저녁형 성향의 사람이 밤늦게 정신이 맑아지고 아침 일찍 일어나는 일정을 힘들어하며 이 성향이 여러 해 이어진다.

# 서술

2004년 주간경향 좌담의 한 참석자는 체질적으로 아침형이 맞지 않아 아침 일찍 일어나면 오히려 잠을 더 자는 것 같고 9시만 되면 해롱댄다고 말했다.[^1] 같은 해 Nature News 기사는 하루 주기가 약 24시간이지만 정확한 시점은 사람마다 다르다고 적었다.[^2]

2007년 김정기와 송혜수의 대학생 연구에서 저녁 활동형 집단은 아침 활동형 집단보다 늦게 자고 늦게 일어났으며 잠드는 데 걸리는 시간이 길었고 스스로 보고한 수면의 질이 낮았다.[^3] 2015년 경향신문 기사는 올빼미형 사람을 야심한 시간이 되면 정신이 맑아지고 아침이 되면 몽롱한 유형으로 묘사했다.[^5]

2016년 Barclay 등이 쌍둥이와 형제자매를 두 시점에 걸쳐 잰 연구에서 저녁 선호는 두 시점 모두 더 나쁜 수면의 질과 함께 나타났다.[^6] 2023년 The Medical Republic 기사가 전한 연구에서 알람을 미루는 사람은 그러지 않는 사람보다 저녁형일 가능성이 네 배 높았다.[^7]

2015년 미국 질병통제예방센터 자료는 사춘기에 생체 리듬이 흔히 늦춰져 청소년이 밤늦게 졸리고 아침에 더 늦게까지 자야 한다고 적는다.[^4]
