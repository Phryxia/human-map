# 연락받는 사람의 감사 과소평가

별칭: 없음

안부를 전하려는 사람이 연락을 받는 사람이 그 연락을 얼마나 고마워할지 실제보다 낮게 어림한다.

# 서술

2022년 7월 논문[^1]은 사전 등록한 여러 실험에서 연락을 받는 사람이 그 연락을 얼마나 고마워하는지 사람들이 꾸준히 과소평가했다고 적었다. 같은 달 기사[^2]는 모든 실험에서 연락한 사람이 연락받은 사람보다 감사의 정도를 상당히 낮게 어림했다고 전했다.
