# 반려동물에게 말 걸기

별칭: Pet-directed speech[^2]

사람이 개나 고양이에게 아기에게 하듯 달래는 말투로 말을 건다.

묶음: [혼자 있음과 상실](../groups/solitude-and-loss.md)

# 서술

1886년 제롬의 수필은 모르는 고양이에게는 "가엾은 야옹이" 라고 말을 시작하고 그다음 달래는 어조로 아기 말을 덧붙이라고 적었다.[^1]

2017년 연구[^2]의 저자들은 반려동물에게 하는 말이 음이 높고 박자가 느린, 아기에게 하는 말투와 매우 닮았다고 적었다.

2026년 블로그 글[^3]의 필자는 사람들이 상대의 마음을 얻으려고 고양이에게도 사람에게 하던 대로 말을 걸고 좋아하는 것을 주고 눈을 맞추려 애쓴다고 적었다.
