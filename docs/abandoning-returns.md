# 반품 포기

별칭: 반품 귀찮음, 원치 않는 물건 그냥 갖기, return hassle

산 물건이 마음에 들지 않거나 고장 난 사람이 반품 절차의 번거로움과 비용 때문에 반품을 그만두고 물건을 그냥 갖는다.

# 서술

2000년 기사[^1]가 옮긴 설문에서 온라인 쇼핑객 41%는 인터넷 판매자에게서 산 물건을 반품하고 싶었지만 너무 번거로워 그만둔 적이 있다고 답했다.

2016년 한국소비자원 보도자료[^3]의 피해 사례에서 해외 직구로 가방을 산 소비자는 쇼핑몰의 반품 승인을 받았다. 관세를 돌려받으려면 대행 수수료가 많이 들거나 세관을 여러 차례 찾아야 했고 그 절차가 복잡해 보여 반품을 포기했다.

2015년 연구[^2]는 반품의 번거로움이 클수록 반품에 드는 거래 비용을 크게 느끼고 산 물건을 그대로 갖는 고객이 늘어난다고 적는다. 2026년 보도자료[^5]의 설문에서 응답자 46%는 지난 1년 사이 반품 절차가 어렵거나 돈이 들어 고장 난 물건이나 원치 않는 물건을 그냥 가졌다고 답했다.

# 조건

2000년 기사[^1]와 2016년 보도자료[^3]의 사례는 온라인 구매와 해외 직구다. 2023년 기사[^4]가 옮긴 영국 설문에서 반품이 어려워 원치 않는 물건을 갖는다는 응답은 18~24세에서 80%였고 55세 이상에서 53%였다.
