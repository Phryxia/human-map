# 혼자 있기 선호

별칭: Preference for solitude[^1]

사람이 다른 사람과 함께 있기보다 혼자 시간을 보내거나 혼자 활동하기를 더 좋아한다.

# 서술

2023년 Zhou 외의 논문[^1]은 Burger 가 혼자 있기 선호를 남과 함께 있기보다 혼자 시간을 보내거나 혼자 활동하기를 더 좋아하는 경향으로 개념화했다고 적었다.

2023년 11월 세계일보 기사[^2]가 전한 피앰아이 조사에서 연애를 하지 않는 이유로 혼자가 편하다는 응답이 33.6%로 가장 많았다.
