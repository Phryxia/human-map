# 돌아온 고향의 낯섦

별칭: 귀향의 낯섦, 역문화 충격, Reverse culture shock

오래 떠나 있다가 고향이나 모국으로 돌아온 사람이 그곳이 기억이나 기대와 달라 낯설고 쓸쓸하다고 느낀다.

# 서술

1921년 F1 의 화자는 이십 년 만에 돌아온 고향을 보고 자기가 기억하는 고향은 이렇지 않았고 훨씬 좋았다고 말한다. 그런데 그 아름다움을 떠올려 말하려 하자 떠오르는 모습도 말도 없다. [F1]

1932년 F2 의 화자는 고향에 돌아와도 그리던 고향이 아니라고 말한다. 산꿩과 뻐꾸기는 제철에 있지만 마음은 고향에 머물지 않고 먼 항구로 떠도는 구름이다. [F2]

2018년 F4 의 칼럼 필자는 유학 5년 만에 한국에 돌아가 지내는 동안 이방인이 된 듯한 묘한 느낌을 받았다. 다시 미국에 돌아와 비행기에서 내릴 때는 고향에 돌아온 것 같은 편안함을 느꼈다고 적는다. [F4]

2024년 F5 의 면담 연구에서 해외 유학을 마치고 돌아온 한국 청소년들은 손을 놓았던 지점에서 학업을 다시 시작하며 익숙하지만 낯선 상황에 맞닥뜨렸다. [F5]

# 조건

2009년 F3 은 모국 문화로 돌아오는 체류자가 낯선 것이 하나도 없으리라고 예상한다고 적는다. [F3]

1921년 F1 과 1932년 F2 는 오래 떠나 있던 고향 마을로 돌아온 화자를, 2009년 F3 과 2018년 F4 와 2024년 F5 는 외국에 머물다 모국으로 돌아온 사람을 다룬다. [F1][F2][F3][F4][F5]
