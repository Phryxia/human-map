# 타인의 표정을 부정적으로 읽기

별칭: 없음

남에게 나쁘게 평가받을까 두려워하는 사람이 다른 사람의 표정을 부정적인 것으로 읽는다.

# 서술

1995년 연구[^1]에서 사회불안이 높은 참가자는 다른 사람의 감정 표현을 부정적인 것으로 판별하는 쪽으로 치우쳤고 서로 다른 감정 상태를 더 잘 가려내지는 않았다.

2026년 10월 잡지 글[^2]은 말수가 적고 표정이 어두운 동료를 보고 "내가 뭐 잘못했나?" 하는 생각이 자주 드는 일을 높은 불안도와 이어 적었다.
