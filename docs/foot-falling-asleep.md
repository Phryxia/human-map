# 발이 저려 절룩이기

별칭: Obdormition[^3]

한 자세로 오래 앉아 있던 사람이 발이나 다리가 저려 감각이 둔해지고 일어선 뒤 한동안 절룩이며 걷는다.

묶음: [건강과 위험](../groups/health-and-safety.md)

# 서술

1895년 소설[^1]에서 율리야는 발이 저려 나른하게 일어나 조금 절룩이며 방을 나갔다.

2021년 The Conversation 글[^2]은 프로그램 한 회가 끝나 일어서려 할 때 한쪽 발이 갑자기 움직이지 않고 이어서 바늘로 찌르는 듯한 느낌이 드는 장면을 적었다.

2023년 병원 건강 정보[^3]는 신경을 누르거나 피의 흐름을 막는 자세 때문에 몸의 한 부분이 잠드는 일이 흔하고 이를 obdormition 이라 부른다고 적었다.
