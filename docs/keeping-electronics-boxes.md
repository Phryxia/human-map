# 전자제품 상자 버리지 않고 두기

별칭: 없음

전자제품을 산 사람이 다 쓴 포장 상자를 버리지 않고 집에 오래 둔다.

묶음: [돈과 소비](../groups/money.md)

# 서술

2013년 기사[^1]의 글쓴이는 오래전에 기부하거나 재활용한 컴퓨터와 텔레비전의 상자, 가졌던 거의 모든 카메라의 상자가 지하실을 채우고 있다고 썼다.

2021년 기사[^2]는 많은 사람이 애플 제품의 예전 기기뿐 아니라 그 포장 상자까지 모아 둔다고 전했다. 2026년 댓글[^3]의 글쓴이는 전자제품 상자를 못 버리게 된다고 적었다.
