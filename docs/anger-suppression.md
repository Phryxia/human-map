# 분노 억누르기

별칭: 없음

화가 난 사람이 그 분노를 겉으로 드러내지 않고 억누른다.

# 서술

1866년 도스토옙스키의 소설[^1]에서 계단 아래로 던져 버리겠다는 말을 들은 루진은 창백해져 입술을 깨물고 숨을 거칠게 쉬면서 화를 누르려 애쓰며 천천히 말을 꺼낸다.

2002년 기사[^2]에서 한 정신의학 조교수는 억누른 분노가 대개 사라지지 않고 결국 다른 때 다른 곳에서 다른 사람에게 나오는 일이 많다고 말했다.

2005년 실험[^3]에서 분노를 일으키는 영상을 본 뒤 감정 표현을 억누른 여성 참가자는 뒤이은 행동에서 격분과 혐오의 표현이 늘었다.
