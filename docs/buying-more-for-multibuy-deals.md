# 묶음 할인 보고 더 사기

별칭: 없음

정해 둔 양만 사려던 사람이 1+1이나 2+1 같은 묶음 할인을 보고 그보다 많이 산다.

묶음: [돈과 소비](../groups/money.md)

# 서술

2020년 12월 영국 보건사회복지부 문서[^1]는 묶음 할인 판촉 때문에 사람들이 원래 살 양보다 20% 가까이 더 산다고 적었다.

2021년 8월 머니투데이 기사[^2]에서 하나만 사려던 사람은 그 상품이 2+1 행사 중이면 덤으로 하나를 더 받으려고 끝내 두 개를 산다.
