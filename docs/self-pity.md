# 자기 연민

별칭: Self-pity[^3]

괴로운 일을 겪은 사람이 자기 처지를 불쌍히 여기며 자기만 힘들다고 느낀다.

묶음: [걱정과 기분](../groups/worry-and-mood.md)

# 서술

1891년 소설[^1]의 화자는 절망한 사람이 자기 연민의 격정과 그것이 낳는 고집스러운 저항 정신에서 자주 피난처를 찾는다고 적었다. 1905년 소설[^2]에서 모욕을 당한 직후의 인물은 갑자기 약하고 무방비하다고 느꼈고 목에서 자기 연민이 고동쳤다.

2003년 Stöber 의 연구[^3]에서 자기 연민이 높은 사람들은 자신이 우연과 힘 있는 타인 양쪽에 좌우된다고 여기는 외부 통제 신념을 보였다.

2026년 브런치 글[^4]의 글쓴이는 자기 연민에 빠지는 순간 모든 상황의 피해자가 된다는 말을 옮기고 자기가 세상에서 제일 불쌍하고 억울하며 자기만 힘들다고 느꼈다고 썼다.
