# 젊은 사람 부러워하기

별칭: Youth envy[^2]

나이 든 사람이 젊은 사람의 젊음과 남은 시간을 보며 부러워한다.

묶음: [가까운 사이의 감정과 말](../groups/close-relationships.md)

# 서술

1936년 이효석의 소설에서 고개를 넘을 때마다 숨이 차 다리를 쉬던 늙은 장돌뱅이는 함께 걷는 젊은 동행을 몹시 부러워했다.[^1]

2009년 칼럼[^2]의 필자는 나이를 감추는 상품의 시장이 번창하는 까닭을 젊음에 대한 부러움이라고 적었다.

2025년 에세이[^3]의 필자는 다 자란 자녀들이 사는 모습을 보며 부러움을 느낀다고 적었다. 필자는 자녀들에게 젊음과 시간과 앞날이 있다고 썼다.
