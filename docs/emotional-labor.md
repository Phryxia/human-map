# 감정노동

별칭: 표면 행위, 스마일 마스크, emotional labor, surface acting

고객을 응대하는 노동자가 일이 요구하는 표정과 말투를 지으려고 실제로 느끼는 감정을 누르거나 꾸민다.

# 서술

2000년 논문[^1]은 일의 역할이 고객에게 특정한 표정을 보이라고 요구할 때 노동자가 감정을 관리하며 겪는 스트레스를 감정노동이라 부른다. 2012년 서울시 기사[^2]에서 한국산업안전보건공단 관계자는 노동자가 고객이나 회사가 원하는 표정, 몸짓, 말투를 쓰다가 자신이 실제로 느끼는 감정을 점점 잊는다고 말했다. 2018년 기사[^3]의 기자는 음식 배달이 늦어 콜센터에 짜증을 퍼부었을 때 상담사가 다 듣고 나서 불편을 드려 죄송하다고 말했다고 썼다.

2019년 연구에서 고객 앞의 표면 행위는 인구 특성, 업무 요구, 부정 정서를 통제한 뒤에도 과음과 관련이 있었다. 저자들은 이 관련을 자기 통제가 약해진 탓으로 설명한다.[^4]
