# 산 채로 묻힐까 두려워하기

별칭: Taphophobia[^3]

어떤 사람은 죽었다는 판정을 잘못 받아 산 채로 묻힐까 두려워한다.

묶음: [걱정과 기분](../groups/worry-and-mood.md)

# 서술

1844년 Poe 의 단편[^1]에서 화자는 몸이 충분히 썩기 전에는 자기를 묻지 않겠다는 맹세를 주위 사람들에게서 받아 냈다.

1926년 영국 하원 토론[^2]에서 한 의원은 산 채로 묻힐까 하는 두려움이 많은 사람 사이에 널리 퍼져 있다고 말했다.

2019년 JSTOR Daily 기사[^3]의 필자는 영안실이나 관 속에서 깨어날까 하는 두려움이 지금도 이어지고 Taphophobia 라는 이름도 붙었다고 썼다.

2023년 Byard 의 논문[^4]은 산 채로 묻히는 데 대한 두려움이 여전히 적지 않은 사람에게 큰 걱정거리라고 적었다.
