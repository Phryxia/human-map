# 조명 효과

별칭: 스포트라이트 효과, Spotlight effect

사람이 자기 행동이나 겉모습을 다른 사람들이 실제보다 더 많이 알아차린다고 믿는다.

# 서술

2025년 Birch 등은 조명 효과를 다른 사람들이 자기 행동과 겉모습을 얼마나 알아차리고 평가하는지를 과대 추정하는 일로 설명한다. [F2]

2025년 F3 의 칼럼은 새 옷을 입은 날, 머리를 엉뚱하게 자른 날, 넘어지거나 커피를 쏟은 날 주변 사람 모두가 나를 쳐다보는 것 같은 과도한 느낌을 받는다고 쓴다. [F3]

# 조건

2021년 Castelli 와 Sarvary 는 온라인 수업에서 일부 학생이 반 친구들이 내내 자신을 보고 있다는 생각에 사로잡힐 수 있다고 쓴다. [F1]

# 파편

- F2 [학술] "For instance, consider the spotlight effect which occurs when individuals overestimate the extent to which others notice and evaluate their actions and appearance (Gilovich et al., 2000)."
