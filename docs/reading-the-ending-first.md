# 결말 먼저 읽기

별칭: 없음

소설이나 이야기를 읽는 사람이 처음부터 읽기 전에 마지막 장을 먼저 펼쳐 결말을 본다.

# 서술

1857년 트롤럽의 소설에서 화자는 셋째 권을 슬쩍 들여다보는 것만으로 사라질 마음 졸임이 무슨 가치가 있느냐고 물었다.[^1]

2011년 3월 The National 칼럼[^2]의 필자는 기억할 수 있는 때부터 책의 결말을 먼저 읽었다고 썼다. 2011년 8월 미국심리과학회 보도자료[^3]는 책을 시작하기 전에 마지막 쪽을 펼치는 사람들의 직관이 더 낫다고 적었다. 같은 보도자료는 스포일러가 이야기를 망치지 않는다는 캘리포니아대 샌디에이고 연구를 소개했다.[^3]

2012년 Sonlight 블로그 글[^4]의 글쓴이는 중학교 영어 교사에게 배운 것과 달리 대개 책의 끝을 먼저 읽으며 그러면 책을 더 즐길 수 있다고 썼다. 2013년 Goodreads 토론 게시글[^5]의 글쓴이는 아주 무서운 책에서 누군가 무사하리라는 것을 알아야 할 때 한두 번 결말을 먼저 봤다고 썼다.

2021년 레이디경향 칼럼[^6]에서 결말을 먼저 읽는 아이들은 끝을 먼저 봐도 재미있다고 말했다. 아이들은 어떻게 그렇게 됐는지 궁금하다고 덧붙였다.[^6]
