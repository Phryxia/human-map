# 불안한 가족을 달래며 제 걱정 감추기

별칭: 없음

병원처럼 겁나는 자리에서 가족이 불안해할 때 사람이 웃거나 달래는 말을 하며 자기도 같은 걱정을 속에 품는다.

묶음: [걱정과 기분](../groups/worry-and-mood.md)

# 서술

1937년 소설[^1]의 덕순이는 수술을 겁내는 아내를 위안하려고 말을 건네면서 속으로는 아내 못지않게 조바심을 낸다.

2016년 연구[^2]의 10일 일상 경험 조사에서 아이를 돌보는 부모는 부정적 감정을 누르는 것과 긍정적 감정을 부풀려 드러내는 것을 함께 쓰는 경향을 보였다.

2017년 에세이[^3]의 필자는 병원 대기실에서 아이가 긴장하지 않도록 웃으며 아이의 기분을 북돋우려 애쓰는 부모를 보았다.

2026년 에세이[^4]의 필자는 아이의 병 진단을 들은 자리에서 자기가 울거나 흔들리면 아이가 더 무섭고 불안할 것 같아 괜찮지 않은데도 괜찮은 척했다.
