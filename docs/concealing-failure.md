# 실패 사실 숨기기

별칭: 불합격 숨기기, Concealment of failure

시험이나 일에서 실패한 사람이 창피해서 그 사실을 가족이나 주변 사람에게 말하지 않거나 숨긴다.

# 서술

1891년 기싱의 소설에서 소설가 리어든은 지난 몇 달 동안 서로 다른 책을 열두 권쯤 시작했고 새로 시작할 때마다 창피해서 아내에게 말하지 못했다고 털어놓는다. [F1]

2024년 F2 의 저자들은 실험에서 실패와 숨김 사이에 강한 관계가 나타났고 이 결과가 뒤이은 세 실험에서 반복됐다고 보고했다. [F2]

2026년 7월 네이버 지식iN 질문 글의 글쓴이는 두 번째 필기 점수를 말하기 싫어서 말하기 싫다고 했다가 말싸움이 시작됐다고 적었다. [F3]

# 조건

2024년 F2 의 실험에서 실패는 숨김과, 성공은 드러내기 행동과 이어졌다. [F2]

1891년 F1 에서 리어든이 숨기는 상대는 아내다. [F1]
