# 이어폰 끼고 길 걷기

별칭: 없음

길을 걷는 사람이 이어폰이나 헤드폰으로 음악을 들으며 다니다 다가오는 차나 열차의 소리를 듣지 못한다.

묶음: [길과 운전](../groups/roads-and-driving.md)

# 서술

2012년 1월 보도자료[^1]가 전한 연구에서 헤드폰을 낀 보행자가 다친 사고의 여러 사례는 보행자가 듣지 못한 경적을 차나 열차가 울린 경우였다. 같은 달 기사[^2]가 전한 국내 사고에서 숨진 학생은 이어폰으로 음악을 들으며 걷느라 열차 소리를 듣지 못했다.

2013년 미국 시애틀 관찰 연구[^3]에서 길을 건너던 보행자의 11.2%가 음악을 듣고 있었다.

2015년 기사[^4]의 기자는 이어폰을 끼고 스마트폰을 보던 보행자가 오토바이와 부딪힐 뻔한 뒤에도 다시 스마트폰을 보며 가던 길을 가는 것을 보았다.

2018년 대학 캠퍼스 두 곳의 관찰 연구[^5]에서 보행자의 19%가 헤드폰을 끼고 있었고 헤드폰은 가장 흔한 주의 분산이었다.

2024년 기사[^6]에서 무선이어폰을 낀 남성은 뒤따르던 운전자가 창문을 열고 소리를 질러도 듣지 못하고 가던 길을 갔다.
