# 무늬에서 얼굴과 모양 보기

별칭: 파레이돌리아[^4], pareidolia[^3]

사람이 구름, 바위, 음식처럼 무작위로 생긴 무늬에서 얼굴이나 동물, 사물의 모양을 본다.

묶음: [기억과 떠오르는 생각](../groups/memory-and-thoughts.md)

# 서술

1623년 초판이 나온 셰익스피어 희곡[^1]에서 안토니는 용 같은 구름, 곰이나 사자 같은 수증기, 탑이 선 성채, 매달린 바위, 갈라진 산을 본다고 말한다.

2013년 논문[^2]의 저자들은 구름이나 바위 같은 무작위 이미지와 자연 이미지에서 생생한 얼굴이 자주 보인다고 썼다. 2014년 논문[^3]의 저자들은 파레이돌리아 가운데 얼굴 파레이돌리아가 가장 잘 알려져 있고 사람들이 구름 속 얼굴, 토스트 속 예수, 토르티야 속 성모 마리아를 봤다고 흔히 보고한다고 적었다.

2021년 코메디닷컴 기사[^4]는 눈, 코, 입이 있는 생물이 아닌 무생물에서 얼굴을 그려 내는 현상을 파레이돌리아라고 부른다고 소개했다.
