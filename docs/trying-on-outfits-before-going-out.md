# 외출 전 옷 여러 번 갈아입기

별칭: 없음

외출을 앞둔 사람이 입을 옷을 정하지 못해 여러 벌을 입어 보고 갈아입는다.

# 서술

1913년 Wharton 의 소설에서 언딘은 하녀의 권유에 못 이겨 디너 드레스를 차례로 입어 보았다. 첫째와 둘째 드레스는 오래 들여다볼수록 벌써 유행이 지나 보였다.[^1]

2005년 Woodward 의 학위논문[^2]은 옷을 입는 일에 여성이 다가올 사회적 자리에 자신을 그려 넣고 남의 의견을 상상하는 과정이 든다고 적는다.

2015년 기사[^3]가 전한 설문에서 여성의 3분의 2는 집을 나서기 전에 옷을 여러 벌 입어 본다고 인정했다. 약 15%는 고른 옷을 후회하고 돌아가 다른 옷을 골랐다.[^3]

2016년 6월 기사[^4]가 전한 설문에서 영국 여성 열에 한 명은 그날 입을 옷을 고르느라 쓴 시간 때문에 직장에 늦는 일이 잦았다.
