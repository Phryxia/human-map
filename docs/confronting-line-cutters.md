# 새치기에 항의하기

별칭: 없음

줄을 선 사람이 끼어든 사람에게 따지거나 눈총을 주며 항의한다.

# 서술

2008년 U2 팬 연구[^1]에서 공연장 앞자리를 얻으려고 밤새 줄을 선 팬들은 줄에서 오래 기다렸거나 열성 팬일수록 새치기 장면에 더 심하게 반응했다.

2008년 9월 PsyBlog 글[^2]은 Milgram 의 뉴욕 줄서기 실험을 전하며 끼어드는 사람 수를 두 배로 늘리자 항의 비율도 거의 두 배가 되어 91%에 이르렀다고 썼다.

2008년 10월 BPS 리서치 다이제스트 글[^3]은 같은 실험에서 사람들이 몇 자리 앞에 끼어든 사람보다 바로 앞에 끼어든 사람에게 훨씬 더 자주 반응했다고 전했다.
