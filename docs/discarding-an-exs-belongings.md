# 헤어진 연인의 물건 없애기

별칭: 없음

연인과 헤어진 사람이 상대에게 받은 편지, 사진, 선물을 태우거나 버린다.

묶음: [가까운 사이의 감정과 말](../groups/close-relationships.md)

# 서술

1811년 오스틴의 소설[^1]에서 약혼을 깨는 편지를 쓴 루시는 추신에 상대의 편지를 모두 태웠고 초상화는 돌려주겠다고 적었다. 같은 추신에서 루시는 상대에게도 자기 편지를 없애 달라고 부탁했다.[^1]

2013년 연구[^2]에서 이별 뒤의 디지털 소유물은 자주 기억을 불러일으키고 마음을 어지럽혔으며 사람마다 서로 다른 처분 방식으로 이어졌다.

2019년 기사[^3]가 전한 미혼남녀 설문에서 헤어진 연인의 선물을 간직하지 않는 이유로 다가올 새로운 사람을 위해서를 꼽은 사람이 42.8%, 전 연인을 빨리 잊을 수 있을 것 같아서를 꼽은 사람이 29.7%였다.

2020년 블로그 글[^4]을 쓴 연구자들은 이별 뒤에 피운 불이 관계가 끝났음을 알리고 지난 관계의 아픈 상징을 뒤에 두고 떠나게 했다고 적었다.

2022년 10월 기사[^5]가 전한 미혼남녀 설문에서 헤어진 연인에게 받은 선물을 그대로 쓴다는 답이 51.3%로 가장 많았고 미련 없이 버린다는 답은 12.1%였다.

2022년 12월 기사[^6]를 쓴 연구자들은 인터넷이 나오기 전에 사람들이 이별을 매듭짓는 행위로 폴라로이드 사진과 연애편지를 불에 태우곤 했다고 적었다.

2026년 게시글[^7]의 글쓴이는 편지와 사진을 넣어 둔 상자를 버리려고 꺼냈다가 편지를 읽고는 버리지 못한 채 새벽 내내 앓았다고 썼다.
