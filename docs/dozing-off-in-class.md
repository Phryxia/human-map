# 수업 중 졸기

별칭: 없음

강의나 수업을 듣는 학생이 자리에 앉은 채 졸거나 잠든다.

묶음: [시간과 하루 습관](../groups/daily-time.md)

# 서술

2004년 9월 기사[^1]에 따르면 영국 대학생 네 명 가운데 한 명은 강의 중에 잠든 적이 있다고 인정했다.

2017년 12월 기사[^2]가 전한 대학생 조사에서 참여 학생의 41%는 강의나 세미나에서 한 번 이상 잠든 적이 있다고 인정했다.

2023년 5월 게시글[^3]의 글쓴이인 교사는 수업 시간에 졸 수 있다고 여기며 자기도 학교에 다닐 때 많이 잤다고 썼다.
