# 애정을 거친 말이나 행동으로 드러내기

별칭: 츤데레[^2]

가까운 사람을 아끼는 사람이 그 마음을 다정한 말 대신 퉁명스러운 말이나 놀림으로 드러낸다.

# 서술

2008년 연구[^1]의 참가자들은 놀림을 대체로 부정적으로 보았지만 가까운 관계 안의 놀림은 훨씬 긍정적으로 보았다.

2025년 기사[^2]는 지시하는 듯한 말이 퉁명스러워 보여도 상대를 세심하게 살피는 표현이라고 적었다.

2026년 에세이[^3]는 가족이 남에게 칭찬받을 때 핀잔을 주는 사람이 가까운 사이라 표현을 조심하지 않거나 칭찬을 그대로 받기 쑥스러워 농담으로 넘기기도 한다고 적었다.
