# 김 서린 유리에 손가락으로 쓰기

별칭: 없음

김이나 성에가 낀 유리창이나 거울 앞에 선 사람이 손가락으로 이름이나 글귀, 그림을 쓴다.

# 서술

1922년 소설[^1]의 인물은 킹스타운에서 몰리가 성에 낀 객차 유리창에 그림을 그리던 일을 떠올린다.

2011년 Straight Dope 댓글의 글쓴이는 호텔에 묵을 때마다 욕실 거울의 김에 "지켜보고 있다" 는 글을 쓴다고 적었다.[^2]

2016년 연구[^3]는 차창이나 유리에 맺힌 결로 위에 사람들이 도형, 그림, 메시지를 자주 끄적인다고 적고 그 행동을 바탕으로 결로를 쓰는 화면을 만들었다.

2022년 Autisable 에세이의 필자는 극장 앞 차 안에서 기다리다 김이 서린 차창에 손가락으로 한 아이의 이름을 쓰며 시간을 보냈다.[^4] 2026년 브런치 에세이의 필자는 어린 시절 성에 낀 창에 남몰래 좋아하던 짝꿍의 이름을 적었다가 부끄러워 손바닥으로 문질러 지우던 밤을 떠올렸다.[^5]
