# 건강기능식품 겹쳐 먹기

별칭: 없음

건강을 챙기려는 사람이 건강기능식품을 여러 개 먹고 같은 원료의 제품까지 겹쳐 먹는다.

묶음: [건강과 위험](../groups/health-and-safety.md)

# 서술

2022년 강남구청 카드뉴스[^1]는 같은 기능성 원료를 쓴 건강기능식품을 여러 개 먹는 소비자가 있다는 제보를 받았다고 적었다.

2024년 보그 코리아 칼럼[^2]의 필자가 아는 사람은 구내염 때문에 먹은 비타민 B가 듣자 입술 건조나 생리 불순 같은 조짐이 보일 때마다 관련 영양제를 찾아 해외에서 사들였다.
