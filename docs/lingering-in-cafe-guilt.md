# 카페에 오래 앉은 손님의 눈치

별칭: 카공족 눈치, 자리값 추가 주문

카페에 오래 머무는 손님이 직원의 시선을 의식해 음료를 더 시키거나 자기가 거슬리는 손님인지 걱정한다.

# 서술

2020년 인스티즈 게시판에서 카페 공부가 몇 시간부터 민폐인지 묻는 글에 한 댓글은 3~4시간보다 더 오래 있을 때 주문을 하나 더 한다고 적었다. [F2]

2024년 아하 질문 게시글의 글쓴이는 구석에서 조용히 공부만 하는데 아르바이트생이 계속 쳐다본다고 적었다. 글쓴이는 그 시선을 눈치로 읽고 자기가 그렇게 거슬리는지 물었다. [F3]

# 조건

2010년 머니투데이 기사의 인터뷰에서 한 손님은 예전에는 오래 앉아 있으면 종업원 눈치가 보였지만 자기 같은 손님이 많아진 뒤로는 부담이 전혀 없다고 말했다. [F1]

2020년 F2 와 2024년 F3 의 글쓴이들은 오래 머무는 시간을 재고 직원의 시선을 살핀다. [F2][F3]
