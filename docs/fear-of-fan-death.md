# 선풍기 틀고 자기 꺼리기

별칭: fan death[^2], 선풍기 사망설[^3]

사람이 닫힌 방에서 선풍기를 틀어 둔 채 자면 죽을 수 있다고 여겨 문을 열어 두거나 타이머를 맞추거나 잠든 가족의 선풍기를 끈다.

# 서술

2007년 6월 인천시 도매시장 관리사무소 안내문[^1]은 선풍기를 쓸 때 자는 동안 질식사고가 날 수 있으니 문이나 창문을 열어 두라고 적었다.

2008년 Global Voices 기사[^2]의 필자는 밀폐된 방에서 선풍기를 켜고 자면 죽을 수 있다는 속설이 한국에서 세대를 거쳐 전해진다고 썼다.

2024년 9월 YTN 대담[^3]에서 한 출연자는 여름에 선풍기를 켜고 자면 어머니가 들어와 끄기도 했고 자기도 타이머를 맞추고 잤다고 기억했다.
