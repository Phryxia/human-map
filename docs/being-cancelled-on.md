# 약속 취소당한 서운함

별칭: 없음

친구와 잡은 약속을 상대가 취소한 사람이 실망하거나 서운해하고 그 정도는 상대와 얼마나 가까운지에 따라 달라진다.

묶음: [가까운 사이의 감정과 말](../groups/close-relationships.md)

# 서술

2005년 3월 Berkeley Parents Network 게시글의 글쓴이는 친한 친구인 다른 엄마가 아이들 놀이 약속에 늦거나 약속을 취소하는 일이 되풀이되자 짜증스럽고 조금 상처받는다고 썼다. 두 아들은 낙담하고 글쓴이도 실망한다고 덧붙였다.[^1]

2023년 1월 Caron 외의 연구[^2]에서 1,192명 가운데 80% 넘게는 약속을 취소한 핑계가 거짓말이었음을 알았을 때 짜증이 났다고 답했다.

2023년 1월 미시간주립대 기사[^3]가 전한 같은 연구의 결과에서 약속을 취소당한 참가자들이 느낀 괴로움은 대체로 낮았다. 취소한 사람이 좋은 친구일 때는 달랐다.
