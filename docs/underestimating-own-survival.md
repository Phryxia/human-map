# 자기 수명 짧게 내다보기

별칭: 없음

은퇴를 앞두었거나 은퇴한 사람이 자기가 노년까지 살 가능성을 공식 추정보다 낮게 본다.

묶음: [판단과 어림의 치우침](../groups/judgment-biases.md)

# 서술

2013년 논문[^1]은 평균으로 볼 때 젊은 사람은 자기가 더 살아남을 가능성을 낮게 보고 나이 든 사람은 높게 본다고 적는다.

2018년 기사[^2]가 전한 영국 연구에서 곧 은퇴할 사람과 막 은퇴한 사람은 노년까지 살 가능성을 공식 추정보다 낮게 보았다.

2019년 연구[^3]는 생명표 확률 대신 응답자의 믿음으로 모형을 맞추면 젊은 층은 26% 덜 저축하고 은퇴자는 자산을 27% 더 느리게 쓴다고 계산했다.

2024년 영국 고용연금부 보고서[^4]는 노년층이 75세, 80세, 85세까지 살 가능성을 낮게 본다고 적는다.
