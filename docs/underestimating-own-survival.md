# 자기 수명 짧게 내다보기

별칭: 없음

은퇴를 앞두었거나 은퇴한 사람이 자기가 노년까지 살 가능성을 공식 추정보다 낮게 본다.

묶음: [판단과 어림의 치우침](../groups/judgment-biases.md)

# 서술

2018년 기사[^1]가 전한 영국 연구에서 곧 은퇴할 사람과 막 은퇴한 사람은 노년까지 살 가능성을 공식 추정보다 낮게 보았다.

2024년 영국 고용연금부 보고서[^2]는 노년층이 75세, 80세, 85세까지 살 가능성을 낮게 본다고 적는다.
