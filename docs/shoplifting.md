# 가게 물건 훔치기

별칭: shoplifting[^3]

손님이 가게에서 값을 치르지 않고 물건을 가지고 나간다.

묶음: [돈과 소비](../groups/money.md)

# 서술

1883년 소설[^1]에서 한 여자는 주머니에 돈이 가득한데도 훔치는 재미만으로 백화점 물건을 훔쳤다.

1896년 미국 신문 기사[^2]는 체포와 폭로가 잦은데도 훔칠 필요가 없는 계층의 사람들이 가게에서 계속 훔친다고 적었다.

1990년 청소년 연구[^3]에서 저자들은 결과가 전형적인 가게 도둑에 대한 통념과 어긋나므로 청소년이 훔치는 까닭을 다시 생각해 볼 일이라고 적었다.

2004년 논문[^4]은 저자들이 kleptomania 라 부르는 상태가 가게 절도의 5%를 차지한다는 추정을 옮겼다.

2008년 미국 전국 조사[^5]에서 평생 한 번 이상 가게 물건을 훔친 사람은 성인의 11.3%였다.

2023년 주간경향 기사[^6]가 전한 서울 집계에서 무인점포 범죄의 83.9%는 절도였다. 범인 연령대는 10대 청소년이 57.3%로 가장 많았다.[^6]

2025년 영국 통계청 발표[^7]에서 잉글랜드와 웨일스의 경찰이 기록한 가게 절도는 한 해 사이 13% 늘어 529,994건에 이르렀다.
