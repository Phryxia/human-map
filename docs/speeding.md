# 과속 운전

별칭: 과속, Speeding

운전자가 운전을 통제하고 있다고 믿거나 더 빨리 도착하려고 제한 속도보다 빠르게 달린다.

# 서술

2003년 이순철의 논문은 운전자들이 과속을 교통사고의 중요한 원인으로 인식하면서도 습관이 된 고속 운전을 쉽게 바꾸지 않는다는 태도 조사 결과를 전한다. 2007년 이순열 등의 초보운전자 경로분석에서 운전자신감은 과속운전을 거쳐 가해 교통사고로 이어졌다. [F1][F2]

2020년 퀸즐랜드 주정부 교통안전 페이지는 사람들 대부분이 과속을 한다고 인정하며 그 이유로 자신이 통제하고 있다고 여기거나 더 빨리 도착한다고 여기는 것을 든다. 2022년 FAAC 의 글이 전한 설문에서 운전자 대부분은 늦었거나 응급 상황이거나 서두르고 있어서 과속한다고 답했다. [F4][F6]

# 조건

2013년 NHTSA 의 2011년 전국 조사 요약에서 16~20세 운전자의 절반이 과속 운전자로 분류되었고 65세 이상에서는 15% 였다. [F3]

2021년 브런치 에세이의 글쓴이는 평소 막히던 길이 수월할 때 저절로 속도를 올리게 되고 그때 평소 알아채지 못하던 과속 단속 카메라를 발견한다고 적었다. [F5]
