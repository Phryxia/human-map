# 빈대 생긴 일 숨기기

별칭: 없음

집에 빈대가 생긴 사람이 창피하거나 불이익이 두려워 주변과 집주인에게 알리지 않고 숨긴다.

# 서술

뉴브런즈윅주 사회개발부의 안내문은 어느 집이든 빈대가 살 수 있으니 이 벌레가 들어와도 부끄러워할 필요가 없고 빨리 손쓰는 것이 중요하다고 적었다.[^1]

2007년 게시판 글의 글쓴이는 도움을 청하면서 이것이 금기이고 창피한 주제인 것 같다고 적었다.[^2] 2015년 Vice 기사의 필자는 창피해서 처음에는 친구 몇 명에게만 말했고 빈대가 그들에게 옮을까 봐 그런 생각을 하게 하고 싶지 않았다고 썼다.[^3]

2022년 Asshoff 외의 논문[^4]은 적어도 익명으로 인터넷 쇼핑을 하기 전에는 사람들이 빈대가 있다는 사실을 드러내는 낙인 때문에 빈대 퇴치 수단을 구하기를 두려워했다고 적었다. 2023년 Meisyara 외의 인도네시아 조사는 빈대가 있다고 알리는 일이 사회적 낙인에 막힐 수 있으며 겪는 사람이 가난하거나 사회적 지위가 낮거나 위생이 나쁜 환경에 산다는 것과 엮인다고 적었다.[^5] 2024년 Sheppard 외의 연구에서 한 저소득 노인은 집주인에게 말하기를 두려워했고 물건을 버리게 하거나 나가라고 할까 봐 걱정했다.[^6]
