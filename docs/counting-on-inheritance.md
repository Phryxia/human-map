# 물려받을 재산 기대하기

별칭: 유산 기대, 상속 기대, Inheritance expectations

사람이 부모나 친척에게서 물려받을 재산을 앞으로의 살림 계산에 넣고 기대한다.

# 서술

1871년 엘리엇의 소설[^1]에서 프레드는 지금의 빚을 갚을 앞날의 수단으로 노인 페더스톤의 땅을 물려받을 전망을 꽤 자신 있게 말한 적이 있었다.

2016년 기사[^2]가 전한 브리티시컬럼비아 신용조합 보고서에서 메트로 밴쿠버 자녀 가운데 39%가 넘는 사람이 30만 달러가 넘는 유산을 기대했고 그보다 많이 남기리라 예상한 부모는 12%였다.
