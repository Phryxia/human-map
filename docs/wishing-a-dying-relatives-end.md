# 앓는 가족의 끝을 속으로 바라기

별칭: 없음

오래 앓거나 죽어 가는 가족을 지키는 사람이 그 고통이나 삶이 어서 끝나기를 속으로 바란다.

묶음: [혼자 있음과 상실](../groups/solitude-and-loss.md)

# 서술

1923년 소설[^1]에서 위독하다는 전보를 받고 모인 자손들은 할머니가 정신을 잃었다 깨어나기를 되풀이하는 동안 얼굴이 축나 간다. 소설은 자손 모두가 말하지 않은 채 할머니의 목숨이 하루바삐 끝나기를 기다렸다고 적는다.

2026년 기사[^2]가 전한 조사에서 부모를 돌보는 사람 가운데 48%가 부모의 고통이 끝나기를 바란 적이 있다고 답했다.
