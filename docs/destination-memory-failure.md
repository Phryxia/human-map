# 누구에게 말했는지 잊기

별칭: 목적지 기억 실패, destination memory failure

이야기나 정보를 남에게 전한 사람이 그것을 누구에게 이미 말했는지 잊는다.

# 서술

2010년 연구[^1]의 저자들은 노인이 어떤 사실을 이미 말한 상대에게 말하지 않았다고 강하게 확신하고 그 때문에 같은 사람에게 정보를 더 자주 되풀이한다고 추측한다.

2016년 글[^2]의 글은 지금 말하는 상대가 그 농담이나 이야기를 이미 들었다는 것을 스스로 깨닫거나 상대에게서 듣는 경험을 묻는다.

2023년 연구[^3]의 저자는 목적지 기억이 실패하면 사람이 같은 상대에게 같은 정보를 되풀이한다고 적었다.

# 조건

2010년 연구[^1]는 젊은 성인과 비교한 노인에 대한 것이다. 2023년 연구[^3]의 저자는 이 되풀이가 기억상실 환자의 대화를 특히 막는다고 적었다.
