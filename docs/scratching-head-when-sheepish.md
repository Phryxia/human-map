# 멋쩍을 때 뒤통수 긁기

별칭: 없음

실수가 드러나거나 멋쩍은 자리에 선 사람이 손으로 뒤통수를 긁거나 문지른다.

묶음: [남의 시선과 창피함](../groups/others-gaze.md)

# 서술

1935년 소설[^1]의 응칠이는 부탁받은 일을 잊은 것이 드러나자 미안스러운 낯으로 뒤통수를 긁적인다.

2016년 일본 몸짓 안내[^2]는 일본에서 겸연쩍은 사람이 손바닥으로 뒤통수를 문지른다고 적는다.
