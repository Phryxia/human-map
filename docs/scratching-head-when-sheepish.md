# 멋쩍을 때 뒤통수 긁기

별칭: 없음

실수가 드러나거나 멋쩍은 자리에 선 사람이 손으로 뒤통수를 긁거나 문지른다.

묶음: [남의 시선과 창피함](../groups/others-gaze.md)

# 서술

1935년 소설[^1]의 응칠이는 부탁받은 일을 잊은 것이 드러나자 미안스러운 낯으로 뒤통수를 긁적인다.

1982년 잡지 기사[^2]의 필자가 본 일본 여성은 잘못된 몸짓을 한 것을 알아채자 당혹감을 드러내려고 머리를 긁으려는 듯 오른손을 머리카락에 댔다.

2002년 논문[^3]은 사람의 전위 행동 가운데 영장류의 털 고르기를 닮은 자기 지향 행동의 예로 머리 긁기와 턱수염 쓰다듬기를 든다.

2016년 일본 몸짓 안내[^4]는 일본에서 겸연쩍은 사람이 손바닥으로 뒤통수를 문지른다고 적는다.
