# 일 맡기지 못하기

별칭: 없음

관리자나 직장인이 남에게 맡길 수 있는 일을 맡기지 않고 직접 한다.

묶음: [일터와 일자리](../groups/work.md)

# 서술

2004년 경영 블로그 글[^1]은 사람들 대부분이 부모에게 배운 대로 일을 제대로 하려면 직접 해야 한다고 믿는다고 적었다.

2016년 Mohammadi 등의 이란 가스회사 조사[^2]에서 관리자의 불안감과 위임하지 않으려는 마음은 위임을 막는 주된 장애가 아니었다. 같은 해 아이리시 타임스 기고[^3]는 관리자들이 결과가 나쁘면 책임과 비난을 여전히 자기가 지리라 믿어 부하에게 맡기기를 피했다고 전했다.

2021년 팀장을 위한 책의 소개[^4]는 업무를 지시하는 것보다 자기가 하는 게 빠르다는 말을 팀장의 고민으로 든다.
