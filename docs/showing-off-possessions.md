# 가진 것 과시하기

별칭: 과시, 과시적 소비, 자랑, 플렉스, Conspicuous consumption

남의 눈을 의식하는 사람이 자기가 가진 물건, 돈, 지위를 다른 사람이 보도록 일부러 드러낸다.

# 서술

1848년 Thackeray 의 소설에서 갑자기 부자 할아버지에게 간 아이는 예전 동네 작은 학교의 아이들을 찾아가 새로 얻은 부와 화려함을 내보인다. 1921년 현진건의 소설에서 은행원 T는 가난한 친척 집에서 새 양산을 펴 보이며 이보다 좋은 것은 살 수 없다는 뜻을 드러내려 애쓴다.[^1][^3]

1899년 Veblen 은 사람의 존중을 얻고 지키려면 부나 힘을 가진 것만으로는 모자라고 그것을 드러내 보여야 한다고 적는다. 존중은 드러난 증거에만 주어지기 때문이라고 그는 적는다.[^2]

2007년 Charles 외는 가계가 기준 집단에 견준 자기 경제적 위치를 보이려고 과시적 소비를 한다는 지위 추구 모형을 내세운다. 2018년 글[^5]의 기사에서 한 인터뷰 대상자는 비싼 옷을 찍어 SNS에 올리면 사람들이 부러워하고 현실에서 얻지 못하는 자존감이 생긴다고 말한다.[^4]

2018년 글[^5]의 인터뷰 대상자는 자기의 현실을 모르는 SNS 안에서 비싼 옷을 드러낸다.
