# 날짜 지난 음식 냄새로 가늠해 먹기

별칭: sniff test[^1]

포장의 날짜가 지난 음식을 앞에 둔 사람이 날짜 대신 냄새, 겉모습, 맛으로 먹어도 되는지 가늠하고 먹는다.

묶음: [건강과 위험](../groups/health-and-safety.md)

# 서술

2005년 게시글[^1]의 글쓴이는 판매 기한 다음 날부터 우유를 냄새로 가늠한다고 썼다.

2016년 덴마크 연구 보도[^2]에서는 나이 든 참가자와 자기 감각을 믿는 참가자가 기한이 지나 버려야 할 음식을 맛볼 때가 더 많았다.

2026년 영국 식품기준청 보고서[^3]의 참가자들은 음식이 먹어도 안전한지 정할 때 냄새, 모양, 질감, 맛을 썼다.
