# 아주 좋거나 아주 나쁠 때 후기 쓰기

별칭: 없음

물건이나 가게를 이용한 사람이 아주 만족했거나 아주 불만스러울 때 온라인 후기를 쓴다.

묶음: [돈과 소비](../groups/money.md)

# 서술

2017년 연구[^1]에서 물건에 극단적인 평점을 매긴 소비자는 좋은 쪽이든 나쁜 쪽이든 중간 평점을 매긴 소비자보다 후기를 더 많이 썼다.

2024년 기사[^2]가 전한 조사에서 손님은 기대가 어긋났을 때, 물건이나 서비스의 질이 낮을 때, 문제가 풀리지 않았을 때 의견을 더 많이 남겼다.
