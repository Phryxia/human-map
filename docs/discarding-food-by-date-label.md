# 날짜 표시만 보고 음식 버리기

별칭: 없음

집에서 음식을 다루는 사람이 포장의 날짜 표시가 지났거나 가까워졌다는 이유로 아직 먹을 수 있는 음식을 버린다.

# 서술

2010년 연구[^1]가 정리한 영국 소비자 조사 표는 음식 폐기로 이어지는 행동 가운데 하나로 'best before' 날짜와 'use by' 날짜를 헷갈리는 것을 들고 음식이 불필요하게 버려질 수 있다고 적는다.

2011년 자료[^2]의 영국 환경식품농촌부 보도자료는 가정에서 버려지는 먹을 수 있는 음식의 원인 가운데 하나로 날짜 표시 혼동을 든다.

2012년 2월 서울시 기사[^3]는 끼워 주기 상품을 다 먹지 못하고 유통기한을 넘겨 버리는 경우가 많다고 전했다.

2012년 3월 기사[^4]는 유통기한을 섭취 가능 기간이나 변질 기한으로 해석하는 사람이 많아 실제 상태와 상관없이 음식을 버리는 경향이 커진다고 적는다.

2019년 연구[^5]의 미국 소비자 조사에서 18\~34세 응답자와 날짜 표시를 잘못 이해한 응답자는 다른 응답자보다 날짜를 보고 음식을 더 자주 버렸다고 답했다.

2024년 자료[^6]의 미국 식품의약국 안내는 소비자 음식 폐기의 약 20%를 날짜 표시 혼동에서 온 것으로 추정한다.
