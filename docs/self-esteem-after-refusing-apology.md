# 사과 거부 뒤의 자존감 상승

별칭: 없음

사과하기를 거부한 사람이 그 뒤 자기 가치감과 힘, 통제감을 더 느낀다.

묶음: [가까운 사이의 감정과 말](../groups/close-relationships.md)

# 서술

2013년 Okimoto 외의 논문[^1]에서 사과를 거부한 참가자는 거부하지 않은 참가자보다 자존감이 더 높았다. 같은 해 NPR 기사[^2]는 사과하지 않는 것이 힘과 통제감과 자기 가치감을 높인다고 전했다.

2026년 Conrad 외의 논문[^3]은 사과하라는 요구를 분명히 받은 가해자가 힘의 느낌을 덜 느끼고 피해자에게 더 화를 내며 피해자를 더 피한다고 제안한다.
