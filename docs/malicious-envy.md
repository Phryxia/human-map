# 악의적 시기

별칭: 악성 시기, malicious envy

앞선 사람을 시기한 사람이 그 사람을 그 자리에서 끌어내리고 싶어 한다.

# 서술

1846년 발자크의 소설에서 리스베트는 윌로 집안 사람들의 오만한 태도를 꺾어 버리고 싶은 마음에 사로잡혔다. [F1]

2011년 F2 의 저자들은 자기 처지를 높이려는 양성 시기와 앞선 사람을 끌어내리려는 악의적 시기를 나눈다. 2016년 F3 의 저자는 이를 시기 대상을 우월한 자리에서 끌어내리려는 행위 경향을 가진 하위 유형으로 정의한다. [F2][F3]

2018년 브런치의 한 글은 열등감에서 나온 시기심을 가진 사람이 상대를 적으로 삼고 뒷담화와 공격을 시작한다고 적는다. 2021년 F5 의 기사는 악의적인 시기심을 가진 사람에게 질투의 대상이 불운을 겪으면 긍정적 감정이 생긴다는 연구팀의 말을 옮긴다. [F4][F5]

# 조건

2018년 F4 의 글쓴이는 그런 공격이 자존감이 낮아 열등감을 인정하지도 긍정적으로 쓰지도 못하는 사람에게서 나온다고 적는다. [F4]
