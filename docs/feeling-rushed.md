# 시간에 쫓기는 느낌

별칭: 시간 압박감, 시간 기근, time pressure, time famine

일과 집안일을 하는 사람이 할 일에 비해 시간이 모자란다고 느끼며 늘 쫓긴다.

# 서술

2017년 게시글[^1]의 글쓴이는 집안일을 할 때마다 쫓기는 기분이 든다고 적었다. 집안일이 얼마 안 되는 자유 시간을 크게 낭비하는 일로 느껴지기 때문이다.

2022년 FAAC 의 글이 전한 설문에서 운전자 대부분은 늦었거나 응급 상황이거나 서두르고 있어서 과속한다고 답했다.[^2]

2025년 게시글[^3]의 글쓴이는 회사에서 늘 쫓기는 기분이고 원하는 만큼 배울 시간이 없다고 적었다.

# 조건

2025년 자료[^4]의 캐나다 통계에서 높은 시간 압박을 느낀 사람은 1992년 약 7명 중 1명(15.0%)이었고 2022년 거의 4명 중 1명(24.2%)이었다.
