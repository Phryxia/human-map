# 이명

별칭: Tinnitus[^2]

바깥에 소리가 없는데도 사람이 귀나 머릿속에서 울리거나 윙윙거리는 소리를 듣는다.

묶음: [건강과 위험](../groups/health-and-safety.md)

# 서술

2010년 게시글[^1]의 글쓴이는 공연을 많이 하면서 귀를 보호할 생각을 해 본 적이 없었는데 어느 밤 집에 들어와서 옆집 도난 경보가 울린다고 믿었다고 썼다.

2018년 기사[^2]가 전한 영국 자선단체 조사에서 18\~24세의 53.4%가 이명을 겪은 적이 있었다. 같은 조사에서 40%는 큰 소음에 노출되면 이명이 영구히 남을 수 있다는 것을 몰랐다.[^2]

2022년 기사[^3]는 사격 훈련에서 귀마개를 쓰지 않으면 이명이 생긴다고 적는다.

2023년 미국 국립 난청·의사소통장애 연구소 자료[^4]는 이명을 흔히 울리는 소리로 묘사하지만 어떤 사람은 으르렁거리거나 윙윙거리는 소리를 듣는다고 적는다.
