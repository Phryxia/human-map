# 이명

별칭: Tinnitus[^1]

바깥에 소리가 없는데도 사람이 귀나 머릿속에서 울리거나 윙윙거리는 소리를 듣는다.

묶음: [건강과 위험](../groups/health-and-safety.md)

# 서술

2018년 기사[^1]가 전한 영국 자선단체 조사에서 18\~24세의 53.4%가 이명을 겪은 적이 있었다. 같은 조사에서 40%는 큰 소음에 노출되면 이명이 영구히 남을 수 있다는 것을 몰랐다.[^1]

2023년 미국 국립 난청·의사소통장애 연구소 자료[^2]는 이명을 흔히 울리는 소리로 묘사하지만 어떤 사람은 으르렁거리거나 윙윙거리는 소리를 듣는다고 적는다.
