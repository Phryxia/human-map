# 머리가 하얘짐

별칭: mind goes blank[^1]

남이 지켜보거나 몰아세우는 자리에서 사람의 머리가 굳어 할 말이나 생각이 떠오르지 않는다.

묶음: [남의 시선과 창피함](../groups/others-gaze.md)

# 서술

2020년 7월 게시글[^1]의 글쓴이는 누가 뒤에 서서 어깨너머로 지켜보면 머리가 하얘진다고 적었다.

2020년 8월 칼럼[^2]은 저녁 모임이나 회의에서 모욕이나 반박을 들은 뒤 머리가 굳어 말을 잃는 일을 적었다.
