# 머리가 하얘짐

별칭: mind goes blank[^4]

남이 지켜보거나 몰아세우는 자리에서 사람의 머리가 굳어 할 말이나 생각이 떠오르지 않는다.

묶음: [남의 시선과 창피함](../groups/others-gaze.md)

# 서술

발행일을 알 수 없는 글[^1]의 필자는 이런 일을 겪는 사람이 가족이나 가까운 친구와는 대화를 곧잘 하면서도 위축되는 자리에서는 머리가 하얘진다고 적었다.

1830년 디드로의 글[^2]에서 필자는 반박을 받으면 거기에 온통 매달려 정신을 잃고 말문이 막히며 계단 아래에 가서야 제정신을 찾는다고 썼다.

1915년 대중 연설 교본[^3]은 연설하는 사람이 애를 썼는데도 요점을 잊고 머리가 잠시 비는 경우를 다뤘다.

2020년 7월 게시글[^4]의 글쓴이는 누가 뒤에 서서 어깨너머로 지켜보면 머리가 하얘진다고 적었다.

2020년 8월 칼럼[^5]은 저녁 모임이나 회의에서 모욕이나 반박을 들은 뒤 머리가 굳어 말을 잃는 일을 적었다.

2025년 의대생 면담 연구[^6]에서 한 참가자는 구술시험 중에 자기 이름과 자주 쓰던 장비를 다루는 법까지 잊고 머리가 하얘진다고 말했다.
