# 정상 집착

별칭: Summit fever, 정상 욕심, Get-there-itis

산을 오르는 사람이 날씨가 나빠지거나 시간이 늦어져도 정상에 가겠다는 마음에 돌아서지 않고 계속 오른다.

# 서술

2008년 K2 사고 기사[^1]는 일부 등반가가 오후 8시가 넘은 어둠 속에서 정상에 닿았다고 전한다. 2014년 우메오 대학 소식[^3]은 같은 사고로 11명이 숨진 일을 두고 참가자들이 목표에 사로잡혀 분명한 위험에도 계속 오르기로 했다고 적는다.

2021년 산행기[^4]의 글쓴이는 구름을 지켜보기로 했지만 정상까지 수백 피트가 남아 계속 올랐다고 적는다. 2026년 기사[^7]에서 구조대원들은 정상 집착에 빠진 사람들이 정상에 올랐다가 안전하게 내려오는 시간을 적게 잡는다고 말했다.

# 조건

2021년 기사[^5]에서 데날리의 레인저들은 여행 일정이 바닥나 갈 때 정상 집착이 생기고 등반대가 더 큰 위험을 감수한다고 말했다.

2008년 에베레스트 사망 연구[^2]에서 살아남은 사람의 정상 도달 시각 중앙값은 오전 9시대, 숨진 사람은 오후 1시대였다.

2024년 로키산 국립공원 안내[^6]는 날씨가 나빠질 때, 몸이 좋지 않을 때, 일행이 돌아서려 할 때를 돌아설 때로 든다.
