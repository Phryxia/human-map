# 안 쓰는 휴대폰 집에 두기

별칭: hibernation[^2]

새 휴대전화로 바꾼 사람이 더는 쓰지 않는 옛 휴대전화를 팔거나 내놓지 않고 서랍 같은 집 안의 자리에 넣어 둔다.

# 서술

2015년 서울시 글[^1]은 폐휴대폰을 두고 개인정보 유출이 우려되고 범죄에 다시 쓰일 수 있다고 적었다. 2021년 연구[^2]의 네덜란드 조사에서 휴대전화 대부분은 3년 안에 교체됐고 옛 폰을 예비용으로 쓰려는 것이 집에 넣어 두는 주된 이유였다.

2022년 국제기구 글[^3]은 쓰지 않게 될 휴대전화 다수가 서랍, 벽장, 찬장, 차고로 들어가거나 쓰레기통에 버려질 것이라는 전문가의 예상을 전했다. 2024년 글[^4]이 전하는 소셜 미디어 투표에서 폰을 재활용한 적이 없는 참여자의 62%는 폰을 남겨 두었다고 답했다.

2026년 기사[^5]가 전하는 미국 연구에서 기기를 재활용하거나 되팔면 데이터가 새어 나갈까 걱정한 사람은 기기를 보관할 가능성이 각각 14%, 9% 높았다. 2026년 정부 자료[^6]는 폐휴대폰을 정보 유출 걱정과 배출의 번거로움 때문에 집에 오래 보관하는 사례가 많다고 적었다.
