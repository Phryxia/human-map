# 위기 때 생필품 사재기

별칭: 패닉 바잉, 비축 구매, panic buying, stockpiling

재난이나 감염병 소식을 들은 사람이 평소보다 많은 생필품을 한꺼번에 사 둔다.

# 서술

2011년 3월 F1 에서 중국 소매점들은 소금 사재기를 보고했다. 일본 원전의 방사능 피해를 막는 데 소금이 도움이 된다고 믿는 손님이 있었다. 상하이의 한 마트에서는 문을 연 지 30분 만에 소금이 다 팔렸다. [F1]

2020년 3월 호주에서는 화장지와 휴지, 쌀과 파스타의 월간 매출이 두 배가 됐다. [F2]

# 조건

2020년 F3 의 22개국 온라인 설문(N=996)에서 코로나19 위협을 더 크게 느낀 사람이 화장지를 더 많이 쌓아 두었다. [F3]
