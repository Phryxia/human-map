# 보내지 않는 편지 쓰기

별칭: 부치지 않는 편지, unsent letter, 보내지 않은 메시지

누군가에게 하고 싶은 말을 편지나 메시지로 써 놓고 보내지 않는다.

# 서술

1853년 브론테의 소설에서 화자는 받은 편지마다 답장을 두 통 쓴다. 한 통은 자기 마음을 달래려고 쓰고 다른 한 통을 상대에게 보낸다. [F1]

1878년 톨스토이의 소설에서 레빈은 쪽지를 열 장 쓰고 모두 찢은 뒤 답장 없이 안장만 보냈다. 1934년 심훈의 소설에서 봉희는 답장이 써지지 않자 짜증을 내며 종이를 찢었다. [F2][F3]

1987년 크리스천 사이언스 모니터의 글쓴이는 보내지 않는 편이 나은 편지가 있다고 적는다. 2017년 리터러리 허브의 글쓴이는 보내지 않을 편지였기에 거르지 않고 썼다고 적는다. [F4][F5]

2018년 해커 뉴스의 한 댓글은 보내지 않은 편지를 많이 썼고 상대에게 생각을 그대로 쓰는 것만으로 후련할 때가 있다고 말한다. [F6]

# 조건

1853년 F1, 1878년 F2, 1934년 F3 는 손으로 쓴 편지와 쪽지다. 2026년 F7 은 온라인에서 쓴 생각을 보내지 않는 경우를 다루고 분노, 죄책감, 그리움의 순간을 든다. [F1][F2][F3][F7]
