# 연인의 지난 연애 질투하기

별칭: Retroactive jealousy[^2]

연인을 둔 사람이 연인이 자기를 만나기 전에 맺은 관계를 떠올리며 괴로워한다.

묶음: [가까운 사이의 감정과 말](../groups/close-relationships.md)

# 서술

1878년 Tolstoy 의 소설[^1]에서 결혼을 앞둔 여자는 약혼자가 건넨 일기에서 지난날의 고백을 읽고 몹시 울었다.

2018년 Refinery29 기사[^2]에서 한 여성은 남자 친구의 전 연인이 자기보다 먼저 같은 자리에서 같은 관계와 감정을 겪었다는 생각이 몹시 거슬린다고 말했다.

2025년 논문[^3]은 마닐라 수도권에 사는 연애 중인 여성들의 이야기를 모았다. 논문은 이 질투가 낮은 자존감을 키워 비교와 지나친 생각을 불렀다고 적었다.
