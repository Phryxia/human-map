# 녹음된 자기 목소리 싫어하기

별칭: 녹음 목소리 거부감, 자기 목소리 낯섦

녹음된 자기 목소리를 듣는 사람이 그 소리를 낯설고 불편하게 느끼거나 싫어한다.

# 서술

2015년 F1 의 글쓴이는 녹음을 다시 들을 때 자기 목소리가 정말 싫다고 적었다. [F1]

2018년 F2 의 저자들은 녹음된 자기 목소리를 들을 때의 불편함이 불쾌한 골짜기의 바닥에 해당할 수 있다고 추측한다. [F2]

# 조건

기록된 조건 없음. [F1][F2]

# 파편
