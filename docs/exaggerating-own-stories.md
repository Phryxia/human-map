# 허풍 떨기

별칭: 없음

자기가 겪은 일을 남에게 이야기하는 사람이 이야기를 재미있게 하거나 자기 경험을 내세우려고 실제보다 부풀려 말한다.

# 서술

1598년 희곡[^1]에서 왕자는 폴스타프가 자기와 싸운 상대의 수를 말할 때마다 늘려 처음 둘이던 것이 열하나가 되었다고 꼬집었다.

2004년 연구[^2]에서 참가자들은 듣는 사람에 따라 같은 일을 다르게 이야기했다. 즐겁게 하려고 할 때는 부풀렸고 알리려고 할 때는 단순하게 말했다.

2005년 신문 칼럼[^3]의 필자는 술자리에서 오가는 군대 이야기 대부분에 과장이 보태지며 재미가 더해지고 더러는 없던 일이 실제처럼 각색되어 전해진다고 적었다.

2020년 12월 낚시 정보 사이트의 설문[^4]에서 낚시하는 응답자의 53%는 친구와 가족에게 잡은 고기의 크기를 부풀려 말한다고 답했다. 같은 달 인터넷 매체 기사[^5]는 예비군끼리 모인 술자리에서 자기 부대를 최고로 여기는 사람이 과장된 무용담을 늘어놓는다고 썼다.
