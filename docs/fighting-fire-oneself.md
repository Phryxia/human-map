# 불이 나면 직접 끄려 하기

별칭: 없음

집이나 일터에서 불이 난 것을 본 사람이 신고나 대피보다 먼저 스스로 불을 끄려 한다.

묶음: [건강과 위험](../groups/health-and-safety.md)

# 서술

2008년 박사논문[^1]의 저자는 소방대가 출동하지 않은 주택 화재에서 거주자가 불붙은 물건을 싱크대나 바닥으로 옮기는 위험한 방법으로 불을 끈 사례가 많은 것을 우려했다.

2014년 화재 생존자 연구[^2]에서 불을 마주한 사람 대부분은 소방대에 신고하거나 불을 끄려 하거나 다른 사람에게 알리는 행동을 했다.

2020년 기사[^3]가 전한 뉴질랜드 연구에서 집에 불이 나면 111 에 신고하기 전에 스스로 끄려 하고 가족에게 먼저 전화하는 사람들이 있었다.

2021년 영국 머지사이드 연구[^4]에서 사고 화재를 직접 끄다 다친 거주자는 연구 기간 화재 부상자의 19.5%였다. 2021년 미국 보고서[^5]에서 주거 건물 화재 부상의 33%는 불을 잡으려다 생겼다. 2021년 인천의 소방서 보도자료[^6]는 소화기로 초기 진화를 하려다 사람이 다치는 일이 이어지자 대피가 먼저라는 홍보를 시작했다고 밝혔다.

2023년 영국 링컨셔 지방정부 소식[^7]은 화재 부상 가운데 일부가 건물을 바로 빠져나가지 않고 불을 잡으려던 데서 생겼다고 썼다.
