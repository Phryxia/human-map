# 울리지 않은 휴대전화 진동 느끼기

별칭: 없음

휴대전화를 가지고 다니는 사람이 전화가 울리지 않았는데도 진동이 왔다고 느낀다.

# 서술

2022년 게시글[^3]의 글쓴이는 아주 작은 진동에도 전화가 왔다고 생각했다. 글쓴이는 휴대전화를 무음으로 바꿔 이에 대처했다.

2013년 연구[^1]의 의학 인턴 74명 연구에서 울리지 않은 진동을 느낀 사람은 인턴 시작 때 78.1%였고 인턴 3개월째 95.9%, 6개월째 93.2%로 늘었다.

2019년 연구[^2]의 이탈리아 10\~14세 학생 조사에서는 나이가 많을수록, 여학생일수록, 스마트폰을 쓰는 시간이 길고 더 자주 확인할수록 울리지 않은 진동이나 벨소리를 느끼는 것과 관련이 있었다.
