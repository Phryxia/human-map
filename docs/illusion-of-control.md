# 통제 착각

별칭: illusion of control[^1], 통제의 환상[^4]

결과가 운에 달린 일을 앞둔 사람이 자기가 고르거나 손을 쓰면 결과를 좌우할 수 있다고 느낀다.

# 서술

2021년 Klusowski 등의 연구[^1]는 17개 실험 참가자 10,825명의 결과를 보고하며 고를 수 있다는 것만으로는 대체로 통제 착각이 생기지 않는다고 결론지었다.

2023년 6월 Polak 등의 복권 실험[^2]에서 참가자들은 부정적 특성만 가진 사람에게 복권 번호 고르기를 맡기는 것을 꾸준히 피했다.

2023년 10월 Yale Insights 기사[^3]는 1975년 연구에서 복권 번호를 직접 고른 사람이 번호를 무작위로 받은 사람보다 모든 복권의 당첨 확률이 같은데도 자기 복권이 당첨될 것이라고 더 여겼다고 전했다.

2023년 12월 데일리안 기사[^4]는 운과 우연까지 자기 힘으로 통제할 수 있다고 생각하는 경향을 통제의 환상이라 부르며 매주 로또를 사는 사람들의 심리를 다뤘다.
