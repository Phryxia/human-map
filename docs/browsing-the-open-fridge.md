# 냉장고 문 열어 두고 먹을 것 고르기

별칭: 없음

집에서 먹을 것을 찾는 사람이 냉장고 문을 열어 둔 채 안을 들여다보며 무엇을 먹을지 고르고 때로는 아무것도 꺼내지 않고 문을 닫는다.

묶음: [시간과 하루 습관](../groups/daily-time.md)

# 서술

2023년 1월 가전 회사 설문을 전한 기사[^1]에서 응답자의 29%가 무엇을 먹을지 정하는 동안 냉장고 문을 열어 둔다고 답했다.

2023년 3월 Hacker News 댓글[^2]의 글쓴이는 자기 행동을 기록하면 냉장고 문을 열고 1분쯤 들여다본 뒤 아무것도 꺼내지 않고 닫는 일이 50번쯤 나올 것이라고 썼다.
