# 헤어진 연인의 SNS 들여다보기

별칭: interpersonal electronic surveillance[^3], Facebook stalking[^3]

연인과 헤어진 사람이 헤어진 상대의 SNS 에 찾아 들어가 근황을 살펴본다.

묶음: [가까운 사이의 감정과 말](../groups/close-relationships.md)

# 서술

2006년 신문 기사[^1]는 옛 애인을 직접 만나거나 남에게 털어놓을 용기가 없는 사람들이 미니홈피로 보고 싶은 마음을 달랜다고 적었다.

2012년 Marshall 의 연구[^2]는 페이스북으로 전 연인을 접하는 일이 지난 관계에서 회복하고 벗어나는 과정을 가로막을 수 있다고 적었다.

2015년 기사[^3]는 심리학자들이 이 행동을 대인 전자 감시라 부르고 흔히는 페이스북 스토킹이라 부른다고 적었다.

2020년 기사[^4]는 헤어진 사람이 전 연인의 카카오톡 프로필을 번번이 살피고 하루에도 수십 번 그의 SNS 에 들어가는 모습을 그렸다.

2026년 Marshall 의 연구[^5]에서 페이스북으로 전 연인을 적극적으로 살핀 일은 이별 뒤 석 달 안과 여섯 달 뒤의 이별 괴로움을 예측했다. 그 관계는 애착 불안이 높은 사람에게서 더 뚜렷했다.
