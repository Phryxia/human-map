# 기준점 의존

별칭: 없음

결과를 받은 사람이 그 결과의 절대 크기보다 동료의 몫이나 자기 기대 같은 기준과 비교해 만족하거나 불만을 느낀다.

# 서술

2010년 Card 등은 같은 부서와 직종의 중위 연봉보다 적게 받는 노동자가 급여 만족과 직무 만족을 더 낮게 보고하고 중위보다 많이 받는 노동자는 만족을 더 높게 보고하지 않는다고 적었다.[^1]

2023년 글[^2]의 칼럼은 은메달 선수보다 동메달 선수의 표정이 더 밝고 평온하다고 적었다.

2026년 글[^3]의 필자는 연봉이 올라도 기대치가 더 크면 불만이 남는다고 적었다.

2010년 연구[^1]에서 기준은 같은 부서와 직종 동료의 중위 연봉이다. 2026년 글[^3]에서 기준은 연봉 협상 전에 기대한 숫자다.
