# 정치 무력감

별칭: 외부 정치 효능감 저하, 정치적 무력감, External political inefficacy

유권자가 정부와 정치인이 자기 같은 사람의 생각에 관심이 없고 자기 표가 결정을 바꾸지 못한다고 믿는다.

# 서술

1982년 F1 의 저자들은 미국에서 정당 일체감이 약해지고 정부가 응답한다는 믿음이 줄어든 것을 두 태도 추세로 들었고 뒤의 것을 낮아진 외부 정치 효능감이라 불렀다. [F1]

2020년 12월 NPR 기사가 전한 조사에서 비투표자의 3분의 2는 투표가 실제 결정이 내려지는 방식과 별 관계가 없다는 데 동의했고 투표한 사람보다 그렇게 답할 가능성이 21%포인트 높았다. [F2]

2024년 4월 퓨 리서치 센터의 글은 2023년 7월 조사에서 미국인 85% 가 대부분의 선출직 공직자는 자기 같은 사람의 생각에 관심이 없다고 답했다고 적었다. [F3]

# 조건

2020년 F2 에서 이 믿음은 투표한 사람보다 비투표자에게서 더 많이 나왔다. [F2]
