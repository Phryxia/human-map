# 장례에서 울음 누르기

별칭: 없음

가까운 사람을 잃은 사람이 장례 자리에서 울음이 나오려는 것을 억누르고 울지 않으려 한다.

묶음: [가까운 사이의 감정과 말](../groups/close-relationships.md)

# 서술

401년 무렵 아우구스티누스의 『고백록』[^1]에서 화자는 어머니의 장례를 눈물 섞인 애도와 신음으로 치르는 것이 알맞지 않다고 여겼다고 적었다.

2020년 2월 경기일보 칼럼[^2]의 필자는 어머니 장례 때 친척들과 마을 어른들이 좋은 곳에 가셨으니 울지 말라고 위로해 장례 동안 제대로 울지 못했다고 적었다.
