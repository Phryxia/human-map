# 집이 어수선하다고 손님에게 사과하기

별칭: 없음

손님을 자기 공간에 들이는 사람이 그곳이 어수선하다고 먼저 사과한다.

묶음: [선물, 대접과 예의](../groups/gifts-and-hospitality.md)

# 서술

1857년 소설[^1]의 인물은 찾아온 손님을 남편의 화실로 들이면서 화가의 작업실이 어수선하고 불편한 것을 양해해 달라고 말했다.

2017년 칼럼[^2]의 필자는 누가 집에 올 때 집에 사람 사는 티가 나 있으면 사과하는 버릇이 있다고 적었다. 필자는 아이 다섯과 개가 있어 집이 늘 그렇다고 썼다.[^2]

2026년 7월 잡지 기사[^3]에서 임상심리학자는 손님을 집에 들이는 일이 자기를 평가해 달라고 청하는 일과 같고 평가받을 두려움 때문에 사람들이 사과할 만큼 불편해한다고 말했다.
