# 남의 메뉴 부러워하기

별칭: food envy[^3]

식당에서 음식을 받은 사람이 일행이나 옆자리 사람이 시킨 메뉴가 더 좋아 보여 자기 주문을 후회한다.

# 서술

AcaWiki 의 연구 요약[^1]에 따르면 일행과 함께 주문한 집단(Collective)의 참가자는 따로 주문한 집단의 참가자보다 자기 선택을 더 후회했다.

2000년 논문[^2]의 초록은 여럿이 차례로 주문하는 자리에서 집단이 있기 때문에 생기는 목표가 때로 개인의 만족을 깎고 후회를 늘리는 선택으로 이어진다고 적는다.

2025년 Daily News 기사[^3]의 필자는 친구의 접시를 부러운 눈으로 보며 주문을 후회하는 일을 food envy 라 부른다.

2026년 브런치 연재 콩트[^4]의 화자는 가장 맛있는 메뉴는 언제나 내가 시키지 않은 메뉴라서 내가 고른 메뉴는 늘 2등이라고 말한다.
