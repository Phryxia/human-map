# 읽지 않은 메일 쌓아 두기

별칭: 없음

메일을 받는 사람이 읽지 않은 메일을 열지도 지우지도 않고 받은편지함에 수백, 수천 통씩 쌓아 둔다.

묶음: [메시지와 휴대전화](../groups/messages-and-phones.md)

# 서술

2015년 6월 YouGov 글[^1]에 따르면 미국 성인이 받은편지함에 둔 읽지 않은 메일은 평균 500통이었고 중앙값은 5통이었다.

2025년 9월 Woot 포럼 댓글[^2]의 글쓴이는 읽지 않은 메일이 4만 5000통이라고 썼다.
