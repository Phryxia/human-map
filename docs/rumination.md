# 반추

별칭: Rumination[^1]

사람이 지난 일이나 자기 문제와 실수를 결론 없이 되풀이해 곱씹는다.

# 서술

2012년 2월 Psychology Today 글[^1]에서 Edward Watkins 는 반추에 아무 데도 이르지 못한 채 문제를 거듭 곱씹는 일, 왜 우울한지에 매달리는 일, 자기 실패와 실수를 되풀이해 돌아보는 일이 든다고 적었다.

2021년 8월 VCU 보도자료[^2]가 전한 연구에서 지난 도발을 곱씹으라는 지시를 받은 참가자들은 당장의 작은 복수보다 늦더라도 큰 복수를 고르기 시작했다. 2025년 Hacker News 댓글[^3]의 글쓴이는 20대의 상당 부분을 덜 어리석게 보냈다면 지금 어디에 있을지를 꽤 자주 곱씹는다고 썼다.
