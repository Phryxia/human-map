# 가구 배치 바꾸기

별칭: Rearranging furniture[^3]

기분이 가라앉거나 답답한 사람이 쓰던 방의 가구 자리를 옮긴다.

묶음: [걱정과 기분](../groups/worry-and-mood.md)

# 서술

1926년 Montgomery 의 소설[^1]에서 Valancy 는 가족이 권하는 약을 거절하고 집안에서 부르던 이름을 거부하던 무렵 자기 방의 침대를 맞은편 구석으로 옮겼다.

2014년 Psychology Today 칼럼[^2]의 저자는 전날 밤 워크숍에서 여성 여러 명이 기분이 좋지 않을 때 가구를 옮긴다고 말했다고 적었다. 2019년 HuffPost 기사[^3]의 필자는 육아휴직 중 고립감과 지루함을 느끼던 때 의자 하나를 옮기는 작은 일로 기분이 나아졌다고 썼다.

2023년 한국의 주거 공간 연구[^4]에서 사회적 거리두기로 겪는 어려움이 클수록 개인 활동을 위해 가구를 다시 배치하는 행동이 늘었다(β = 0.198).
