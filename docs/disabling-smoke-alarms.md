# 화재감지기 꺼 두기

별칭: 없음

요리 연기 따위로 화재감지기가 자주 울리는 집의 사람이 배터리를 빼거나 감지기를 떼어 감지기를 꺼 둔다.

# 서술

2000년 연구[^1]는 잦은 오경보 때문에 감지기가 자주 분리된다고 적었다. 2008년 기사[^2]가 전하는 캐나다 조사에서 감지기의 배터리를 빼거나 연결을 끊은 사람의 51%는 배터리를 다시 넣거나 감지기를 다시 연결하는 일을 잊은 적이 있었다.

2011년 기관 글[^3]은 작동하지 않는 감지기의 두 가지 주된 이유로 배터리가 없거나 다 된 것과 일부러 전원을 끊은 것을 든다. 2013년 댓글[^4]의 글쓴이는 감지기를 떼어 탁자에 두고 요리할 때마다 배터리를 뺐다가 나중에 다시 끼웠다.

2014년 기사[^5]의 아파트 화재에서 거주자들은 스토브를 쓸 때마다 울리던 감지기의 배터리를 빼 두었다. 2022년 연구[^6]에서 감지기를 떼어 낸 가장 흔한 이유는 오경보와 조리 중 울림이었다. 2024년 기관 글[^7]의 연구자는 오경보를 되풀이해 겪은 사람들이 기기를 꺼 버리는 경향을 여러 연구가 확인했다고 말한다.
