# 금지된 것에 대한 호기심

별칭: 판도라 효과, Pandora effect

하지 말라는 것이나 알면 손해가 날 수 있는 것 앞에서 사람이 궁금함을 이기지 못하고 끝내 열어 보거나 알아본다.

# 서술

1889년 동화집[^1]에 실린 이야기에서 열지 말라는 방 앞에 선 아내는 남편의 명령과 어기면 닥칠 불행을 한동안 생각했지만 유혹을 이기지 못했다. 2016년 실험[^2]에서 호기심은 참가자가 뚜렷한 이득 없이 불쾌한 자극, 전기 충격에까지 스스로를 내맡기게 했다.
