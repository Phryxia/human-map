# 자리 양보 망설임

별칭: 자리 양보 주저, 양보 억제

대중교통에 앉은 사람이 노인이나 임산부에게 자리를 내줄지 망설이다 내주지 않거나 말없이 일어난다.

# 서술

2019년 글[^2]이 전하는 영국 조사에서 응답자의 39%는 노인에게 자리를 권하지 않는 이유로 상대를 불쾌하게 할까 봐 두렵다는 것을 꼽았다.

2020년 게시글[^3]의 글쓴이는 여기 앉으라고 말하면 지하철 안에서 말을 해야 하고 코로나도 걱정돼서 말없이 자리에서 일어났다. 상대는 그 자리에 앉지 않았다.

2003년 연구[^1]의 지하철 연구에서 양보를 억제한 요인은 양보에 따르는 몸과 마음의 부담, 양보를 주고받는 상황에서 생기는 거부감, 주변에 양보할 만한 다른 사람이 있을 때의 책임 분산, 상황 해석의 애매함이었다.
