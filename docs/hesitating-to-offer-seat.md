# 자리 양보 망설임

별칭: 없음

대중교통에 앉은 사람이 노인이나 임산부에게 자리를 내줄지 망설이다 내주지 않거나 말없이 일어난다.

묶음: [낯선 사람과 공공장소](../groups/strangers-and-public-places.md)

# 서술

1997년 뉴욕 데일리 뉴스 기사[^1]에서 예절 강사는 일부 젊은이가 스스로를 늙었다고 여기지 않는 사람의 기분을 상하게 할까 봐 나이 든 사람에게 자리를 내주기를 망설인다고 설명했다.

2003년 지하철 연구[^2]에서 양보를 억제한 요인은 양보에 따르는 몸과 마음의 부담, 양보를 주고받는 상황에서 생기는 거부감, 주변에 양보할 만한 다른 사람이 있을 때의 책임 분산, 상황 해석의 애매함이었다.

2019년 글[^3]이 전하는 영국 조사에서 응답자의 39%는 노인에게 자리를 권하지 않는 이유로 상대를 불쾌하게 할까 봐 두렵다는 것을 꼽았다.

2020년 게시글의 글쓴이는 여기 앉으라고 말하면 지하철 안에서 말을 해야 하고 코로나도 걱정돼서 말없이 자리에서 일어났다. 상대는 그 자리에 앉지 않았다.[^4]
