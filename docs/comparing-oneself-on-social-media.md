# 소셜 미디어 속 남과 자기 견주기

별칭: 없음

소셜 미디어에서 남의 게시물을 보는 사람이 자기 삶이나 모습을 그들과 견준다.

묶음: [남의 시선과 창피함](../groups/others-gaze.md)

# 서술

2022년 Samra 외의 연구[^1]에서 여성 참가자는 남성 참가자보다 자기보다 나아 보이는 사람의 이미지를 더 좋아했고 소셜 미디어에서 자기를 남과 더 부정적으로 견주었다.

2024년 정책주간지 기사[^2]가 전한 설문에서 응답자의 28.2%가 인플루언서가 보여 주는 삶과 자기를 견주다가 자존감이 낮아졌다고 답했다.
