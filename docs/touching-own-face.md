# 무심코 얼굴 만지기

별칭: 없음

생각에 잠기거나 마음이 불편한 사람이 무심코 턱이나 수염, 이마를 손으로 만진다.

묶음: [걱정과 기분](../groups/worry-and-mood.md)

# 서술

1880년 헨리 제임스의 소설[^1]에서 모리스는 옛 약혼녀에게 다시 시작할 수 없다는 말을 듣고 흐린 눈으로 수염을 쓰다듬으며 서 있었다. 1892년 체호프의 단편[^2]에서 신경이 예민한 이반 드미트리치는 클럽에 앉아 초조하게 수염을 잡아당기며 잡지와 책을 훑었다.

2024년 기사[^3]는 무심코 얼굴을 만지는 행동이 작업 기억, 감정과 얼마간 이어져 있고 의식적으로 참기가 거의 불가능하다고 적는다.
