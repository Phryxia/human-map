# 신발 아끼려고 들고 맨발로 걷기

별칭: 없음

신발이 닳을까 아끼는 사람이 신발을 손에 들고 맨발로 걷다가 길이 험하거나 목적지가 가까워지면 신는다.

묶음: [돈과 소비](../groups/money.md)

# 서술

1863년 소설[^1]의 처녀들은 길의 첫 구간을 신발과 양말을 손에 들고 맨발로 걸었고 몽크스헤이븐에 가까워지자 걸음을 멈췄다.

1938년 미국 구술 기록[^2]의 화자는 어린 시절 신발과 양말을 손에 들고 맨발로 교회까지 걸어가 교회 옆집에서 신발을 신었고 예배가 끝나면 다시 벗었다고 말했다. 화자는 신발 가죽을 아껴야 했고 맨발은 닳지 않는다고 덧붙였다.

2017년 칼럼[^3]의 필자는 고무신을 아끼려고 손에 들고 맨발로 다니는 것이 보통이었고 자갈길에서만 신었다고 적었다.
