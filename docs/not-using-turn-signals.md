# 방향지시등 켜지 않기

별칭: 방향지시등 미점등[^6]

운전자가 차로를 바꾸거나 방향을 틀 때 방향지시등을 켜지 않는다.

# 서술

1976년 영국 하원의 서면 질문은 고속도로에서 차로를 바꿀 때 신호를 제대로 하지 않아 사고가 일어난다며 신호의 필요를 물었다.[^1]

2006년 기사[^2]가 전한 설문에서 응답자의 42%는 시간이 충분하지 않아 방향지시등을 쓰지 않는다고 답했다. 같은 설문의 17%는 켜면 끄는 것을 잊어서 쓰지 않는다고 답했다.[^2] 2010년 경기일보 기고[^3]는 일부러 켜지 않는 운전자도 있으나 휴대전화로 통화하는 중이라 켜지 않는 경우도 많다고 적었다.

2014년 기사[^4]의 관찰에서 방향을 바꾼 차 454대 가운데 방향지시등을 켠 차는 225대(49.6%)였다. 2018년 홍승권과 김정식의 논문[^5]에서 운전자가 방향지시등을 켜지 않는 가장 큰 이유는 뒤에 차가 없다는 것이었다.

2021년 세계일보 기사[^6]는 방향지시등 미점등이 범칙금 부과 대상인지 몰랐다는 반응이 대부분이라고 적었다. 2024년 실제 주행 데이터 연구[^7]에서 운전자는 차로 변경의 60%에서 변경 전에, 33%에서 변경을 시작한 뒤에 방향지시등을 켰고 7%에서는 켜지 않았다. 2026년 기사[^8]는 깜빡이를 켜는 운전자가 오히려 손해를 보는 분위기도 있다고 적었다.
