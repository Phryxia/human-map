# 구독 해지 포기

별칭: 없음

정기 결제 서비스를 해지하려던 사람이 해지 절차가 번거로워 도중에 그만두고 돈을 계속 낸다.

묶음: [돈과 소비](../groups/money.md)

# 서술

2023년 9월 Sheil 외의 연구[^1]는 온라인 서비스의 가입은 대개 간단하지만 해지는 힘들고 헷갈려 많은 사람이 체념하고 쓰지도 않는 서비스에 돈을 계속 낸다고 적는다.

2024년 3월 Hacker News 댓글[^2]의 글쓴이는 채팅 상담을 몇 시간이나 하고도 해지가 되지 않자 어느 순간 해지를 그만두었다.

2025년 4월 서울시 구독서비스 실태조사 보도자료[^3]의 사례에서 한 이용자는 해지 메뉴를 찾기 어렵고 설문을 해야만 취소할 수 있어 해지하다가 귀찮아 창을 닫았고 그달에도 자동 결제가 됐다.
