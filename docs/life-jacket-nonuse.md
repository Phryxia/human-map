# 구명조끼 미착용

별칭: 구명복 안 입기, Life jacket nonuse

배를 타거나 물놀이, 낚시를 하는 사람이 구명조끼를 입지 않는다.

# 서술

2024년 F4 의 기사는 저수지 낚시터 이용객이 구명조끼를 챙겨 오지 않은 채 낚시를 하고 있었다고 쓴다. [F4]

2020년 미국 해안경비대 F3 은 2019년 레저 보트 익사자 가운데 구명조끼 착용 여부가 보고된 사람의 86% 가 구명조끼를 입지 않았다고 발표했다. [F3]

# 조건

2011년 F1 의 글은 사람들이 구명조끼를 불편해하고 수영 실력을 뽐내려 하며 설마 하는 안전 불감증 때문에 구명조끼를 꺼린다고 쓴다. [F1]

2013년 Quistberg 등의 레저 보트 소유자 면담 연구에서 불편함과 구명조끼를 입으면 경험이 없거나 수영을 못한다는 표시라는 믿음이 꾸준한 착용을 막았다. [F2]
