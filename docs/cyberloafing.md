# 근무 중 사적인 인터넷 사용

별칭: Cyberloafing[^1], 업무 중 딴짓[^3]

직장인이 근무 시간에 업무와 상관없는 웹사이트와 SNS 를 본다.

# 서술

2001년 연구[^1]의 응답자들은 부당한 대우를 받았다고 느낄 때 회사의 인터넷을 사적인 용도로 쓰는 것을 정당하다고 여겼다.

2012년 댓글[^2]의 글쓴이는 할 일이 없는 동안 회사에서 이 사이트를 본다고 썼다.

2019년 고용노동부 카드뉴스[^3]는 업무 중 딴짓 유형 가운데 SNS 가 32%로 가장 많았다고 적는다.

2024년 연구[^4]의 저자들은 이 행동이 불공정하다는 지각의 결과로 자주 나타나고 상대적 박탈감이 줄면 함께 준다고 주장한다.
