# 스마트폰 확인 습관

별칭: 스마트폰 손에서 못 놓기, Checking habit

스마트폰 이용자가 화면을 짧게 자주 들여다보다가 다른 일로 넘어가 쓰는 시간이 늘고 그 시간을 조절하지 못한다.

# 서술

2012년 Oulasvirta 등은 스마트폰을 짧게 들여다보는 확인 습관이 때때로 이용자를 기기의 다른 일로 이끌고 전체 사용량을 늘릴 수 있다고 적는다.[^1] 2020년 문헌 고찰[^2]의 저자들은 FOMO 가 SNS 알림을 지나치게 확인하고 응답하게 몰 수 있다고 적는다.

2023년 Hudecek 등은 저자들이 PSU(problematic smartphone use)라 부르는 사용 수준이 높은 사람이 운전 중에도 휴대전화를 쓸 가능성이 더 크다고 적는다.[^3]

2024년 K-공감 기사가 옮긴 과학기술정보통신부 조사에서 응답자의 23%가 이용시간 조절에 어려움을 겪었다. 청소년은 36.7%로 연령대 가운데 가장 높았다.[^4]

2024년 자료[^4]에서 이용시간을 조절하기 어렵다는 응답은 청소년에게서 가장 많았다.
