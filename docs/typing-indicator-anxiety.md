# 입력 중 표시를 보며 애태우기

별칭: 없음

메신저로 답을 기다리는 사람이 상대의 입력 중 표시가 떴다 사라지거나 오래 이어지는 것을 보며 불안해하고 상대가 무엇을 쓰다 말았는지 짐작한다.

묶음: [걱정과 기분](../groups/worry-and-mood.md)

# 서술

2016년 5월 기사[^1]의 기자는 상사나 어려운 동료의 입력 중 표시가 Slack 에서 떴다가 사라지면 곧 꾸지람을 들으리라고 생각한다고 적었다.

2017년 9월 댓글[^2]의 글쓴이는 입력 중 표시를 보면 상대가 답을 몇 번이나 처음부터 다시 쓰는지 알 수 있고 답이 오지 않아도 상대가 답을 보내려 했다는 것을 알 수 있다고 적었다.

2021년 연구[^3]의 저자들은 입력 중 표시가 너무 오래 이어지는 것을 볼 때의 거북함을 적었다. 저자들에 따르면 그 표시는 상대가 답을 썼다 다시 쓰며 어떻게 답할지 망설인다는 것을 보여 준다.[^3]
