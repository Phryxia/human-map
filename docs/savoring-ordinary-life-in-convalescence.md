# 회복기에 일상을 새롭게 느끼기

별칭: 없음

병에서 회복하는 사람이 숨쉬기, 바깥 풍경, 살아 있음 같은 평범한 것에서 즐거움과 고마움을 크게 느낀다.

# 서술

1840년 소설[^1]의 회복기 화자는 숨 쉬는 것만으로 즐거웠고 모든 것에 차분한 호기심을 느꼈다고 말한다. 2020년 블로그 글[^3]의 글쓴이는 코로나에서 회복하던 중 주변의 풍경과 소리에 곧바로 마음이 가라앉았다고 쓴다.

2013년 연구[^2]에서 병원 밖 심정지에서 살아난 참가자들은 아직 살아 있음에 고마워했고 소중한 사람들 곁에 있으려고 계속 살기로 마음먹었다. 2022년 연구[^4]에서 코로나19로 입원했던 사람들은 삶의 새 의미와 삶을 더 소중히 여기는 마음을 말했다.
