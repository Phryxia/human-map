# 투표했다고 거짓으로 답하기

별칭: 투표 과대보고, 투표 참여 과다 응답, Vote overreporting

투표하지 않은 사람이 설문이나 면접에서 투표했다고 답한다.

# 서술

1989년 10월 미국 인구조사국 보고서는 1988년 선거에서 투표했다고 답한 사람이 1억 220만 명이고 하원 사무처가 기록한 실제 투표자보다 약 1060만 명 많았다고 적었다.[^2]

2014년 2월 미네소타대 선거 블로그의 필자는 투표가 사회에서 좋게 여겨지는 행동이기 때문에 사람들이 평균적으로 투표하지 않았는데도 투표했다고 말하는 경향이 있다고 썼다.[^4]

1986년 연구[^1]의 저자들은 고학력자, 투표라는 규범을 가장 지지하는 사람, 투표 규범이 가장 두드러지는 사람이 투표를 과대보고하는 경향이 가장 강하다고 보고했다.

2012년 연구[^3]의 저자들은 정치에 관여하고 정치와 관련된 자원을 갖춘 비투표자가 투표했다고 일관되게 잘못 답한다고 보고했다.
