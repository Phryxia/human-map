# 뜨거운 음식 식힌 뒤 냉장고에 넣기

별칭: 없음

남은 음식을 보관하려는 사람이 뜨거운 음식을 냉장고에 바로 넣지 않고 상온에 두어 식힌다.

묶음: [건강과 위험](../groups/health-and-safety.md)

# 서술

2014년 식품의약품안전처 안내[^1]는 뜨거운 음식이 냉장고 안 온도를 올려 다른 식품의 보관 온도도 올라갈 수 있으므로 바로 넣지 말라고 적었다.

2024년 3월 Food Network 글[^2]은 뜨거운 음식이 냉장고 안의 주변 음식을 데울 수 있다고 썼다. 같은 해 10월 대학 보도자료[^3]에서 전문가는 뜨거운 음식을 냉장고에 넣어도 괜찮다고 말했다.

2026년 레이디경향 기사[^4]는 뜨거운 음식은 완전히 식혀 넣어야 한다고 생각해 몇 시간씩 상온에 두는 경우도 있다고 적었다.
