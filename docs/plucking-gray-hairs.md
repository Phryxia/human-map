# 흰머리 뽑기

별칭: 없음

사람이 자기나 가까운 사람의 머리에서 흰머리를 보면 늙어 보이지 않게 하려고 뽑는다.

# 서술

1884년 우화집[^1]에서 젊은 아내는 틈날 때마다 남편의 흰머리를 뽑았고 늙은 아내는 남편의 검은 머리를 찾아 뽑았다.

2001년 기사[^2]의 한 학생은 거울에 머리를 비춰 볼 때마다 신경질이 나서 흰머리를 뽑았다. 학생의 어머니는 흰머리를 뽑으면 더 늘어난다며 뽑지 못하게 했다.

2013년 게시글[^3]의 글쓴이는 서른두 살에 생애 두 번째 흰머리를 뽑았고 첫 흰머리는 스무 살 때 뽑았다고 적었다.

2016년 기사[^4]가 전한 설문에서 여성 10명 가운데 8명은 첫 흰머리를 보자마자 뽑기 시작했고 남성 다수는 그대로 두었다.

2021년 연구[^5]가 다룬 이옥의 「각로선생전」은 흰머리를 뽑는 이유의 첫째로 관직에 있으려면 늙어 보이지 말아야 한다는 사정을 든다. 2023년 에세이[^6]의 필자는 흰머리를 없애고 싶은 까닭으로 먼저 뽑는 일 자체가 아주 만족스럽다는 점을 꼽는다.
