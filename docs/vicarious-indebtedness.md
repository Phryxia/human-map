# 가까운 사람이 받은 도움에 대신 빚진 느낌

별칭: Social debt sharing[^2]

가까운 사람이 남에게 도움이나 호의를 받았을 때 사람이 자기가 받은 것처럼 그 도움을 갚아야 할 빚으로 느낀다.

묶음: [선물, 대접과 예의](../groups/gifts-and-hospitality.md)

# 서술

2016년 독자 투고[^1]의 필자는 어머니를 돌본 의료진을 두고 자기 가족이 그 친절을 결코 갚지 못할 것이라고 적었다.

2024년 연구[^2]에서 참가자들은 다른 사람이 자기 연인에게 베푼 호의에 대신 고마움과 부채감을 느꼈다.
