# 늘 앉던 자리에 앉기

별칭: 없음

지정석이 없는 강의실이나 공원 같은 곳을 되풀이해 찾는 사람이 늘 앉던 자리에 다시 앉는다.

묶음: [낯선 사람과 공공장소](../groups/strangers-and-public-places.md)

# 서술

1922년 맨스필드의 단편에서 미스 브릴은 일요일마다 앉는 공원 벤치를 자기의 특별한 자리로 여겼다.[^1]

2005년 칼럼[^2]의 필자는 늘 쓰던 교실 좌석에 다른 사람이 있으면 마음속에 저항이 생기지만 비켜 달라고 요구하지는 못한다고 적는다.

2007년 연구[^3]에서 특정 좌석을 자기 자리로 주장하는 점수는 좌석 배치와 상관없이 여성이 남성보다 높았다. 2012년 연구[^4]는 공공 공간을 되풀이해 쓰는 사람들이 같은 위치를 차지하는 경향이 있다는 가설을 세우고 대학 강의실 두 곳을 관찰했다.
