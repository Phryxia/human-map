# 외국인에게 반말하기

별칭: 없음

한국어 화자가 한국어가 서툰 외국인에게 처음 만난 사이에서도 반말을 쓴다.

묶음: [낯선 사람과 공공장소](../groups/strangers-and-public-places.md)

# 서술

2009년 칼럼[^1]의 필자는 외국인과 한국말로 말할 때 "당신네 회사에 전화해 봐도 되요?" 대신 "전화 괜찮아?" 하는 식으로 말하면 된다고 적었다.

2020년 HelloTalk 게시글[^2]의 글쓴이는 한국인들, 특히 한국 남성들이 자기에게 처음 말을 걸 때 존댓말을 쓰지 않는다고 했다.

2024년 세계일보 칼럼[^3]의 필자는 존댓말과 반말이 있는 언어권에서 온 외국인에게 낯선 사람이 느닷없이 쓰는 반말은 귀에 거슬릴 수밖에 없다고 썼다.

2026년 고용노동부 보도자료[^4]는 이주노동자를 "야, 너" 같은 호칭 대신 이름으로 부르는 문화를 퍼뜨리려는 캠페인을 알렸다.
