# 죽은 이에게 말 걸기

별칭: 없음

가까운 사람을 잃은 사람이 무덤 앞이나 혼자 있는 자리, 메신저에서 세상을 떠난 그에게 말을 걸거나 메시지를 보낸다.

# 서술

1846년 Emily Brontë 의 시[^1]에서 화자는 차가운 무덤 속의 유일한 사랑을 그대라 부르며 이제 그대를 사랑하기를 잊었느냐고 물었다.

1847년 Brontë 의 소설[^2]에서 Heathcliff 는 흐느끼며 죽은 Catherine 의 이름을 부르고 이번에는 들어 달라고 애원했다.

1925년 김소월의 시[^3]에서 화자는 떨어져 나가앉은 산 위에서 그대의 이름을 설움에 겹도록 불렀다.

2011년 Foster 등의 연구에서 암으로 아이를 잃은 부모와 형제 가운데 여럿이 묘지에서 죽은 아이에게 말을 걸었다. 한 형제는 가끔 무덤에 가서 그에게 이야기한다고 말했다.[^4]

2022년 Goodall 등의 체계적 문헌고찰[^5]은 자살 사별 뒤의 지속 유대가 드러나는 사적인 모습으로 고인에게 글을 쓰거나 말을 거는 일을 든다.

2023년 9월 호주 Willed 의 글[^6]은 사랑하는 사람에게 소리 내어 말을 걸면 그가 아직 곁에 있는 것처럼 느낄 수 있다고 적었다. 2024년 뉴시스 기사에 따르면 아들을 먼저 떠나보낸 어머니가 아들을 그리는 메시지를 보냈고 생면부지의 청년이 답신을 보냈다.[^7]

2026년 9월 파이낸셜뉴스 기사[^8]는 추석을 앞둔 봉안당에서 봉안함 앞에 서서 살아 있는 가족에게 하듯 조용히 이야기를 건네는 추모객을 적었다.
