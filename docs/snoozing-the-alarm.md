# 알람 끄고 다시 잠들기

별칭: 스누즈, 알람 미루기, Snoozing

아침에 알람을 들은 사람이 알람을 끄거나 미루고 다시 잠든다.

# 서술

2010년 클리앙 게시글의 글쓴이는 아침에 일어나기가 힘들어 10분만 더 자려 한다고 적었다. 같은 글에서 그 상태로도 휴대폰 알람은 잘 맞춘다고 덧붙였다. [F1]

2016년 클리앙 댓글의 글쓴이는 한 번에 일어난다는 보장이 없어 불안하니 알람을 여러 개 맞춘다고 적었다. 2022년 Ogawa 등의 연구에서 응답자의 70.5%가 휴대전화의 스누즈 기능을 자주 쓴다고 답했고 주된 이유로 늦잠에 대한 불안을 덜려는 것을 들었다. [F3][F4]

2023년 클리앙 댓글의 글쓴이는 다시 잠든 뒤 눈을 떴을 때 개운하고 바깥 햇볕이 쨍쨍하다가 다음 순간 등골이 서늘해지는 느낌을 적었다. 2023년 NBC 기사가 전한 조사에서 응답자의 60%는 알람과 알람 사이에 가장 자주 또는 늘 다시 잠든다고 답했다. [F5][F6]

# 조건

2012년 F2 에서 수면 의사는 대부분의 사람이 잠이 모자란 주중에 스누즈를 누르고 잠이 충분한 주말에는 누르지 않는다고 말했다. [F2]

2022년 F4 의 응답자는 일본의 대학생이다. 2016년 F3 와 2022년 F4 는 알람을 여러 번 울리게 하는 이유로 제때 깨지 못할까 하는 불안을 든다. [F3][F4]
