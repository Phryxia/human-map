# 층간소음 보복

별칭: 없음

공동주택에서 이웃의 소음에 시달린 사람이 소음을 낸다고 여긴 이웃에게 일부러 소음을 되돌려 보낸다.

# 서술

2019년 기사[^1]에서 여러 차례 항의해도 소음이 이어지자 한 주민은 층간 소음 보복용 스피커를 온라인으로 사서 설치했다.

2022년 정책브리핑 칼럼[^2]은 층간 소음 보복행위가 스토킹 범죄로 처벌받을 수 있다고 적었다.

2023년 기사[^3]는 천장에 붙이는 블루투스 스피커 같은 층간소음 보복용 제품을 온라인 쇼핑몰에서 어렵지 않게 살 수 있다고 적었다.
