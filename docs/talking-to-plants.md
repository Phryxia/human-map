# 식물에게 말 걸기

별칭: 없음

화초나 꽃을 기르거나 바라보는 사람이 식물에게 말을 건넨다.

묶음: [혼자 있음과 상실](../groups/solitude-and-loss.md)

# 서술

1871년 캐럴의 소설에서 앨리스는 바람에 흔들리는 참나리에게 말을 걸며 네가 말을 할 수 있으면 좋겠다고 했다.[^1]

2022년 기사[^2]가 전한 설문에서 정원을 가꾸는 사람의 55%가 가끔 또는 자주 식물에게 말을 건다고 답했고 43%는 식물에 이름을 붙였다고 했다.

2023년 서울시 기사[^3]는 화초를 바라보며 말을 건네는 엄마의 모습을 보던 젊은 세대가 이제 원룸에도 반려식물을 둔다고 적었다.

2025년 연구[^4]의 응답자들은 실내 식물에 이름을 붙이고 말을 걸고 식물을 창작과 공부에 끌어들이는 일을 식물과 맺은 관계를 이어 가는 일로 들었다.
