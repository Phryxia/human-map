# 자외선 차단제 안 바르기

별칭: 선크림 안 바르기, Sunscreen nonuse

햇볕에 나가는 사람이 번거롭거나 필요 없다고 여겨 자외선 차단제를 바르지 않는다.

# 서술

2020년 Diehl 외의 독일 조사에서 자외선 차단제를 바르지 않는 주된 이유는 번거로움과 바를 필요를 느끼지 않는다는 것이었다. [F3]

2015년 NCI 블로그 글은 남성이 자외선 차단제를 남자답지 않거나 지저분하거나 번거롭다고 여길 수 있다는 연구 저자들의 말을 전했다. [F2]

# 조건

2015년 비즈한국 기사가 전한 설문에서 선크림을 규칙적으로 바르는 비율은 여성 41.4%, 남성 9.5%였고 자외선을 피하려는 노력을 전혀 하지 않는 비율은 남성 22.5%, 여성 3.0%였다. [F1]

2022년 Advanced Dermatology 의 설문에서 미국인 응답자의 61%는 구름이 조금 끼었거나 흐린 날에는 자외선 차단제를 전혀 바르지 않는다고 답했다. [F4]
