# 되풀이 사과

별칭: 과잉 사과, 습관적 사과, over-apologizing

사소한 일로 남에게 폐를 끼쳤다고 여기는 사람이 미안하다는 말을 거듭하거나 사과할 일이 아닌 일에도 사과한다.

# 서술

1883년 F1 에서 장군에게 사과한 관리 체르뱌코프는 장군이 말을 하지 않자 얼굴이 하얗게 질려 장군이 화가 났다고 생각한다. [F1]

2017년 F2 는 어떤 사람들에게 사소한 일마다 미안하다고 말하고 싶은 충동이 저절로 일어나고 실제 뉘우침과는 거의 상관이 없다고 적었다. [F2]

# 조건
