# 되풀이 사과

별칭: 과잉 사과, 습관적 사과, over-apologizing

사소한 일로 남에게 폐를 끼쳤다고 여기는 사람이 미안하다는 말을 거듭하거나 사과할 일이 아닌 일에도 사과한다.

# 서술

1883년 작품[^1]에서 장군에게 사과한 관리 체르뱌코프는 장군이 말을 하지 않자 얼굴이 하얗게 질려 장군이 화가 났다고 생각한다.

2010년 게시글[^2]의 댓글 글쓴이는 자기 행동이 남을 언짢게 했는지 가늠하기 어려워 만일을 위해 사과하고 평화를 지키려 한다고 썼다.

2017년 글[^3]은 어떤 사람들에게 사소한 일마다 미안하다고 말하고 싶은 충동이 저절로 일어나고 실제 뉘우침과는 거의 상관이 없다고 적었다.

2018년 연구[^4]의 문헌 고찰이 전하는 대학생 표본 연구에서 긍정 평가 두려움은 사소한 실수에 거듭 사과하는 것과 같은 복종적 인지와 행동과 관련이 있었다. 2024년 글[^5]의 임상심리학자는 불안해서 하는 사과를 불안을 잠깐 가라앉히는 안전 행동으로 본다.
