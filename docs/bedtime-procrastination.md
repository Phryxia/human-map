# 잠자리 미루기

별칭: 취침 미루기, 보복성 수면 미루기, bedtime procrastination, revenge bedtime procrastination

졸리거나 피곤한 사람이 휴대폰이나 다른 활동을 놓지 않고 정해 둔 시각보다 늦게 잠자리에 든다.

# 서술

2014년 F1 의 저자들은 외부 사정이 막지 않는데도 의도한 시각에 잠자리에 들지 못하는 것을 잠자리 미루기라고 정의했다. [F1]

2023년 F4 의 문답 기사에서 답변자는 졸리거나 피곤한데도 잠을 미루는 사람들이 전자기기로 게임을 하거나 좋아하는 드라마를 보거나 친구와 채팅하기를 더 원한다고 말했다. [F4]

2026년 9월 8일 루리웹 게시글의 글쓴이는 할 일을 미루다 보니 수면을 미루게 되고 수면을 미루다 보니 할 일이 조금씩 미뤄진다고 적었다. [F5]

2026년 9월 12일 루리웹 게시글의 글쓴이는 문제가 있거나 할 일이 있던 것도 아닌데 자기 전에 잠깐 폰을 보려다 그대로 밤을 새웠다고 적었다. [F6]

# 조건

2014년 F1 의 정의는 외부 사정이 잠자리에 드는 것을 막지 않는 경우만 잠자리 미루기에 넣는다. 2026년 F6 의 글쓴이도 문제나 할 일이 없었다고 적었다. [F1][F6]

2018년 3월 F3 에서는 하루 동안 많은 욕구를 참으려 해 소진된 참가자가 잠자리를 더 미뤘다. 2018년 2월 F2 의 저자들은 자신들의 결과가 잠자리 미루기를 자기조절 자원 부족의 결과로 보는 지배적인 생각과 어긋난다고 적었다. [F2][F3]
