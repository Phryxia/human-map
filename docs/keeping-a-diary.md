# 일기 쓰기

별칭: 일기, 저널링, keeping a diary, journaling

사람이 겪은 일과 생각을 날마다 또는 일이 있을 때 일기로 적어 둔다.

# 서술

1892년 소설[^1]의 화자는 자신이 이름난 사람이 아니어도 자기 일기가 흥미로울 수 있다고 여긴다.

2014년 설문[^2]에서 일기를 쓰는 대학생의 45.7%가 일상을 기록하고 기억하려고 쓴다고 답했고 이 이유가 1위였다. 2023년 독일 조사[^3]에서 독일인 8%가 적어도 한 주에 한 번 일기를 썼고 3%는 날마다 썼다.
