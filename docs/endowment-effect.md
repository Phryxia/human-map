# 소유 효과

별칭: 보유 효과, Endowment effect

자신이 가진 물건에 가지지 않은 사람보다 높은 값을 매기는 사람의 심리다.

# 서술

Kahneman, Knetsch, Thaler 는 1990년 논문 초록에서 이론의 예상과 달리 수용 의사 금액의 측정값이 지불 의사 금액의 측정값을 크게 넘는다고 적는다.[^1]

2019년 한 기고문은 머그컵을 몇 분 동안 소유한 집단이 평균 5.25달러에 팔겠다고 답했고 현금을 받은 집단은 같은 컵을 2.75달러에 사겠다고 답했다고 소개한다.[^3]

2022년 한국경제 생글생글은 소유물을 과대평가하는 현상을 리처드 세일러가 보유 효과라 불렀다고 적는다.[^4]

2007년 Reb 와 Connolly 는 대상에 매기는 금액에 유의한 효과를 낸 것이 사실상의 소유가 아니라 점유였다고 적는다.[^2]

1990년 연구[^1]는 학습 기회가 있는 시장 환경에서도 관찰된 거래량이 코즈 정리의 예측보다 적다고 적는다.
