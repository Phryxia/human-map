# 애착 물건

별칭: 애착 인형[^4], transitional object[^1], security blanket[^3]

아이가 담요나 인형 같은 특정 물건에 정을 붙여 늘 지니고 다니고 잠들 때 찾는다.

묶음: [가까운 사이의 감정과 말](../groups/close-relationships.md)

# 서술

2004년 12월 연구[^1]의 표본에서 애착 물건을 쓰는 아이는 18.2%였고 그 아이들은 애착 물건이 없는 아이들보다 훨씬 이른 나이에 젖을 뗐다.

2008년 11월 Straight Dope 게시글[^2]의 글쓴이는 아이가 낮에는 인형들을 거의 내버려 두다가 잘 때가 되면 모두 모아 안고 잠든다고 적었다.

2010년 10월 Live Science 기사[^3]가 전한 연구에서 아이들의 약 60%는 생후 3년 동안 장난감이나 담요, 고무젖꼭지에 애착을 보였다.

2023년 11월 데일리안 칼럼[^4]은 아이들이 애착 인형과 늘 한 몸처럼 다니고 어디를 가든 그것을 챙긴다고 적었다.
