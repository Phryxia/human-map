# 하품 전염

별칭: Contagious yawning[^3], yawn contagion[^4], 하품 전염[^5]

남이 하품하는 것을 보거나 하품 이야기를 읽은 사람이 따라 하품한다.

# 서술

1898년 6월 12일의 한 일기[^1]의 글쓴이는 사람들이 자기 앞에서 하품하면 그것이 옮을 수 있다는 것을 알아서 하품하지 않겠다고 스스로에게 말한다고 썼다.

2000년 3월 Straight Dope 게시글[^2]의 글쓴이는 아들이 앞에서 하품하면 어김없이 자기도 하품한다고 썼다.

2003년 연구[^3]는 하품 전염을 흔하지만 잘 이해되지 않은 현상이라 불렀다. 2011년 12월 연구[^4]에서 하품이 옮는 비율은 혈연, 친구, 지인, 낯선 사람 순으로 높았다. 같은 달 경향신문 기사[^5]도 이 연구를 전하며 하품 전염 대부분이 직접적인 혈연 사이에서 일어났다고 적었다.
