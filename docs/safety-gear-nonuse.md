# 안전 장비 미착용

별칭: 없음

다칠 위험이 있는 자리에 있는 사람이 위험을 줄이는 보호 장비를 쓸 수 있는데도 착용하지 않는다.

묶음: [건강과 위험](../groups/health-and-safety.md)

# 서술

영국 보건안전청 안내[^1]는 노동자가 개인보호구를 편하다고 느낄 때 훨씬 더 자주 착용한다고 적는다.

2025년 기사[^2]가 전한 고용주 조사에서 노동자의 약 절반은 원하지 않거나 필요하다고 여기지 않아서 알맞은 개인보호구를 착용하지 않았다.
