# 빨리 답해야 한다는 압박

별칭: 즉답 압박, 메신저 응답 의무감, pressure to respond

메시지를 받은 사람이 되도록 빨리 답해야 한다는 압박을 느낀다.

# 서술

2010년 F1 의 면담에서 21~28세 참여자들은 연락이 닿아야 한다는 요구와 기대 때문에 소통 과부하를 겪고 모든 연락을 감당하지 못하는 데서 죄책감을 느낀다고 말했다. [F1]

2017년 F2 의 저자들은 휴대기기로 문자 메시지를 주고받는 이용자 다수가 메시지를 빨리 주고받아야 한다는 압박을 받는다고 적었다. [F2]

2023년 3월 GQ 코리아 기사의 필자는 카카오톡의 읽음 표시 숫자가 없어지기 때문에 메시지를 읽은 사람 다수가 곧바로 답장하려 한다고 썼고 이를 강박이라 불렀다. [F3]

# 조건

2023년 F3 에서 곧바로 답장하려는 마음은 상대가 메시지를 읽었는지 알 수 있는 읽음 표시와 함께 나왔다. [F3]

2010년 F1 의 참여자들이 말한 기대는 일, 공부, 사교 생활의 연락에 두루 걸쳐 있었다. [F1]
