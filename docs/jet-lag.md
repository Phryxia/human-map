# 시차증

별칭: Jet lag[^1]

여러 시간대를 건너 비행한 사람이 도착한 뒤 며칠 동안 낮에 졸리고 밤에 잠들기 어렵다고 느낀다.

묶음: [시간과 하루 습관](../groups/daily-time.md)

# 서술

2007년 리뷰[^1]의 저자들은 시차증에서 잠을 잃고 수행이 떨어지는 어려움을 강조했다.

2017년 6월 여행 칼럼[^2]의 필자는 시간대에 적응한 현지인들과 저녁을 먹으며 수프 위로 꾸벅꾸벅 조는 일을 적었다.

2024년 11월 호주 공공 건강 안내[^3]는 시차증의 주된 증상으로 낮에 몹시 피곤하고 밤에 잠들기 어려운 것을 꼽았다. 2026년 5월 Live Science 기사[^4]는 장거리 여행자 대부분이 낮에 지나치게 피곤하고 밤에는 잠들지 못하는 혼란을 겪어 봤다고 썼다.
