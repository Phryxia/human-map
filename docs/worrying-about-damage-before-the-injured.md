# 다친 사람보다 망가진 물건 먼저 걱정하기

별칭: 없음

가족이 넘어지거나 사고를 당한 자리에서 사람이 다친 사람의 몸보다 깨지거나 망가진 물건의 손해를 먼저 아까워한다.

묶음: [가까운 사이의 감정과 말](../groups/close-relationships.md)

# 서술

1935년 소설[^1]의 어머니는 넘어져 일어나지 못하는 딸을 보고도 딸이 다쳤는지보다 깨진 동이를 먼저 아까워했다.

2026년 기사[^2]가 옮긴 온라인 게시글에서 트럭을 몰다 사고를 당한 남편이 전화하자 아내는 남편의 몸보다 차가 얼마나 망가졌는지를 먼저 물었다.
