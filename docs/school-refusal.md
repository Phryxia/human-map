# 등교 거부

별칭: 등교거부, School refusal

학생이 친구 관계나 괴롭힘 같은 학교 안의 어려움으로 학교에 가기를 꺼리고 집에 머문다.

# 서술

2003년 F1 의 Fremont 는 가정이나 학교, 또래와 겪은 스트레스 사건이 등교 거부를 일으킬 수 있다고 적었다. [F1]

2007년 F2 의 기사가 옮긴 일본 조사에서 초중학생이 등교를 거부한 이유로 가장 많이 꼽은 것은 이지메를 뺀 친구관계 15.6%였다. 같은 조사에서 이지메는 3.2%였다. [F2]

2019년 F3 의 저자들은 부적 강화로 등교를 거부하는 학생 집단이 다른 집단보다 괴롭힘 피해 점수가 유의하게 높았다고 보고했다. [F3]

2022년 F4 의 상담 칼럼에 나온 학생은 아침에 깨지만 학교에 가기 싫어 다시 잠든다고 말했다. 그 학생은 친구가 없다는 것과 공부가 힘들다는 것을 이유로 들었다. [F4]

# 조건

2007년 F2 는 일본 초중학생의 응답이다. 그 응답에서 친구관계 다음은 부모와의 관계 9.3%, 학업 부진 7.9% 순이었다. [F2]
