# 자기 비하

별칭: 없음

사람이 남 앞에서 먼저 자기 약점이나 실수를 꺼내 자기를 깎아내리거나 우스개로 낮추어 말한다.

묶음: [남의 시선과 창피함](../groups/others-gaze.md)

# 서술

1864년 소설[^1]의 화자는 첫머리에서 자기를 아픈 사람, 심술궂은 사람, 매력 없는 사람이라고 소개했다.

2016년 Fox 외의 논문[^2]은 자기 패배적 유머를 자기를 대가로 남과의 관계를 좋게 하려는 유머로 설명하고 자기 약점과 실수, 잘못을 두고 우스운 말을 해서 사람들이 자기를 더 좋아하거나 받아들이게 하려 한다는 문항을 예로 들었다.

2026년 브런치 글[^3]의 필자는 사람들이 칭찬보다 놀림을, 따뜻한 말보다 자기비하를 먼저 꺼낸다고 썼다.
