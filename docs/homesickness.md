# 향수

별칭: 고향 그리움, 홈식니스, Homesickness

고향을 떠난 사람이 두고 온 집과 풍경과 가족을 그리워한다.

# 서술

정지용의 시에서 화자는 실개천이 휘돌아 나가고 황소가 우는 고향의 풍경을 하나씩 떠올리고 그곳을 꿈에서도 잊을 수 없다고 말한다. [F1]

2002년 Stroebe 등은 대학생의 향수가 흔하게 나타나며 그 비율이 네덜란드에서 약 50%, 영국에서 약 80%였다고 적는다. [F2]
2020-04 F3 의 기사는 유학 초기의 유학생이 호소하는 외로움이 향수병으로 이어지는 경우가 흔하다고 쓴다. [F3]

# 조건

2002년 F2 에서 향수를 겪는 비율은 나라마다 달랐다. [F2]
