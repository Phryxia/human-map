# 승낙 과소평가

별칭: Underestimation-of-Compliance Effect[^2]

남에게 직접 부탁하는 사람이 상대가 그 부탁을 들어줄 가능성을 실제보다 낮게 어림한다.

# 서술

2008년 7월 논문[^1]의 첫 세 연구에서 참가자들은 남이 자기의 직접적인 도움 요청에 응할 가능성을 많게는 50%까지 낮게 어림했다.

2016년 리뷰[^2]의 저자는 이 오류가 요청에 "아니요" 라고 말하는 일의 어색함을 요청하는 사람이 헤아리지 못하는 데서 생긴다고 썼다.

2020년 2월 NPR 방송[^3]에서 연구자는 설문 참여를 부탁하러 나가기 전에 몇 명이 응할지 어림한 참가자들이 응할 사람 수를 크게 낮게 잡았다고 말했다.
