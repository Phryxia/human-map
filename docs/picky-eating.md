# 편식

별칭: 반찬 투정[^1], Picky eating[^3]

아이나 어른이 싫어하는 음식을 가려 먹지 않고 좋아하는 음식만 먹는다.

묶음: [시간과 하루 습관](../groups/daily-time.md)

# 서술

1923년 소설[^1]의 주인공은 고운 옷과 맛난 음식을 해 주는 사람에게 옷 투정과 반찬 투정을 마구 해도 매도 맞지 않고 꾸중도 듣지 않는 것을 신기하게 여긴다.

1956년 소설[^2]의 한 인물은 어렸을 때 편식이 심했고 나이가 들면서 차차 나아졌다고 말한다.

2010년 종단 연구[^3]에서는 어느 나이에서 재든 아이의 13%에서 22%가 편식하는 아이였다.

2014년 건강 기사[^4]는 억지로 먹도록 강요당한 경험, 구토나 복통 같은 불쾌한 경험, 동물에 대한 동정심 같은 심리 요인으로도 편식이 생길 수 있다고 적었다.

2015년 Lam 의 리뷰 논문[^5]은 한 연구의 자료를 들어 편식이 대개 한동안 나타났다가 지나가는 행동이고 미취학 아동 발달의 한 부분이라고 적는다.

2024년 서울시 보도자료[^6]는 유아기에 편식하는 식습관이 생기면 성인이 되어서도 바꾸기 쉽지 않다고 적었다.
