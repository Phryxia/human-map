# 모인 자리에서 말하지 않기

별칭: 조직 침묵, 직원 침묵, Organizational silence, 질문 안 하기

수업이나 직장처럼 여럿이 모인 자리에서 할 말이나 물을 것이 있는 사람이 그것을 말하지 않고 입을 다문다.

# 서술

2000년 Morrison 과 Milliken 은 여러 조직에서 직원들이 잠재적 문제에 관한 정보를 널리 말하지 않게 만드는 강한 힘이 있다고 주장한다. [F1]

2022년 한 블라인드 게시글의 글쓴이는 아직은 튀고 싶지 않아서 말을 자제하고 싶다고 쓴다. 글쓴이는 그런 자신을 모순적이라 부르고 상처받고 싶지 않은 것 같다고 적는다. [F2]

# 조건

2000년 F1 은 조직 안에서 직원이 문제를 알리는 일에 대한 것이다. 2022년 F2 는 대학에서 교수에게 질문하는 일을 다룬 게시글이다. [F1][F2]

2022년 Balikçi·Uğurlu 는 직원이 지각한 계약 위반이 체념이나 방어에서 나오는 침묵에 양의 효과가 있다고 보고했다. [F3]
