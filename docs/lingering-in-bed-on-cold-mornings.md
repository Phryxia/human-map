# 추운 아침 이불 속에 머물기

별칭: 이불 밖은 위험해, 이불에서 못 나오기

추운 아침에 잠이 깬 사람이 따뜻한 이불 속에 더 있고 싶어 일어나기를 미룬다.

# 서술

마르쿠스 아우렐리우스의 명상록 1862년 영역본[^1]에서 화자는 아침에 마지못해 일어나며 이불을 덮고 몸을 따뜻하게 두는 편이 더 즐겁다는 마음을 스스로 되묻는다.

2019년 영국 기사[^3]가 전한 설문에서 응답자 10명 가운데 7명은 바깥 날씨가 쌀쌀해 보이면 이불과 함께 몇 분 더 있고 싶은 마음을 뿌리치기 어렵다고 답했다.

# 조건

2010년 일본 기사[^2]는 홋카이도와 도호쿠처럼 추운 북쪽 지역에서 잠이 깬 뒤 이불을 나오기까지 걸린 시간이 전국 평균보다 길었다고 전했다.

2019년 기사[^3]의 응답자는 바깥 날씨가 쌀쌀해 보일 때를 들었다.
