# 조용한 사직

별칭: Quiet quitting[^1], 조용한 퇴사[^3]

일하는 사람이 회사를 그만두지 않은 채 맡은 최소한의 일만 하고 그 이상은 애쓰지 않는다.

# 서술

2022년 9월 Gallup 글[^1]은 직장에서 기대 이상으로 애쓰지 않고 직무 기술서에 적힌 일만 하는 사람이 수백만 명이라는 생각이 소셜 미디어에서 퍼진다고 쓴다.

2023년 11월 기사[^2]가 전한 직장인 1,000명 조사에서 응답자의 58% 정도가 조용한 사직을 고려 중이라고 답했다.

2024년 3월 기사[^3]가 전한 조사에서 직장인 2명 중 1명꼴로 퇴사하지는 않고 최소한의 업무만 처리하는 조용한 퇴사 상태였다.

2026년 1월 댓글[^4]의 글쓴이는 되도록 적게 일하고 받는 돈에 비해 내놓는 노동을 최소로 줄인다고 썼다. 같은 달 간호 연구[^5]는 조용한 사직을 몰입 감소, 최소 업무만 하기, 추가 책임 피하기, 조직에 대한 무관심으로 규정한다.
