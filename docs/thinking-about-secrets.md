# 비밀에 대한 생각에 사로잡히기

별칭: 없음

비밀을 가진 사람이 그것을 숨겨야 할 자리가 아닐 때에도 그 비밀을 자꾸 떠올린다.

# 서술

2017년 Scientific American 기사[^1]가 전한 연구에서 사람들은 누구와도 어울리지 않을 때 비밀을 떠올리는 일이 대화 중에 비밀을 감추는 일보다 두 배쯤 잦다고 답했다. 같은 해 Slepian 외의 논문[^2]은 감추는 횟수와 상관없이 비밀로 생각이 흘러가는 횟수가 낮은 안녕감을 예측했다고 적었다.

2019년 ScienceDaily 기사[^3]가 전한 연구에서 비밀에 죄책감보다 수치심을 느끼는 사람이 숨기는 일에 대한 생각에 더 사로잡혔다.
