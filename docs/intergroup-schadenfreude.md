# 경쟁 집단의 불행에 대한 기쁨

별칭: 없음

자기 집단과 겨루는 집단의 사람이 실패하거나 다치는 것을 본 사람이 기쁨을 느낀다.

# 서술

2011년 3월 연구[^1]의 저자들은 자기 집단 사람의 실패는 고통스럽고 경쟁하는 바깥 집단 사람의 실패는 기쁨을 줄 수 있다고 썼다. 이 연구에서 레드삭스와 양키스의 열성 팬이 야구 장면을 볼 때 상대 팀이 지는 장면은 응원 팀이 이기는 장면처럼 쾌감과 이어진 뇌 부위를 움직였고 상대 팀이 제3의 팀에 질 때도 그랬다.[^1]

2018년 9월 NPR 방송[^2]에서 연구자는 응원하는 팀에 강하게 동일시하는 농구 팬들이 상대 팀 라이벌 선수가 크게 다쳤을 때 꽤 기뻐했다고 말했다.
