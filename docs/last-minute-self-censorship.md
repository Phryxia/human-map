# 게시 직전 자기검열

별칭: 막판 자기검열, last-minute self-censorship, 쓰던 댓글 지우기

온라인 게시물이나 댓글을 써 놓은 사람이 올리기 직전에 올리지 않기로 하고 지운다.

# 서술

2011년 해커 뉴스의 한 댓글은 쓴 댓글을 다시 읽고 토론에 보탤 만큼이 아니라고 보면 올리지 않고 탭을 닫는 일이 많다고 말한다. [F1]

2013년 Das 와 Kramer 는 페이스북 사용자의 71%가 조사 기간에 어느 정도의 막판 자기검열을 보였다고 보고했다. [F2]

# 조건

기록된 조건 없음. [F1][F2]

# 파편

- F1 [SNS] "Many times I read a comment after writing it, see that although it does add a little, it does not add enough to the discussion, and just close the tab without posting the comment." (댓글을 쓴 뒤 다시 읽어 보면 조금 보태기는 해도 토론에 보탤 만큼은 아니라는 걸 알게 되고, 그냥 댓글을 올리지 않은 채 탭을 닫는 일이 많다.) — Hacker News, 댓글, 2011-04-04, https://news.ycombinator.com/item?id=2406082, 2026-10-18 접속
- F2 [학술] "Our results indicate that 71% of users exhibited some level of last-minute self-censorship in the time period" (결과에 따르면 사용자의 71%가 그 기간에 어느 정도의 막판 자기검열을 보였다.) — Sauvik Das, Adam Kramer, "Self-Censorship on Facebook", Proceedings of the International AAAI Conference on Web and Social Media 7(1), 2013, https://aaai.org/papers/00120-14412-self-censorship-on-facebook/, 2026-10-18 접속
