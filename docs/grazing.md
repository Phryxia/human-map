# 조금씩 자꾸 집어 먹기

별칭: Grazing[^2], Picking and nibbling[^2]

사람이 끼니를 따로 정하지 않고 하루 동안 적은 양의 음식을 여러 번 되풀이해 먹고 마신다.

묶음: [시간과 하루 습관](../groups/daily-time.md)

# 서술

2008년 미국 농무부 경제연구소 자료[^1]에서 인구의 8%는 하루 4.5시간 넘게 먹고 마셨고 자료는 이들을 늘 풀을 뜯는 사람들이라는 뜻의 'constant grazers' 로 불렀다.

2021년 연구[^2]는 심리학 연구가 이 행동을 적은 양의 음식을 체계 없이 되풀이해 먹기, 끊임없는 과식, 집어 먹고 야금야금 먹기, 무질서한 식사 같은 이름으로 불러 왔다고 적었다.
