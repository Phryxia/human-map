# 세금 공제를 노린 기부

별칭: 없음

사람이 세금 공제를 받으려고 기부하거나 공제에 맞춰 기부의 시점과 금액을 정한다.

묶음: [시민 참여와 공공의 일](../groups/civic-life.md)

# 서술

2008년 Bakija 와 Heim 의 연구[^1]는 기부의 세후 가격이 바뀔 것을 미리 내다본 사람들, 특히 소득이 아주 높은 사람들이 기부 시점을 다시 정한 증거를 일부 찾았다.

2024년 연구[^2]는 미국의 세법 개정이 미리 알려지자 기부자들이 기부 시점을 어느 정도 옮긴 증거를 찾았다.

2025년 전북일보 기사[^3]에서 전북자치도 관계자는 고향사랑기부제에 연말정산 혜택이 있어 세액공제를 바로 느낄 수 있는 11월과 12월에 모금이 몰린다고 말했다.
