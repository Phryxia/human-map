# 불길한 숫자 피하기

별칭: 없음

어떤 사람은 4 처럼 불길하다고 여기는 숫자가 든 집 주소를 꺼리거나 바꾸려 한다.

묶음: [돈과 소비](../groups/money.md)

# 서술

2010년 CTV 기사[^1]에 따르면 번지 끝자리가 4인 집을 산 사람 가운데 많은 수가 더 운이 좋은 숫자가 들어가게 주소를 바꿔 달라고 시에 청원했다.

2013년 Fortin 등의 연구[^2]는 집 거래 약 11만 7천 건을 분석해 번지 끝자리가 4인 집이 다른 집보다 2.2% 싸게 팔리고 8인 집이 2.5% 비싸게 팔렸다고 보고했다.
