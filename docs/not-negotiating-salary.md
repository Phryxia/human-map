# 연봉 협상하지 않기

별칭: 첫 제안 그대로 받기, Not negotiating salary

일자리 제안을 받은 사람이 돈을 더 달라고 하기가 불편하거나 제안이 철회될까 걱정해 연봉을 협상하지 않고 처음 제시된 금액을 받아들인다.

# 서술

2015년 댓글의 글쓴이는 연봉을 협상한 적이 한 번도 없고 제시된 금액을 받아들이거나 일자리를 거절했다고 썼다.[^1] 2017년 기사가 전한 조사에서 협상하지 않는 사람의 51%는 돈을 더 달라고 하기가 불편하다고 답했다. 47%는 고용주가 제안을 철회할까 두려워했고 36%는 욕심 많아 보이기를 원하지 않았다.[^2]

2023년 미국 조사 보고[^3]에서 첫 연봉을 협상하지 않은 사람의 38%는 더 많은 급여를 요구하기가 편하지 않았다고 답했다. 2023년 학회 초록[^4]에서 전공의 과정을 마친 여성 의사들이 첫 직장 협상을 하지 않은 이유로 든 것은 제안이 철회될까 하는 두려움, 무엇을 협상할 수 있는지 모른다는 것, 제시된 연봉을 전공의 시절 소득과 견준 것이었다.
