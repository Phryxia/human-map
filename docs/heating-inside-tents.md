# 텐트 안에서 난로 켜고 자기

별칭: 없음

추운 날 야영하는 사람이 몸을 데우려고 일산화탄소가 나오는 난로나 숯불을 텐트 안에 켜 두고 잠든다.

# 서술

1985년 미국 소비자제품안전위원회 보도자료[^1]에서 숯을 태워 일산화탄소로 숨진 사람 가운데 일부는 텐트나 캠핑카 안에서 몸을 데우려고 숯을 피운 야영객이었다.

2022년 코메디닷컴 기사[^2]에서 경찰은 텐트 안에 가스난로가 있는 것을 확인하고 두 사람이 난로를 켜 놓고 자다 일산화탄소 중독으로 숨졌다고 추정했다. 2023년 사냥 게시판 댓글의 글쓴이는 창을 조금 열어 둔 채 텐트에서 난로를 밤새 켜 둔다고 썼다.[^3] 2025년 SBS Biz 기사가 전한 한국소비자원 집계에서 캠핑장 중독 사고는 8건이었고 모두 일산화탄소 중독이었다.[^4]
