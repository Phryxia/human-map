# 안경 벗어 닦기

별칭: 없음

마음이 흔들리거나 시간을 끌고 싶은 안경 쓴 사람이 안경을 벗어 닦으며 뜸을 들인다.

묶음: [시간과 하루 습관](../groups/daily-time.md)

# 서술

1911년 소설[^1]의 인물은 안경을 벗어 물기를 닦고 떨리는 손으로 다시 썼다.

2014년 몸짓 사전[^2]은 닦을 필요가 없는데 안경을 벗어 닦는 것을 시간 끌기로 읽을 수 있다고 적는다.
