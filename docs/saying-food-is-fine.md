# 음식이 마음에 들지 않아도 괜찮다고 답하기

별칭: 없음

식당에서 음식이나 서비스가 마음에 들지 않은 손님이 직원이 어떠냐고 물으면 괜찮다고 답한다.

# 서술

2012년 댓글[^1]의 글쓴이는 나쁜 서비스나 음식 앞에서 전형적인 영국식 고분고분함으로 다 괜찮다고 답한다고 썼다.

2014년 칼럼[^2]의 필자는 웨이터가 다가와 어떠냐고 묻자 다 괜찮다고 답했고 그것이 거짓말이었다고 적었다.
