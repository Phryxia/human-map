# 연애 질투

별칭: Romantic jealousy[^4]

연인을 둔 사람이 연인 곁의 경쟁자나 사소한 단서를 보고 연인을 의심하며 괴로워한다.

# 서술

1622년 셰익스피어의 희곡에서 이아고는 질투하는 사람에게 공기처럼 가벼운 사소한 일도 성서의 증거처럼 강한 확증이 된다고 말한다.[^1] 1922년 영역된 프루스트의 소설에서 스완은 오데트가 할 수 있는 모든 말을 의심스럽게 여긴다.[^2]

2014년 글[^3]의 필자는 연인이 샘낼 만한 경쟁자에게 관심을 보이는 것을 보면 사람을 무력하게 만드는 질투와 시기가 뒤섞여 생길 수 있다고 썼다. 2016년 Sun 외의 연구에서 연애 질투의 강도는 연애에서 느끼는 행복의 강도와 관련되었다.[^4] 2017년 네이트 판 게시글의 글쓴이는 남자친구가 다른 여사친과 대화를 많이 나누거나 톡을 하면 기분이 나빴다고 적었다.[^5]

2020년 Pollet 와 Saxton 의 메타분석에서 경쟁자의 매력이 일으키는 질투에는 작고 유의한 성별 효과가 있었고 경쟁자의 지배성에는 그런 반응이 없었다.[^6]

2026년 PsyPost 기사가 전한 실험에서 남녀 모두 연인이 다른 사람에게 자원을 내주는 일을 심각한 관계 위협으로 여겼다.[^7] 2026년 let's talk 포럼 게시글의 글쓴이는 연인이 문자를 할 때나 혼자 떠난 해외여행에서 새 친구를 사귈 때 질투가 난다고 썼다.[^8]
