# 명절 잔소리를 웃음으로 넘기기

별칭: 명절 잔소리 흘려듣기, 적당히 대답하고 넘기기

명절에 친척에게 취업이나 결혼에 관한 잔소리를 들은 사람이 맞서지 않고 웃거나 적당히 대답해 넘긴다.

# 서술

2020년 1월 K-공감 기사가 전한 취업포털 설문에서 명절 잔소리를 들었을 때의 대처로 웃음으로 대충 넘긴다는 응답이 32.8% 로 가장 많았다.[^1]

2024년 1월 GQ 코리아 기사는 "네. 그럴게요" 하고 적당히 대답한 뒤 흘리는 대처를 소개했다. 저자는 이 방법이 가장 빠르고 유연한 대처일지도 모른다고 추측한다.[^2]
