# 계획 오류

별칭: planning fallacy, 계획 착오

일을 계획하는 사람이 그 일에 들 시간과 품을 실제보다 적게 어림한다.

# 서술

2008년 F1 의 저자들은 사람들이 일을 끝내는 데 드는 작업을 적게 어림하고 그 때문에 예상보다 늦게 끝내거나 마감 직전에 지나치게 많은 일을 몰아서 한다고 쓴다. 2019년 F2 의 학위논문은 사람들이 일에 걸릴 시간을 짧게 어림하기 쉽다고 쓴다. [F1][F2]

2019년 F3 의 글에서 저자는 계획과 예측에서 사람들이 과거를 잘 알면서도 그것을 되풀이할 수 있다고 적는다. 2021년 F4 의 기사는 과거에 틀린 사례를 보여 주어도 자기 상황은 낙관하는 면이 있다는 심리학자들의 말을 옮긴다. 2026년 F5 의 기사는 같은 일을 여러 번 겪어 실제 걸리는 시간을 이미 알면서도 이 어림이 되풀이된다고 적는다. [F3][F4][F5]

# 조건

2021년 F4 의 기사는 계획을 세울 때 차질을 빚을 수 있는 불편한 정보를 무시하는 데서 이 오류가 생긴다고 적는다. [F4]
