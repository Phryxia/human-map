# 밤 소리를 침입자로 여기기

별칭: 없음

밤에 집에 있는 사람이 작은 소리를 듣고 누가 들어왔다고 여기며 겁을 먹는다.

묶음: [걱정과 기분](../groups/worry-and-mood.md)

# 서술

1922년 조이스의 소설[^1]에서 몰리는 밤에 부엌에서 도둑 소리를 들었다고 확신했던 일을 떠올린다. 그날 남편은 촛불과 부지깽이를 들고 내려갔고 하얗게 질려 겁에 떨었다.

2007년 연구[^2]에서 밤의 두려움을 보고한 아동과 청소년이 가장 많이 꼽은 것은 침입자와 집에 누가 쳐들어오는 일이었다.

2019년 서울신문 좌담 기사[^3]에서 원룸에 혼자 지낸 한 참석자는 방범시설이 갖춰져 있었는데도 누가 들여다보는 것 같았고 작은 소리에도 놀랐다고 말했다.

2025년 Substack 글[^4]의 필자는 혼자 있는 밤에 낯선 소리를 듣고 잘못 들은 건지, 위층 이웃의 소리인지, 침입자인지를 차례로 생각했다.
