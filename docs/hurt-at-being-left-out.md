# 나만 빼고 모인 것을 안 서운함

별칭: 없음

친구나 아는 사람들이 자기만 부르지 않고 모이거나 놀러 간 것을 뒤늦게 안 사람이 서운해하거나 마음 아파한다.

묶음: [가까운 사이의 감정과 말](../groups/close-relationships.md)

# 서술

1925년 소설[^1]에서 Clarissa 는 점심 모임이 재미있기로 이름난 Lady Bruton 이 자기를 부르지 않은 것을 알고 몸과 머리에서 기운이 빠지는 것을 느꼈다.

2018년 9월 ScienceDaily 기사[^2]가 전한 연구에서 친한 친구가 얽힌 배제 정보를 본 참가자들은 대조군보다 부정적 감정을 더 많이 겪었다.

2019년 8월 네이트 판 게시글[^3]의 글쓴이는 페이스북에서 친구들이 자기만 빼고 여행을 간 것을 보았다.

2022년 문헌 검토[^4]에 실린 청소년들은 행사에 초대받지 못하는 일과 메시지에 답이 오지 않는 일을 은근한 온라인 배제로 이야기했다.
