# 끝내지 못한 일 계속 떠올리기

별칭: 자이가르닉 효과, Zeigarnik effect

일을 끝내지 못한 사람이 그 일을 끝낸 일보다 더 자주, 더 오래 떠올린다.

# 서술

행동과학 해설 사이트 Coglode 의 글[^1]은 끝내지 않은 일이 끝낸 일보다 마음에 더 남는다고 적었다.

# 조건

2011년 연구[^2]에서 참가자에게 끝내지 못한 목표에 대한 구체적인 계획을 세우게 하자 그 목표가 계속 떠오르고 다른 일을 방해하는 효과가 사라졌다.
