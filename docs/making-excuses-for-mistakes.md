# 변명

별칭: 없음

잘못이나 실수를 지적받은 사람이 책임을 덜려고 그렇게 된 사정을 늘어놓는다.

묶음: [가까운 사이의 감정과 말](../groups/close-relationships.md)

# 서술

1953년 소설[^1]의 한 인물은 상대가 늦은 데 대해 댄 변명이 불충분하다고 얼굴로는 웃으면서 새침한 어조로 말한다.

2025년 연구[^2]는 잘못을 두고 자신을 변명하는 사람이 책임을 받아들이지 않는 일이 잦고 그 예로 책임을 남에게 돌린다고 적었다.
