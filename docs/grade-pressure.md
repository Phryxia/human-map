# 성적 압박

별칭: 없음

시험과 성적을 앞둔 학생이 좋은 성적을 내야 한다는 무거운 압박을 느낀다.

묶음: [걱정과 기분](../groups/worry-and-mood.md)

# 서술

2004년 기사[^1]에서 한 교사는 초등학교 때부터 12년 동안 쌓은 실력이 하루에 결판난다는 중압감이 수능 부정행위로 이어졌다고 말했다.

2018년 서울시 자료[^2]에서 아동과 청소년 응답자의 49.7%가 성적과 적성을 포함한 공부를 고민거리로 꼽았다.

2019년 글[^3]이 전한 조사에서 학생의 80%가 학교에서 잘해야 한다는 압박을 꽤 많이 또는 많이 느꼈다.
