# 밥 먹으며 책 읽기

별칭: 없음

밥을 먹는 사람이 식탁에 책이나 신문, 잡지를 펴 두고 먹으면서 읽는다.

묶음: [시간과 하루 습관](../groups/daily-time.md)

# 서술

1905년 Conan Doyle 의 소설[^1]에서 Holmes 는 신문을 양념병 받침에 기대 세우고 먹으면서 읽다가 한두 번 소리 내어 웃었다.

2005년 게시판 댓글[^2]의 글쓴이는 책이 저절로 펼쳐져 있지 않고 음식을 흘릴 수 있으며 식탁에 자리가 모자라 혼자 먹을 때도 먹으며 읽지 않는다고 썼다.

2010년 게시판 댓글[^3]의 글쓴이는 혼자일 때는 먹으면서 읽기를 고르고 다른 사람과 함께일 때는 읽기를 무례하다고 여겨 이야기를 나눈다고 썼다.

2012년 Book Riot 에세이[^4]의 글쓴이는 사람들이 먹으면서 읽는 진짜 까닭을 읽기를 멈추지 않으려는 데서 찾았다.

2019년 PsyPost 기사[^5]가 전한 실험에서 잡지나 스마트폰을 보며 먹은 참가자는 아무것도 보지 않고 먹을 때보다 열량을 15% 안팎 더 먹었다. 2020년 문헌 검토[^6]는 스마트폰을 쓰거나 인쇄된 글을 읽으며 먹을 때 총 섭취 열량이 15% 늘고 지방 섭취도 늘었다는 결과를 정리했다.

2026년 7월 블로그 글[^7]의 글쓴이는 밥과 반찬을 집어 먹으면서 틈틈이 책장을 넘기느라 오른손이 바빴던 일을 적었다.
