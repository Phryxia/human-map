# 리베이트 받지 않기

별칭: slippage[^2]

물건을 산 뒤 신청하면 돈을 돌려받는 리베이트를 받을 수 있는 소비자가 그것을 청구하지 않고 넘긴다.

# 서술

2004년 대학 보도자료[^1]가 전한 연구에서 리베이트를 받지 않은 참가자의 60%는 미루거나 잊은 것을 이유로 들었다.

2021년 논문[^2]의 저자는 신청해야 받는 리베이트가 판매를 늘리는데도 많은 소비자가 끝내 청구하지 않는다고 적었다. 저자에 따르면 마케터들은 이를 slippage 라 부른다.
