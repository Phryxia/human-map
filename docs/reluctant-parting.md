# 이별을 아쉬워하기

별칭: 없음

헤어지는 사람이 헤어짐을 아쉬워해 작별을 늦추거나 떠나는 상대를 오래 지켜본다.

묶음: [선물, 대접과 예의](../groups/gifts-and-hospitality.md)

# 서술

1597년 Shakespeare 의 희곡[^1]에서 줄리엣은 헤어짐을 달콤한 슬픔이라 부르고 아침이 올 때까지 잘 자라는 인사를 하겠다고 말했다.

2009년 9월 KTV 보도[^2]에서 이산가족 상봉을 마치고 헤어지는 남북의 가족은 차창을 사이에 두고 잡은 손을 쉽게 놓지 못했다.

2024년 2월 연구[^3]는 옷 가게 점원이 손님을 출입구까지 배웅하는 일을 이별을 미루는 일로 다룬다. 저자는 이 배웅이 아쉬움을 연출하는 의례적 실천일 가능성을 말한다.

2025년 12월 댓글[^4]의 글쓴이는 작별할 때 마무리 대화에 이어 문 앞에 서서 하는 대화, 차 옆에 서서 하는 대화를 잇는다고 적었다.

2026년 6월 기사[^5]는 한 사진가가 27년 동안 부모 집을 다녀갈 때마다 진입로에서 손을 흔들며 배웅하는 부모를 사진으로 남긴 일을 다룬다.
