# 집에서 새 구경하기

별칭: Backyard birding[^2]

사람이 자기 집 마당이나 집 안에서 찾아오는 새를 지켜본다.

묶음: [시간과 하루 습관](../groups/daily-time.md)

# 서술

2020년 8월 Audubon 기사[^1]에서 오래 마당의 새를 지켜본 사람들은 모이통을 더 자주 채웠고 새를 처음 알게 된 사람들은 첫 모이통 세트와 쌍안경과 도감을 샀다.

2024년 미국 어류야생동물관리국 글[^2]은 새를 보는 미국인의 95%인 9100만 명이 자기 집에서 편히 새를 본다고 적었다.
