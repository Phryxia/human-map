# 답하지 않은 뒤의 수치감

별칭: 답장 죄책감, email guilt, text guilt

받은 연락에 답하지 않거나 늦게 답하는 사람이 그 일로 부끄러움이나 죄책감을 느낀다.

# 서술

1878년 F1 의 소설에서 레빈은 답장 없이 안장만 보낸 뒤 부끄러운 일을 했다고 느낀다. [F1]

2015년 F2 의 글쓴이는 답장을 쓰는 데 오래 걸릴수록 죄책감과 수치감이 쌓인다고 적었다. [F2]

# 조건

2015년 F2 의 글쓴이는 답장이 늦어지는 시간의 길이를 이 느낌이 커지는 조건으로 든다. [F2]

# 파편

(문제는 실제로 답장을 쓰는 데 오래 걸릴수록 죄책감과 수치감이 더 쌓인다는 것이다.) — Jim McDermott, "Email Debt Forgiveness Day: A Jubilee for the Rest of Us", America Magazine, 2015-04-30, https://www.americamagazine.org/politics-society/dispatches/2015/04/30/email-debt-forgiveness-day-jubilee-rest-us/, 2026-10-19 접속
