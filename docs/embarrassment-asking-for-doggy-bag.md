# 남은 음식 포장 요청 부끄러워하기

별칭: doggy bag shame[^1]

식당에서 음식을 남긴 손님이 남은 음식을 싸 달라고 하기를 부끄러워해 요청하지 않는다.

묶음: [남의 시선과 창피함](../groups/others-gaze.md)

# 서술

2015년 이탈리아 기사[^1]가 전한 설문에서 응답자의 약 40%는 식당에 남은 음식을 가져가도 되는지 묻기를 부끄러워한다고 답했다.

2021년 2월 Hacker News 댓글[^2]의 글쓴이는 식당에서 남은 음식 포장을 청하면 비웃음만 샀고 지금도 자주 그렇다고 썼다.

2023년 몰도바 소비자 연구[^3]에서 포장을 요청하지 않는 이유로 49%가 요청하기 부끄럽다고 답했다. 2023년 스코틀랜드 공공기관 페이지[^4]는 손님들이 남은 음식 포장을 권해 주기를 바라지만 5분의 2는 수줍어서 요청하지 못한다고 적는다.
