# 잠자리에서 시계 보기

별칭: Clock-watching[^7], Time monitoring behavior[^7]

잠들지 못하고 누워 있는 사람이 시계를 자꾸 보며 몇 시인지와 남은 잠 시간을 확인한다.

# 서술

1913년 소설[^1]의 화자는 밤에 성냥을 그어 시계를 보곤 했고 자정 가까운 때였다. 2016년 칼럼[^5]의 글쓴이는 잠이 안 오는 날이면 시계를 들여다보며 몇 시인지 자꾸 확인하는 자신을 본다고 썼다.

2012년 게시판 댓글[^4]의 글쓴이는 밤의 약 5%를 잠들려고 애쓰는 데, 나머지 95%를 지금 잠들면 몇 시간 잘 수 있는지 계산하는 데 쓴다고 적었다. 2025년 기사[^8]는 새벽에 깨어 시계를 보는 순간 남은 수면 시간을 계산하게 되고 몇 시간밖에 못 잔다는 생각이 든다고 썼다. 2026년 게시글[^9]의 글쓴이는 1시에 누워 뒤척이다 시계를 보니 3시 반이었고 눈은 뻐근한데 잠은 오지 않는다고 적었다.

2023년 연구[^7]의 저자들은 시계 보기와 잠 시간 계산이 잠 대신 스트레스를 주는 깨어 있는 활동에 시간을 쓰게 해 잠 못 드는 상태를 직접 키운다고 쓴다.

2007년 실험[^2]에서 시계를 지켜본 사람은 지켜보지 않은 사람보다 잠들기 전 걱정이 많았고 잠들기까지 더 오래 걸렸으며 이 결과는 잘 자는 사람과 잘 못 자는 사람 모두에게 해당했다. 같은 해 칼럼[^3]에서 수면 전문의인 필자는 잠들려고 애쓰는 중에 자주 시계를 보거나 시간을 확인하는 행동을 쉽게 관찰할 수 있다고 썼다. 2022년 빅토리아 주 정부 건강 안내[^6]는 분이 흘러가는 것을 지켜보면 계속 깨어 있게 된다고 적었다.
