# 가면 증후군

별칭: Impostor syndrome[^2]

일을 잘 해낸 사람이 그 성과를 자기 능력이 아니라 운으로 돌리고 실력이 들통날까 두려워한다.

# 서술

2016년 지식iN 게시글[^1]의 글쓴이는 일을 잘 해내 칭찬을 받거나 시험을 잘 보면 다음번에 못할까 걱정하고 그저 운이 좋아서 그랬다고 생각한다고 썼다.

2019년 체계적 문헌고찰[^2]은 가면 증후군을 객관적으로 성공했는데도 자기 성취를 자기 것으로 받아들이지 못하고 사기꾼으로 드러날까 하는 두려움과 자기 의심을 계속 품는 성취도 높은 사람들의 상태로 적었다.
