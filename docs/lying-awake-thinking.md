# 생각 때문에 잠 못 이루기

별칭: 수면 전 걱정, 잠자리 반추, pre-sleep worry

잠자리에 누운 사람이 낮에 겪은 일이나 잠에 대한 걱정을 되풀이해 생각하느라 잠들지 못한다.

# 서술

1847년 브론테의 소설에서 제인은 촛불을 끄고 누운 뒤에도 가로수 길에서 멈춰 선 상대의 표정을 생각하느라 잠들지 못했다. [F1]

1921년 김동인의 소설에서 화자는 그날 들은 배따라기 노래와 이야기가 귀에 울려 밤에 잠을 못 이뤘고 이튿날 아침 밥도 먹지 않고 그 사람을 다시 찾아갔다. [F2]

2007년 F3 의 실험에서 시계를 지켜본 참가자는 지켜보지 않은 참가자보다 잠들기 전 걱정을 더 많이 보고했고 잠들기까지 더 오래 걸렸다. [F3]

2014년 F4 의 저자들은 잠에 관한 잠들기 전 걱정이 잠들기까지 걸린 시간과 수면 효율을 예측했고 일반적인 걱정은 불면증의 자기보고 심각도를 예측했다고 보고했다. [F4]

# 조건

2007년 F3 에서 시계를 지켜볼 때 걱정이 늘고 잠들기까지 오래 걸린 결과는 잘 자는 사람과 잘 못 자는 사람 모두에게 나타났다. [F3]

2022년 F5 의 미국 국립심장폐혈액연구소는 잠을 충분히 잘지 걱정하고 시계를 지켜보는 것이 불면증의 위험을 높이거나 불면증을 더 나쁘게 한다고 적었다. [F5]

1847년 F1 과 1921년 F2 에서 잠을 막은 생각은 그날 만난 사람과 들은 이야기였고 2014년 F4 와 2022년 F5 에서는 잠 자체에 대한 걱정이었다. [F1][F2][F4][F5]
