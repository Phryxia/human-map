# 손가락 마디 꺾기

별칭: Knuckle cracking[^2]

초조하거나 언짢은 사람이 손가락 마디를 꺾어 소리를 내는 일을 버릇처럼 되풀이한다.

묶음: [걱정과 기분](../groups/worry-and-mood.md)

# 서술

1887년 단편[^1]에서 막무가내인 민원인에게 시달린 은행장은 신경질적으로 손가락을 꺾으며 물병 쪽으로 자꾸 오갔다.

2017년 연구[^2]의 저자들은 스스로 손가락 마디를 꺾는 일이 흔한 버릇이고 보고된 유병률이 25%에서 45%라고 적었다.
