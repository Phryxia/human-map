# 읽음 표시를 피하려고 메시지 열지 않기

별칭: 없음

메신저 메시지를 받은 사람이 상대에게 읽음 표시가 뜨지 않도록 대화방을 열지 않고 알림 미리보기 같은 다른 경로로 내용을 본다.

# 서술

2012년 8월 주간경향은 카카오톡 수신확인의 불편함을 사용자 대부분이 겪으면서 안 읽은 상태를 유지한 채 메시지를 확인하는 카카오톡 몰래보기가 개발됐다고 썼다.[^1]

2017년 Lynden 과 Rasmussen 은 읽음 표시를 회피 전략, 앱 확인 증가, 불안감 같은 행동과 정서 효과에 연결했다.[^2]

2026년 8월 브런치 글의 글쓴이는 휴가 중에 온 업무 카톡을 알림 창에 뜬 문장 앞쪽으로 이미 다 읽었지만 카톡방은 열지 않았다고 썼다. 그 방에서 글쓴이 이름 옆에는 아직 숫자 1이 붙어 있었을 것이라고 적었다.[^3]
