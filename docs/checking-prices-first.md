# 값부터 보고 고르기

별칭: 없음

돈을 쓰려는 사람이 무엇을 고르기 전에 값부터 확인하고 그 값에 맞춰 고른다.

묶음: [돈과 소비](../groups/money.md)

# 서술

1923년 소설[^1]의 가난한 유학생은 이발소 의자에 앉으면서도 벽에 붙은 정가표를 곁눈으로 보고 생각한 대로 이십 전인 것을 확인한 뒤 안심한다.

2011년 게시글[^2]의 글쓴이는 가장 비싼 요리와 가장 싼 요리는 값에 비해 부풀려졌기 쉬우니 값이 중간쯤인 요리를 고르라고 적었다.

2016년 기사[^3]가 전한 메뉴 연구자의 말에 따르면 식당들은 손님이 오른쪽 가격 줄을 훑어 가장 싼 요리를 고른다는 것을 알게 되었다.

2024년 연구[^4]에서 매장의 쇼핑객은 상품을 두고 고민한 경우의 약 62%에서 가격 정보를 응시했다.
