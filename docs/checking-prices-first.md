묶음: [돈과 소비](../groups/money.md)

# 서술

1923년 소설[^1]의 가난한 유학생은 이발소 의자에 앉으면서도 벽에 붙은 정가표를 곁눈으로 보고 생각한 대로 이십 전인 것을 확인한 뒤 안심한다.

2016년 기사[^2]가 전한 메뉴 연구자의 말에 따르면 식당들은 손님이 오른쪽 가격 줄을 훑어 가장 싼 요리를 고른다는 것을 알게 되었다.
