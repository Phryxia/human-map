# 잘못 배달된 물건 돌려주지 않기

별칭: 없음

자기가 주문하지 않은 물건이 잘못 배달된 사람이 그것을 보낸 곳에 알리거나 돌려주지 않고 갖는다.

묶음: [돈과 소비](../groups/money.md)

# 서술

2008년 게시글[^1]의 글쓴이는 잘못 배달된 상자를 그냥 집 안에 들여놓아야 한다는 것을 알면서도 훔치는 것 같은 죄책감이 든다고 적었다. 2011년 게시글[^2]의 글쓴이는 주문하지 않은 택배를 받고 안에 든 것을 가져도 되는지 물었다.

2025년 실험[^3]에서 받을 몫이 아닌 상품을 배달받은 고객 622명 가운데 517명이 그 상품을 신고하지 않았다.
