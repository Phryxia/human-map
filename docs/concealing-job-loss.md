# 실직 사실 숨기기

별칭: 취업 실패 숨기기, Concealing unemployment

일자리를 잃었거나 구하지 못한 사람이 그 사실을 가족이나 아는 사람에게 숨긴다.

# 서술

1934년 채만식의 소설에서 P는 신문사 사장에게 취직을 부탁했다 거절당한 뒤 복도에서 만난 편집국장이 사장을 만나러 왔느냐고 묻자 아니라고 거짓말을 한다. 소설은 거절당한 이야기를 하기가 창피했고 직접 찾아왔다고 하기가 혐의쩍어 시치미를 뗐다고 적는다. [F1]

2009년 경향신문 기사는 취업포털 설문에서 가족에게 실직 사실을 숨긴 실직자들이 든 이유를 전했다. 걱정 끼치고 싶지 않아서가 61.6%, 어떻게 얘기를 꺼낼지 몰라서가 17.4%, 자존심이 상해서가 10.5%였다. [F2]

2025년 시대 기사는 중국에서 실직자가 가족 등에게 실직 사실을 숨길 수 있게 돕는 가짜 사무실이 인기를 끈다고 전했다. [F3]

# 조건

1934년 F1 의 인물은 거절당한 일을 이미 취직을 부탁해 둔 사람에게 숨긴다. 2009년 F2 의 응답자들은 실직 사실을 가족에게 숨긴다. 2025년 F3 에서는 숨기는 일에 돈을 내고 쓰는 사무실이 있다. [F1][F2][F3]
