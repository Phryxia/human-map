# 택배 기사에게 음료와 간식 두기

별칭: 없음

택배를 받는 주민이 더위나 물량이 몰린 때 집 앞이나 공용 현관에 택배 기사와 집배원이 가져갈 물, 음료, 간식, 감사 쪽지를 놓아 둔다.

묶음: [선물, 대접과 예의](../groups/gifts-and-hospitality.md)

# 서술

2016년 미국 우정청 소식[^1]은 폭염 속 캘리포니아에서 고객이 집배원을 위해 물을 놓아 두기도 한다고 적었다.

2020년 서울시 시민기자 글[^2]에 따르면 초등학생부터 노인까지 여러 나이의 주민이 감사 메모와 함께 마스크, 음료, 에너지 바를 문고리에 걸거나 문에 붙여 두었다.

2024년 기사[^3]가 전한 글의 글쓴이는 현관 앞 생수대를 두고 고생하는 사람들에게 감사하는 마음의 작은 표시이지만 공개하기는 자랑 같아 민망하다고 썼다. 2025년 기사[^4]가 전한 사진에는 공용 출입문 옆 아이스박스에 얼린 생수, 캔커피, 음료와 간식이 담겨 있었다.
