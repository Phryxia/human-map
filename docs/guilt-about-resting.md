# 쉬는 데 죄책감 느끼기

별칭: 없음

쉬거나 아무것도 하지 않고 시간을 보낸 사람이 해야 할 일을 하지 않았다는 죄책감을 느낀다.

# 서술

2010년 블로그 글[^1]의 글쓴이는 늦잠을 자며 책을 읽는 동안 일어나 일하라는 죄책감이 들 때마다 그것을 미뤄 두고 다시 읽었다. 2019년 포럼 게시글[^2]의 글쓴이는 아침에 몸이 무거워 아무것도 하지 않고 스누커 중계를 본 뒤 하루를 낭비한 것 같은 죄책감을 느꼈다.

2024년 블로그 글[^3]의 글쓴이는 주말에 낮잠을 자고 아무것도 하지 않으면 죄책감이 들었다고 쓴다. 2026년 글[^5]에서 상담실을 찾은 사람은 늦잠을 자고 일어나면 반나절을 날린 것 같아 죄책감이 밀려온다고 말했다.

2025년 논문[^4]은 배우자를 돌보는 사람들이 자기만의 시간을 가질 때 흔히 죄책감을 느낀다고 쓴다.
