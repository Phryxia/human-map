# 엘리베이터 안의 침묵

별칭: 없음

엘리베이터에 낯선 사람과 함께 탄 사람이 말을 멈추고 신발, 문, 층수 표시기를 바라본다.

# 서술

1983년 Zuckerman 등의 관찰에서 엘리베이터 승객의 절반쯤은 탈 때 함께 탄 사람을 잠깐 쳐다본 뒤 더는 눈을 맞추지 않았다.[^1] 2000년 매일신문 기사의 화자는 아파트 엘리베이터에서 얼굴을 마주치지 않으려 했지만 새로 탄 10층 남자와 눈이 마주쳤다고 적었다.[^2]

2012년 NPR 방송의 한 출연자는 엘리베이터에서 대화가 멈추고 모두 내릴 때까지 신발이나 문이나 층수 표시기를 바라본다고 말했다.[^3]

2026년 해커 뉴스의 한 댓글은 엘리베이터에서 말없이 어색하게 서서 올라가는 순간이 많다고 적었다.[^4]
