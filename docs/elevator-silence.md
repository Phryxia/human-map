# 엘리베이터 안의 침묵

별칭: 엘리베이터에서 시선 피하기

엘리베이터에 낯선 사람과 함께 탄 사람이 말을 멈추고 신발, 문, 층수 표시기를 바라본다.

# 서술

2012년 NPR 방송의 한 출연자는 엘리베이터에서 대화가 멈추고 모두 내릴 때까지 신발이나 문이나 층수 표시기를 바라본다고 말했다.[^1]

2026년 해커 뉴스의 한 댓글은 엘리베이터에서 말없이 어색하게 서서 올라가는 순간이 많다고 적었다.[^2]
