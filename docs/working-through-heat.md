# 폭염 속 바깥일 계속하기

별칭: 더위 속 작업 강행, 폭염 속 밭일

폭염 속에서 밭일이나 바깥일을 하는 사람이 더위로 몸이 처지거나 쉬라는 말을 들어도 일을 멈추지 않는다.

# 서술

2008년 미국 질병통제예방센터 보고서[^1]에서 2005년 담배밭의 한 노동자는 오후 2시 45분쯤 느리게 일하다 고용주의 아들에게 쉬라는 말을 들었지만 계속 일했다. 2016년 농장 노동자 연구[^2]는 그저 계속 일할 수밖에 없다는 노동자의 말을 제목으로 삼는다.

2026년 기사[^5]에서 한 시설하우스 농가는 일손이 없는 사람들은 30분도 쉬지 않고 12시에 밥을 먹은 뒤 12시 반이면 작업에 들어간다고 말했다.

# 조건

2024년 사설[^3]은 고령 농업인들이 농사에는 다 때가 있다며 작업을 멈추지 못한다고 적는다. 2026년 기사[^6]는 고령층이 오래 이어 온 농사일을 습관처럼 계속하고 폭염 때 작업을 삼가라는 지자체 안내를 대수롭지 않게 여긴다고 적는다.

2026년 르포[^4]의 한 농민은 새벽에 몇 시간 일하고 해가 뜨면 작업을 멈춘다고 말했다.
