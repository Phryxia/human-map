# 아이리시 굿바이

별칭: 인사 없이 자리 뜨기, French leave, 프렌치 리브

모임에 있던 사람이 아무에게도 작별 인사를 하지 않고 조용히 자리를 떠난다.

# 서술

1882년 Braddon 의 소설 Mount Royal 에서 한 인물은 손님이 아무에게도 작별 인사를 하지 않고 떠나 버린 일을 되풀이해 말한다. [F1]

2023년 Mental Floss 기사는 인사 한마디 없이 빠져나가는 퇴장을 아이리시 굿바이, 프렌치 리브 같은 이름으로 다른 나라 사람의 무례한 퇴장 방식이라 부르는 관습을 전한다. [F2]

2023년 Hacker News 의 한 댓글 작성자는 아이리시 굿바이가 있는 까닭으로 그 대안이 길고 거창한 작별이라는 점을 들었다. [F3]
