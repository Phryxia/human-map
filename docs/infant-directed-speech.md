# 아기에게 쓰는 말투

별칭: Motherese[^3], infant-directed speech[^4], 패런티즈[^5]

어른이 아기에게 말할 때 목소리를 높이고 말을 늘이며 맘마 같은 아기 말을 쓴다.

묶음: [가까운 사이의 감정과 말](../groups/close-relationships.md)

# 서술

1929년 최서해의 소설[^1]에서 할머니는 앓는 손녀를 안았다 뉘었다 하며 아프냐 맘마 먹겠느냐 하고 물었다.

1989년 Fernald 등의 연구[^2]에서 여러 언어의 부모가 아기에게 하는 말은 같은 꼴로 운율이 바뀌었다. 2014년 한국 연구[^3]에서 어머니들의 평균 음높이는 아기가 없을 때 199.79Hz, 아기가 있을 때 227.15Hz였다.

2022년 연구[^4]에서 조사한 사회의 전부나 대부분에서 아기에게 하는 말은 음이 더 높고 음역이 더 넓었으며 모음 대비가 더 컸다. 2026년 육아 글[^5]은 이 말투를 쓰는 어른이 평소 목소리보다 거의 한 옥타브 높여 말하고 모음을 길게 늘여 천천히 말했다고 적었다.
