# 의인화

별칭: Anthropomorphism[^2]

사람이 동물, 식물, 물건처럼 사람이 아닌 것에 사람의 성질과 마음이 있다고 여기고 그렇게 대한다.

묶음: [혼자 있음과 상실](../groups/solitude-and-loss.md)

# 서술

1757년 흄의 책[^1]은 인류에게 모든 존재를 자기와 같은 것으로 여기고 자기가 잘 아는 성질을 모든 대상에 옮기는 경향이 있다고 적었다.

2010년 2월 ScienceDaily 기사[^2]는 사람들이 식물에게 말을 걸고 사람 같은 신에게 기도하고 차에 이름을 붙이고 반려동물에게 옷을 입힌다고 썼다.

2015년 Chicago Booth Review 기사[^3]는 Epley 의 주장으로 사람에게는 주변 사람과 이어지려는 근본적인 욕구가 있어 사람 아닌 것과도 이어지려고 그것을 의인화할 수 있다고 전했다.
