# 야생동물에게 먹이 주기

별칭: 없음

공원이나 관광지를 찾은 사람이 그곳에 사는 야생동물에게 먹이를 준다.

묶음: [시민 참여와 공공의 일](../groups/civic-life.md)

# 서술

1995년 설문 연구[^1]에서 많은 사람이 재미로, 그리고 먹이가 원숭이의 형편을 낫게 한다고 믿어 야생 원숭이에게 먹이를 줬다.

1998년 기사[^2]는 한 부부가 아이 얼굴에 땅콩버터를 바르고 새끼 곰 두 마리가 그것을 핥아 먹는 동안 사진을 찍은 일을 전한다.

2007년 환경부 보도자료[^3]에서 지리산에 풀어 준 반달가슴곰 한 마리는 탐방로에 머물며 탐방객에게서 먹이를 자주 받아 먹었다.

2016년 미국 국립공원관리청 안내문[^4]은 공원 방문객이 고마움, 호기심, 친근감 같은 좋은 뜻에서 야생동물에게 무언가를 답례로 주고 싶어 한다고 쓴다.

2025년 기사[^5]에서 먹이를 주지 말라는 안내판을 가리키자 관광객들은 재미를 망친다고 불평했다.
