# 귀가 늦추기

별칭: Furariimen[^3]

집에 있는 가족과 마주치거나 집안일을 맡기 싫은 사람이 일부러 집에 늦게 들어간다.

# 서술

2012년 게시글[^1]의 글쓴이는 남편이 집에 가는 것이 점점 싫어져 스스로 술자리를 만든다고 썼다.

2015년 기사[^2]에서 부모 집에 사는 30대 직장인은 부모의 잔소리를 피하려고 귀가 시간을 늦췄고 부모는 무슨 일을 하길래 한밤중에 퇴근하느냐고 묻기 시작했다.

2019년 기사[^3]는 일본에서 가정생활에 더 참여하라는 배우자의 요구를 피하려고 일과가 끝나도 집으로 향하지 않는 남성들을 전한다.
