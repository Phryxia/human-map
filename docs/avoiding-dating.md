# 연애 기피

별칭: 없음

교제 상대가 없는 미혼자가 연애나 교제를 바라지 않거나 혼자가 편하다며 이성을 만나지 않는다.

# 서술

일본 국립사회보장·인구문제연구소의 제15회 출생동향기본조사 보고서[^1]에서 2015년 조사의 미혼자 가운데 교제하는 이성이 없다고 답한 비율은 남성 69.8%, 여성 59.1%였고 직전 조사보다 높았다. 교제 상대가 없으면서 교제를 바라지도 않는 미혼자는 남성 30.2%, 여성 25.9%였다.[^1]

2023년 11월 세계일보 기사[^2]는 데이터 컨설팅 기업 피앰아이가 전국 20\~69세 남녀 3000명에게 물은 조사를 전했다. 연애를 하지 않는 이유로 혼자가 편하다는 답이 33.6%로 가장 많았고 만날 기회가 없다는 답이 18.0%로 뒤를 이었다.[^2]
