# 다이어트 중 폭식

별칭: 없음

먹는 것을 참던 사람이 한 번 다이어트가 깨지면 그동안 참던 음식을 한꺼번에 많이 먹는다.

# 서술

2020년 논문[^2]의 저자들은 식이 절제가 흐트러지면 절제하던 사람들이 적어도 잠시 다이어트 목표를 버리고 스스로 금했던 음식을 실컷 먹는다고 썼다. 2021년 영국 국민보건서비스 기관의 글[^3]은 다이어트가 제한과 폭식의 순환을 거쳐 섭식 문제를 더 일으킬 수 있다고 적었다.

2026년 게시글[^4]의 글쓴이는 처음에는 먹고 싶은 것을 거의 다 참다가 버티던 끝에 갑자기 폭식으로 이어지는 날이 생긴다고 썼다.

1988년 연구[^1]에서 고칼로리 밀크셰이크를 먼저 받은 절제형 여대생은 다이어트를 하지 않는 사람보다 점심 칼로리를 유의하게 더 많이 먹었다고 보고했다.

2020년 논문[^2]에서 이 현상은 절제가 흐트러진 뒤에 나타났다. 2026년 게시글[^4]에서는 의욕이 커서 거의 모든 것을 참던 다이어트 초기가 폭식에 앞섰다.
