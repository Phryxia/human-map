# 일기 숨기기

별칭: 없음

일기나 사적인 글을 쓰는 사람이 가족이나 같이 사는 사람이 읽을까 봐 그것을 숨겨 두거나 치운다.

묶음: [가까운 사이의 감정과 말](../groups/close-relationships.md)

# 서술

1892년 단편 소설[^1]의 화자는 남편이 오자 그가 자기가 글 쓰는 것을 싫어한다며 쓰던 것을 치웠다.

2008년 잡지 기사[^2]의 저자가 이야기를 나눈 사람 대부분은 가족이 가지 않을 곳에 일기를 숨겨 사생활을 지켰다. 2013년 연구[^3]에서 한 어머니는 딸의 방을 청소하다가 침대 머리판 밑에 숨겨 둔 딸의 글을 찾았다.

2021년 게시글[^4]의 글쓴이는 엄마에게 절대 보이고 싶지 않아 일기를 꽁꽁 숨겨 두었는데 엄마가 그것을 찾아 읽었다고 썼다.
