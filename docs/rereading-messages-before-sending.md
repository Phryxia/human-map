# 보내기 전 메시지 다시 읽기

별칭: 없음

이메일이나 메시지를 쓴 사람이 보내기 전에 초안을 여러 번 다시 읽거나 고쳐 쓴다.

# 서술

1866년 소설[^1]에서 편지를 쓰던 인물은 마음에 들게 쓰려고 두세 장을 찢었고 끝내 더 잘 쓸 수 없다고 체념하자 다시 읽지 않고 보냈다.

1875년 소설[^2]에서 편지를 다 쓴 인물은 그것을 혼자 다시 읽으며 편지 전체에 조심성 없는 열의의 어조가 배어 있다고 생각했다.

1919년 소설[^3]에서 좋아하는 사람에게 보일 글을 쓰던 인물은 말이 모자라 쓴 말 위아래에 다른 말을 덧쓰다가 만족하지 못한 채 펜을 놓는다.

2007년 논문[^4]은 컴퓨터 매개 소통의 사용자가 인상을 관리하고 바라는 관계를 맺으려고 기술의 특성을 이용해 자기가 쓰는 메시지를 다듬는다고 적었다.

2019년 글[^5]의 조사에서 응답자의 절반 넘게 이메일 초안을 두 번에서 네 번까지 읽은 뒤에 보냈다.

2024년 게시글[^6]의 글쓴이는 이메일을 보내기 전에 스무 번쯤 고쳐 쓴다고 적었다.

2026년 에세이[^7]의 필자는 손편지를 쓸 때 첫 줄을 고민하며 한참 펜만 들고 있었고 지운 흔적이 싫어 새 종이를 꺼내 몇 번을 다시 썼다고 적는다.
