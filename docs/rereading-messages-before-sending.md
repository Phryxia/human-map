# 보내기 전 메시지 다시 읽기

별칭: 없음

이메일이나 메시지를 쓴 사람이 보내기 전에 초안을 여러 번 다시 읽거나 고쳐 쓴다.

# 서술

1866년 소설[^1]에서 편지를 쓰던 인물은 마음에 들게 쓰려고 두세 장을 찢었고 끝내 더 잘 쓸 수 없다고 체념하자 다시 읽지 않고 보냈다.

1875년 소설[^2]에서 편지를 다 쓴 인물은 그것을 혼자 다시 읽으며 편지 전체에 조심성 없는 열의의 어조가 배어 있다고 생각했다.

2019년 글[^3]의 조사에서 응답자의 절반 넘게 이메일 초안을 두 번에서 네 번까지 읽은 뒤에 보냈다.

2024년 게시글[^4]의 글쓴이는 이메일을 보내기 전에 스무 번쯤 고쳐 쓴다고 적었다.
