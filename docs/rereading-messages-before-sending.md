# 보내기 전 메시지 다시 읽기

별칭: 이메일 여러 번 고쳐 쓰기, 전송 전 검토

이메일이나 메시지를 쓴 사람이 보내기 전에 초안을 여러 번 다시 읽거나 고쳐 쓴다.

# 서술

2019년 글[^1]의 조사에서 응답자의 절반 넘게 이메일 초안을 두 번에서 네 번까지 읽은 뒤에 보냈다.

2024년 게시글[^2]의 글쓴이는 이메일을 보내기 전에 스무 번쯤 고쳐 쓴다고 적었다.
