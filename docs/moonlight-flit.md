# 야반도주

별칭: 빚 때문에 몰래 떠나기, moonlight flit, 요니게

빚이나 밀린 집세를 갚지 못한 사람이 채권자나 집주인 모르게 밤중에 살던 곳을 떠나는 행동이다.

# 서술

이익상의 1926년 소설에서 빚을 갚을 수 없게 된 득춘 부부는 여러 날 생각한 끝에 마을을 슬그머니 도망하기로 작정한다.[^1]

1956년 스코틀랜드어 사전은 이 말을 빚을 갚지 않거나 불쾌한 결과를 피하려고 밤을 틈타 몰래 옮겨 가는 일로 풀이한다.[^2]

2010년 영국 임대인 블로그는 달아난 세입자가 남긴 밀린 집세와 망가진 집을 되찾으려고 집주인들이 소송을 낸다고 적는다.[^4]

2004년 서울신문은 장기불황 속에 돈 빌려준 전주에게 빚을 갚지 못한 사채업자의 야반도주가 늘었다고 보도했다.[^3]

1926년 작품[^1]은 소작농의 농사 빚을, 2010년 글[^4]은 셋집의 밀린 집세를 다룬다.
