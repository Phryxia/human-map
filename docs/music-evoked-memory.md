# 노래가 불러낸 옛 기억

별칭: Music-evoked autobiographical memories[^2]

오래전에 듣던 노래를 다시 들은 사람에게 그 노래를 듣던 무렵의 장면과 사정이 떠오른다.

묶음: [기억과 떠오르는 생각](../groups/memory-and-thoughts.md)

# 서술

1918년 로런스의 시에서 해 질 녘 한 여자가 부르는 노래는 화자를 여러 해 전으로 데려가 피아노 아래 앉은 아이를 보게 했다.[^1]

2009년 연구[^2]의 저자는 개인의 과거에서 온 익숙한 노래가 감정이 두드러진 일화 기억을 불러낼 때 등쪽 내측 전전두피질이 음악과 기억을 잇는다고 적었다.

2010년 칼럼[^3]의 필자는 가요를 들으면 그 노래가 나왔을 무렵의 사회나 자신의 개인 사정이 불현듯 떠오른다고 적었다.

2022년 연구[^4]에서 음악이 불러낸 자전적 기억은 일부러 떠올렸는지와 상관없이 얼굴이 불러낸 기억보다 일화가 풍부하고 지각 세부가 많았다.
