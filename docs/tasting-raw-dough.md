# 날반죽 맛보기

별칭: 없음

과자나 케이크를 만드는 사람이 굽기 전의 날반죽을 맛보거나 먹는다.

묶음: [건강과 위험](../groups/health-and-safety.md)

# 서술

2022년 미국 위험분석학회 보도자료[^1]가 전한 조사에서 소비자의 66%가 날 쿠키 반죽이나 반죽을 먹는다고 답했다.

2023년 미국 식품의약국 안내[^2]는 익히지 않은 밀가루와 반죽을 먹거나 맛보지 말라고 적었다.

2024년 대학 기사[^3]가 전한 2019년 조사에서 참가자의 34%가 그 전 12개월 사이에 날반죽을 맛보거나 먹었다고 답했다.
