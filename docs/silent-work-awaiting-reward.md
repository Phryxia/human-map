# 보상을 기다리며 불만 없이 일하기

별칭: 열정페이 감수, 보상 지연 중 순응

약속된 보상이 올 때를 기다리며 불만을 말하지 않고 일을 계속하는 행동이다.

# 서술

김유정의 1935년 소설에서 화자는 때가 되면 장인님이 알아서 하리라 여기고 군소리 없이 일만 해 왔다고 말한다. [F1]

2015년 서울신문은 구직 청년 가운데 58.9%가 해결책이 없는 데다 하고 싶은 일이어서 열정페이를 경험해도 참았고, 일을 그만둔 경우는 27.2%에 그쳤다고 보도한다. [F2]

# 조건

2015년 F2 는 해결책이 없다는 판단과 하고 싶은 일이라는 사정을 참은 이유로 적는다. [F2]

2022년 F3 의 저자들은 심리적 계약 위반을 지각한 사람에게서 체념형 침묵과 방어형 침묵이 늘어나는 양의 효과를 보고한다. [F3]

1935년 F1 은 때가 되면 성사되리라는 믿음이 일하는 이유라고 화자가 말하는 경우를 다룬다. [F1]

# 파편

- F1 [문학] "때가 되면 장인님이 어련하랴 싶어서 군소리 없이 꾸벅꾸벅 일만 해왔다." — 김유정, 「봄봄」, 1935, https://ko.wikisource.org/wiki/봄봄, 2026-10-16 접속
- F2 [매체] "하지만 청년들 가운데 58.9%는 해결책이 없는 데다, 하고 싶은 일이기 때문에 열정페이를 경험해도 참았으며, 일을 그만둔 경우는 27.2%에 그쳤다." — 서울신문, "구직 청년 2명 중 1명 '열정페이'에 울었다", 2015-06-24, https://m.go.seoul.co.kr/news/2015/06/25/20150625012001, 2026-10-16 접속
