# 가족을 요양시설에 들인 죄책감

별칭: 없음

나이 든 가족을 요양시설에 들인 사람이 그 결정을 두고 죄책감을 느낀다.

묶음: [가까운 사이의 감정과 말](../groups/close-relationships.md)

# 서술

2014년 유선영과 탁영란의 연구[^1]에서 노인을 요양시설에 들인 가족의 우울을 예측한 요인은 죄책감과 입소 결정에 노인이 참여했는지였다.

2023년 7월 AgingCare 게시글[^2]의 글쓴이는 어머니를 요양시설에 들이게 되자 어머니의 자립을 빼앗고 어머니를 배신한다는 후회가 들기 시작했다고 썼다.

2023년 8월 AARP 기사[^3]의 필자는 2019년의 한 연구에서 돌보는 가족의 50% 넘게가 요양원 입소를 두고 적어도 어느 정도 죄책감을 느꼈고 13% 넘게가 몹시 죄책감을 느꼈다고 전했다.
