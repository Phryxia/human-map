# 체면 지키기

별칭: Chemyeon[^2]

남 앞에서 위신을 잃지 않으려는 사람이 손해를 보더라도 사회 규범과 겉으로 보이는 모양새를 지킨다.

묶음: [남의 시선과 창피함](../groups/others-gaze.md)

# 서술

2021년 연구[^1]의 저자들은 사람들이 사회적 교류에서 체면을 잃지 않으려고 사회 규범을 따르는 경향이 있다는 앞선 연구들을 인용했다.

2024년 2월 코리아헤럴드 기사[^2]는 한국의 체면이 격식과 겉모습을 더 앞세우고 한국인이 때로 돈을 잃으면서까지 그 겉모습을 지킨다고 썼다.
