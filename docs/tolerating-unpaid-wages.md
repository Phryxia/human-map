# 임금 체불 참기

별칭: 없음

임금을 제때 다 받지 못한 노동자가 일자리를 잃을까 봐 신고하거나 따지지 않고 참으며 일한다.

# 서술

2003년 영국 하원 토론의 한 발언은 재택 노동자 가운데 임금을 덜 받고도 이의를 제기하려는 사람이 적고 그들은 이의를 제기하면 일자리를 잃을까 두려워한다고 말했다.[^1]

2018년 Farbenblum 과 Berg 의 보고서[^2]는 임금을 덜 받은 참가자 대다수가 그것을 바로잡으려 하지 않은 이유를 분석했다. 2024년 한경비즈니스 기사[^3]는 노동부가 퇴직자와 달리 임금체불 신고가 쉽지 않은 재직 근로자를 위해 익명제보센터를 더 연다고 전했다.

2026년 고용노동부 보도자료[^4]가 옮긴 장관의 말은 일을 하고도 대가를 제대로 받지 못한 상황에서도 회사에 다니려면 참고 견뎌야 하는 일이 많다고 했다.
