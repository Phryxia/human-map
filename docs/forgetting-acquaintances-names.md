# 아는 사람 이름 잊기

별칭: 없음

아는 사람을 만난 사람이 얼굴은 알아보면서 그 사람의 이름이 떠오르지 않아 당혹스러워하거나 짜증스러워한다.

# 서술

1841년 소설[^1]의 인물은 전에 만난 적이 있다면서 상대에게 이름을 잊었다고 말하고 이름을 듣자 이마를 두드리며 그 이름을 되뇐다. 2011년 기사[^2]는 얼굴은 눈에 익은데 어떻게 아는 사람인지 생각나지 않는 경우가 흔하다고 쓴다. 2026년 기사[^4]는 이런 일이 되풀이되면 상대에게 무례하게 보일까 걱정이 되기도 한다고 적는다.

2022년 연구[^3]에서 중년 참가자들이 이름을 떠올리지 못했을 때 가장 강하게 느낀 부정적 감정은 당혹감보다 짜증이었다.
