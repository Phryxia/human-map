# 선물 받을 사람이 기뻐할 모습 떠올리기

별칭: 없음

선물을 마련한 사람이 그것을 건넬 때 받는 사람이 기뻐할 모습을 미리 떠올린다.

묶음: [선물, 대접과 예의](../groups/gifts-and-hospitality.md)

# 서술

1921년 소설[^1]의 사내는 장에서 거울을 산 뒤 아내가 기뻐할 모양을 생각하며 늘 들르던 탁주 집에도 들르지 않고 집으로 돌아온다.

2018년 연구[^2]에서 선물하는 사람은 받는 사람의 반응이 가장 클 선물을 골랐고 선물을 직접 건네지 않으리라 예상할 때는 그 선호가 줄었다. 같은 해 연구 보도[^3]에 따르면 받는 사람의 반응을 볼 수 없다는 것을 알게 된 사람에게서는 놀라게 할 선물을 고르던 쏠림이 사라졌다.

2024년 게시글[^4]의 글쓴이는 선물 받을 사람이 기뻐할 것을 생각하면 깜짝 선물을 준비하는 과정이 신나고 준비한 선물만 봐도 신난다고 적는다.

2025년 에세이[^5]의 필자는 선물을 받을 때는 받는 순간부터 행복하지만 줄 때는 주겠다고 생각한 때부터 행복하다고 적는다.
