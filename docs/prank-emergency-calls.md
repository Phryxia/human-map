# 긴급전화 장난 신고

별칭: 없음

사람이 위급한 일이 없는데 장난으로 119나 999 같은 긴급전화에 걸어 도움을 청한다.

묶음: [시민 참여와 공공의 일](../groups/civic-life.md)

# 서술

2017년 영국 콘월 소방 당국의 공지[^1]에서 한 아이는 소방, 경찰, 구급의 도움을 청하는 전화를 걸고 끊었고 당국은 이를 장난 전화로 판단했다.

2024년 기사[^2]에서 소방청 관계자는 119 장난 전화를 거는 신고자 가운데 어린이가 많아 처벌이 어렵다고 말했다.
