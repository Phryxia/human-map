# 수의 미리 장만하기

별칭: 없음

어떤 사람은 자기나 부모가 장례 때 입을 수의를 살아 있을 때 미리 장만해 둔다.

묶음: [혼자 있음과 상실](../groups/solitude-and-loss.md)

# 서술

1999년 남민이의 논문[^1]은 한국에서 윤년의 윤달에 수의를 장만하는 것을 길하다고 여긴다고 적었다.

2012년 매일신문 기사[^2]는 한 장의업체의 말을 빌려 윤달에는 수의 주문이 평소의 4, 5배 넘게 는다고 전했다.
