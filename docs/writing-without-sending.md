# 써 놓고 내보내지 않기

별칭: 썼다 지웠다, 보내지 않은 메시지, 임시보관함에 남기기

메시지나 게시물을 쓴 사람이 보내거나 올리기 전에 그만두고 지우거나 남겨 둔다.

# 서술

2013년 Sleeper 외는 페이스북 사용자가 특정 청중을 고르는 대신 공유하지 않기로 하는 경우가 있다고 적었다. [F1]

2014년 해커 뉴스의 한 댓글은 문자를 다 쓴 뒤 보낼지 다시 생각하고 지웠다고 말한다. 2017년 다른 댓글은 충동적인 기분에 쓰고 보내지 않은 메시지가 많다고 말한다. [F2][F3]

2025년 매경이코노미 기사에 실린 누리꾼 반응은 카카오톡 답장을 고민하며 썼다 지웠다 하는 과정이 상대에게 보이는 것을 꺼렸다. [F4]

# 조건

2013년 F1 은 청중을 고를 수 없을 때 공유하지 않는 경우를 다룬다. 2017년 F3 은 충동적인 기분에 쓴 메시지를 든다. 2025년 F4 는 상대가 입력 중임을 볼 수 있는 메신저에서 답장을 쓰는 경우다. [F1][F3][F4]
