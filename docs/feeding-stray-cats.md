# 길고양이에게 밥 주기

별칭: 캣맘[^4]

동네의 주인 없는 고양이에게 사람이 사료나 물을 꾸준히 챙겨 준다.

# 서술

2010년 미국 학위논문[^1]의 면담에서 길고양이를 돌보는 사람들은 강한 개인적 효능감과 스스로에게서 나온 동기를 보였다.

2019년 6월 인천시 웹진의 칼럼은 길고양이에게 먹이를 주어야 한다고 여기는 사람들이 고양이도 하나의 생명체라고 주장한다고 적었다.[^2]

2022년 7월 레바논 베이루트 연구[^3]에서 고양이에게 먹이를 주는 사람들은 냄새와 소란을 두고 다른 주민이나 집주인과 자주 맞닥뜨렸다.

2024년 9월 정책브리핑의 글은 길고양이에게 꾸준히 먹이를 주는 사람을 뜻하던 캣맘이라는 말이 한국에서 이웃 사이의 갈등 때문에 주변에 민폐를 끼치는 사람이라는 뜻으로도 쓰인다고 썼다.[^4] 2026년 4월 동네 게시판의 글쓴이는 사료 투기 금지 팻말을 붙이자 옆으로 자리를 옮겨 밥을 준다고 전했다.[^5]
