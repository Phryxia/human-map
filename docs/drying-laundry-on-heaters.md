# 난방기에 빨래 말리기

별칭: 없음

겨울에 집 안에서 빨래를 말리는 사람이 젖은 옷을 히터나 난로 위, 바로 앞에 널어 둔다.

묶음: [건강과 위험](../groups/health-and-safety.md)

# 서술

2006년 댓글[^1]의 글쓴이는 특히 겨울이면 라디에이터와 문, 계단 난간에 빨래를 널어 말린다고 적었다. 2008년 댓글[^2]의 글쓴이는 온수만 켜서 욕실 라디에이터를 데우고 그 위에 무거운 옷을 걸쳐 말린다고 적었다.

2019년 기관 글[^3]은 겨울철에 난방기구로 옷을 말리는 경우가 적지 않다고 적고 빨랫감이 기구 위로 떨어지면 불로 번질 수 있다고 덧붙인다. 2021년 기사[^4]가 전하는 영국 조사에서 성인 3,000명 가운데 10명에 1명은 전기히터로 옷을 말린 적이 있다고 인정했다.

2026년 기사[^5]는 겨울에 실내에서 빨래를 말리는 집의 사람이 옷을 빨리 말리려고 히터 위나 바로 앞에 널고 싶어 한다고 적었다.
