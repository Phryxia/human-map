# 창피한 일을 꾸며 둘러대기

별칭: 없음

창피한 일을 겪은 사람이 그 일을 사실대로 말하지 않고 다른 이야기로 꾸며 남에게 둘러댄다.

# 서술

심훈의 소설에서 머슴에게 얻어맞은 인물은 맞았다고 하기 창피해서 술에 취해 자전거를 타다 봉변을 당했다고 꾸며 댔다. [F1]

2026년 Substack 에세이의 글쓴이는 다친 일이 몹시 창피해서 어쩌다 다쳤는지 사람들에게 사실대로 알릴 수 없다고 적었다. [F2]

# 조건

F1 과 F2 에서 꾸며 대는 대상은 몸을 다친 까닭이다. [F1][F2]
