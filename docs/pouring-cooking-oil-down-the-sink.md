# 요리 기름 싱크대에 붓기

별칭: 없음

요리하고 남은 기름을 버리는 사람이 기름을 쓰레기통 대신 부엌 싱크대에 부어 흘려보낸다.

묶음: [시민 참여와 공공의 일](../groups/civic-life.md)

# 서술

발행일이 적히지 않은 아일랜드 상하수도 기관 공지[^1]에 따르면 아일랜드 전국 조사에서 기름과 지방을 싱크대에 붓는 가구는 2018년 44%에서 2024년 36%로 줄었다.

2022년 10월 기사[^2]가 전한 영국 Unblocktober 조사에서 응답자의 65%는 기름과 지방을 싱크대에 붓는다고 인정했다.
