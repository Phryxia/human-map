# 사칭 문자 링크 누르기

별칭: 없음

지인, 택배 회사, 기관을 사칭한 문자나 이메일을 받은 사람이 그 안의 링크를 누른다.

묶음: [돈과 소비](../groups/money.md)

# 서술

2013년 9월 머니투데이 기사[^1]는 지인의 이름으로 친밀하게 오는 문자 메시지라 무심결에 누르기 쉽다고 적는다.

2013년 10월 아주경제 기사[^2]에 따르면 이런 문자는 돌잔치와 청첩장, 무료 쿠폰과 상품권, 법원 소환과 경찰 출두, 고객센터를 사칭한 문구를 썼다.

2019년 연구[^3]에서 모의 피싱 이메일을 받은 이용자의 43%가 그 이메일에 넘어갔고 나이 든 여성이 가장 잘 넘어갔다.

2023년 미국 연방거래위원회 소비자 경보[^4]는 가짜 배송 알림을 보낸 쪽이 받는 사람에게 바라는 일을 적는다. 받는 사람이 생각하지 않고 링크를 눌러 개인정보나 금융정보를 넣는 일이다.
