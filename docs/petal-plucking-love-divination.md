# 꽃잎 뜯으며 사랑 점치기

별칭: 없음

좋아하는 사람이 있는 사람이 꽃잎을 하나씩 뜯으며 사랑한다와 사랑하지 않는다를 번갈아 말하고 마지막 꽃잎의 말을 답으로 삼는다.

# 서술

1808년 괴테의 희곡에서 처녀는 사랑한다, 안 한다를 번갈아 말하다가 마지막 잎을 뜯으며 그가 나를 사랑한다고 기뻐 외친다.[^1]

2013년 블로그 글의 필자는 그 꽃을 사랑한다, 사랑하지 않는다 꽃이라 불렀다고 적었다. 필자와 친구들은 풀밭을 뒤져 그 꽃을 찾았고 누가 쓸 차례인지를 두고 다투었다.[^2]
