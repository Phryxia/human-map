# 머리가 마음에 들지 않아도 미용사에게 괜찮다고 답하기

별칭: 없음

미용실에서 자른 머리가 마음에 들지 않는 손님이 미용사에게는 괜찮다거나 마음에 든다고 답한다.

묶음: [가까운 사이의 감정과 말](../groups/close-relationships.md)

# 서술

2018년 인사이트 기사[^1]는 보여 준 연예인 머리와 결과가 크게 달라도 미용사에게는 완벽하다고 칭찬하고 집에 와서 소심한 자신을 자책하는 모습을 적었다.

2024년 영국 Stylist 기사[^2]는 마음에 들지 않는 머리를 하고도 고개를 끄덕이며 고맙다고 하고 값을 치른 뒤 집에 가서 혼자 우는 모습을 영국 사람다운 일로 들었다. 2025년 디시인사이드 게시글[^3]의 글쓴이는 얼굴 길이까지만 잘라 달라고 했는데 결과가 달랐고 미용사가 길이를 묻자 괜찮다고 답해 버렸다.
