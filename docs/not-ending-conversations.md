# 원할 때 대화 끝내지 못하기

별칭: 없음

대화를 끝내고 싶은 사람이 먼저 끝내자고 말하지 못하고 대화를 이어 간다.

# 서술

2021년 연구[^1]에서 두 사람이 모두 원할 때 끝난 대화는 거의 없었고 한 사람이라도 원할 때 끝난 대화도 드물었다.

같은 해 댓글[^2]의 글쓴이는 그만할 때라는 것을 자기도 상대도 안다고 느끼면서 둘 다 대화를 계속한다고 적었다. 다른 댓글[^3]의 글쓴이는 상대가 코로나19 통계 이야기를 꺼내면 적어도 10분은 붙잡힌다고 썼다. 말을 끊으면 상대가 그날 내내 화를 낼 것이기 때문이다.[^3]
