# 알아들은 척하기

별칭: 아는 척 고개 끄덕이기, 이해한 척, feigned understanding

사람이 남의 말이나 설명을 알아듣지 못했는데 알아들은 듯이 고개를 끄덕이거나 맞장구친다.

# 서술

1869년 소설[^1]에서 페탸는 데니소프가 말을 꺼내자마자 다 알아들은 듯 고개를 끄덕이며 그렇다고 대답했고 실제로는 하나도 알아듣지 못했다. 1941년 소설[^2]의 화자는 말이 통하지 않는 두 사람이 서로 알아듣는 체 고개를 끄덕이고 웃는 모습을 적었다.

2018년 논문[^3]의 저자는 환자가 체면을 지키고 유능해 보이며 자기 진료를 스스로 맡고 있음을 보이려고 의료 권고를 이해했다고 거짓으로 말하기 쉽다고 썼다.

2026년 글[^5]의 필자는 회의실에서 사람들이 흐름을 못 따라가는 사람처럼 보일까 봐 두려워 고개를 끄덕이며 무언가를 적는다고 썼다.

# 조건

1941년 소설[^2]의 두 사람은 서로 말이 통하지 않는 사이였다. 2024년 에세이[^4]의 필자는 상대에게 되물었는데도 알아듣지 못하자 한 번 더 물었고 그래도 알아듣지 못하자 짐작하는 수밖에 없다고 느꼈다.
