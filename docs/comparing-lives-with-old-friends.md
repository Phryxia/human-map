# 옛 친구를 다시 만나 처지 견주기

별칭: 없음

오랜만에 옛 친구나 동창을 만난 사람이 상대의 직업, 지위, 형편을 듣고 자기 처지와 견주며 기분이나 태도가 바뀐다.

묶음: [가까운 사이의 감정과 말](../groups/close-relationships.md)

# 서술

1883년 단편[^1]에서 기차역에서 어린 시절 친구를 반갑게 만난 마른 사내는 친구가 자기보다 훨씬 높은 관등에 올랐다는 말을 듣자 갑자기 창백해지고 굳었다가 곧 얼굴 가득 웃음을 지었다.

2026년 기사[^2]의 필자는 동창회에서 오랜만에 만난 친구의 직업, 경제 형편, 결혼 여부, 자녀 이야기를 들으며 자기 삶을 견줄 수 있다고 적었다.
