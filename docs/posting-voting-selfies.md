# 투표 인증샷 올리기

별칭: 투표 인증샷[^2]

투표를 마친 사람이 투표했다는 것을 보이는 사진을 찍어 소셜 미디어에 올린다.

묶음: [시민 참여와 공공의 일](../groups/civic-life.md)

# 서술

2010년 6월 기사[^1]는 지방선거 날 연예인들이 투표장에 간 사진을 트위터에 올리고 투표 참여를 권하자 따라 올리는 누리꾼이 늘었다고 적었다.

2013년 연구[^2]의 저자들은 SNS 투표 인증샷을 시민이 스스로 나선 정치참여 활동으로 보고 연구 대상으로 삼았다.

2017년 5월 정책브리핑 기사[^3]는 대통령 선거 날 투표를 마친 사람들이 저마다 다른 포즈로 인증샷을 찍었다고 적었다. 같은 달 정책기자단 기사[^4]의 필자는 20대 초반 청년들이 인증샷을 개인 SNS에 올리며 투표 참여를 권한 까닭을 물었다.

2025년 5월 기사[^5]는 손등 대신 캐릭터가 그려진 투표 인증 용지에 도장을 찍어 SNS에 올리는 일이 MZ세대를 중심으로 퍼진다고 적었다.
