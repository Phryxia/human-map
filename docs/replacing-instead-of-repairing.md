# 고치지 않고 새로 사기

별칭: 없음

가전 같은 물건이 고장 난 사람이 고칠 수 있는데도 수리비가 비싸거나 수리를 맡기기 번거로워 고치지 않고 새것을 산다.

# 서술

2016년 가전 애호가 포럼 댓글의 글쓴이는 새 제품을 사는 값에 견줘 수리비가 너무 높아져 사람들이 가전을 고치지 않는다고 썼다.[^1] 2019년 Circular Online 기사[^2]가 전한 조사에서 고장 난 가전을 버리고 새로 사겠다고 답한 사람들은 주된 이유로 편함을 들었다.

2023년 클리앙 댓글의 글쓴이는 오래된 냉장고의 수리비가 40만 원 나오자 그냥 새로 샀고 잘한 결정이라고 여겼다.[^3] 2024년 미주중앙일보 기사[^4]에서 냉장고 수리 견적을 받은 사람은 수리기사가 몇백 달러만 더 주면 새것을 살 수 있다고 하자 수리를 포기하고 새것을 샀다. 2025년 NIM 보도자료에서 소비자 약 60%는 수리비가 적당해야 고치겠다고 답했다.[^5]
