# 잠에서 깨어 기지개 켜기

별칭: Pandiculating[^2], Pandiculation[^3]

잠에서 깬 사람이 하품을 하며 몸을 쭉 펴 기지개를 켠다.

묶음: [시간과 하루 습관](../groups/daily-time.md)

# 서술

1885년 소설[^1]에서 모닥불 곁에 담요를 덮고 자던 사람은 날이 밝을 무렵 하품하고 기지개를 켠 뒤 담요를 걷었다.

2020년 기사[^2]의 필자는 사람 대부분이 잠에서 깨면 맨 먼저 기지개를 켜고 하품하며 이 동작을 pandiculating 이라 부른다고 적었다.

2021년 Healthline 글[^3]은 의식하지 않고 하는 기지개를 pandiculation 이라 부르고 포유류 대부분에서 보이는 행동이라고 적었다.
