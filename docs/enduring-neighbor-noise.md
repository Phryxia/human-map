# 층간소음 참기

별칭: 없음

공동주택에 사는 사람이 위층이나 이웃의 소음에 시달리면서 항의하거나 신고하지 않고 참는다.

# 서술

2013년 국민권익위원회의 온라인 설문에서 층간소음이 났을 때 참는다고 답한 응답자는 46%였다.[^1]

2022년 정책브리핑의 기고 칼럼은 층간소음 피해자가 6개월에서 2~3년까지 참다가 신고하는 경우가 많다고 적는다. 같은 글은 오래 소음에 시달리면 불안, 예민함, 스트레스가 생긴다고 쓴다.[^2]

# 조건

2013년 자료[^1]는 층간소음이 발생한 경우에 어떻게 대응하는지를 물은 설문의 응답이다.

2022년 글[^2]은 참는 기간이 끝난 뒤 신고로 넘어가는 경우를 적는다.
