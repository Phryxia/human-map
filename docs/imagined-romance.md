# 상상 속 연애

별칭: imaginationship[^2]

사람이 실제로 사귀지 않는 상대와 연애하는 장면을 혼자 머릿속으로 그리거나 소리 내어 해 본다.

묶음: [가까운 사이의 감정과 말](../groups/close-relationships.md)

# 서술

1925년 소설[^1]의 기숙사 사감은 한밤중에 학생들에게 온 연애편지를 침대에 펼쳐 놓고 혼자 두 팔을 벌린다. 그는 입을 내민 채 남자의 목소리를 흉내 내어 편지의 말을 중얼거린다.

2023년 기사[^2]는 실제로 사귀지 않는 사람과 사귀는 공상을 imaginationship 이라 부른다고 전했다.
