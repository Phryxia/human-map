# 운전 그만두기 미루기

별칭: 운전면허 반납 망설임, 운전대 못 놓기, Driving cessation reluctance

고령 운전자가 운전에 부담을 느끼면서도 운전을 그만두거나 운전면허를 반납하는 일을 미룬다.

# 서술

2006년 Rudman 외가 면담한 캐나다의 고령 운전자 가운데 많은 이들은 사고나 사고가 날 뻔한 일만을 운전을 그만둘 계기로 꼽았고 운전 중단을 미리 계획한 사람은 적었다. [F1]

2016년 Pachana 외의 조사 참가자들은 운전 중단을 스스로 더 늙었다고 느끼게 하는 큰 사건으로 보고했다. 2024년 Savoie 외는 운전 중단을 독립, 자유, 자율의 상실과 이어진 어려운 전환으로 적었다. [F2][F5]

2019년 F3 의 칼럼에 나오는 80세 넘은 운전자는 안전이 늘 마음에 걸리지만 다른 방도가 없다며 해가 진 뒤의 운전만 줄였다. 2023년 F4 의 기사는 농어촌 고령자의 면허 반납률이 낮은 까닭으로 차 없이는 생활하기 어렵다는 점을 든다. [F3][F4]

# 조건

2006년 F1 에서는 사고나 사고가 날 뻔한 일이 운전을 그만두는 계기였다. [F1]

2023년 F4 는 농어촌 지역에서 면허 반납률이 특히 낮다고 적는다. 2019년 F3 의 운전자도 혼자 사는 농촌 거주자였다. [F3][F4]
