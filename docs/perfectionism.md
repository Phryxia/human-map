# 완벽주의

별칭: perfectionism[^2]

어떤 사람은 자기 일이 흠 없이 완벽해야 한다고 여겨 자신과 남에게 아주 높은 기준을 둔다.

묶음: [성향과 기질](../groups/traits.md)

# 서술

1831년 발자크의 소설[^1]에서 늙은 화가는 그림이 끝났다고 잠시 생각했지만 몇몇 세부가 틀렸다고 확신하며 의문을 풀 때까지 쉴 수 없다고 말했다.

2010년 댓글[^2]의 글쓴이는 완벽주의 때문에 글을 쓰기 시작조차 못 한다고 적었다. 쓴 글이 대단하지 않으면 그것을 내놓을 자격이 없다고 느낀다고 했다.[^2]

2019년 메타분석[^3]은 1989년에서 2016년 사이 다차원 완벽주의 척도에 답한 미국, 캐나다, 영국 대학생 41,641명의 164개 표본을 모았다. 자신에게 높은 기준을 두는 완벽주의, 남이 자신에게 높은 기준을 둔다고 느끼는 완벽주의, 남에게 높은 기준을 두는 완벽주의의 점수는 척도에 답한 해가 늦은 표본일수록 모두 선형으로 높았다. 성별과 나라 사이의 차이를 통제해도 이 경향은 남았고 증가 폭은 남이 자신에게 높은 기준을 둔다고 느끼는 완벽주의가 가장 컸다.[^3]

2023년 기사[^4]는 완벽주의 성향을 가진 사람이 모든 일을 잘 해내야 한다고 생각해 아예 시작하지 않거나 이런저런 핑계로 시작을 미룬다고 썼다.
