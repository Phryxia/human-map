# 완벽주의

별칭: 완벽 추구, perfectionism

어떤 사람은 자기 일이 흠 없이 완벽해야 한다고 여겨 자신과 남에게 아주 높은 기준을 둔다.

# 서술

2019년 메타분석[^1]은 1989년에서 2016년 사이 다차원 완벽주의 척도에 답한 미국, 캐나다, 영국 대학생 41,641명의 164개 표본을 모았다. 자신에게 높은 기준을 두는 완벽주의, 남이 자신에게 높은 기준을 둔다고 느끼는 완벽주의, 남에게 높은 기준을 두는 완벽주의의 점수가 모두 직선으로 올랐다.[^1]

2023년 기사[^2]는 완벽주의 성향을 가진 사람이 모든 일을 잘 해내야 한다고 생각해 아예 시작하지 않거나 이런저런 핑계로 시작을 미룬다고 썼다.

# 조건

2019년 메타분석[^1]에서 1989년에서 2016년 사이 나중 시기에 조사된 대학생일수록 세 가지 완벽주의 점수가 높았다.
