# 자꾸 도움을 청하는 친척 성가셔하기

별칭: 없음

친척이 되풀이해 돈이나 양식을 청하면 청을 받는 사람이 그를 성가셔하고 청을 끊는다.

묶음: [돈과 소비](../groups/money.md)

# 서술

1938년 소설[^1]의 화자는 자기를 길러 준 아주머니가 이따금 찾아와 양식이 없다고 하소연하면 성가시다고 털어놓는다. 화자는 그때마다 들어주면 제 일을 못 하니 대개 잘라 거절한다고 말한다.

2013년 게시글[^2]의 글쓴이는 가까운 친척이 늘 돈을 달라고 졸라 둘의 관계가 크게 틀어졌다고 적었다.

2015년 칼럼[^3]의 필자는 병, 학비, 끼니, 손님 대접을 이유로 끝없이 돈을 청하는 친척들에게 이따금 이용당한다고 느낀다고 썼다.

2026년 연구[^4]에서 남아프리카공화국의 여자 대학 신입생 일부는 가족이 돈을 청할 때 그것을 당연하게 여기고 자기를 조종하려 든다고 느껴 짜증을 드러냈다.
