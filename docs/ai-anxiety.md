# 인공지능을 두고 느끼는 불안

별칭: 없음

사람이 인공지능과 그 빠른 발전을 떠올리며 무섭고 걱정스럽다고 느낀다.

묶음: [걱정과 기분](../groups/worry-and-mood.md)

# 서술

2024년 사우디아라비아 성인 설문 연구[^1]에서 인공지능의 빠른 발전과 관련한 실존 불안이 높은 비율로 나타났다. 2024년 영국 정부 조사 보고서[^2]에서 인공지능을 떠올릴 때 먼저 나온 낱말은 'scary' 와 'worried' 같은 부정적인 말이었고 보고서는 대중의 불안이 여전히 높다고 적었다.
