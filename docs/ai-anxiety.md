# 인공지능을 두고 느끼는 불안

별칭: 없음

사람이 인공지능과 그 빠른 발전을 떠올리며 무섭고 걱정스럽다고 느낀다.

묶음: [걱정과 기분](../groups/worry-and-mood.md)

# 서술

1982년 시사 잡지 에세이[^1]는 기계가 인공지능을 갖게 되면 따라잡힐 것이라는 사람의 두려움이 더 급하고 복잡해진다고 적었다.

2011년 게시판 댓글[^2]의 글쓴이는 인공지능의 앞날을 무섭다고 했고 기계에 모든 힘을 넘기고도 마음대로 다룰 수 있다고 믿는 태도를 걱정했다.

2024년 사우디아라비아 성인 설문 연구[^3]에서 인공지능의 빠른 발전과 관련한 실존 불안이 높은 비율로 나타났다. 2024년 영국 정부 조사 보고서[^4]에서 인공지능을 떠올릴 때 먼저 나온 낱말은 'scary' 와 'worried' 같은 부정적인 말이었고 보고서는 대중의 불안이 여전히 높다고 적었다.

2026년 9월 블로그 글[^5]의 글쓴이는 몇 년 전 자기를 포함해 많은 사람이 인공지능 앞에서 실존적 위기의 순간을 겪고 지나왔다고 썼다.
