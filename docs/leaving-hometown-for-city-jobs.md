# 일자리와 학교를 찾아 대도시로 떠나기

별칭: 없음

작은 도시나 지방에서 자란 젊은 사람이 대학이나 일자리를 찾아 고향을 떠나 수도나 대도시로 옮겨 산다.

묶음: [사는 곳과 옮겨 살기](../groups/where-to-live.md)

# 서술

2004년 게시판 댓글[^1]의 글쓴이는 더 좋은 일자리를 얻을 기회가 있어서 대도시로 옮겼고 그곳이 자기 경력에 훨씬 낫다고 적었다.

2010년 미국 농무부 경제연구소 글[^2]은 농촌의 젊은이 다수가 고등학교를 마친 뒤 학업을 잇거나 군에 들어가려고 떠난다고 적었다.

2021년 한국개발연구원 보고서[^3]에서 한국 청년은 진학 단계에서는 서울의 4년제 대학으로, 취업 단계에서는 수도권 전반으로 많이 옮겨 갔다.

2025년 기사[^4]가 전한 통계청 분석에서 혼자 옮긴 청년이 수도권으로 들어온 사유는 직업이었다.
