# 여행 기념품 사 오기

별칭: 오미야게[^3], Omiyage[^5]

여행이나 출장에서 돌아오는 사람이 직장 동료나 가족에게 줄 기념품을 사 온다.

묶음: [선물, 대접과 예의](../groups/gifts-and-hospitality.md)

# 서술

1906년 나쓰메 소세키의 소설에서 먼 곳으로 떠나게 된 주인공은 늙은 하녀 기요에게 무엇을 선물로 사다 줄지 물었고 기요는 에치고의 조릿대 엿이 먹고 싶다고 했다.[^1]

2014년 기사[^2]가 전한 설문에서 응답자 22.2%는 남들도 휴가 뒤 선물을 사 오니까, 20.2%는 휴가 동안 자기 업무를 대신 해 준 것이 미안해서 선물을 산다고 답했다.

2024년 기사[^3]는 일본에서는 출장이든 어디든 다녀오면 사 간다는 답이 정해져 있다고 적는다.

2025년 연구[^4]의 참가자는 여행 뒤 오미야게를 주는 일이 너무 당연해서 더는 선물처럼 느껴지지 않는다고 말했다. 2026년 기사[^5]의 필자는 많은 직장인에게 오미야게 구매가 자발적인 배려라기보다 사회적 기대가 되었다고 적는다.
