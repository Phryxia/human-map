# 이별 앞에서 눈물 참기

별칭: 없음

연인과 헤어지는 사람이 슬픔을 드러내지 않으려고 눈물을 참고 아무렇지 않은 척한다.

# 서술

1925년 김소월의 시에서 화자는 자기를 보기 싫어 떠나는 사람 앞에서 죽어도 눈물을 흘리지 않겠다고 말한다.[^1]

2018년 인사이트 기사는 헤어지는 사람이 눈물을 참으려 애쓰고 억지로 즐거운 척을 하기도 한다고 적는다.[^2]

2020년 게시글[^3]의 글쓴이는 헤어지자고 한 여자친구를 만난 자리에서 그의 눈물 맺힌 눈을 보고 울음이 터질 뻔했지만 달을 쳐다보며 참았다.

2026년 9월 블로그 글의 필자는 이별을 말하러 간 자리에서 상대에게 덕분에 행복했다고 말하며 억지로 울지 않고 끝까지 이야기했다.[^4]
